# AML.M0000 — Limit Public Release of Information

<a id="amlm0000"></a>

**ATLAS:** [AML.M0000](https://atlas.mitre.org/mitigations/AML.M0000) · addresses 7 techniques

Limit the public release of technical information about the AI stack used in an organization's products or services. Technical knowledge of how AI is used can be leveraged by adversaries to perform targeting and tailor attacks to the target system.
