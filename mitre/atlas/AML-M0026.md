# AML.M0026 — Privileged AI Agent Permissions Configuration

<a id="amlm0026"></a>

**ATLAS:** [AML.M0026](https://atlas.mitre.org/mitigations/AML.M0026) · addresses **7** techniques

AI agents may be granted elevated privileges above that of a normal user to enable desired workflows. When deploying a privileged AI agent, or an agent that interacts with multiple users, it is important to implement robust policies and controls on permissions of the privileged agent.
