# AML.T0008.005 — AI Service Proxies

<a id="amlt0008005"></a>

**ATLAS tactics:** resource-development
**Sub-technique of:** [AML.T0008 — Acquire Infrastructure](/mitre/atlas/AML-T0008.md)
**ATLAS:** [AML.T0008.005](https://atlas.mitre.org/techniques/AML.T0008.005)

Adversaries may utilize commercial proxy services that resell access to AI services such as frontier model APIs. This infrastructure can be used to conduct large-scale campaigns to perform Exfiltration via AI Inference API via distillation. Adversaries may also use this infrastructure to Generate Malicious Commands for offensive cyber operations, or to generate content for Spearphishing via Social Engineering LLM.
