# AML.T0011.000: Unsafe AI Artifacts

<a id="amlt0011000"></a>

ATLAS tactics: execution  
Sub-technique of: [AML.T0011: User Execution](/mitre/atlas/AML-T0011.md)  
ATLAS: [AML.T0011.000](https://atlas.mitre.org/techniques/AML.T0011.000)  

Adversaries may develop new AI artifacts or manipulate existing AI artifacts that have a deleterious effect when loaded, executed, interpreted, or used for inference by a victim. The unsafe artifacts may continue to work as expected from the victim's perspective. Unsafe AI artifacts may include serialized models, model packages, and bundled components such as prompt or chat templates, tokenizer metadata, configuration, pre-processing logic, post-processing logic, or other executable or behavior-shaping metadata. An unsafe artifact may exploit deserialization or another software vulnerability to execute code on the host. However, exploitation of a software vulnerability is not required. An artifact may instead use functionality intentionally supported by an AI runtime to alter model context, model outputs, safety behavior, or agent actions. Adversaries may introduce unsafe artifacts through a Supply Chain Compromise. Execution may occur when a user loads the artifact, starts an inference runtime, submits an inference request, or otherwise causes the artifact's bundled logic to be processed.

## Mitigations (5)

- [AML.M0011: Restrict Library Loading](/mitre/atlas/AML-M0011.md): Prevent abuse of library loading mechanisms in the operating system and software to load untrusted code by configuring appropriate library loading mechanisms and investigating potential vulnerable software.
- [AML.M0013: Code Signing](/mitre/atlas/AML-M0013.md): Enforce binary and application integrity with digital signature verification to prevent untrusted code from executing.
- [AML.M0014: Verify AI Artifacts](/mitre/atlas/AML-M0014.md): Verify the integrity and authenticity of AI artifacts before importing, loading, or deploying them.
- [AML.M0016: Vulnerability Scanning](/mitre/atlas/AML-M0016.md): Vulnerability scanning is used to find potentially exploitable software vulnerabilities to remediate them.
- [AML.M0018: User Training](/mitre/atlas/AML-M0018.md): Educate AI model developers to on AI supply chain risks and potentially malicious AI artifacts.
