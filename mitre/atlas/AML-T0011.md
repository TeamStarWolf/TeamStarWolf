# AML.T0011: User Execution

<a id="amlt0011"></a>

ATLAS tactics: execution  
ATLAS: [AML.T0011](https://atlas.mitre.org/techniques/AML.T0011)  

An adversary may rely upon specific actions by a user in order to gain execution. Users may inadvertently execute unsafe code introduced via AI Supply Chain Compromise. Users may be subjected to social engineering to get them to execute malicious code by, for example, opening a malicious document file or link.

## Mitigations (5)

- [AML.M0011: Restrict Library Loading](/mitre/atlas/AML-M0011.md): Prevent abuse of library loading mechanisms in the operating system and software to load untrusted code by configuring appropriate library loading mechanisms and investigating potential vulnerable software.
- [AML.M0014: Verify AI Artifacts](/mitre/atlas/AML-M0014.md): Verify the cryptographic checksum of all AI artifacts to verify that the file was not modified by an attacker.
- [AML.M0016: Vulnerability Scanning](/mitre/atlas/AML-M0016.md): Vulnerability scanning is used to find potentially exploitable software vulnerabilities to remediate them.
- [AML.M0018: User Training](/mitre/atlas/AML-M0018.md): Educate AI model developers to on AI supply chain risks and potentially malicious AI artifacts.
- [AML.M0023: AI Bill of Materials](/mitre/atlas/AML-M0023.md): An AI Bill of Materials (AI BOM) contains a full listing of artifacts and resources that were used in building the AI.
