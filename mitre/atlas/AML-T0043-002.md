# AML.T0043.002 — Black-Box Transfer

<a id="amlt0043002"></a>

**ATLAS tactics:** ai-attack-adaptation
**Sub-technique of:** [AML.T0043 — Craft Adversarial Data](/mitre/atlas/AML-T0043.md)
**ATLAS:** [AML.T0043.002](https://atlas.mitre.org/techniques/AML.T0043.002)

In Black-Box Transfer attacks, the adversary uses one or more proxy models (trained via Create Proxy AI Model or Train Proxy via Replication) they have full access to and are representative of the target model. The adversary uses White-Box Optimization on the proxy models to generate adversarial examples. If the set of proxy models are close enough to the target model, the adversarial example should generalize from one to another.
