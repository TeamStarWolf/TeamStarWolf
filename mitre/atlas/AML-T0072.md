# AML.T0072 — Cyber Communication Channel

<a id="amlt0072"></a>

**ATLAS tactics:** command-and-control
**ATLAS:** [AML.T0072](https://atlas.mitre.org/techniques/AML.T0072)

Adversaries use network services, repositories, relays, or other communication channels for command and control, either synchronously or asynchronously.
