# AML.T0091.000: Application Access Token

<a id="amlt0091000"></a>

ATLAS tactics: lateral-movement  
Sub-technique of: [AML.T0091: Use Alternate Authentication Material](/mitre/atlas/AML-T0091.md)  
ATLAS: [AML.T0091.000](https://atlas.mitre.org/techniques/AML.T0091.000)  

Adversaries may use stolen application access tokens to bypass the typical authentication process and access restricted accounts, information, or services on remote systems. These tokens are typically stolen from users or services and used in lieu of login credentials. Application access tokens are used to make authorized API requests on behalf of a user or service and are commonly used to access resources in cloud, container-based applications, software-as-a-service (SaaS), and AI-as-a-service(AIaaS). They are commonly used for AI services such as chatbots, LLMs, and predictive inference APIs.

## Mitigations (2)

- [AML.M0019: Control Access to AI Models and Data in Production](/mitre/atlas/AML-M0019.md): Require users to verify their identities before accessing a production model.
- [AML.M0043: AI Agent External Resource Lifecycle Management](/mitre/atlas/AML-M0043.md): Organizations should control external resources created or acquired by AI agents during execution by treating those resources as attributable, lifecycle-managed assets.
