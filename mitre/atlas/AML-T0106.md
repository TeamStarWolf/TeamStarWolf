# AML.T0106: Exploitation for Credential Access

<a id="amlt0106"></a>

ATLAS tactics: credential-access  
ATLAS: [AML.T0106](https://atlas.mitre.org/techniques/AML.T0106)  

Adversaries may exploit software vulnerabilities in an attempt to collect credentials. Exploitation of a software vulnerability occurs when an adversary takes advantage of a programming error in a program, service, or within the operating system software or kernel itself to execute adversary-controlled code.

## Mitigations (2)

- [AML.M0016: Vulnerability Scanning](/mitre/atlas/AML-M0016.md): Vulnerability scanning is used to find potentially exploitable software vulnerabilities to remediate them.
- [AML.M0042: Threat Intelligence Program](/mitre/atlas/AML-M0042.md): A Threat Intelligence Program enables organizations to proactively collect, analyze, and share information on threats to AI and cyber systems by leveraging internal observations and external reporting.
