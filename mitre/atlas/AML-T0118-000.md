# AML.T0118.000: Communication via Shared Artifacts

<a id="amlt0118000"></a>

ATLAS tactics: ai-attack-adaptation  
Sub-technique of: [AML.T0118: Autonomous AI Agent Communication](/mitre/atlas/AML-T0118.md)  
ATLAS: [AML.T0118.000](https://atlas.mitre.org/techniques/AML.T0118.000)  

Autonomous AI agents may communicate by creating or modifying artifacts in a shared resource that persists outside their individual execution contexts. Shared artifacts may convey discoveries, objectives, tasking, credentials, capabilities, operating rules, progress, scripts, targeting information, instructions, or results. Shared artifacts allow communication to occur asynchronously and across independent runs. An agent may publish information for later retrieval, adopt information left by another agent, or update the shared state with new findings, progress, or results. Participating agents do not need to share a model, orchestrator, context window, or overlapping execution period. The shared resource may be established for the operation or may be an existing repository, file store, message board, database, object store, queue, or similar service repurposed by the agents.

## Mitigations (6)

- [AML.M0026: Manage AI Agent Service Access](/mitre/atlas/AML-M0026.md): Limit service AI agents--agents using independently assigned service or workload permissions--to explicitly authorized workflows.
- [AML.M0027: Manage User-Delegated AI Agent Access](/mitre/atlas/AML-M0027.md): Limit user-delegated AI agents to explicitly authorized tasks and permissions.
- [AML.M0028: Enforce Access Controls for AI Agent Tools](/mitre/atlas/AML-M0028.md): Limit AI agent tool access to each caller's authorized, task-required operations and resources, including when tools are shared across agents, users, or tenants.
- [AML.M0032: Segmentation of AI Agent Components](/mitre/atlas/AML-M0032.md): Define enforceable security boundaries around AI agent tools, data sources, identities, and execution environments.
- [AML.M0038: AI Agent Scope Drift Detection](/mitre/atlas/AML-M0038.md): Continuously evaluate whether an AI Agent's planned actions remain consistent with its current authorized objective throughout execution.
- [AML.M0043: AI Agent External Resource Lifecycle Management](/mitre/atlas/AML-M0043.md): Organizations should control external resources created or acquired by AI agents during execution by treating those resources as attributable, lifecycle-managed assets.
