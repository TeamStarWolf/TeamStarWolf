# AML.T0118.001: Direct Agent Communication

<a id="amlt0118001"></a>

ATLAS tactics: ai-attack-adaptation  
Sub-technique of: [AML.T0118: Autonomous AI Agent Communication](/mitre/atlas/AML-T0118.md)  
ATLAS: [AML.T0118.001](https://atlas.mitre.org/techniques/AML.T0118.001)  

Autonomous AI agents may communicate directly through agent-to-agent, sub-agent, or orchestrator interfaces. An agent may provide another agent with operational context, discoveries, objectives, tasking, capabilities, credentials, or constraints, and may receive status, findings, or completed work in response. Direct communication may include delegation when the sending agent formulates or selects an objective or subtask and the recipient retains meaningful discretion over how to perform it. Direct exchanges may also report discoveries, request independent validation, synchronize activity, transfer capabilities, or return findings without delegating a new task.

## Mitigations (5)

- [AML.M0026: Manage AI Agent Service Access](/mitre/atlas/AML-M0026.md): Limit service AI agents--agents using independently assigned service or workload permissions--to explicitly authorized workflows.
- [AML.M0027: Manage User-Delegated AI Agent Access](/mitre/atlas/AML-M0027.md): Limit user-delegated AI agents to explicitly authorized tasks and permissions.
- [AML.M0028: Enforce Access Controls for AI Agent Tools](/mitre/atlas/AML-M0028.md): Limit AI agent tool access to each caller's authorized, task-required operations and resources, including when tools are shared across agents, users, or tenants.
- [AML.M0032: Segmentation of AI Agent Components](/mitre/atlas/AML-M0032.md): Define enforceable security boundaries around AI agent tools, data sources, identities, and execution environments.
- [AML.M0038: AI Agent Scope Drift Detection](/mitre/atlas/AML-M0038.md): Continuously evaluate whether an AI Agent's planned actions remain consistent with its current authorized objective throughout execution.
