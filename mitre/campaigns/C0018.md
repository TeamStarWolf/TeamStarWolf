# C0018 — C0018

<a id="c0018"></a>

**ATT&CK:** [C0018](https://attack.mitre.org/campaigns/C0018)  
**Active:** 2022-02-01 – 2022-03-01  

[C0018](https://attack.mitre.org/campaigns/C0018) was a month-long ransomware intrusion that successfully deployed [AvosLocker](https://attack.mitre.org/software/S1053) onto a compromised network. The unidentified actors gained initial access to the victim network through an exposed server and used a variety of open-source tools prior to executing [AvosLocker](https://attack.mitre.org/software/S1053).
