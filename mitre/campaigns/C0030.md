# C0030 — Triton Safety Instrumented System Attack

<a id="c0030"></a>

**ATT&CK:** [C0030](https://attack.mitre.org/campaigns/C0030)  
**Active:** 2017-06-01 – 2017-08-01  

[Triton Safety Instrumented System Attack](https://attack.mitre.org/campaigns/C0030) was a campaign employed by [TEMP.Veles](https://attack.mitre.org/groups/G0088) which leveraged the [Triton](https://attack.mitre.org/software/S1009) malware framework against a petrochemical organization. The malware and techniques used within this campaign targeted specific Triconex [Safety Controller](https://attack.mitre.org/assets/A0010)s within the environment. The incident was eventually discovered due to a safety trip that occurred as a result of an issue in the malware.
