# CAPEC-272 — Protocol Manipulation

<a id="capec-272"></a>

**Abstraction:** Meta  
**Typical severity:** Medium  
**Status:** Draft  

An adversary subverts a communications protocol to perform an attack. This type of attack can allow an adversary to impersonate others, discover sensitive information, control the outcome of a session, or perform other attacks.
