# CAPEC-310 — Scanning for Vulnerable Software

<a id="capec-310"></a>

**Abstraction:** Detailed  
**Typical severity:** Low  
**Status:** Draft  

An attacker engages in scanning activity to find vulnerable software versions or types, such as operating system versions or network services. Vulnerable or exploitable network configurations, such as improperly firewalled systems, or misconfigured systems in the DMZ or external network, provide windows of opportunity for an attacker.
