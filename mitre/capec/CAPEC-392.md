# CAPEC-392 — Lock Bumping

<a id="capec-392"></a>

**Abstraction:** Detailed  
**Typical severity:**   
**Likelihood:** 

An attacker uses a bump key to force a lock on a building or facility and gain entry. Lock Bumping is the use of a special type of key that can be tapped or bumped to cause the pins within the lock to fall into temporary alignment, allowing the lock to be opened.
