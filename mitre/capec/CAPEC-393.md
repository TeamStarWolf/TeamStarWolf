# CAPEC-393 — Lock Picking

<a id="capec-393"></a>

**Abstraction:** Detailed  
**Status:** Draft  

An attacker uses lock picking tools and techniques to bypass the locks on a building or facility. Lock picking is the use of a special set of tools to manipulate the pins within a lock. Different sets of tools are required for each type of lock. Lock picking attacks have the advantage of being non-invasive in that if performed correctly the lock will not be damaged.
