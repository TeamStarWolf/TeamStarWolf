# CAPEC-401: Physically Hacking Hardware

<a id="capec-401"></a>

Abstraction: Standard  
Typical severity: High  
Likelihood: Low  
Status: Stable  

An adversary exploits a weakness in access control to gain access to currently installed hardware and precedes to implement changes or secretly replace a hardware component which undermines the system's integrity for the purpose of carrying out an attack.

## Related CWE (1)

- [CWE-1263: Improper Physical Access Control](https://cwe.mitre.org/data/definitions/1263.html): The product is designed with access restricted to certain information, but it does not sufficiently protect against an unauthorized actor with physical access to these areas.
