# CAPEC-620 — Drop Encryption Level

<a id="capec-620"></a>

**Abstraction:** Standard  
**Typical severity:** High  
**Likelihood:** 

An attacker forces the encryption level to be lowered, thus enabling a successful attack against the encrypted data.
