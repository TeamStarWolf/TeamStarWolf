# D3FEND: Bootloader Authentication

<a id="bootloader-authentication"></a>

D3FEND tactic: Harden  
Digital artifacts: Boot Loader  

Cryptographically authenticating the bootloader software before system boot.

## ATT&CK techniques countered (1)

- [T1542.003: Bootkit](/mitre/techniques/T1542-003.md): authenticates. Adversaries may use bootkits to persist on systems.
