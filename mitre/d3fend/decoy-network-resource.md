# D3FEND: Decoy Network Resource

<a id="decoy-network-resource"></a>

D3FEND tactic: Deceive  
Digital artifacts: Network Resource  

Deploying a network resource for the purposes of deceiving an adversary.

## ATT&CK techniques countered (8)

- [T1037.003: Network Logon Script](/mitre/techniques/T1037-003.md): spoofs. Adversaries may use network logon scripts automatically executed at logon initialization to establish persistence.
- [T1039: Data from Network Shared Drive](/mitre/techniques/T1039.md): spoofs. Adversaries may search network shares on computers they have compromised to find files of interest.
- [T1070.005: Network Share Connection Removal](/mitre/techniques/T1070-005.md): spoofs. Adversaries may remove share connections that are no longer useful in order to clean up traces of their operation.
- [T1074.002: Remote Data Staging](/mitre/techniques/T1074-002.md): spoofs. Adversaries may stage data collected from multiple systems in a central location or directory on one system prior to Exfiltration.
- [T1080: Taint Shared Content](/mitre/techniques/T1080.md): spoofs. Adversaries may deliver payloads to remote systems by adding content to shared storage locations, such as network drives or internal code repositories.
- [T1213.001: Confluence](/mitre/techniques/T1213-001.md): spoofs. Adversaries may leverage Confluence repositories to mine valuable information.
- [T1213.002: Sharepoint](/mitre/techniques/T1213-002.md): spoofs. Adversaries may leverage the SharePoint repository as a source to mine valuable information.
- [T1491.002: External Defacement](/mitre/techniques/T1491-002.md): spoofs. An adversary may deface systems external to an organization in an attempt to deliver messaging, intimidate, or otherwise mislead an organization or users.
