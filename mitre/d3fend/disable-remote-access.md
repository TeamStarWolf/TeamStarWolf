# D3FEND: Disable Remote Access

<a id="disable-remote-access"></a>

D3FEND tactic: Harden  
Digital artifacts: Application Configuration  

Limiting access to a computing device which is not required through or from a non-organization-controlled network.

## ATT&CK techniques countered (8)

- [T0858](https://attack.mitre.org/techniques/T0858): configures
- [T0868](https://attack.mitre.org/techniques/T0868): configures
- [T1114.003: Email Forwarding Rule](/mitre/techniques/T1114-003.md): configures. Adversaries may setup email forwarding rules to collect sensitive information.
- [T1562.002: Disable Windows Event Logging](/mitre/techniques/T1562-002.md): configures. Adversaries may disable Windows event logging to limit data that can be leveraged for detections and audits.
- [T1562.003: Impair Command History Logging](/mitre/techniques/T1562-003.md): configures. Adversaries may impair command history logging to hide commands they run on a compromised system.
- [T1564.008: Email Hiding Rules](/mitre/techniques/T1564-008.md): configures. Adversaries may use email rules to hide inbound emails in a compromised user's mailbox.
- [T1685.001: Disable or Modify Windows Event Log](/mitre/techniques/T1685-001.md): configures. Adversaries may disable or modify the Windows Event Log to limit data that can be leveraged for detections and audits.
- [T1690: Prevent Command History Logging](/mitre/techniques/T1690.md): configures. Adversaries may impair command history logging to hide commands they run on a compromised system.
