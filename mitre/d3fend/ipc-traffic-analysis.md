# D3FEND: IPC Traffic Analysis

<a id="ipc-traffic-analysis"></a>

D3FEND tactic: Detect  
Digital artifacts: Intranet IPC Network Traffic  

Analyzing standard inter process communication (IPC) protocols to detect deviations from normal protocol activity.

## ATT&CK techniques countered (1)

- [T1197: BITS Jobs](/mitre/techniques/T1197.md): analyzes. Adversaries may abuse BITS jobs to persistently execute code and perform various background tasks.
