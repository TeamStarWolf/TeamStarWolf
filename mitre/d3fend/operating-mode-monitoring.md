# D3FEND: Operating Mode Monitoring

<a id="operating-mode-monitoring"></a>

D3FEND tactic: Detect  
Digital artifacts: OT Controller Operating Mode  

Detects operating modes such as Program, Run, Remote, or Stop.

## ATT&CK techniques countered (2)

- [T0800: Activate Firmware Update Mode](https://attack.mitre.org/techniques/T0800): monitors
- [T0858: Change Operating Mode](https://attack.mitre.org/techniques/T0858): monitors
