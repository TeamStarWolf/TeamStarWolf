# D3FEND: Operating Mode Restriction

<a id="operating-mode-restriction"></a>

D3FEND tactic: Isolate  
Digital artifacts: OT Controller Operating Mode  

Restricting unauthorized changes to the operating mode prevents devices from switching into inappropriate or vulnerable states during normal use.

## ATT&CK techniques countered (2)

- [T0800: Activate Firmware Update Mode](https://attack.mitre.org/techniques/T0800): restricts
- [T0858: Change Operating Mode](https://attack.mitre.org/techniques/T0858): restricts
