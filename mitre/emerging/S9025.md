# S9025 — NOOPLDR

**Classification:** community / emerging  
**Type:** malware  
**Local ref:** `S9025` (not official ATT&CK)  
**Platforms:** Windows  

NOOPLDR is a shellcode loader with XML/C# and DLL versions that has been used by [MirrorFace](https://attack.mitre.org/groups/G1054) to load HiddenFace.
