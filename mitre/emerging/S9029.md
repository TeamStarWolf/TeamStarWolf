# S9029 — IronWind

<a id="s9029"></a>

**Classification:** community / emerging  
**Type:** malware  
**Local ref:** `S9029` (not official ATT&CK)  
**Platforms:** Windows  

IronWind is a custom loader malware that has been in use since at least 2023 by actors including [WIRTE](https://attack.mitre.org/groups/G0090) to target entities in the Middle East.
