# F3 — Fight Fraud Framework

The CTID **Fight Fraud Framework (F3)** models the fraud lifecycle as tactics + techniques, alongside ATT&CK. 39 F3 techniques are ATT&CK-derived and cross-link to their [technique pages](/mitre/techniques/README.md); the rest are fraud-specific.
