# G0133: Nomadic Octopus

<a id="g0133"></a>

ATT&CK: [G0133](https://attack.mitre.org/groups/G0133)  
Aliases: DustSquad  

[Nomadic Octopus](https://attack.mitre.org/groups/G0133) is a Russian-speaking cyber espionage threat group that has primarily targeted Central Asia, including local governments, diplomatic missions, and individuals, since at least 2014. [Nomadic Octopus](https://attack.mitre.org/groups/G0133) has been observed conducting campaigns involving Android and Windows malware, mainly using the Delphi programming language, and building custom variants.
