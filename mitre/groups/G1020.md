# G1020: Mustard Tempest

<a id="g1020"></a>

ATT&CK: [G1020](https://attack.mitre.org/groups/G1020)  
Aliases: DEV-0206, TA569, GOLD PRELUDE, UNC1543  

[Mustard Tempest](https://attack.mitre.org/groups/G1020) is an initial access broker that has operated the [SocGholish](https://attack.mitre.org/software/S1124) distribution network since at least 2017. [Mustard Tempest](https://attack.mitre.org/groups/G1020) has partnered with [Indrik Spider](https://attack.mitre.org/groups/G0119) to provide access for the download of additional malware including LockBit, [WastedLocker](https://attack.mitre.org/software/S0612), and remote access tools.
