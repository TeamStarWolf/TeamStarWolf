# M1026: Privileged Account Management

<a id="m1026"></a>

ATT&CK: [M1026](https://attack.mitre.org/mitigations/M1026), addresses 112 techniques

Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).

## How to implement

- Adopt a PAM solution with vaulting, session brokering, and check-out; enforce JIT/JEA and separate admin workstations (PAWs).
- Eliminate shared/standing privileged credentials; log and review all privileged sessions.
- NIST: AC-2(7), AC-6, IA-5.
