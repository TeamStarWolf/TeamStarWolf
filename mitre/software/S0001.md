# S0001: Trojan.Mebromi

<a id="s0001"></a>

Type: malware  
ATT&CK: [S0001](https://attack.mitre.org/software/S0001)  
Platforms: Windows  

[Trojan.Mebromi](https://attack.mitre.org/software/S0001) is BIOS-level malware that takes control of the victim before MBR.
