# S0002 — Mimikatz

<a id="s0002"></a>

**Type:** tool  
**ATT&CK:** [S0002](https://attack.mitre.org/software/S0002)  
**Platforms:** Windows  

[Mimikatz](https://attack.mitre.org/software/S0002) is a credential dumper capable of obtaining plaintext Windows account logins and passwords, along with many other features that make it useful for testing the security of networks.
