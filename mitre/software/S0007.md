# S0007 — Skeleton Key

<a id="s0007"></a>

**Type:** malware  
**ATT&CK:** [S0007](https://attack.mitre.org/software/S0007)  
**Platforms:** Windows  

[Skeleton Key](https://attack.mitre.org/software/S0007) is malware used to inject false credentials into domain controllers with the intent of creating a backdoor password. Functionality similar to [Skeleton Key](https://attack.mitre.org/software/S0007) is included as a module in [Mimikatz](https://attack.mitre.org/software/S0002).
