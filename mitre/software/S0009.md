# S0009 — Hikit

<a id="s0009"></a>

**Type:** malware  
**ATT&CK:** [S0009](https://attack.mitre.org/software/S0009)  
**Platforms:** Windows  

[Hikit](https://attack.mitre.org/software/S0009) is malware that has been used by [Axiom](https://attack.mitre.org/groups/G0001) for late-stage persistence and exfiltration after the initial compromise.
