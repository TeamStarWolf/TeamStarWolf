# S0011 — Taidoor

<a id="s0011"></a>

**Type:** malware  
**ATT&CK:** [S0011](https://attack.mitre.org/software/S0011)  
**Platforms:** Windows  

[Taidoor](https://attack.mitre.org/software/S0011) is a remote access trojan (RAT) that has been used by Chinese government cyber actors to maintain access on victim networks. [Taidoor](https://attack.mitre.org/software/S0011) has primarily been used against Taiwanese government organizations since at least 2010.
