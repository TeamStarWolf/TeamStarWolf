# S0012: PoisonIvy

<a id="s0012"></a>

Type: malware  
ATT&CK: [S0012](https://attack.mitre.org/software/S0012)  
Platforms: Windows  
Aliases: Breut, Poison Ivy, Darkmoon  

[PoisonIvy](https://attack.mitre.org/software/S0012) is a popular remote access tool (RAT) that has been used by many groups.
