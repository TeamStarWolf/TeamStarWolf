# S0013 — PlugX

<a id="s0013"></a>

**Type:** malware  
**ATT&CK:** [S0013](https://attack.mitre.org/software/S0013)  
**Platforms:** Windows  
**Aliases:** Thoper, TVT, DestroyRAT, Sogu, Kaba, Korplug  

[PlugX](https://attack.mitre.org/software/S0013) is a remote access tool (RAT) with modular plugins that has been used by multiple threat groups.
