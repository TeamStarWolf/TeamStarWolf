# S0015 — Ixeshe

<a id="s0015"></a>

**Type:** malware  
**ATT&CK:** [S0015](https://attack.mitre.org/software/S0015)  
**Platforms:** Windows  

[Ixeshe](https://attack.mitre.org/software/S0015) is a malware family that has been used since at least 2009 against targets in East Asia.
