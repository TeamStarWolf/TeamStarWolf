# S0016: P2P ZeuS

<a id="s0016"></a>

Type: malware  
ATT&CK: [S0016](https://attack.mitre.org/software/S0016)  
Platforms: Windows  
Aliases: Peer-to-Peer ZeuS, Gameover ZeuS  

[P2P ZeuS](https://attack.mitre.org/software/S0016) is a closed-source fork of the leaked version of the ZeuS botnet. It presents improvements over the leaked version, including a peer-to-peer architecture.
