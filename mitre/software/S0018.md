# S0018 — Sykipot

<a id="s0018"></a>

**Type:** malware  
**ATT&CK:** [S0018](https://attack.mitre.org/software/S0018)  
**Platforms:** Windows  

[Sykipot](https://attack.mitre.org/software/S0018) is malware that has been used in spearphishing campaigns since approximately 2007 against victims primarily in the US. One variant of [Sykipot](https://attack.mitre.org/software/S0018) hijacks smart cards on victims. The group using this malware has also been referred to as Sykipot.
