# S0019: Regin

<a id="s0019"></a>

Type: malware  
ATT&CK: [S0019](https://attack.mitre.org/software/S0019)  
Platforms: Windows  

[Regin](https://attack.mitre.org/software/S0019) is a malware platform that has targeted victims in a range of industries, including telecom, government, and financial institutions. Some [Regin](https://attack.mitre.org/software/S0019) timestamps date back to 2003.
