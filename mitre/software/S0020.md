# S0020 — China Chopper

<a id="s0020"></a>

**Type:** malware  
**ATT&CK:** [S0020](https://attack.mitre.org/software/S0020)  
**Platforms:** Windows  

[China Chopper](https://attack.mitre.org/software/S0020) is a [Web Shell](https://attack.mitre.org/techniques/T1505/003) hosted on Web servers to provide access back into an enterprise network that does not rely on an infected system calling back to a remote command and control server. It has been used by several threat groups.
