# S0021 — Derusbi

<a id="s0021"></a>

**Type:** malware  
**ATT&CK:** [S0021](https://attack.mitre.org/software/S0021)  
**Platforms:** Windows, Linux  
**Aliases:** PHOTO  

[Derusbi](https://attack.mitre.org/software/S0021) is malware used by multiple Chinese APT groups. Both Windows and Linux variants have been observed.
