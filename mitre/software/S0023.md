# S0023: CHOPSTICK

<a id="s0023"></a>

Type: malware  
ATT&CK: [S0023](https://attack.mitre.org/software/S0023)  
Platforms: Windows, Linux  
Aliases: Backdoor.SofacyX, SPLM, Xagent, X-Agent, webhp  

[CHOPSTICK](https://attack.mitre.org/software/S0023) is a malware family of modular backdoors used by [APT28](https://attack.mitre.org/groups/G0007). It has been used since at least 2012 and is usually dropped on victims as second-stage malware, though it has been used as first-stage malware in several cases. It has both Windows and Linux variants. It is tracked separately from the [X-Agent for Android](https://attack.mitre.org/software/S0314).
