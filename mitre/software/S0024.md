# S0024 — Dyre

<a id="s0024"></a>

**Type:** malware  
**ATT&CK:** [S0024](https://attack.mitre.org/software/S0024)  
**Platforms:** Windows  
**Aliases:** Dyzap, Dyreza  

[Dyre](https://attack.mitre.org/software/S0024) is a banking Trojan that has been used for financial gain.
