# S0025 — CALENDAR

<a id="s0025"></a>

**Type:** malware  
**ATT&CK:** [S0025](https://attack.mitre.org/software/S0025)  
**Platforms:** Windows  

[CALENDAR](https://attack.mitre.org/software/S0025) is malware used by [APT1](https://attack.mitre.org/groups/G0006) that mimics legitimate Gmail Calendar traffic.
