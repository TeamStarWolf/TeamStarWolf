# S0026: GLOOXMAIL

<a id="s0026"></a>

Type: malware  
ATT&CK: [S0026](https://attack.mitre.org/software/S0026)  
Platforms: Windows  
Aliases: Trojan.GTALK  

[GLOOXMAIL](https://attack.mitre.org/software/S0026) is malware used by [APT1](https://attack.mitre.org/groups/G0006) that mimics legitimate Jabber/XMPP traffic.
