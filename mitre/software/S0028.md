# S0028 — SHIPSHAPE

<a id="s0028"></a>

**Type:** malware  
**ATT&CK:** [S0028](https://attack.mitre.org/software/S0028)  

[SHIPSHAPE](https://attack.mitre.org/software/S0028) is malware developed by [APT30](https://attack.mitre.org/groups/G0013) that allows propagation and exfiltration of data over removable devices. [APT30](https://attack.mitre.org/groups/G0013) may use this capability to exfiltrate data across air-gaps.

## Techniques used (3)

- [T1091 — Replication Through Removable Media](/mitre/techniques/T1091.md)
- [T1547.001 — Registry Run Keys / Startup Folder](/mitre/techniques/T1547-001.md)
- [T1547.009 — Shortcut Modification](/mitre/techniques/T1547-009.md)
