# S0029: PsExec

<a id="s0029"></a>

Type: tool  
ATT&CK: [S0029](https://attack.mitre.org/software/S0029)  
Platforms: Windows  

[PsExec](https://attack.mitre.org/software/S0029) is a free Microsoft tool that can be used to execute a program on another computer. It is used by IT administrators and attackers.
