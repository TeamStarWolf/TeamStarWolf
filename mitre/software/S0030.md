# S0030: Carbanak

<a id="s0030"></a>

Type: malware  
ATT&CK: [S0030](https://attack.mitre.org/software/S0030)  
Platforms: Windows  
Aliases: Anunak  

[Carbanak](https://attack.mitre.org/software/S0030) is a full-featured, remote backdoor used by a group of the same name ([Carbanak](https://attack.mitre.org/groups/G0008)). It is intended for espionage, data exfiltration, and providing remote access to infected machines.
