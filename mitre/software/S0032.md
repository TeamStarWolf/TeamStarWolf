# S0032: gh0st RAT

<a id="s0032"></a>

Type: malware  
ATT&CK: [S0032](https://attack.mitre.org/software/S0032)  
Platforms: Windows, macOS  
Aliases: Mydoor, Moudoor  

[gh0st RAT](https://attack.mitre.org/software/S0032) is a remote access tool (RAT). The source code is public and it has been used by multiple groups.
