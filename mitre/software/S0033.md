# S0033: NetTraveler

<a id="s0033"></a>

Type: malware  
ATT&CK: [S0033](https://attack.mitre.org/software/S0033)  
Platforms: Windows  

[NetTraveler](https://attack.mitre.org/software/S0033) is malware that has been used in multiple cyber espionage campaigns for basic surveillance of victims. The earliest known samples have timestamps back to 2005, and the largest number of observed samples were created between 2010 and 2013.
