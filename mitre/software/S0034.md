# S0034 — NETEAGLE

<a id="s0034"></a>

**Type:** malware  
**ATT&CK:** [S0034](https://attack.mitre.org/software/S0034)  
**Platforms:** Windows  

[NETEAGLE](https://attack.mitre.org/software/S0034) is a backdoor developed by [APT30](https://attack.mitre.org/groups/G0013) with compile dates as early as 2008. It has two main variants known as “Scout” and “Norton.”
