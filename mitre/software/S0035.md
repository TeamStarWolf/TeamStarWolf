# S0035 — SPACESHIP

<a id="s0035"></a>

**Type:** malware  
**ATT&CK:** [S0035](https://attack.mitre.org/software/S0035)  
**Platforms:** Windows  

[SPACESHIP](https://attack.mitre.org/software/S0035) is malware developed by [APT30](https://attack.mitre.org/groups/G0013) that allows propagation and exfiltration of data over removable devices. [APT30](https://attack.mitre.org/groups/G0013) may use this capability to exfiltrate data across air-gaps.
