# S0036: FLASHFLOOD

<a id="s0036"></a>

Type: malware  
ATT&CK: [S0036](https://attack.mitre.org/software/S0036)  
Platforms: Windows  

[FLASHFLOOD](https://attack.mitre.org/software/S0036) is malware developed by [APT30](https://attack.mitre.org/groups/G0013) that allows propagation and exfiltration of data over removable devices. [APT30](https://attack.mitre.org/groups/G0013) may use this capability to exfiltrate data across air-gaps.
