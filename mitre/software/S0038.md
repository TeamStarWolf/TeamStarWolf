# S0038 — Duqu

<a id="s0038"></a>

**Type:** malware  
**ATT&CK:** [S0038](https://attack.mitre.org/software/S0038)  
**Platforms:** Windows  

[Duqu](https://attack.mitre.org/software/S0038) is a malware platform that uses a modular approach to extend functionality after deployment within a target network.
