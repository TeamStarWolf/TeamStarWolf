# S0040 — HTRAN

<a id="s0040"></a>

**Type:** tool  
**ATT&CK:** [S0040](https://attack.mitre.org/software/S0040)  
**Platforms:** Linux, Windows  
**Aliases:** HUC Packet Transmit Tool  

[HTRAN](https://attack.mitre.org/software/S0040) is a tool that proxies connections through intermediate hops and aids users in disguising their true geographical location. It can be used by adversaries to hide their location when interacting with the victim networks.
