# S0042: LOWBALL

<a id="s0042"></a>

Type: malware  
ATT&CK: [S0042](https://attack.mitre.org/software/S0042)  
Platforms: Windows  

[LOWBALL](https://attack.mitre.org/software/S0042) is malware used by [admin@338](https://attack.mitre.org/groups/G0018). It was used in August 2015 in email messages targeting Hong Kong-based media organizations.
