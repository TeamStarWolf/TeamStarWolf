# S0043 — BUBBLEWRAP

<a id="s0043"></a>

**Type:** malware  
**ATT&CK:** [S0043](https://attack.mitre.org/software/S0043)  
**Platforms:** Windows  
**Aliases:** Backdoor.APT.FakeWinHTTPHelper  

[BUBBLEWRAP](https://attack.mitre.org/software/S0043) is a full-featured, second-stage backdoor used by the [admin@338](https://attack.mitre.org/groups/G0018) group. It is set to run when the system boots and includes functionality to check, upload, and register plug-ins that can further enhance its capabilities.
