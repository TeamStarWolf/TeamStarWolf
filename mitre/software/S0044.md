# S0044 — JHUHUGIT

<a id="s0044"></a>

**Type:** malware  
**ATT&CK:** [S0044](https://attack.mitre.org/software/S0044)  
**Platforms:** Windows  
**Aliases:** Trojan.Sofacy, Seduploader, JKEYSKW, Sednit, GAMEFISH, SofacyCarberp  

[JHUHUGIT](https://attack.mitre.org/software/S0044) is malware used by [APT28](https://attack.mitre.org/groups/G0007). It is based on Carberp source code and serves as reconnaissance malware.
