# S0045: ADVSTORESHELL

<a id="s0045"></a>

Type: malware  
ATT&CK: [S0045](https://attack.mitre.org/software/S0045)  
Platforms: Windows  
Aliases: AZZY, EVILTOSS, NETUI, Sedreco  

[ADVSTORESHELL](https://attack.mitre.org/software/S0045) is a spying backdoor that has been used by [APT28](https://attack.mitre.org/groups/G0007) from at least 2012 to 2016. It is generally used for long-term espionage and is deployed on targets deemed interesting after a reconnaissance phase.
