# S0050 — CosmicDuke

<a id="s0050"></a>

**Type:** malware  
**ATT&CK:** [S0050](https://attack.mitre.org/software/S0050)  
**Platforms:** Windows  
**Aliases:** TinyBaron, BotgenStudios, NemesisGemina  

[CosmicDuke](https://attack.mitre.org/software/S0050) is malware that was used by [APT29](https://attack.mitre.org/groups/G0016) from 2010 to 2015.
