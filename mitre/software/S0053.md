# S0053: SeaDuke

<a id="s0053"></a>

Type: malware  
ATT&CK: [S0053](https://attack.mitre.org/software/S0053)  
Platforms: Windows  
Aliases: SeaDaddy, SeaDesk  

[SeaDuke](https://attack.mitre.org/software/S0053) is malware that was used by [APT29](https://attack.mitre.org/groups/G0016) from 2014 to 2015. It was used primarily as a secondary backdoor for victims that were already compromised with [CozyCar](https://attack.mitre.org/software/S0046).
