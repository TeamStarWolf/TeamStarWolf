# S0055: RARSTONE

<a id="s0055"></a>

Type: malware  
ATT&CK: [S0055](https://attack.mitre.org/software/S0055)  
Platforms: Windows  

[RARSTONE](https://attack.mitre.org/software/S0055) is malware used by the [Naikon](https://attack.mitre.org/groups/G0019) group that has some characteristics similar to [PlugX](https://attack.mitre.org/software/S0013).

## Techniques used (4)

- [T1055.001: Dynamic-link Library Injection](/mitre/techniques/T1055-001.md)
- [T1083: File and Directory Discovery](/mitre/techniques/T1083.md)
- [T1095: Non-Application Layer Protocol](/mitre/techniques/T1095.md)
- [T1105: Ingress Tool Transfer](/mitre/techniques/T1105.md)

## Used by groups (1)

[Naikon](/mitre/groups/G0019.md)
