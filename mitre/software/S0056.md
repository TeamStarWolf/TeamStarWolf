# S0056: Net Crawler

<a id="s0056"></a>

Type: malware  
ATT&CK: [S0056](https://attack.mitre.org/software/S0056)  
Platforms: Windows  
Aliases: NetC  

[Net Crawler](https://attack.mitre.org/software/S0056) is an intranet worm capable of extracting credentials using credential dumpers and spreading to systems on a network over SMB by brute forcing accounts with recovered passwords and using [PsExec](https://attack.mitre.org/software/S0029) to execute a copy of [Net Crawler](https://attack.mitre.org/software/S0056).
