# S0062: DustySky

<a id="s0062"></a>

Type: malware  
ATT&CK: [S0062](https://attack.mitre.org/software/S0062)  
Platforms: Windows  
Aliases: NeD Worm  

[DustySky](https://attack.mitre.org/software/S0062) is multi-stage malware written in.NET that has been used by [Molerats](https://attack.mitre.org/groups/G0021) since May 2015.
