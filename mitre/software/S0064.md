# S0064: ELMER

<a id="s0064"></a>

Type: malware  
ATT&CK: [S0064](https://attack.mitre.org/software/S0064)  
Platforms: Windows  

[ELMER](https://attack.mitre.org/software/S0064) is a non-persistent, proxy-aware HTTP backdoor written in Delphi that has been used by [APT16](https://attack.mitre.org/groups/G0023).
