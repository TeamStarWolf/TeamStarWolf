# S0066 — 3PARA RAT

<a id="s0066"></a>

**Type:** malware  
**ATT&CK:** [S0066](https://attack.mitre.org/software/S0066)  
**Platforms:** Windows  

[3PARA RAT](https://attack.mitre.org/software/S0066) is a remote access tool (RAT) programmed in C++ that has been used by [Putter Panda](https://attack.mitre.org/groups/G0024).
