# S0067: pngdowner

<a id="s0067"></a>

Type: malware  
ATT&CK: [S0067](https://attack.mitre.org/software/S0067)  
Platforms: Windows  

[pngdowner](https://attack.mitre.org/software/S0067) is malware used by [Putter Panda](https://attack.mitre.org/groups/G0024). It is a simple tool with limited functionality and no persistence mechanism, suggesting it is used only as a simple "download-and- execute" utility.
