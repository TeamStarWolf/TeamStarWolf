# S0070: HTTPBrowser

<a id="s0070"></a>

Type: malware  
ATT&CK: [S0070](https://attack.mitre.org/software/S0070)  
Platforms: Windows  
Aliases: Token Control, HttpDump  

[HTTPBrowser](https://attack.mitre.org/software/S0070) is malware that has been used by several threat groups. It is believed to be of Chinese origin.
