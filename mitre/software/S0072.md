# S0072 — OwaAuth

<a id="s0072"></a>

**Type:** malware  
**ATT&CK:** [S0072](https://attack.mitre.org/software/S0072)  
**Platforms:** Windows  

[OwaAuth](https://attack.mitre.org/software/S0072) is a Web shell and credential stealer deployed to Microsoft Exchange servers that appears to be exclusively used by [Threat Group-3390](https://attack.mitre.org/groups/G0027).
