# S0075 — Reg

<a id="s0075"></a>

**Type:** tool  
**ATT&CK:** [S0075](https://attack.mitre.org/software/S0075)  
**Platforms:** Windows  
**Aliases:** reg.exe  

[Reg](https://attack.mitre.org/software/S0075) is a Windows utility used to interact with the Windows Registry. It can be used at the command-line interface to query, add, modify, and remove information. Utilities such as [Reg](https://attack.mitre.org/software/S0075) are known to be used by persistent threats.
