# S0076: FakeM

<a id="s0076"></a>

Type: malware  
ATT&CK: [S0076](https://attack.mitre.org/software/S0076)  
Platforms: Windows  

[FakeM](https://attack.mitre.org/software/S0076) is a shellcode-based Windows backdoor that has been used by [Scarlet Mimic](https://attack.mitre.org/groups/G0029).
