# S0077: CallMe

<a id="s0077"></a>

Type: malware  
ATT&CK: [S0077](https://attack.mitre.org/software/S0077)  
Platforms: macOS  

[CallMe](https://attack.mitre.org/software/S0077) is a Trojan designed to run on Apple OSX. It is based on a publicly available tool called Tiny SHell.
