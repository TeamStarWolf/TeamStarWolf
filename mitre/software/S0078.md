# S0078 — Psylo

<a id="s0078"></a>

**Type:** malware  
**ATT&CK:** [S0078](https://attack.mitre.org/software/S0078)  
**Platforms:** Windows  

[Psylo](https://attack.mitre.org/software/S0078) is a shellcode-based Trojan that has been used by [Scarlet Mimic](https://attack.mitre.org/groups/G0029). It has similar characteristics as [FakeM](https://attack.mitre.org/software/S0076).
