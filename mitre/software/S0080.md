# S0080: Mivast

<a id="s0080"></a>

Type: malware  
ATT&CK: [S0080](https://attack.mitre.org/software/S0080)  
Platforms: Windows  

[Mivast](https://attack.mitre.org/software/S0080) is a backdoor that has been used by [Deep Panda](https://attack.mitre.org/groups/G0009). It was reportedly used in the Anthem breach.
