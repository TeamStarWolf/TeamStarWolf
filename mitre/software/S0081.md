# S0081: Elise

<a id="s0081"></a>

Type: malware  
ATT&CK: [S0081](https://attack.mitre.org/software/S0081)  
Platforms: Windows  
Aliases: BKDR_ESILE, Page  

[Elise](https://attack.mitre.org/software/S0081) is a custom backdoor Trojan that appears to be used exclusively by [Lotus Blossom](https://attack.mitre.org/groups/G0030). It is part of a larger group of tools referred to as LStudio, ST Group, and APT0LSTU.
