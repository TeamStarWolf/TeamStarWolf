# S0083: Misdat

<a id="s0083"></a>

Type: malware  
ATT&CK: [S0083](https://attack.mitre.org/software/S0083)  
Platforms: Windows  

[Misdat](https://attack.mitre.org/software/S0083) is a backdoor that was used in [Operation Dust Storm](https://attack.mitre.org/campaigns/C0016) from 2010 to 2011.
