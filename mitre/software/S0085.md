# S0085 — S-Type

<a id="s0085"></a>

**Type:** malware  
**ATT&CK:** [S0085](https://attack.mitre.org/software/S0085)  
**Platforms:** Windows  

[S-Type](https://attack.mitre.org/software/S0085) is a backdoor that was used in [Operation Dust Storm](https://attack.mitre.org/campaigns/C0016) since at least 2013.
