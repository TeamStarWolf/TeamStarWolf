# S0087 — Hi-Zor

<a id="s0087"></a>

**Type:** malware  
**ATT&CK:** [S0087](https://attack.mitre.org/software/S0087)  
**Platforms:** Windows  

[Hi-Zor](https://attack.mitre.org/software/S0087) is a remote access tool (RAT) that has characteristics similar to [Sakula](https://attack.mitre.org/software/S0074). It was used in a campaign named INOCNATION.
