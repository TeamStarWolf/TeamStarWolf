# S0088: Kasidet

<a id="s0088"></a>

Type: malware  
ATT&CK: [S0088](https://attack.mitre.org/software/S0088)  
Platforms: Windows  

[Kasidet](https://attack.mitre.org/software/S0088) is a backdoor that has been dropped by using malicious VBA macros.
