# S0090 — Rover

<a id="s0090"></a>

**Type:** malware  
**ATT&CK:** [S0090](https://attack.mitre.org/software/S0090)  
**Platforms:** Windows  

[Rover](https://attack.mitre.org/software/S0090) is malware suspected of being used for espionage purposes. It was used in 2015 in a targeted email sent to an Indian Ambassador to Afghanistan.
