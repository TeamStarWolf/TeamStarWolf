# S0092: Agent.btz

<a id="s0092"></a>

Type: malware  
ATT&CK: [S0092](https://attack.mitre.org/software/S0092)  
Platforms: Windows  

[Agent.btz](https://attack.mitre.org/software/S0092) is a worm that primarily spreads itself via removable devices such as USB drives. It reportedly infected U.S. military networks in 2008.
