# S0098: T9000

<a id="s0098"></a>

Type: malware  
ATT&CK: [S0098](https://attack.mitre.org/software/S0098)  
Platforms: Windows  

[T9000](https://attack.mitre.org/software/S0098) is a backdoor that is a newer variant of the T5000 malware family, also known as Plat1. Its primary function is to gather information about the victim. It has been used in multiple targeted attacks against U.S.-based organizations.
