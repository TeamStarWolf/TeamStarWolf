# S0099 — Arp

<a id="s0099"></a>

**Type:** tool  
**ATT&CK:** [S0099](https://attack.mitre.org/software/S0099)  
**Platforms:** Linux, Windows, macOS  
**Aliases:** arp.exe  

[Arp](https://attack.mitre.org/software/S0099) displays and modifies information about a system's Address Resolution Protocol (ARP) cache.
