# S0100 — ipconfig

<a id="s0100"></a>

**Type:** tool  
**ATT&CK:** [S0100](https://attack.mitre.org/software/S0100)  

[ipconfig](https://attack.mitre.org/software/S0100) is a Windows utility that can be used to find information about a system's TCP/IP, DNS, DHCP, and adapter configuration.
