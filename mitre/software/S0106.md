# S0106: cmd

<a id="s0106"></a>

Type: tool  
ATT&CK: [S0106](https://attack.mitre.org/software/S0106)  
Platforms: Windows  
Aliases: cmd.exe  

[cmd](https://attack.mitre.org/software/S0106) is the Windows command-line interpreter that can be used to interact with systems and execute other processes and utilities. Cmd.exe contains native functionality to perform many operations to interact with the system, including listing files in a directory (e.g., <code>dir</code>), deleting files (e.g., <code>del</code>), and copying files (e.g., <code>copy</code>).
