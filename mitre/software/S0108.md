# S0108 — netsh

<a id="s0108"></a>

**Type:** tool  
**ATT&CK:** [S0108](https://attack.mitre.org/software/S0108)  
**Platforms:** Windows  
**Aliases:** netsh.exe  

[netsh](https://attack.mitre.org/software/S0108) is a scripting utility used to interact with networking components on local or remote systems.
