# S0111: schtasks

<a id="s0111"></a>

Type: tool  
ATT&CK: [S0111](https://attack.mitre.org/software/S0111)  
Platforms: Windows  
Aliases: schtasks.exe  

[schtasks](https://attack.mitre.org/software/S0111) is used to schedule execution of programs or scripts on a Windows system to run at a specific date and time.
