# S0113: Prikormka

<a id="s0113"></a>

Type: malware  
ATT&CK: [S0113](https://attack.mitre.org/software/S0113)  
Platforms: Windows  

[Prikormka](https://attack.mitre.org/software/S0113) is a malware family used in a campaign known as Operation Groundbait. It has predominantly been observed in Ukraine and was used as early as 2008.
