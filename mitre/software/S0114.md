# S0114: BOOTRASH

<a id="s0114"></a>

Type: malware  
ATT&CK: [S0114](https://attack.mitre.org/software/S0114)  
Platforms: Windows  

[BOOTRASH](https://attack.mitre.org/software/S0114) is a [Bootkit](https://attack.mitre.org/techniques/T1542/003) that targets Windows operating systems. It has been used by threat actors that target the financial sector.
