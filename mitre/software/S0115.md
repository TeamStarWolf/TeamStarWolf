# S0115: Crimson

<a id="s0115"></a>

Type: malware  
ATT&CK: [S0115](https://attack.mitre.org/software/S0115)  
Platforms: Windows  
Aliases: MSIL/Crimson  

[Crimson](https://attack.mitre.org/software/S0115) is a remote access Trojan that has been used by [Transparent Tribe](https://attack.mitre.org/groups/G0134) since at least 2016.
