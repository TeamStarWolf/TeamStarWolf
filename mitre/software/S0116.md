# S0116: UACMe

<a id="s0116"></a>

Type: tool  
ATT&CK: [S0116](https://attack.mitre.org/software/S0116)  

[UACMe](https://attack.mitre.org/software/S0116) is an open source assessment tool that contains many methods for bypassing Windows User Account Control on multiple versions of the operating system.
