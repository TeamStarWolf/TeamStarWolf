# S0118: Nidiran

<a id="s0118"></a>

Type: malware  
ATT&CK: [S0118](https://attack.mitre.org/software/S0118)  
Platforms: Windows  
Aliases: Backdoor.Nidiran  

[Nidiran](https://attack.mitre.org/software/S0118) is a custom backdoor developed and used by [Suckfly](https://attack.mitre.org/groups/G0039). It has been delivered via strategic web compromise.
