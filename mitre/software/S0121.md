# S0121 — Lslsass

<a id="s0121"></a>

**Type:** tool  
**ATT&CK:** [S0121](https://attack.mitre.org/software/S0121)  
**Platforms:** Windows  

[Lslsass](https://attack.mitre.org/software/S0121) is a publicly-available tool that can dump active logon session password hashes from the lsass process.
