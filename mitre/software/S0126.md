# S0126 — ComRAT

<a id="s0126"></a>

**Type:** malware  
**ATT&CK:** [S0126](https://attack.mitre.org/software/S0126)  
**Platforms:** Windows  

[ComRAT](https://attack.mitre.org/software/S0126) is a second stage implant suspected of being a descendant of [Agent.btz](https://attack.mitre.org/software/S0092) and used by [Turla](https://attack.mitre.org/groups/G0010). The first version of [ComRAT](https://attack.mitre.org/software/S0126) was identified in 2007, but the tool has undergone substantial development for many years since.
