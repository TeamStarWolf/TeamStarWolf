# S0128 — BADNEWS

<a id="s0128"></a>

**Type:** malware  
**ATT&CK:** [S0128](https://attack.mitre.org/software/S0128)  
**Platforms:** Windows  

[BADNEWS](https://attack.mitre.org/software/S0128) is malware that has been used by the actors responsible for the [Patchwork](https://attack.mitre.org/groups/G0040) campaign. Its name was given due to its use of RSS feeds, forums, and blogs for command and control.
