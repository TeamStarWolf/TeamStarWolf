# S0129 — AutoIt backdoor

<a id="s0129"></a>

**Type:** malware  
**ATT&CK:** [S0129](https://attack.mitre.org/software/S0129)  
**Platforms:** Windows  

[AutoIt backdoor](https://attack.mitre.org/software/S0129) is malware that has been used by the actors responsible for the MONSOON campaign. The actors frequently used it in weaponized.pps files exploiting CVE-2014-6352. This malware makes use of the legitimate scripting language for Windows GUI automation with the same name.
