# S0130 — Unknown Logger

<a id="s0130"></a>

**Type:** malware  
**ATT&CK:** [S0130](https://attack.mitre.org/software/S0130)  
**Platforms:** Windows  

[Unknown Logger](https://attack.mitre.org/software/S0130) is a publicly released, free backdoor. Version 1.5 of the backdoor has been used by the actors responsible for the MONSOON campaign.
