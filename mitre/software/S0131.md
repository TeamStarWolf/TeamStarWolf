# S0131: TINYTYPHON

<a id="s0131"></a>

Type: malware  
ATT&CK: [S0131](https://attack.mitre.org/software/S0131)  

[TINYTYPHON](https://attack.mitre.org/software/S0131) is a backdoor that has been used by the actors responsible for the MONSOON campaign. The majority of its code was reportedly taken from the MyDoom worm.
