# S0133: Miner-C

<a id="s0133"></a>

Type: malware  
ATT&CK: [S0133](https://attack.mitre.org/software/S0133)  

[Miner-C](https://attack.mitre.org/software/S0133) is malware that mines victims for the Monero cryptocurrency. It has targeted FTP servers and Network Attached Storage (NAS) devices to spread.
