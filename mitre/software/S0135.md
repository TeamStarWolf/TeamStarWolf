# S0135 — HIDEDRV

<a id="s0135"></a>

**Type:** malware  
**ATT&CK:** [S0135](https://attack.mitre.org/software/S0135)  
**Platforms:** Windows  

[HIDEDRV](https://attack.mitre.org/software/S0135) is a rootkit used by [APT28](https://attack.mitre.org/groups/G0007). It has been deployed along with [Downdelph](https://attack.mitre.org/software/S0134) to execute and hide that malware.
