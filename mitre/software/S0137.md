# S0137 — CORESHELL

<a id="s0137"></a>

**Type:** malware  
**ATT&CK:** [S0137](https://attack.mitre.org/software/S0137)  
**Platforms:** Windows  
**Aliases:** Sofacy, SOURFACE  

[CORESHELL](https://attack.mitre.org/software/S0137) is a downloader used by [APT28](https://attack.mitre.org/groups/G0007). The older versions of this malware are known as SOURFACE and newer versions as CORESHELL.
