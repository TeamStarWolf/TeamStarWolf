# S0139 — PowerDuke

<a id="s0139"></a>

**Type:** malware  
**ATT&CK:** [S0139](https://attack.mitre.org/software/S0139)  
**Platforms:** Windows  

[PowerDuke](https://attack.mitre.org/software/S0139) is a backdoor that was used by [APT29](https://attack.mitre.org/groups/G0016) in 2016. It has primarily been delivered through Microsoft Word or Excel attachments containing malicious macros.
