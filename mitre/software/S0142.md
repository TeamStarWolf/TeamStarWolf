# S0142: StreamEx

<a id="s0142"></a>

Type: malware  
ATT&CK: [S0142](https://attack.mitre.org/software/S0142)  
Platforms: Windows  

[StreamEx](https://attack.mitre.org/software/S0142) is a malware family that has been used by [Deep Panda](https://attack.mitre.org/groups/G0009) since at least 2015. In 2016, it was distributed via legitimate compromised Korean websites.
