# S0143 — Flame

<a id="s0143"></a>

**Type:** malware  
**ATT&CK:** [S0143](https://attack.mitre.org/software/S0143)  
**Platforms:** Windows  
**Aliases:** Flamer, sKyWIper  

[Flame](https://attack.mitre.org/software/S0143) is a sophisticated toolkit that has been used to collect information since at least 2010, largely targeting Middle East countries.
