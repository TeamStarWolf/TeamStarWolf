# S0144 — ChChes

<a id="s0144"></a>

**Type:** malware  
**ATT&CK:** [S0144](https://attack.mitre.org/software/S0144)  
**Platforms:** Windows  
**Aliases:** Scorpion, HAYMAKER  

[ChChes](https://attack.mitre.org/software/S0144) is a Trojan that appears to be used exclusively by [menuPass](https://attack.mitre.org/groups/G0045). It was used to target Japanese organizations in 2016. Its lack of persistence methods suggests it may be intended as a first-stage tool.
