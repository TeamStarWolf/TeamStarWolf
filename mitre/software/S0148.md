# S0148 — RTM

<a id="s0148"></a>

**Type:** malware  
**ATT&CK:** [S0148](https://attack.mitre.org/software/S0148)  
**Platforms:** Windows  
**Aliases:** Redaman  

[RTM](https://attack.mitre.org/software/S0148) is custom malware written in Delphi. It is used by the group of the same name ([RTM](https://attack.mitre.org/groups/G0048)). Newer versions of the malware have been reported publicly as Redaman.
