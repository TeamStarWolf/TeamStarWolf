# S0149: MoonWind

<a id="s0149"></a>

Type: malware  
ATT&CK: [S0149](https://attack.mitre.org/software/S0149)  
Platforms: Windows  

[MoonWind](https://attack.mitre.org/software/S0149) is a remote access tool (RAT) that was used in 2016 to target organizations in Thailand.
