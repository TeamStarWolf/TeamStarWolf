# S0152 — EvilGrab

<a id="s0152"></a>

**Type:** malware  
**ATT&CK:** [S0152](https://attack.mitre.org/software/S0152)  
**Platforms:** Windows  

[EvilGrab](https://attack.mitre.org/software/S0152) is a malware family with common reconnaissance capabilities. It has been deployed by [menuPass](https://attack.mitre.org/groups/G0045) via malicious Microsoft Office documents as part of spearphishing campaigns.
