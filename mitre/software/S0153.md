# S0153: RedLeaves

<a id="s0153"></a>

Type: malware  
ATT&CK: [S0153](https://attack.mitre.org/software/S0153)  
Platforms: Windows  
Aliases: BUGJUICE  

[RedLeaves](https://attack.mitre.org/software/S0153) is a malware family used by [menuPass](https://attack.mitre.org/groups/G0045). The code overlaps with [PlugX](https://attack.mitre.org/software/S0013) and may be based upon the open source tool Trochilus.
