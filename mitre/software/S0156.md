# S0156 — KOMPROGO

<a id="s0156"></a>

**Type:** malware  
**ATT&CK:** [S0156](https://attack.mitre.org/software/S0156)  
**Platforms:** Windows  

[KOMPROGO](https://attack.mitre.org/software/S0156) is a signature backdoor used by [APT32](https://attack.mitre.org/groups/G0050) that is capable of process, file, and registry management.
