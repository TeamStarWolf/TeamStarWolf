# S0160 — certutil

<a id="s0160"></a>

**Type:** tool  
**ATT&CK:** [S0160](https://attack.mitre.org/software/S0160)  
**Platforms:** Windows  
**Aliases:** certutil.exe  

[certutil](https://attack.mitre.org/software/S0160) is a command-line utility that can be used to obtain certificate authority information and configure Certificate Services.
