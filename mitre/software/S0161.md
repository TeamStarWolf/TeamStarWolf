# S0161 — XAgentOSX

<a id="s0161"></a>

**Type:** malware  
**ATT&CK:** [S0161](https://attack.mitre.org/software/S0161)  
**Platforms:** macOS  
**Aliases:** OSX.Sofacy  

[XAgentOSX](https://attack.mitre.org/software/S0161) is a trojan that has been used by [APT28](https://attack.mitre.org/groups/G0007) on OS X and appears to be a port of their standard [CHOPSTICK](https://attack.mitre.org/software/S0023) or XAgent trojan.
