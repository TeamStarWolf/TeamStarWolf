# S0162: Komplex

<a id="s0162"></a>

Type: malware  
ATT&CK: [S0162](https://attack.mitre.org/software/S0162)  
Platforms: macOS  

[Komplex](https://attack.mitre.org/software/S0162) is a backdoor that has been used by [APT28](https://attack.mitre.org/groups/G0007) on OS X and appears to be developed in a similar manner to [XAgentOSX](https://attack.mitre.org/software/S0161).
