# S0163: Janicab

<a id="s0163"></a>

Type: malware  
ATT&CK: [S0163](https://attack.mitre.org/software/S0163)  
Platforms: macOS  

[Janicab](https://attack.mitre.org/software/S0163) is an OS X trojan that relied on a valid developer ID and oblivious users to install it.
