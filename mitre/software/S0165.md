# S0165: OSInfo

<a id="s0165"></a>

Type: malware  
ATT&CK: [S0165](https://attack.mitre.org/software/S0165)  
Platforms: Windows  

[OSInfo](https://attack.mitre.org/software/S0165) is a custom tool used by [APT3](https://attack.mitre.org/groups/G0022) to do internal discovery on a victim's computer and network.
