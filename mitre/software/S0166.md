# S0166 — RemoteCMD

<a id="s0166"></a>

**Type:** malware  
**ATT&CK:** [S0166](https://attack.mitre.org/software/S0166)  
**Platforms:** Windows  

[RemoteCMD](https://attack.mitre.org/software/S0166) is a custom tool used by [APT3](https://attack.mitre.org/groups/G0022) to execute commands on a remote system similar to SysInternal's PSEXEC functionality.

- [T1105 — Ingress Tool Transfer](/mitre/techniques/T1105.md)
- [T1569.002 — Service Execution](/mitre/techniques/T1569-002.md)
