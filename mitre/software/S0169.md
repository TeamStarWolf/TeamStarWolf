# S0169: RawPOS

<a id="s0169"></a>

Type: malware  
ATT&CK: [S0169](https://attack.mitre.org/software/S0169)  
Platforms: Windows  
Aliases: FIENDCRY, DUEBREW, DRIFTWOOD  

[RawPOS](https://attack.mitre.org/software/S0169) is a point-of-sale (POS) malware family that searches for cardholder data on victims. It has been in use since at least 2008. FireEye divides RawPOS into three components: FIENDCRY, DUEBREW, and DRIFTWOOD.
