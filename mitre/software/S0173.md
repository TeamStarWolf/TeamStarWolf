# S0173: FLIPSIDE

<a id="s0173"></a>

Type: malware  
ATT&CK: [S0173](https://attack.mitre.org/software/S0173)  
Platforms: Windows  

[FLIPSIDE](https://attack.mitre.org/software/S0173) is a simple tool similar to Plink that is used by [FIN5](https://attack.mitre.org/groups/G0053) to maintain access to victims.

## Techniques used (1)

- [T1572: Protocol Tunneling](/mitre/techniques/T1572.md)
