# S0177 — Power Loader

<a id="s0177"></a>

**Type:** malware  
**ATT&CK:** [S0177](https://attack.mitre.org/software/S0177)  

[Power Loader](https://attack.mitre.org/software/S0177) is modular code sold in the cybercrime market used as a downloader in malware families such as Carberp, Redyms and Gapz.
