# S0178: Truvasys

<a id="s0178"></a>

Type: malware  
ATT&CK: [S0178](https://attack.mitre.org/software/S0178)  
Platforms: Windows  

[Truvasys](https://attack.mitre.org/software/S0178) is first-stage malware that has been used by [PROMETHIUM](https://attack.mitre.org/groups/G0056). It is a collection of modules written in the Delphi programming language.
