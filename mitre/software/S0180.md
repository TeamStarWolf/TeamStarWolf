# S0180: Volgmer

<a id="s0180"></a>

Type: malware  
ATT&CK: [S0180](https://attack.mitre.org/software/S0180)  
Platforms: Windows  

[Volgmer](https://attack.mitre.org/software/S0180) is a backdoor Trojan designed to provide covert access to a compromised system. It has been used since at least 2013 to target the government, financial, automotive, and media industries. Its primary delivery mechanism is suspected to be spearphishing.
