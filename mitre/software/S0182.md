# S0182: FinFisher

<a id="s0182"></a>

Type: malware  
ATT&CK: [S0182](https://attack.mitre.org/software/S0182)  
Platforms: Windows, Android  
Aliases: FinSpy  

[FinFisher](https://attack.mitre.org/software/S0182) is a government-grade commercial surveillance spyware reportedly sold exclusively to government agencies for use in targeted and lawful criminal investigations. It is heavily obfuscated and uses multiple anti-analysis techniques. It has other variants including [Wingbird](https://attack.mitre.org/software/S0176).
