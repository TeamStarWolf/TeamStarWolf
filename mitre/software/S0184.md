# S0184 — POWRUNER

<a id="s0184"></a>

**Type:** malware  
**ATT&CK:** [S0184](https://attack.mitre.org/software/S0184)  
**Platforms:** Windows  

[POWRUNER](https://attack.mitre.org/software/S0184) is a PowerShell script that sends and receives commands to and from the C2 server.
