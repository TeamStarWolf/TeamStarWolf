# S0186 — DownPaper

<a id="s0186"></a>

**Type:** malware  
**ATT&CK:** [S0186](https://attack.mitre.org/software/S0186)  
**Platforms:** Windows  

[DownPaper](https://attack.mitre.org/software/S0186) is a backdoor Trojan; its main functionality is to download and run second stage malware.
