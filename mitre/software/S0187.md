# S0187: Daserf

<a id="s0187"></a>

Type: malware  
ATT&CK: [S0187](https://attack.mitre.org/software/S0187)  
Platforms: Windows  
Aliases: Muirim, Nioupale  

[Daserf](https://attack.mitre.org/software/S0187) is a backdoor that has been used to spy on and steal from Japanese, South Korean, Russian, Singaporean, and Chinese victims. Researchers have identified versions written in both Visual C and Delphi.
