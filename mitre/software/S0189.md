# S0189 — ISMInjector

<a id="s0189"></a>

**Type:** malware  
**ATT&CK:** [S0189](https://attack.mitre.org/software/S0189)  
**Platforms:** Windows  

[ISMInjector](https://attack.mitre.org/software/S0189) is a Trojan used to install another [OilRig](https://attack.mitre.org/groups/G0049) backdoor, ISMAgent.
