# S0191: Winexe

<a id="s0191"></a>

Type: tool  
ATT&CK: [S0191](https://attack.mitre.org/software/S0191)  

[Winexe](https://attack.mitre.org/software/S0191) is a lightweight, open source tool similar to [PsExec](https://attack.mitre.org/software/S0029) designed to allow system administrators to execute commands on remote servers. [Winexe](https://attack.mitre.org/software/S0191) is unique in that it is a GNU/Linux based client.
