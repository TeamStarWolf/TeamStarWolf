# S0192 — Pupy

<a id="s0192"></a>

**Type:** tool  
**ATT&CK:** [S0192](https://attack.mitre.org/software/S0192)  
**Platforms:** Linux, Windows, macOS, Android  

[Pupy](https://attack.mitre.org/software/S0192) is an open source, cross-platform (Windows, Linux, OSX, Android) remote administration and post-exploitation tool. It is written in Python and can be generated as a payload in several different ways (Windows exe, Python file, PowerShell oneliner/file, Linux elf, APK, Rubber Ducky, etc.). [Pupy](https://attack.mitre.org/software/S0192) is publicly available on GitHub.
