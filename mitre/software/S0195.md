# S0195: SDelete

<a id="s0195"></a>

Type: tool  
ATT&CK: [S0195](https://attack.mitre.org/software/S0195)  
Platforms: Windows  

[SDelete](https://attack.mitre.org/software/S0195) is an application that securely deletes data in a way that makes it unrecoverable. It is part of the Microsoft Sysinternals suite of tools.
