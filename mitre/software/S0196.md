# S0196: PUNCHBUGGY

<a id="s0196"></a>

Type: malware  
ATT&CK: [S0196](https://attack.mitre.org/software/S0196)  
Platforms: Windows  
Aliases: ShellTea  

[PUNCHBUGGY](https://attack.mitre.org/software/S0196) is a backdoor malware used by [FIN8](https://attack.mitre.org/groups/G0061) that has been observed targeting POS networks in the hospitality industry.
