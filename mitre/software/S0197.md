# S0197: PUNCHTRACK

<a id="s0197"></a>

Type: malware  
ATT&CK: [S0197](https://attack.mitre.org/software/S0197)  
Platforms: Windows  
Aliases: PSVC  

[PUNCHTRACK](https://attack.mitre.org/software/S0197) is non-persistent point of sale (POS) system malware utilized by [FIN8](https://attack.mitre.org/groups/G0061) to scrape payment card data.

- [T1027: Obfuscated Files or Information](/mitre/techniques/T1027.md)
- [T1074.001: Local Data Staging](/mitre/techniques/T1074-001.md)
