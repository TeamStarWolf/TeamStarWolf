# S0198 — NETWIRE

<a id="s0198"></a>

**Type:** malware  
**ATT&CK:** [S0198](https://attack.mitre.org/software/S0198)  
**Platforms:** Windows, Linux, macOS  

[NETWIRE](https://attack.mitre.org/software/S0198) is a publicly available, multiplatform remote administration tool (RAT) that has been used by criminal and APT groups since at least 2012.
