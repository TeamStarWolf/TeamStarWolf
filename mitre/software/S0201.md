# S0201 — JPIN

<a id="s0201"></a>

**Type:** malware  
**ATT&CK:** [S0201](https://attack.mitre.org/software/S0201)  
**Platforms:** Windows  

[JPIN](https://attack.mitre.org/software/S0201) is a custom-built backdoor family used by [PLATINUM](https://attack.mitre.org/groups/G0068). Evidence suggests developers of [JPIN](https://attack.mitre.org/software/S0201) and [Dipsind](https://attack.mitre.org/software/S0200) code bases were related in some way.
