# S0204 — Briba

<a id="s0204"></a>

**Type:** malware  
**ATT&CK:** [S0204](https://attack.mitre.org/software/S0204)  
**Platforms:** Windows  

[Briba](https://attack.mitre.org/software/S0204) is a trojan used by [Elderwood](https://attack.mitre.org/groups/G0066) to open a backdoor and download files on to compromised hosts.
