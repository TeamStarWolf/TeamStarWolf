# S0205: Naid

<a id="s0205"></a>

Type: malware  
ATT&CK: [S0205](https://attack.mitre.org/software/S0205)  
Platforms: Windows  

[Naid](https://attack.mitre.org/software/S0205) is a trojan used by [Elderwood](https://attack.mitre.org/groups/G0066) to open a backdoor on compromised hosts.
