# S0206: Wiarp

<a id="s0206"></a>

Type: malware  
ATT&CK: [S0206](https://attack.mitre.org/software/S0206)  
Platforms: Windows  

[Wiarp](https://attack.mitre.org/software/S0206) is a trojan used by [Elderwood](https://attack.mitre.org/groups/G0066) to open a backdoor on compromised hosts.
