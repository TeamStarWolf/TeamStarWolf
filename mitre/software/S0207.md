# S0207: Vasport

<a id="s0207"></a>

Type: malware  
ATT&CK: [S0207](https://attack.mitre.org/software/S0207)  
Platforms: Windows  

[Vasport](https://attack.mitre.org/software/S0207) is a trojan used by [Elderwood](https://attack.mitre.org/groups/G0066) to open a backdoor on compromised hosts.
