# S0208 — Pasam

<a id="s0208"></a>

**Type:** malware  
**ATT&CK:** [S0208](https://attack.mitre.org/software/S0208)  
**Platforms:** Windows  

[Pasam](https://attack.mitre.org/software/S0208) is a trojan used by [Elderwood](https://attack.mitre.org/groups/G0066) to open a backdoor on compromised hosts.
