# S0210: Nerex

<a id="s0210"></a>

Type: malware  
ATT&CK: [S0210](https://attack.mitre.org/software/S0210)  
Platforms: Windows  

[Nerex](https://attack.mitre.org/software/S0210) is a Trojan used by [Elderwood](https://attack.mitre.org/groups/G0066) to open a backdoor on compromised hosts.
