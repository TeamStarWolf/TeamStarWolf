# S0211: Linfo

<a id="s0211"></a>

Type: malware  
ATT&CK: [S0211](https://attack.mitre.org/software/S0211)  
Platforms: Windows  

[Linfo](https://attack.mitre.org/software/S0211) is a rootkit trojan used by [Elderwood](https://attack.mitre.org/groups/G0066) to open a backdoor on compromised hosts.
