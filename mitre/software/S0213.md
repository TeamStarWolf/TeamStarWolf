# S0213 — DOGCALL

<a id="s0213"></a>

**Type:** malware  
**ATT&CK:** [S0213](https://attack.mitre.org/software/S0213)  
**Platforms:** Windows  

[DOGCALL](https://attack.mitre.org/software/S0213) is a backdoor used by [APT37](https://attack.mitre.org/groups/G0067) that has been used to target South Korean government and military organizations in 2017. It is typically dropped using a Hangul Word Processor (HWP) exploit.
