# S0214: HAPPYWORK

<a id="s0214"></a>

Type: malware  
ATT&CK: [S0214](https://attack.mitre.org/software/S0214)  

[HAPPYWORK](https://attack.mitre.org/software/S0214) is a downloader used by [APT37](https://attack.mitre.org/groups/G0067) to target South Korean government and financial victims in November 2016.
