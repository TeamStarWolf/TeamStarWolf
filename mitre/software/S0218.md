# S0218: SLOWDRIFT

<a id="s0218"></a>

Type: malware  
ATT&CK: [S0218](https://attack.mitre.org/software/S0218)  
Platforms: Windows  

[SLOWDRIFT](https://attack.mitre.org/software/S0218) is a backdoor used by [APT37](https://attack.mitre.org/groups/G0067) against academic and strategic victims in South Korea.
