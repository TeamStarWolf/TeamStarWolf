# S0220 — Chaos

<a id="s0220"></a>

**Type:** malware  
**ATT&CK:** [S0220](https://attack.mitre.org/software/S0220)  
**Platforms:** Linux  

[Chaos](https://attack.mitre.org/software/S0220) is Linux malware that compromises systems by brute force attacks against SSH services. Once installed, it provides a reverse shell to its controllers, triggered by unsolicited packets.
