# S0222 — CCBkdr

<a id="s0222"></a>

**Type:** malware  
**ATT&CK:** [S0222](https://attack.mitre.org/software/S0222)  
**Platforms:** Windows  

[CCBkdr](https://attack.mitre.org/software/S0222) is malware that was injected into a signed version of CCleaner and distributed from CCleaner's distribution website.
