# S0223 — POWERSTATS

<a id="s0223"></a>

**Type:** malware  
**ATT&CK:** [S0223](https://attack.mitre.org/software/S0223)  
**Platforms:** Windows  
**Aliases:** Powermud  

[POWERSTATS](https://attack.mitre.org/software/S0223) is a PowerShell-based first stage backdoor used by [MuddyWater](https://attack.mitre.org/groups/G0069).
