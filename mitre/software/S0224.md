# S0224: Havij

<a id="s0224"></a>

Type: tool  
ATT&CK: [S0224](https://attack.mitre.org/software/S0224)  

[Havij](https://attack.mitre.org/software/S0224) is an automatic SQL Injection tool distributed by the Iranian ITSecTeam security company. Havij has been used by penetration testers and adversaries.
