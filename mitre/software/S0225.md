# S0225 — sqlmap

<a id="s0225"></a>

**Type:** tool  
**ATT&CK:** [S0225](https://attack.mitre.org/software/S0225)  

[sqlmap](https://attack.mitre.org/software/S0225) is an open source penetration testing tool that can be used to automate the process of detecting and exploiting SQL injection flaws.
