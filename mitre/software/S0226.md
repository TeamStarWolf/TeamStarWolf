# S0226: Smoke Loader

<a id="s0226"></a>

Type: malware  
ATT&CK: [S0226](https://attack.mitre.org/software/S0226)  
Platforms: Windows  
Aliases: Dofoil  

[Smoke Loader](https://attack.mitre.org/software/S0226) is a malicious bot application that can be used to load other malware. [Smoke Loader](https://attack.mitre.org/software/S0226) has been seen in the wild since at least 2011 and has included a number of different payloads. It is notorious for its use of deception and self-protection. It also comes with several plug-ins.
