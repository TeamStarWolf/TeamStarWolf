# S0228: NanHaiShu

<a id="s0228"></a>

Type: malware  
ATT&CK: [S0228](https://attack.mitre.org/software/S0228)  
Platforms: Windows  

[NanHaiShu](https://attack.mitre.org/software/S0228) is a remote access tool and JScript backdoor used by [Leviathan](https://attack.mitre.org/groups/G0065). [NanHaiShu](https://attack.mitre.org/software/S0228) has been used to target government and private-sector organizations that have relations to the South China Sea dispute.
