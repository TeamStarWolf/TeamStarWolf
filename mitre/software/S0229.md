# S0229 — Orz

<a id="s0229"></a>

**Type:** malware  
**ATT&CK:** [S0229](https://attack.mitre.org/software/S0229)  
**Platforms:** Windows  
**Aliases:** AIRBREAK  

[Orz](https://attack.mitre.org/software/S0229) is a custom JavaScript backdoor used by [Leviathan](https://attack.mitre.org/groups/G0065). It was observed being used in 2014 as well as in August 2017 when it was dropped by Microsoft Publisher files.
