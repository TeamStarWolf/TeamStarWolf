# S0232: HOMEFRY

<a id="s0232"></a>

Type: malware  
ATT&CK: [S0232](https://attack.mitre.org/software/S0232)  
Platforms: Windows  

[HOMEFRY](https://attack.mitre.org/software/S0232) is a 64-bit Windows password dumper/cracker that has previously been used in conjunction with other [Leviathan](https://attack.mitre.org/groups/G0065) backdoors.

## Techniques used (3)

- [T1003: OS Credential Dumping](/mitre/techniques/T1003.md)
- [T1027.013: Encrypted/Encoded File](/mitre/techniques/T1027-013.md)
- [T1059.003: Windows Command Shell](/mitre/techniques/T1059-003.md)
