# S0239: Bankshot

<a id="s0239"></a>

Type: malware  
ATT&CK: [S0239](https://attack.mitre.org/software/S0239)  
Platforms: Windows  
Aliases: Trojan Manuscript  

[Bankshot](https://attack.mitre.org/software/S0239) is a remote access tool (RAT) that was first reported by the Department of Homeland Security in December of 2017. In 2018, [Lazarus Group](https://attack.mitre.org/groups/G0032) used the [Bankshot](https://attack.mitre.org/software/S0239) implant in attacks against the Turkish financial sector.
