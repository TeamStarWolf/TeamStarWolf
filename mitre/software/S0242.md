# S0242 — SynAck

<a id="s0242"></a>

**Type:** malware  
**ATT&CK:** [S0242](https://attack.mitre.org/software/S0242)  
**Platforms:** Windows  

[SynAck](https://attack.mitre.org/software/S0242) is variant of Trojan ransomware targeting mainly English-speaking users since at least fall 2017.
