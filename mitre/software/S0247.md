# S0247 — NavRAT

<a id="s0247"></a>

**Type:** malware  
**ATT&CK:** [S0247](https://attack.mitre.org/software/S0247)  
**Platforms:** Windows  

[NavRAT](https://attack.mitre.org/software/S0247) is a remote access tool designed to upload, download, and execute files. It has been observed in attacks targeting South Korea.
