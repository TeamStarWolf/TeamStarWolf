# S0248: yty

<a id="s0248"></a>

Type: malware  
ATT&CK: [S0248](https://attack.mitre.org/software/S0248)  
Platforms: Windows  

[yty](https://attack.mitre.org/software/S0248) is a modular, plugin-based malware framework. The components of the framework are written in a variety of programming languages.
