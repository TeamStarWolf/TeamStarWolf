# S0250 — Koadic

<a id="s0250"></a>

**Type:** tool  
**ATT&CK:** [S0250](https://attack.mitre.org/software/S0250)  
**Platforms:** Windows  

[Koadic](https://attack.mitre.org/software/S0250) is a Windows post-exploitation framework and penetration testing tool that is publicly available on GitHub. [Koadic](https://attack.mitre.org/software/S0250) has several options for staging payloads and creating implants, and performs most of its operations using Windows Script Host.
