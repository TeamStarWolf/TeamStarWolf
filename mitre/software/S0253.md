# S0253: RunningRAT

<a id="s0253"></a>

Type: malware  
ATT&CK: [S0253](https://attack.mitre.org/software/S0253)  
Platforms: Windows  

[RunningRAT](https://attack.mitre.org/software/S0253) is a remote access tool that appeared in operations surrounding the 2018 Pyeongchang Winter Olympics along with [Gold Dragon](https://attack.mitre.org/software/S0249) and [Brave Prince](https://attack.mitre.org/software/S0252).
