# S0254 — PLAINTEE

<a id="s0254"></a>

**Type:** malware  
**ATT&CK:** [S0254](https://attack.mitre.org/software/S0254)  
**Platforms:** Windows  

[PLAINTEE](https://attack.mitre.org/software/S0254) is a malware sample that has been used by [Rancor](https://attack.mitre.org/groups/G0075) in targeted attacks in Singapore and Cambodia.
