# S0255 — DDKONG

<a id="s0255"></a>

**Type:** malware  
**ATT&CK:** [S0255](https://attack.mitre.org/software/S0255)  

[DDKONG](https://attack.mitre.org/software/S0255) is a malware sample that was part of a campaign by [Rancor](https://attack.mitre.org/groups/G0075). [DDKONG](https://attack.mitre.org/software/S0255) was first seen used in February 2017.
