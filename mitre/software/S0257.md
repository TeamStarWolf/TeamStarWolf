# S0257 — VERMIN

<a id="s0257"></a>

**Type:** malware  
**ATT&CK:** [S0257](https://attack.mitre.org/software/S0257)  
**Platforms:** Windows  

[VERMIN](https://attack.mitre.org/software/S0257) is a remote access tool written in the Microsoft.NET framework. It is mostly composed of original code, but also has some open source code.
