# S0258: RGDoor

<a id="s0258"></a>

Type: malware  
ATT&CK: [S0258](https://attack.mitre.org/software/S0258)  
Platforms: Windows  

[RGDoor](https://attack.mitre.org/software/S0258) is a malicious Internet Information Services (IIS) backdoor developed in the C++ language. [RGDoor](https://attack.mitre.org/software/S0258) has been seen deployed on webservers belonging to the Middle East government organizations. [RGDoor](https://attack.mitre.org/software/S0258) provides backdoor access to compromised IIS servers.
