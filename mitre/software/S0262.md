# S0262 — QuasarRAT

<a id="s0262"></a>

**Type:** tool  
**ATT&CK:** [S0262](https://attack.mitre.org/software/S0262)  
**Platforms:** Windows  
**Aliases:** xRAT  

[QuasarRAT](https://attack.mitre.org/software/S0262) is an open-source, remote access tool that has been publicly available on GitHub since at least 2014. [QuasarRAT](https://attack.mitre.org/software/S0262) is developed in the C# language.
