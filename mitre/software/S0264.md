# S0264 — OopsIE

<a id="s0264"></a>

**Type:** malware  
**ATT&CK:** [S0264](https://attack.mitre.org/software/S0264)  
**Platforms:** Windows  

[OopsIE](https://attack.mitre.org/software/S0264) is a Trojan used by [OilRig](https://attack.mitre.org/groups/G0049) to remotely execute commands as well as upload/download files to/from victims.
