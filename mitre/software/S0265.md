# S0265: Kazuar

<a id="s0265"></a>

Type: malware  
ATT&CK: [S0265](https://attack.mitre.org/software/S0265)  
Platforms: Windows, macOS  

[Kazuar](https://attack.mitre.org/software/S0265) is a fully featured, multi-platform backdoor Trojan written using the Microsoft.NET framework.
