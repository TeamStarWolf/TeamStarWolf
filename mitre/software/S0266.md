# S0266 — TrickBot

<a id="s0266"></a>

**Type:** malware  
**ATT&CK:** [S0266](https://attack.mitre.org/software/S0266)  
**Platforms:** Windows  
**Aliases:** Totbrick, TSPY_TRICKLOAD  

[TrickBot](https://attack.mitre.org/software/S0266) is a Trojan spyware program written in C++ that first emerged in September 2016 as a possible successor to [Dyre](https://attack.mitre.org/software/S0024). [TrickBot](https://attack.mitre.org/software/S0266) was developed and initially used by [Wizard Spider](https://attack.mitre.org/groups/G0102) for targeting banking sites in North America, Australia, and throughout Europe; it has since been used against all sectors worldwide as part of "big game hunting" ransomware campaigns.
