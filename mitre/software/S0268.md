# S0268: Bisonal

<a id="s0268"></a>

Type: malware  
ATT&CK: [S0268](https://attack.mitre.org/software/S0268)  
Platforms: Windows  

[Bisonal](https://attack.mitre.org/software/S0268) is a remote access tool (RAT) that has been used by [Tonto Team](https://attack.mitre.org/groups/G0131) against public and private sector organizations in Russia, South Korea, and Japan since at least December 2010.
