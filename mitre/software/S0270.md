# S0270 — RogueRobin

<a id="s0270"></a>

**Type:** malware  
**ATT&CK:** [S0270](https://attack.mitre.org/software/S0270)  
**Platforms:** Windows  

[RogueRobin](https://attack.mitre.org/software/S0270) is a payload used by [DarkHydrus](https://attack.mitre.org/groups/G0079) that has been developed in PowerShell and C#.
