# S0273: Socksbot

<a id="s0273"></a>

Type: malware  
ATT&CK: [S0273](https://attack.mitre.org/software/S0273)  
Platforms: Windows  

[Socksbot](https://attack.mitre.org/software/S0273) is a backdoor that abuses Socket Secure (SOCKS) proxies.
