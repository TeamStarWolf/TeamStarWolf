# S0274: Calisto

<a id="s0274"></a>

Type: malware  
ATT&CK: [S0274](https://attack.mitre.org/software/S0274)  
Platforms: macOS  

[Calisto](https://attack.mitre.org/software/S0274) is a macOS Trojan that opens a backdoor on the compromised machine. [Calisto](https://attack.mitre.org/software/S0274) is believed to have first been developed in 2016.
