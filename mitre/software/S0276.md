# S0276: Keydnap

<a id="s0276"></a>

Type: malware  
ATT&CK: [S0276](https://attack.mitre.org/software/S0276)  
Platforms: macOS  
Aliases: OSX/Keydnap  

This piece of malware steals the content of the user's keychain while maintaining a permanent backdoor.
