# S0280: MirageFox

<a id="s0280"></a>

Type: malware  
ATT&CK: [S0280](https://attack.mitre.org/software/S0280)  
Platforms: Windows  

[MirageFox](https://attack.mitre.org/software/S0280) is a remote access tool used against Windows systems. It appears to be an upgraded version of a tool known as Mirage, which is a RAT believed to originate in 2012.
