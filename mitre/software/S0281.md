# S0281 — Dok

<a id="s0281"></a>

**Type:** malware  
**ATT&CK:** [S0281](https://attack.mitre.org/software/S0281)  
**Platforms:** macOS  
**Aliases:** Retefe  

[Dok](https://attack.mitre.org/software/S0281) is a Trojan application disguised as a.zip file that is able to collect user credentials and install a malicious proxy server to redirect a user's network traffic (i.e. [Adversary-in-the-Middle](https://attack.mitre.org/techniques/T1557)).
