# S0283: jRAT

<a id="s0283"></a>

Type: malware  
ATT&CK: [S0283](https://attack.mitre.org/software/S0283)  
Platforms: Linux, Windows, macOS, Android  
Aliases: JSocket, AlienSpy, Frutas, Sockrat, Unrecom, jFrutas, Adwind, jBiFrost, Trojan.Maljava  

[jRAT](https://attack.mitre.org/software/S0283) is a cross-platform, Java-based backdoor originally available for purchase in 2012. Variants of [jRAT](https://attack.mitre.org/software/S0283) have been distributed via a software-as-a-service platform, similar to an online subscription model.
