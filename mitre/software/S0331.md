# S0331 — Agent Tesla

<a id="s0331"></a>

**Type:** malware  
**ATT&CK:** [S0331](https://attack.mitre.org/software/S0331)  
**Platforms:** Windows  

[Agent Tesla](https://attack.mitre.org/software/S0331) is a spyware Trojan written for the.NET framework that has been observed since at least 2014.
