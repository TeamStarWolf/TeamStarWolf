# S0332 — Remcos

<a id="s0332"></a>

**Type:** tool  
**ATT&CK:** [S0332](https://attack.mitre.org/software/S0332)  
**Platforms:** Windows  

[Remcos](https://attack.mitre.org/software/S0332) is a closed-source tool that is marketed as a remote control and surveillance software by a company called Breaking Security. [Remcos](https://attack.mitre.org/software/S0332) has been observed being used in malware campaigns.
