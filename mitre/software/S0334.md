# S0334: DarkComet

<a id="s0334"></a>

Type: malware  
ATT&CK: [S0334](https://attack.mitre.org/software/S0334)  
Platforms: Windows  
Aliases: DarkKomet, Fynloski, Krademok, FYNLOS  

[DarkComet](https://attack.mitre.org/software/S0334) is a Windows remote administration tool and backdoor.
