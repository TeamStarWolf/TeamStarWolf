# S0335 — Carbon

<a id="s0335"></a>

**Type:** malware  
**ATT&CK:** [S0335](https://attack.mitre.org/software/S0335)  
**Platforms:** Windows  

[Carbon](https://attack.mitre.org/software/S0335) is a sophisticated, second-stage backdoor and framework that can be used to steal sensitive information from victims. [Carbon](https://attack.mitre.org/software/S0335) has been selectively used by [Turla](https://attack.mitre.org/groups/G0010) to target government and foreign affairs-related organizations in Central Asia.
