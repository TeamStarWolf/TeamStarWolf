# S0340: Octopus

<a id="s0340"></a>

Type: malware  
ATT&CK: [S0340](https://attack.mitre.org/software/S0340)  
Platforms: Windows  

[Octopus](https://attack.mitre.org/software/S0340) is a Windows Trojan written in the Delphi programming language that has been used by [Nomadic Octopus](https://attack.mitre.org/groups/G0133) to target government organizations in Central Asia since at least 2014.
