# S0341: Xbash

<a id="s0341"></a>

Type: malware  
ATT&CK: [S0341](https://attack.mitre.org/software/S0341)  
Platforms: Windows, Linux  

[Xbash](https://attack.mitre.org/software/S0341) is a malware family that has targeted Linux and Microsoft Windows servers. The malware has been tied to the Iron Group, a threat actor group known for previous ransomware attacks. [Xbash](https://attack.mitre.org/software/S0341) was developed in Python and then converted into a self-contained Linux ELF executable by using PyInstaller.
