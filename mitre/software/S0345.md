# S0345: Seasalt

<a id="s0345"></a>

Type: malware  
ATT&CK: [S0345](https://attack.mitre.org/software/S0345)  
Platforms: Windows  

[Seasalt](https://attack.mitre.org/software/S0345) is malware that has been linked to [APT1](https://attack.mitre.org/groups/G0006)'s 2010 operations. It shares some code similarities with [OceanSalt](https://attack.mitre.org/software/S0346).
