# S0346 — OceanSalt

<a id="s0346"></a>

**Type:** malware  
**ATT&CK:** [S0346](https://attack.mitre.org/software/S0346)  
**Platforms:** Windows  

[OceanSalt](https://attack.mitre.org/software/S0346) is a Trojan that was used in a campaign targeting victims in South Korea, United States, and Canada. [OceanSalt](https://attack.mitre.org/software/S0346) shares code similarity with [SpyNote RAT](https://attack.mitre.org/software/S0305), which has been linked to [APT1](https://attack.mitre.org/groups/G0006).
