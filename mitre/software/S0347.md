# S0347 — AuditCred

<a id="s0347"></a>

**Type:** malware  
**ATT&CK:** [S0347](https://attack.mitre.org/software/S0347)  
**Platforms:** Windows  
**Aliases:** Roptimizer  

[AuditCred](https://attack.mitre.org/software/S0347) is a malicious DLL that has been used by [Lazarus Group](https://attack.mitre.org/groups/G0032) during their 2018 attacks.
