# S0348: Cardinal RAT

<a id="s0348"></a>

Type: malware  
ATT&CK: [S0348](https://attack.mitre.org/software/S0348)  
Platforms: Windows  

[Cardinal RAT](https://attack.mitre.org/software/S0348) is a potentially low volume remote access trojan (RAT) observed since December 2015. [Cardinal RAT](https://attack.mitre.org/software/S0348) is notable for its unique utilization of uncompiled C# source code and the Microsoft Windows built-in csc.exe compiler.
