# S0349: LaZagne

<a id="s0349"></a>

Type: tool  
ATT&CK: [S0349](https://attack.mitre.org/software/S0349)  
Platforms: Linux, macOS, Windows  

[LaZagne](https://attack.mitre.org/software/S0349) is a post-exploitation, open-source tool used to recover stored passwords on a system. It has modules for Windows, Linux, and OSX, but is mainly focused on Windows systems. [LaZagne](https://attack.mitre.org/software/S0349) is publicly available on GitHub.
