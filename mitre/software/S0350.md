# S0350 — zwShell

<a id="s0350"></a>

**Type:** malware  
**ATT&CK:** [S0350](https://attack.mitre.org/software/S0350)  
**Platforms:** Windows  

[zwShell](https://attack.mitre.org/software/S0350) is a remote access tool (RAT) written in Delphi that has been seen in the wild since the spring of 2010 and used by threat actors during [Night Dragon](https://attack.mitre.org/campaigns/C0002).
