# S0351: Cannon

<a id="s0351"></a>

Type: malware  
ATT&CK: [S0351](https://attack.mitre.org/software/S0351)  
Platforms: Windows  

[Cannon](https://attack.mitre.org/software/S0351) is a Trojan with variants written in C# and Delphi. It was first observed in April 2018.
