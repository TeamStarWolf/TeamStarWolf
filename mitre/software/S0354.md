# S0354 — Denis

<a id="s0354"></a>

**Type:** malware  
**ATT&CK:** [S0354](https://attack.mitre.org/software/S0354)  
**Platforms:** Windows  

[Denis](https://attack.mitre.org/software/S0354) is a Windows backdoor and Trojan used by [APT32](https://attack.mitre.org/groups/G0050). [Denis](https://attack.mitre.org/software/S0354) shares several similarities to the [SOUNDBITE](https://attack.mitre.org/software/S0157) backdoor and has been used in conjunction with the [Goopy](https://attack.mitre.org/software/S0477) backdoor.
