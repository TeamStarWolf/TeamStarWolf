# S0357: Impacket

<a id="s0357"></a>

Type: tool  
ATT&CK: [S0357](https://attack.mitre.org/software/S0357)  
Platforms: Linux, macOS, Windows  

[Impacket](https://attack.mitre.org/software/S0357) is an open source collection of modules written in Python for programmatically constructing and manipulating network protocols. [Impacket](https://attack.mitre.org/software/S0357) contains several tools for remote service execution, Kerberos manipulation, Windows credential dumping, packet sniffing, and relay attacks.
