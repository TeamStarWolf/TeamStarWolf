# S0358: Ruler

<a id="s0358"></a>

Type: tool  
ATT&CK: [S0358](https://attack.mitre.org/software/S0358)  
Platforms: Windows, Office Suite  

[Ruler](https://attack.mitre.org/software/S0358) is a tool to abuse Microsoft Exchange services. It is publicly available on GitHub and the tool is executed via the command line. The creators of [Ruler](https://attack.mitre.org/software/S0358) have also released a defensive tool, NotRuler, to detect its usage.
