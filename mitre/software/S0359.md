# S0359 — Nltest

<a id="s0359"></a>

**Type:** tool  
**ATT&CK:** [S0359](https://attack.mitre.org/software/S0359)  
**Platforms:** Windows  

[Nltest](https://attack.mitre.org/software/S0359) is a Windows command-line utility used to list domain controllers and enumerate domain trusts.
