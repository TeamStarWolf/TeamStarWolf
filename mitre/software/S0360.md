# S0360 — BONDUPDATER

<a id="s0360"></a>

**Type:** malware  
**ATT&CK:** [S0360](https://attack.mitre.org/software/S0360)  
**Platforms:** Windows  

[BONDUPDATER](https://attack.mitre.org/software/S0360) is a PowerShell backdoor used by [OilRig](https://attack.mitre.org/groups/G0049). It was first observed in November 2017 during targeting of a Middle Eastern government organization, and an updated version was observed in August 2018 being used to target a government organization with spearphishing emails.
