# S0361 — Expand

<a id="s0361"></a>

**Type:** tool  
**ATT&CK:** [S0361](https://attack.mitre.org/software/S0361)  
**Platforms:** Windows  

[Expand](https://attack.mitre.org/software/S0361) is a Windows utility used to expand one or more compressed CAB files. It has been used by [BBSRAT](https://attack.mitre.org/software/S0127) to decompress a CAB file into executable content.
