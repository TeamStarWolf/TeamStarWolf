# S0362: Linux Rabbit

<a id="s0362"></a>

Type: malware  
ATT&CK: [S0362](https://attack.mitre.org/software/S0362)  
Platforms: Linux  

[Linux Rabbit](https://attack.mitre.org/software/S0362) is malware that targeted Linux servers and IoT devices in a campaign lasting from August to October 2018. It shares code with another strain of malware known as Rabbot. The goal of the campaign was to install cryptocurrency miners onto the targeted servers and devices.
