# S0366 — WannaCry

<a id="s0366"></a>

**Type:** malware  
**ATT&CK:** [S0366](https://attack.mitre.org/software/S0366)  
**Platforms:** Windows  
**Aliases:** WanaCry, WanaCrypt, WanaCrypt0r, WCry  

[WannaCry](https://attack.mitre.org/software/S0366) is ransomware that was first seen in a global attack during May 2017, which affected more than 150 countries. It contains worm-like features to spread itself across a computer network using the SMBv1 exploit EternalBlue.
