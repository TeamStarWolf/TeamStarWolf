# S0367: Emotet

<a id="s0367"></a>

Type: malware  
ATT&CK: [S0367](https://attack.mitre.org/software/S0367)  
Platforms: Windows  
Aliases: Geodo  

[Emotet](https://attack.mitre.org/software/S0367) is a modular malware variant which is primarily used as a downloader for other malware variants such as [TrickBot](https://attack.mitre.org/software/S0266) and [IcedID](https://attack.mitre.org/software/S0483). Emotet first emerged in June 2014, initially targeting the financial sector, and has expanded to multiple verticals over time.
