# S0369 — CoinTicker

<a id="s0369"></a>

**Type:** malware  
**ATT&CK:** [S0369](https://attack.mitre.org/software/S0369)  
**Platforms:** macOS  

[CoinTicker](https://attack.mitre.org/software/S0369) is a malicious application that poses as a cryptocurrency price ticker and installs components of the open source backdoors EvilOSX and EggShell.
