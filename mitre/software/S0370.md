# S0370 — SamSam

<a id="s0370"></a>

**Type:** malware  
**ATT&CK:** [S0370](https://attack.mitre.org/software/S0370)  
**Platforms:** Windows  
**Aliases:** Samas  

[SamSam](https://attack.mitre.org/software/S0370) is ransomware that appeared in early 2016. Unlike some ransomware, its variants have required operators to manually interact with the malware to execute some of its core components.
