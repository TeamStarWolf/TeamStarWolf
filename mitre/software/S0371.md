# S0371 — POWERTON

<a id="s0371"></a>

**Type:** malware  
**ATT&CK:** [S0371](https://attack.mitre.org/software/S0371)  
**Platforms:** Windows  

[POWERTON](https://attack.mitre.org/software/S0371) is a custom PowerShell backdoor first observed in 2018. It has typically been deployed as a late-stage backdoor by [APT33](https://attack.mitre.org/groups/G0064). At least two variants of the backdoor have been identified, with the later version containing improved functionality.
