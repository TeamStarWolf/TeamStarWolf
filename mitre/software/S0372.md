# S0372 — LockerGoga

<a id="s0372"></a>

**Type:** malware  
**ATT&CK:** [S0372](https://attack.mitre.org/software/S0372)  
**Platforms:** Windows  

[LockerGoga](https://attack.mitre.org/software/S0372) is ransomware that was first reported in January 2019, and has been tied to various attacks on European companies, including industrial and manufacturing firms.
