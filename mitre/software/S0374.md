# S0374 — SpeakUp

<a id="s0374"></a>

**Type:** malware  
**ATT&CK:** [S0374](https://attack.mitre.org/software/S0374)  
**Platforms:** Linux, macOS  

[SpeakUp](https://attack.mitre.org/software/S0374) is a Trojan backdoor that targets both Linux and OSX devices. It was first observed in January 2019.
