# S0376 — HOPLIGHT

<a id="s0376"></a>

**Type:** malware  
**ATT&CK:** [S0376](https://attack.mitre.org/software/S0376)  
**Platforms:** Windows  

[HOPLIGHT](https://attack.mitre.org/software/S0376) is a backdoor Trojan that has reportedly been used by the North Korean government.
