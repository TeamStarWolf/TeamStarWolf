# S0380 — StoneDrill

<a id="s0380"></a>

**Type:** malware  
**ATT&CK:** [S0380](https://attack.mitre.org/software/S0380)  
**Platforms:** Windows  
**Aliases:** DROPSHOT  

[StoneDrill](https://attack.mitre.org/software/S0380) is wiper malware discovered in destructive campaigns against both Middle Eastern and European targets in association with [APT33](https://attack.mitre.org/groups/G0064).
