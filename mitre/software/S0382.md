# S0382: ServHelper

<a id="s0382"></a>

Type: malware  
ATT&CK: [S0382](https://attack.mitre.org/software/S0382)  
Platforms: Windows  

[ServHelper](https://attack.mitre.org/software/S0382) is a backdoor first observed in late 2018. The backdoor is written in Delphi and is typically delivered as a DLL file.
