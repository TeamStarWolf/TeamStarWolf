# S0385 — njRAT

<a id="s0385"></a>

**Type:** malware  
**ATT&CK:** [S0385](https://attack.mitre.org/software/S0385)  
**Platforms:** Windows  
**Aliases:** Njw0rm, LV, Bladabindi  

[njRAT](https://attack.mitre.org/software/S0385) is a remote access tool (RAT) that was first observed in 2012. It has been used by threat actors in the Middle East.
