# S0387: KeyBoy

<a id="s0387"></a>

Type: malware  
ATT&CK: [S0387](https://attack.mitre.org/software/S0387)  
Platforms: Windows  

[KeyBoy](https://attack.mitre.org/software/S0387) is malware that has been used in targeted campaigns against members of the Tibetan Parliament in 2016.
