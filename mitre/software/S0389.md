# S0389: JCry

<a id="s0389"></a>

Type: malware  
ATT&CK: [S0389](https://attack.mitre.org/software/S0389)  

[JCry](https://attack.mitre.org/software/S0389) is ransomware written in Go. It was identified as apart of the #OpJerusalem 2019 campaign.
