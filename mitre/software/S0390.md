# S0390 — SQLRat

<a id="s0390"></a>

**Type:** malware  
**ATT&CK:** [S0390](https://attack.mitre.org/software/S0390)  

[SQLRat](https://attack.mitre.org/software/S0390) is malware that executes SQL scripts to avoid leaving traditional host artifacts. [FIN7](https://attack.mitre.org/groups/G0046) has been observed using it.
