# S0393 — PowerStallion

<a id="s0393"></a>

**Type:** malware  
**ATT&CK:** [S0393](https://attack.mitre.org/software/S0393)  
**Platforms:** Windows  

[PowerStallion](https://attack.mitre.org/software/S0393) is a lightweight [PowerShell](https://attack.mitre.org/techniques/T1059/001) backdoor used by [Turla](https://attack.mitre.org/groups/G0010), possibly as a recovery access tool to install other backdoors.
