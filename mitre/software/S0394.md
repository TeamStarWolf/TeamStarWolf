# S0394: HiddenWasp

<a id="s0394"></a>

Type: malware  
ATT&CK: [S0394](https://attack.mitre.org/software/S0394)  
Platforms: Linux  

[HiddenWasp](https://attack.mitre.org/software/S0394) is a Linux-based Trojan used to target systems for remote control. It comes in the form of a statically linked ELF binary with stdlibc++.
