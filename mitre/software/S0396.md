# S0396: EvilBunny

<a id="s0396"></a>

Type: malware  
ATT&CK: [S0396](https://attack.mitre.org/software/S0396)  
Platforms: Windows  

[EvilBunny](https://attack.mitre.org/software/S0396) is a C++ malware sample observed since 2011 that was designed to be a execution platform for Lua scripts.
