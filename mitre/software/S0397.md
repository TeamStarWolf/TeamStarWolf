# S0397: LoJax

<a id="s0397"></a>

Type: malware  
ATT&CK: [S0397](https://attack.mitre.org/software/S0397)  
Platforms: Windows  

[LoJax](https://attack.mitre.org/software/S0397) is a UEFI rootkit used by [APT28](https://attack.mitre.org/groups/G0007) to persist remote access software on targeted systems.
