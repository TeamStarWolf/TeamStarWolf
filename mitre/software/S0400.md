# S0400: RobbinHood

<a id="s0400"></a>

Type: malware  
ATT&CK: [S0400](https://attack.mitre.org/software/S0400)  
Platforms: Windows  

[RobbinHood](https://attack.mitre.org/software/S0400) is ransomware that was first observed being used in an attack against the Baltimore city government's computer network.
