# S0402: OSX/Shlayer

<a id="s0402"></a>

Type: malware  
ATT&CK: [S0402](https://attack.mitre.org/software/S0402)  
Platforms: macOS  
Aliases: Zshlayer, Crossrider  

[OSX/Shlayer](https://attack.mitre.org/software/S0402) is a Trojan designed to install adware on macOS that was first discovered in 2018.
