# S0404: esentutl

<a id="s0404"></a>

Type: tool  
ATT&CK: [S0404](https://attack.mitre.org/software/S0404)  
Platforms: Windows  
Aliases: esentutl.exe  

[esentutl](https://attack.mitre.org/software/S0404) is a command-line tool that provides database utilities for the Windows Extensible Storage Engine.
