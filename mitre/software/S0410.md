# S0410: Fysbis

<a id="s0410"></a>

Type: malware  
ATT&CK: [S0410](https://attack.mitre.org/software/S0410)  
Platforms: Linux  

[Fysbis](https://attack.mitre.org/software/S0410) is a Linux-based backdoor used by [APT28](https://attack.mitre.org/groups/G0007) that dates back to at least 2014.
