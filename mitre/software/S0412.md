# S0412 — ZxShell

<a id="s0412"></a>

**Type:** malware  
**ATT&CK:** [S0412](https://attack.mitre.org/software/S0412)  
**Platforms:** Windows  
**Aliases:** Sensocode  

[ZxShell](https://attack.mitre.org/software/S0412) is a remote administration tool and backdoor that can be downloaded from the Internet, particularly from Chinese hacker websites. It has been used since at least 2004.
