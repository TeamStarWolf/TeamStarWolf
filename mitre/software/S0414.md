# S0414 — BabyShark

<a id="s0414"></a>

**Type:** malware  
**ATT&CK:** [S0414](https://attack.mitre.org/software/S0414)  
**Platforms:** Windows  
**Aliases:** LATEOP  

[BabyShark](https://attack.mitre.org/software/S0414) is a Microsoft Visual Basic (VB) script-based malware family that is believed to be associated with several North Korean campaigns.
