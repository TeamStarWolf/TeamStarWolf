# S0415 — BOOSTWRITE

<a id="s0415"></a>

**Type:** malware  
**ATT&CK:** [S0415](https://attack.mitre.org/software/S0415)  
**Platforms:** Windows  

[BOOSTWRITE](https://attack.mitre.org/software/S0415) is a loader crafted to be launched via abuse of the DLL search order of applications used by [FIN7](https://attack.mitre.org/groups/G0046).
