# S0416 — RDFSNIFFER

<a id="s0416"></a>

**Type:** malware  
**ATT&CK:** [S0416](https://attack.mitre.org/software/S0416)  
**Platforms:** Windows  

[RDFSNIFFER](https://attack.mitre.org/software/S0416) is a module loaded by [BOOSTWRITE](https://attack.mitre.org/software/S0415) which allows an attacker to monitor and tamper with legitimate connections made via an application designed to provide visibility and system management capabilities to remote IT techs.
