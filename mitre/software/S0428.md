# S0428 — PoetRAT

<a id="s0428"></a>

**Type:** malware  
**ATT&CK:** [S0428](https://attack.mitre.org/software/S0428)  
**Platforms:** Windows  

[PoetRAT](https://attack.mitre.org/software/S0428) is a remote access trojan (RAT) that was first identified in April 2020. [PoetRAT](https://attack.mitre.org/software/S0428) has been used in multiple campaigns against the private and public sectors in Azerbaijan, including ICS and SCADA systems in the energy sector. The STIBNITE activity group has been observed using the malware. [PoetRAT](https://attack.mitre.org/software/S0428) derived its name from references in the code to poet William Shakespeare.
