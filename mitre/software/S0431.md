# S0431: HotCroissant

<a id="s0431"></a>

Type: malware  
ATT&CK: [S0431](https://attack.mitre.org/software/S0431)  
Platforms: Windows  

[HotCroissant](https://attack.mitre.org/software/S0431) is a remote access trojan (RAT) attributed by U.S. government entities to malicious North Korean government cyber activity, tracked collectively as HIDDEN COBRA. [HotCroissant](https://attack.mitre.org/software/S0431) shares numerous code similarities with [Rifdoor](https://attack.mitre.org/software/S0433).
