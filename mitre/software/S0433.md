# S0433: Rifdoor

<a id="s0433"></a>

Type: malware  
ATT&CK: [S0433](https://attack.mitre.org/software/S0433)  
Platforms: Windows  

[Rifdoor](https://attack.mitre.org/software/S0433) is a remote access trojan (RAT) that shares numerous code similarities with [HotCroissant](https://attack.mitre.org/software/S0431).
