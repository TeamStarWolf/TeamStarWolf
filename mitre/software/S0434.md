# S0434: Imminent Monitor

<a id="s0434"></a>

Type: tool  
ATT&CK: [S0434](https://attack.mitre.org/software/S0434)  
Platforms: Windows  

[Imminent Monitor](https://attack.mitre.org/software/S0434) was a commodity remote access tool (RAT) offered for sale from 2012 until 2019, when an operation was conducted to take down the Imminent Monitor infrastructure. Various cracked versions and variations of this RAT are still in circulation.
