# S0436 — TSCookie

<a id="s0436"></a>

**Type:** malware  
**ATT&CK:** [S0436](https://attack.mitre.org/software/S0436)  
**Platforms:** Windows  

[TSCookie](https://attack.mitre.org/software/S0436) is a remote access tool (RAT) that has been used by [BlackTech](https://attack.mitre.org/groups/G0098) in campaigns against Japanese targets.. [TSCookie](https://attack.mitre.org/software/S0436) has been referred to as [PLEAD](https://attack.mitre.org/software/S0435) though more recent reporting indicates a separation between the two.
