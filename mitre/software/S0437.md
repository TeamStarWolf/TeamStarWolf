# S0437 — Kivars

<a id="s0437"></a>

**Type:** malware  
**ATT&CK:** [S0437](https://attack.mitre.org/software/S0437)  
**Platforms:** Windows  

[Kivars](https://attack.mitre.org/software/S0437) is a modular remote access tool (RAT), derived from the Bifrost RAT, that was used by [BlackTech](https://attack.mitre.org/groups/G0098) in a 2010 campaign.
