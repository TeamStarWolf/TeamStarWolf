# S0438: Attor

<a id="s0438"></a>

Type: malware  
ATT&CK: [S0438](https://attack.mitre.org/software/S0438)  
Platforms: Windows  

[Attor](https://attack.mitre.org/software/S0438) is a Windows-based espionage platform that has been seen in use since 2013. [Attor](https://attack.mitre.org/software/S0438) has a loadable plugin architecture to customize functionality for specific targets.
