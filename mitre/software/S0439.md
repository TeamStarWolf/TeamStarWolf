# S0439 — Okrum

<a id="s0439"></a>

**Type:** malware  
**ATT&CK:** [S0439](https://attack.mitre.org/software/S0439)  
**Platforms:** Windows  

[Okrum](https://attack.mitre.org/software/S0439) is a Windows backdoor that has been seen in use since December 2016 with strong links to [Ke3chang](https://attack.mitre.org/groups/G0004).
