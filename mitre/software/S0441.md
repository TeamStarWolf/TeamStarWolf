# S0441: PowerShower

<a id="s0441"></a>

Type: malware  
ATT&CK: [S0441](https://attack.mitre.org/software/S0441)  
Platforms: Windows  

[PowerShower](https://attack.mitre.org/software/S0441) is a PowerShell backdoor used by [Inception](https://attack.mitre.org/groups/G0100) for initial reconnaissance and to download and execute second stage payloads.
