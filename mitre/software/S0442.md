# S0442 — VBShower

<a id="s0442"></a>

**Type:** malware  
**ATT&CK:** [S0442](https://attack.mitre.org/software/S0442)  
**Platforms:** Windows  

[VBShower](https://attack.mitre.org/software/S0442) is a backdoor that has been used by [Inception](https://attack.mitre.org/groups/G0100) since at least 2019. [VBShower](https://attack.mitre.org/software/S0442) has been used as a downloader for second stage payloads, including [PowerShower](https://attack.mitre.org/software/S0441).
