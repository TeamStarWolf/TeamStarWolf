# S0443 — MESSAGETAP

<a id="s0443"></a>

**Type:** malware  
**ATT&CK:** [S0443](https://attack.mitre.org/software/S0443)  
**Platforms:** Linux  

[MESSAGETAP](https://attack.mitre.org/software/S0443) is a data mining malware family deployed by [APT41](https://attack.mitre.org/groups/G0096) into telecommunications networks to monitor and save SMS traffic from specific phone numbers, IMSI numbers, or that contain specific keywords.
