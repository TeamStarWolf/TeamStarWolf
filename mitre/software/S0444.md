# S0444 — ShimRat

<a id="s0444"></a>

**Type:** malware  
**ATT&CK:** [S0444](https://attack.mitre.org/software/S0444)  
**Platforms:** Windows  

[ShimRat](https://attack.mitre.org/software/S0444) has been used by the suspected China-based adversary [Mofang](https://attack.mitre.org/groups/G0103) in campaigns targeting multiple countries and sectors including government, military, critical infrastructure, automobile, and weapons development. The name "[ShimRat](https://attack.mitre.org/software/S0444)" comes from the malware's extensive use of Windows Application Shimming to maintain persistence.
