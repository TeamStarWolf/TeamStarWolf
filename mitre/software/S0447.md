# S0447: Lokibot

<a id="s0447"></a>

Type: malware  
ATT&CK: [S0447](https://attack.mitre.org/software/S0447)  
Platforms: Windows  

[Lokibot](https://attack.mitre.org/software/S0447) is a widely distributed information stealer that was first reported in 2015. It is designed to steal sensitive information such as usernames, passwords, cryptocurrency wallets, and other credentials. [Lokibot](https://attack.mitre.org/software/S0447) can also create a backdoor into infected systems to allow an attacker to install additional payloads.
