# S0451 — LoudMiner

<a id="s0451"></a>

**Type:** malware  
**ATT&CK:** [S0451](https://attack.mitre.org/software/S0451)  
**Platforms:** macOS, Windows  

[LoudMiner](https://attack.mitre.org/software/S0451) is a cryptocurrency miner which uses virtualization software to siphon system resources. The miner has been bundled with pirated copies of Virtual Studio Technology (VST) for Windows and macOS.
