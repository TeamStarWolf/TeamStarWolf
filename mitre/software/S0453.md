# S0453: Pony

<a id="s0453"></a>

Type: malware  
ATT&CK: [S0453](https://attack.mitre.org/software/S0453)  
Platforms: Windows  

[Pony](https://attack.mitre.org/software/S0453) is a credential stealing malware, though has also been used among adversaries for its downloader capabilities. The source code for Pony Loader 1.0 and 2.0 were leaked online, leading to their use by various threat actors.
