# S0457: Netwalker

<a id="s0457"></a>

Type: malware  
ATT&CK: [S0457](https://attack.mitre.org/software/S0457)  
Platforms: Windows  

[Netwalker](https://attack.mitre.org/software/S0457) is fileless ransomware written in PowerShell and executed directly in memory.
