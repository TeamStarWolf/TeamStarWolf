# S0458 — Ramsay

<a id="s0458"></a>

**Type:** malware  
**ATT&CK:** [S0458](https://attack.mitre.org/software/S0458)  
**Platforms:** Windows  

[Ramsay](https://attack.mitre.org/software/S0458) is an information stealing malware framework designed to collect and exfiltrate sensitive documents, including from air-gapped systems. Researchers have identified overlaps between [Ramsay](https://attack.mitre.org/software/S0458) and the [Darkhotel](https://attack.mitre.org/groups/G0012)-associated Retro malware.
