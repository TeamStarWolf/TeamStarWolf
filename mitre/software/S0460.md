# S0460: Get2

<a id="s0460"></a>

Type: malware  
ATT&CK: [S0460](https://attack.mitre.org/software/S0460)  
Platforms: Windows  

[Get2](https://attack.mitre.org/software/S0460) is a downloader written in C++ that has been used by [TA505](https://attack.mitre.org/groups/G0092) to deliver [FlawedGrace](https://attack.mitre.org/software/S0383), [FlawedAmmyy](https://attack.mitre.org/software/S0381), Snatch and [SDBbot](https://attack.mitre.org/software/S0461).
