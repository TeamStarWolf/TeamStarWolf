# S0461: SDBbot

<a id="s0461"></a>

Type: malware  
ATT&CK: [S0461](https://attack.mitre.org/software/S0461)  
Platforms: Windows  

[SDBbot](https://attack.mitre.org/software/S0461) is a backdoor with installer and loader components that has been used by [TA505](https://attack.mitre.org/groups/G0092) since at least 2019.
