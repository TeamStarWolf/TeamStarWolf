# S0462 — CARROTBAT

<a id="s0462"></a>

**Type:** malware  
**ATT&CK:** [S0462](https://attack.mitre.org/software/S0462)  
**Platforms:** Windows  

[CARROTBAT](https://attack.mitre.org/software/S0462) is a customized dropper that has been in use since at least 2017. [CARROTBAT](https://attack.mitre.org/software/S0462) has been used to install [SYSCON](https://attack.mitre.org/software/S0464) and has infrastructure overlap with [KONNI](https://attack.mitre.org/software/S0356).
