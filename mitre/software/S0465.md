# S0465 — CARROTBALL

<a id="s0465"></a>

**Type:** tool  
**ATT&CK:** [S0465](https://attack.mitre.org/software/S0465)  
**Platforms:** Windows  

[CARROTBALL](https://attack.mitre.org/software/S0465) is an FTP downloader utility that has been in use since at least 2019. [CARROTBALL](https://attack.mitre.org/software/S0465) has been used as a downloader to install [SYSCON](https://attack.mitre.org/software/S0464).
