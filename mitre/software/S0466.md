# S0466 — WindTail

<a id="s0466"></a>

**Type:** malware  
**ATT&CK:** [S0466](https://attack.mitre.org/software/S0466)  
**Platforms:** macOS  

[WindTail](https://attack.mitre.org/software/S0466) is a macOS surveillance implant used by [Windshift](https://attack.mitre.org/groups/G0112). [WindTail](https://attack.mitre.org/software/S0466) shares code similarities with Hack Back aka KitM OSX.
