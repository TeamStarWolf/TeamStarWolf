# S0467 — TajMahal

<a id="s0467"></a>

**Type:** malware  
**ATT&CK:** [S0467](https://attack.mitre.org/software/S0467)  
**Platforms:** Windows  

[TajMahal](https://attack.mitre.org/software/S0467) is a multifunctional spying framework that has been in use since at least 2014. [TajMahal](https://attack.mitre.org/software/S0467) is comprised of two separate packages, named Tokyo and Yokohama, and can deploy up to 80 plugins.
