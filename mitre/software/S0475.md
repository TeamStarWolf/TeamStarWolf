# S0475 — BackConfig

<a id="s0475"></a>

**Type:** malware  
**ATT&CK:** [S0475](https://attack.mitre.org/software/S0475)  
**Platforms:** Windows  

[BackConfig](https://attack.mitre.org/software/S0475) is a custom Trojan with a flexible plugin architecture that has been used by [Patchwork](https://attack.mitre.org/groups/G0040).
