# S0476 — Valak

<a id="s0476"></a>

**Type:** malware  
**ATT&CK:** [S0476](https://attack.mitre.org/software/S0476)  
**Platforms:** Windows  

[Valak](https://attack.mitre.org/software/S0476) is a multi-stage modular malware that can function as a standalone information stealer or downloader, first observed in 2019 targeting enterprises in the US and Germany.
