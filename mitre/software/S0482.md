# S0482 — Bundlore

<a id="s0482"></a>

**Type:** malware  
**ATT&CK:** [S0482](https://attack.mitre.org/software/S0482)  
**Platforms:** macOS  
**Aliases:** OSX.Bundlore  

[Bundlore](https://attack.mitre.org/software/S0482) is adware written for macOS that has been in use since at least 2015. Though categorized as adware, [Bundlore](https://attack.mitre.org/software/S0482) has many features associated with more traditional backdoors.
