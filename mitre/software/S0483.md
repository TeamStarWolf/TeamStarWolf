# S0483 — IcedID

<a id="s0483"></a>

**Type:** malware  
**ATT&CK:** [S0483](https://attack.mitre.org/software/S0483)  
**Platforms:** Windows  

[IcedID](https://attack.mitre.org/software/S0483) is a modular banking malware designed to steal financial information that has been observed in the wild since at least 2017. [IcedID](https://attack.mitre.org/software/S0483) has been downloaded by [Emotet](https://attack.mitre.org/software/S0367) in multiple campaigns.
