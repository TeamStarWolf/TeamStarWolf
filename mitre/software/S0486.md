# S0486 — Bonadan

<a id="s0486"></a>

**Type:** malware  
**ATT&CK:** [S0486](https://attack.mitre.org/software/S0486)  
**Platforms:** Linux  

[Bonadan](https://attack.mitre.org/software/S0486) is a malicious version of OpenSSH which acts as a custom backdoor. [Bonadan](https://attack.mitre.org/software/S0486) has been active since at least 2018 and combines a new cryptocurrency-mining module with the same credential-stealing module used by the Onderon family of backdoors.
