# S0495 — RDAT

<a id="s0495"></a>

**Type:** malware  
**ATT&CK:** [S0495](https://attack.mitre.org/software/S0495)  
**Platforms:** Windows  

[RDAT](https://attack.mitre.org/software/S0495) is a backdoor used by the suspected Iranian threat group [OilRig](https://attack.mitre.org/groups/G0049). [RDAT](https://attack.mitre.org/software/S0495) was originally identified in 2017 and targeted companies in the telecommunications sector.
