# S0499 — Hancitor

<a id="s0499"></a>

**Type:** malware  
**ATT&CK:** [S0499](https://attack.mitre.org/software/S0499)  
**Platforms:** Windows  
**Aliases:** Chanitor  

[Hancitor](https://attack.mitre.org/software/S0499) is a downloader that has been used by [Pony](https://attack.mitre.org/software/S0453) and other information stealing malware.
