# S0502 — Drovorub

<a id="s0502"></a>

**Type:** malware  
**ATT&CK:** [S0502](https://attack.mitre.org/software/S0502)  
**Platforms:** Linux  

[Drovorub](https://attack.mitre.org/software/S0502) is a Linux malware toolset comprised of an agent, client, server, and kernel modules, that has been used by [APT28](https://attack.mitre.org/groups/G0007).
