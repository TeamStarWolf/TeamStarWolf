# S0503 — FrameworkPOS

<a id="s0503"></a>

**Type:** malware  
**ATT&CK:** [S0503](https://attack.mitre.org/software/S0503)  
**Aliases:** Trinity  

[FrameworkPOS](https://attack.mitre.org/software/S0503) is a point of sale (POS) malware used by [FIN6](https://attack.mitre.org/groups/G0037) to steal payment card data from sytems that run physical POS devices.
