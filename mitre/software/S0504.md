# S0504 — Anchor

<a id="s0504"></a>

**Type:** malware  
**ATT&CK:** [S0504](https://attack.mitre.org/software/S0504)  
**Platforms:** Linux, Windows  
**Aliases:** Anchor_DNS  

[Anchor](https://attack.mitre.org/software/S0504) is one of a family of backdoor malware that has been used in conjunction with [TrickBot](https://attack.mitre.org/software/S0266) on selected high profile targets since at least 2018.
