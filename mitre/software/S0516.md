# S0516: SoreFang

<a id="s0516"></a>

Type: malware  
ATT&CK: [S0516](https://attack.mitre.org/software/S0516)  
Platforms: Windows  

[SoreFang](https://attack.mitre.org/software/S0516) is first stage downloader used by [APT29](https://attack.mitre.org/groups/G0016) for exfiltration and to load other malware.
