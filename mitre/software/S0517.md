# S0517 — Pillowmint

<a id="s0517"></a>

**Type:** malware  
**ATT&CK:** [S0517](https://attack.mitre.org/software/S0517)  
**Platforms:** Windows  

[Pillowmint](https://attack.mitre.org/software/S0517) is a point-of-sale malware used by [FIN7](https://attack.mitre.org/groups/G0046) designed to capture credit card information.
