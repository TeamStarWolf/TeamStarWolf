# S0518 — PolyglotDuke

<a id="s0518"></a>

**Type:** malware  
**ATT&CK:** [S0518](https://attack.mitre.org/software/S0518)  
**Platforms:** Windows  

[PolyglotDuke](https://attack.mitre.org/software/S0518) is a downloader that has been used by [APT29](https://attack.mitre.org/groups/G0016) since at least 2013. [PolyglotDuke](https://attack.mitre.org/software/S0518) has been used to drop [MiniDuke](https://attack.mitre.org/software/S0051).
