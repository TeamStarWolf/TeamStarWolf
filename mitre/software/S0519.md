# S0519: SYNful Knock

<a id="s0519"></a>

Type: malware  
ATT&CK: [S0519](https://attack.mitre.org/software/S0519)  
Platforms: Network Devices  

[SYNful Knock](https://attack.mitre.org/software/S0519) is a stealthy modification of the operating system of network devices that can be used to maintain persistence within a victim's network and provide new capabilities to the adversary.
