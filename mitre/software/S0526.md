# S0526: KGH_SPY

<a id="s0526"></a>

Type: malware  
ATT&CK: [S0526](https://attack.mitre.org/software/S0526)  
Platforms: Windows  

[KGH_SPY](https://attack.mitre.org/software/S0526) is a modular suite of tools used by [Kimsuky](https://attack.mitre.org/groups/G0094) for reconnaissance, information stealing, and backdoor capabilities. [KGH_SPY](https://attack.mitre.org/software/S0526) derived its name from PDB paths and internal names found in samples containing "KGH".
