# S0527: CSPY Downloader

<a id="s0527"></a>

Type: tool  
ATT&CK: [S0527](https://attack.mitre.org/software/S0527)  
Platforms: Windows  

[CSPY Downloader](https://attack.mitre.org/software/S0527) is a tool designed to evade analysis and download additional payloads used by [Kimsuky](https://attack.mitre.org/groups/G0094).
