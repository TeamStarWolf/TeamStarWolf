# S0528 — Javali

<a id="s0528"></a>

**Type:** malware  
**ATT&CK:** [S0528](https://attack.mitre.org/software/S0528)  
**Platforms:** Windows  

[Javali](https://attack.mitre.org/software/S0528) is a banking trojan that has targeted Portuguese and Spanish-speaking countries since 2017, primarily focusing on customers of financial institutions in Brazil and Mexico.
