# S0530: Melcoz

<a id="s0530"></a>

Type: malware  
ATT&CK: [S0530](https://attack.mitre.org/software/S0530)  
Platforms: Windows  

[Melcoz](https://attack.mitre.org/software/S0530) is a banking trojan family built from the open source tool Remote Access PC. [Melcoz](https://attack.mitre.org/software/S0530) was first observed in attacks in Brazil and since 2018 has spread to Chile, Mexico, Spain, and Portugal.
