# S0531 — Grandoreiro

<a id="s0531"></a>

**Type:** malware  
**ATT&CK:** [S0531](https://attack.mitre.org/software/S0531)  
**Platforms:** Windows  

[Grandoreiro](https://attack.mitre.org/software/S0531) is a banking trojan written in Delphi that was first observed in 2016 and uses a Malware-as-a-Service (MaaS) business model. [Grandoreiro](https://attack.mitre.org/software/S0531) has confirmed victims in Brazil, Mexico, Portugal, and Spain.
