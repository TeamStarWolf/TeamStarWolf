# S0532 — Lucifer

<a id="s0532"></a>

**Type:** malware  
**ATT&CK:** [S0532](https://attack.mitre.org/software/S0532)  
**Platforms:** Windows  

[Lucifer](https://attack.mitre.org/software/S0532) is a crypto miner and DDoS hybrid malware that leverages well-known exploits to spread laterally on Windows platforms.
