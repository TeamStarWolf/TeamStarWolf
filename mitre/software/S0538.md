# S0538 — Crutch

<a id="s0538"></a>

**Type:** malware  
**ATT&CK:** [S0538](https://attack.mitre.org/software/S0538)  
**Platforms:** Windows  

[Crutch](https://attack.mitre.org/software/S0538) is a backdoor designed for document theft that has been used by [Turla](https://attack.mitre.org/groups/G0010) since at least 2015.
