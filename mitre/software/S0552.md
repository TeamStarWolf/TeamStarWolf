# S0552: AdFind

<a id="s0552"></a>

Type: tool  
ATT&CK: [S0552](https://attack.mitre.org/software/S0552)  
Platforms: Windows  

[AdFind](https://attack.mitre.org/software/S0552) is a free command-line query tool that can be used for gathering information from Active Directory.
