# S0553 — MoleNet

<a id="s0553"></a>

**Type:** malware  
**ATT&CK:** [S0553](https://attack.mitre.org/software/S0553)  
**Platforms:** Windows  

[MoleNet](https://attack.mitre.org/software/S0553) is a downloader tool with backdoor capabilities that has been observed in use since at least 2019.
