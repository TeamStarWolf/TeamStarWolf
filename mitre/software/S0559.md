# S0559 — SUNBURST

<a id="s0559"></a>

**Type:** malware  
**ATT&CK:** [S0559](https://attack.mitre.org/software/S0559)  
**Platforms:** Windows  
**Aliases:** Solorigate  

[SUNBURST](https://attack.mitre.org/software/S0559) is a trojanized DLL designed to fit within the SolarWinds Orion software update framework. It was used by [APT29](https://attack.mitre.org/groups/G0016) since at least February 2020.
