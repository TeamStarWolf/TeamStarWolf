# S0560 — TEARDROP

<a id="s0560"></a>

**Type:** malware  
**ATT&CK:** [S0560](https://attack.mitre.org/software/S0560)  
**Platforms:** Windows  

[TEARDROP](https://attack.mitre.org/software/S0560) is a memory-only dropper that was discovered on some victim machines during investigations related to the [SolarWinds Compromise](https://attack.mitre.org/campaigns/C0024). It was likely used by [APT29](https://attack.mitre.org/groups/G0016) since at least May 2020.
