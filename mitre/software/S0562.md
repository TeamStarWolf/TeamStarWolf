# S0562 — SUNSPOT

<a id="s0562"></a>

**Type:** malware  
**ATT&CK:** [S0562](https://attack.mitre.org/software/S0562)  
**Platforms:** Windows  

[SUNSPOT](https://attack.mitre.org/software/S0562) is an implant that injected the [SUNBURST](https://attack.mitre.org/software/S0559) backdoor into the SolarWinds Orion software update framework. It was used by [APT29](https://attack.mitre.org/groups/G0016) since at least February 2020.
