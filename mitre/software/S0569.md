# S0569 — Explosive

<a id="s0569"></a>

**Type:** malware  
**ATT&CK:** [S0569](https://attack.mitre.org/software/S0569)  
**Platforms:** Windows  

[Explosive](https://attack.mitre.org/software/S0569) is a custom-made remote access tool used by the group [Volatile Cedar](https://attack.mitre.org/groups/G0123). It was first identified in the wild in 2015.
