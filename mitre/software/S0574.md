# S0574 — BendyBear

<a id="s0574"></a>

**Type:** malware  
**ATT&CK:** [S0574](https://attack.mitre.org/software/S0574)  
**Platforms:** Windows  

[BendyBear](https://attack.mitre.org/software/S0574) is an x64 shellcode for a stage-zero implant designed to download malware from a C2 server. First discovered in August 2020, [BendyBear](https://attack.mitre.org/software/S0574) shares a variety of features with [Waterbear](https://attack.mitre.org/software/S0579), malware previously attributed to the Chinese cyber espionage group [BlackTech](https://attack.mitre.org/groups/G0098).
