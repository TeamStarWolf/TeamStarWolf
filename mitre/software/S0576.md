# S0576 — MegaCortex

<a id="s0576"></a>

**Type:** malware  
**ATT&CK:** [S0576](https://attack.mitre.org/software/S0576)  
**Platforms:** Windows  

[MegaCortex](https://attack.mitre.org/software/S0576) is ransomware that first appeared in May 2019. [MegaCortex](https://attack.mitre.org/software/S0576) has mainly targeted industrial organizations.
