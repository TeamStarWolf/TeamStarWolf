# S0579 — Waterbear

<a id="s0579"></a>

**Type:** malware  
**ATT&CK:** [S0579](https://attack.mitre.org/software/S0579)  
**Platforms:** Windows  

[Waterbear](https://attack.mitre.org/software/S0579) is modular malware attributed to [BlackTech](https://attack.mitre.org/groups/G0098) that has been used primarily for lateral movement, decrypting, and triggering payloads and is capable of hiding network behaviors.
