# S0581: IronNetInjector

<a id="s0581"></a>

Type: tool  
ATT&CK: [S0581](https://attack.mitre.org/software/S0581)  
Platforms: Windows  

[IronNetInjector](https://attack.mitre.org/software/S0581) is a [Turla](https://attack.mitre.org/groups/G0010) toolchain that utilizes scripts from the open-source IronPython implementation of Python with a.NET injector to drop one or more payloads including [ComRAT](https://attack.mitre.org/software/S0126).
