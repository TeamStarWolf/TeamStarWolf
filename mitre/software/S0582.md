# S0582: LookBack

<a id="s0582"></a>

Type: malware  
ATT&CK: [S0582](https://attack.mitre.org/software/S0582)  
Platforms: Windows  

[LookBack](https://attack.mitre.org/software/S0582) is a remote access trojan written in C++ that was used against at least three US utility companies in July 2019. The TALONITE activity group has been observed using [LookBack](https://attack.mitre.org/software/S0582).
