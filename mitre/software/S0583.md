# S0583: Pysa

<a id="s0583"></a>

Type: malware  
ATT&CK: [S0583](https://attack.mitre.org/software/S0583)  
Platforms: Windows  
Aliases: Mespinoza  

[Pysa](https://attack.mitre.org/software/S0583) is a ransomware that was first used in October 2018 and has been seen to target particularly high-value finance, government and healthcare organizations.
