# S0585: Kerrdown

<a id="s0585"></a>

Type: malware  
ATT&CK: [S0585](https://attack.mitre.org/software/S0585)  
Platforms: Windows  

[Kerrdown](https://attack.mitre.org/software/S0585) is a custom downloader that has been used by [APT32](https://attack.mitre.org/groups/G0050) since at least 2018 to install spyware from a server on the victim's network.
