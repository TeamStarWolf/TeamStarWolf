# S0586 — TAINTEDSCRIBE

<a id="s0586"></a>

**Type:** malware  
**ATT&CK:** [S0586](https://attack.mitre.org/software/S0586)  
**Platforms:** Windows  

[TAINTEDSCRIBE](https://attack.mitre.org/software/S0586) is a fully-featured beaconing implant integrated with command modules used by [Lazarus Group](https://attack.mitre.org/groups/G0032). It was first reported in May 2020.
