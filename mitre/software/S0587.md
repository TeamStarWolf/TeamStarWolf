# S0587: Penquin

<a id="s0587"></a>

Type: malware  
ATT&CK: [S0587](https://attack.mitre.org/software/S0587)  
Platforms: Linux  
Aliases: Penquin 2.0, Penquin_x64  

[Penquin](https://attack.mitre.org/software/S0587) is a remote access trojan (RAT) with multiple versions used by [Turla](https://attack.mitre.org/groups/G0010) to target Linux systems since at least 2014.
