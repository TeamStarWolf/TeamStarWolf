# S0590 — NBTscan

<a id="s0590"></a>

**Type:** tool  
**ATT&CK:** [S0590](https://attack.mitre.org/software/S0590)  
**Platforms:** Windows, Linux, macOS  

[NBTscan](https://attack.mitre.org/software/S0590) is an open source tool that has been used by state groups to conduct internal reconnaissance within a compromised network.
