# S0592: RemoteUtilities

<a id="s0592"></a>

Type: tool  
ATT&CK: [S0592](https://attack.mitre.org/software/S0592)  
Platforms: Windows  

[RemoteUtilities](https://attack.mitre.org/software/S0592) is a legitimate remote administration tool that has been used by [MuddyWater](https://attack.mitre.org/groups/G0069) since at least 2021 for execution on target machines.
