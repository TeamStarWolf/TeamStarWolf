# S0598 — P.A.S. Webshell

<a id="s0598"></a>

**Type:** malware  
**ATT&CK:** [S0598](https://attack.mitre.org/software/S0598)  
**Platforms:** Linux, Windows  
**Aliases:** Fobushell  

[P.A.S. Webshell](https://attack.mitre.org/software/S0598) is a publicly available multifunctional PHP webshell in use since at least 2016 that provides remote access and execution on target web servers.
