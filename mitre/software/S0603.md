# S0603: Stuxnet

<a id="s0603"></a>

Type: malware  
ATT&CK: [S0603](https://attack.mitre.org/software/S0603)  
Platforms: Windows  
Aliases: W32.Stuxnet  

[Stuxnet](https://attack.mitre.org/software/S0603) was the first publicly reported malware to specifically target industrial control systems devices. [Stuxnet](https://attack.mitre.org/software/S0603) is a large and complex malware that utilized multiple behaviors, including numerous zero-day vulnerabilities, a sophisticated Windows rootkit, and network infection routines. [Stuxnet](https://attack.mitre.org/software/S0603) was discovered in 2010, with some components being used as early as November 2008.
