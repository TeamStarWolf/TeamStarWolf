# S0606: Bad Rabbit

<a id="s0606"></a>

Type: malware  
ATT&CK: [S0606](https://attack.mitre.org/software/S0606)  
Platforms: Windows  
Aliases: Win32/Diskcoder.D  

[Bad Rabbit](https://attack.mitre.org/software/S0606) is a self-propagating ransomware that affected the Ukrainian transportation sector in 2017. [Bad Rabbit](https://attack.mitre.org/software/S0606) has also targeted organizations and consumers in Russia.
