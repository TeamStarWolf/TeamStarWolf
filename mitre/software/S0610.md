# S0610: SideTwist

<a id="s0610"></a>

Type: malware  
ATT&CK: [S0610](https://attack.mitre.org/software/S0610)  
Platforms: Windows  

[SideTwist](https://attack.mitre.org/software/S0610) is a C-based backdoor that has been used by [OilRig](https://attack.mitre.org/groups/G0049) since at least 2021.
