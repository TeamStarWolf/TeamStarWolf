# S0613: PS1

<a id="s0613"></a>

Type: malware  
ATT&CK: [S0613](https://attack.mitre.org/software/S0613)  
Platforms: Windows  

[PS1](https://attack.mitre.org/software/S0613) is a loader that was used to deploy 64-bit backdoors in the [CostaRicto](https://attack.mitre.org/groups/G0132) campaign.
