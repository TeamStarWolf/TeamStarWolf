# S0614 — CostaBricks

<a id="s0614"></a>

**Type:** malware  
**ATT&CK:** [S0614](https://attack.mitre.org/software/S0614)  
**Platforms:** Windows  

[CostaBricks](https://attack.mitre.org/software/S0614) is a loader that was used to deploy 32-bit backdoors in the [CostaRicto](https://attack.mitre.org/groups/G0132) campaign.
