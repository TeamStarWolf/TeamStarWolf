# S0617 — HELLOKITTY

<a id="s0617"></a>

**Type:** malware  
**ATT&CK:** [S0617](https://attack.mitre.org/software/S0617)  
**Platforms:** Windows  

[HELLOKITTY](https://attack.mitre.org/software/S0617) is a ransomware written in C++ that shares similar code structure and functionality with [DEATHRANSOM](https://attack.mitre.org/software/S0616) and [FIVEHANDS](https://attack.mitre.org/software/S0618). [HELLOKITTY](https://attack.mitre.org/software/S0617) has been used since at least 2020, targets have included a Polish video game developer and a Brazilian electric power company.
