# S0618: FIVEHANDS

<a id="s0618"></a>

Type: malware  
ATT&CK: [S0618](https://attack.mitre.org/software/S0618)  
Platforms: Windows  

[FIVEHANDS](https://attack.mitre.org/software/S0618) is a customized version of [DEATHRANSOM](https://attack.mitre.org/software/S0616) ransomware written in C++. [FIVEHANDS](https://attack.mitre.org/software/S0618) has been used since at least 2021, including in Ransomware-as-a-Service (RaaS) campaigns, sometimes along with [SombRAT](https://attack.mitre.org/software/S0615).
