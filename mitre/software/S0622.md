# S0622: AppleSeed

<a id="s0622"></a>

Type: malware  
ATT&CK: [S0622](https://attack.mitre.org/software/S0622)  
Platforms: Windows, Android  

[AppleSeed](https://attack.mitre.org/software/S0622) is a backdoor that has been used by [Kimsuky](https://attack.mitre.org/groups/G0094) to target South Korean government, academic, and commercial targets since at least 2021.
