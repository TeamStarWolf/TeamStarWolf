# S0623: Siloscape

<a id="s0623"></a>

Type: malware  
ATT&CK: [S0623](https://attack.mitre.org/software/S0623)  
Platforms: Windows, Containers  

[Siloscape](https://attack.mitre.org/software/S0623) is malware that targets Kubernetes clusters through Windows containers. [Siloscape](https://attack.mitre.org/software/S0623) was first observed in March 2021.
