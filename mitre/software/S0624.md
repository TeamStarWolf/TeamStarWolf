# S0624 — Ecipekac

<a id="s0624"></a>

**Type:** malware  
**ATT&CK:** [S0624](https://attack.mitre.org/software/S0624)  
**Platforms:** Windows  
**Aliases:** HEAVYHAND, SigLoader, DESLoader  

[Ecipekac](https://attack.mitre.org/software/S0624) is a multi-layer loader that has been used by [menuPass](https://attack.mitre.org/groups/G0045) since at least 2019 including use as a loader for [P8RAT](https://attack.mitre.org/software/S0626), [SodaMaster](https://attack.mitre.org/software/S0627), and [FYAnti](https://attack.mitre.org/software/S0628).
