# S0625: Cuba

<a id="s0625"></a>

Type: malware  
ATT&CK: [S0625](https://attack.mitre.org/software/S0625)  
Platforms: Windows  

[Cuba](https://attack.mitre.org/software/S0625) is a Windows-based ransomware family that has been used against financial institutions, technology, and logistics organizations in North and South America as well as Europe since at least December 2019.
