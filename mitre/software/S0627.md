# S0627: SodaMaster

<a id="s0627"></a>

Type: malware  
ATT&CK: [S0627](https://attack.mitre.org/software/S0627)  
Platforms: Windows  
Aliases: DARKTOWN, dfls, DelfsCake  

[SodaMaster](https://attack.mitre.org/software/S0627) is a fileless malware used by [menuPass](https://attack.mitre.org/groups/G0045) to download and execute payloads since at least 2020.
