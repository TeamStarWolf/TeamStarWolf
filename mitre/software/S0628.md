# S0628 — FYAnti

<a id="s0628"></a>

**Type:** malware  
**ATT&CK:** [S0628](https://attack.mitre.org/software/S0628)  
**Platforms:** Windows  
**Aliases:** DILLJUICE stage2  

[FYAnti](https://attack.mitre.org/software/S0628) is a loader that has been used by [menuPass](https://attack.mitre.org/groups/G0045) since at least 2020, including to deploy [QuasarRAT](https://attack.mitre.org/software/S0262).
