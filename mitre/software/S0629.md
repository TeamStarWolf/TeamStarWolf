# S0629 — RainyDay

<a id="s0629"></a>

**Type:** malware  
**ATT&CK:** [S0629](https://attack.mitre.org/software/S0629)  
**Platforms:** Windows  

[RainyDay](https://attack.mitre.org/software/S0629) is a backdoor tool that has been used by [Naikon](https://attack.mitre.org/groups/G0019) since at least 2020.
