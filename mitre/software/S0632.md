# S0632: GrimAgent

<a id="s0632"></a>

Type: malware  
ATT&CK: [S0632](https://attack.mitre.org/software/S0632)  
Platforms: Windows  

[GrimAgent](https://attack.mitre.org/software/S0632) is a backdoor that has been used before the deployment of [Ryuk](https://attack.mitre.org/software/S0446) ransomware since at least 2020; it is likely used by [FIN6](https://attack.mitre.org/groups/G0037) and [Wizard Spider](https://attack.mitre.org/groups/G0102).
