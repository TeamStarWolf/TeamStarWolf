# S0633 — Sliver

<a id="s0633"></a>

**Type:** tool  
**ATT&CK:** [S0633](https://attack.mitre.org/software/S0633)  
**Platforms:** Windows, Linux, macOS  

[Sliver](https://attack.mitre.org/software/S0633) is an open source, cross-platform, red team command and control (C2) framework written in Golang. [Sliver](https://attack.mitre.org/software/S0633) includes its own package manager, "armory," for staging and downloading additional tools and payloads to the primary C2 framework.
