# S0635 — BoomBox

<a id="s0635"></a>

**Type:** malware  
**ATT&CK:** [S0635](https://attack.mitre.org/software/S0635)  
**Platforms:** Windows  

[BoomBox](https://attack.mitre.org/software/S0635) is a downloader responsible for executing next stage components that has been used by [APT29](https://attack.mitre.org/groups/G0016) since at least 2021.
