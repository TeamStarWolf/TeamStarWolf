# S0638: Babuk

<a id="s0638"></a>

Type: malware  
ATT&CK: [S0638](https://attack.mitre.org/software/S0638)  
Platforms: Windows, Linux  
Aliases: Babyk, Vasa Locker  

[Babuk](https://attack.mitre.org/software/S0638) is a Ransomware-as-a-service (RaaS) malware that has been used since at least 2021. The operators of [Babuk](https://attack.mitre.org/software/S0638) employ a "Big Game Hunting" approach to targeting major enterprises and operate a leak site to post stolen data as part of their extortion scheme.
