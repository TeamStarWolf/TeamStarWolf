# S0640 — Avaddon

<a id="s0640"></a>

**Type:** malware  
**ATT&CK:** [S0640](https://attack.mitre.org/software/S0640)  
**Platforms:** Windows  

[Avaddon](https://attack.mitre.org/software/S0640) is ransomware written in C++ that has been offered as Ransomware-as-a-Service (RaaS) since at least June 2020.
