# S0642 — BADFLICK

<a id="s0642"></a>

**Type:** malware  
**ATT&CK:** [S0642](https://attack.mitre.org/software/S0642)  
**Platforms:** Windows  

[BADFLICK](https://attack.mitre.org/software/S0642) is a backdoor used by [Leviathan](https://attack.mitre.org/groups/G0065) in spearphishing campaigns first reported in 2018 that targeted the U.S. engineering and maritime industries.
