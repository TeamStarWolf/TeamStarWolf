# S0644 — ObliqueRAT

<a id="s0644"></a>

**Type:** malware  
**ATT&CK:** [S0644](https://attack.mitre.org/software/S0644)  
**Platforms:** Windows  

[ObliqueRAT](https://attack.mitre.org/software/S0644) is a remote access trojan, similar to [Crimson](https://attack.mitre.org/software/S0115), that has been in use by [Transparent Tribe](https://attack.mitre.org/groups/G0134) since at least 2020.
