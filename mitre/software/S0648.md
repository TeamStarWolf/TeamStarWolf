# S0648: JSS Loader

<a id="s0648"></a>

Type: malware  
ATT&CK: [S0648](https://attack.mitre.org/software/S0648)  
Platforms: Windows  

[JSS Loader](https://attack.mitre.org/software/S0648) is Remote Access Trojan (RAT) with.NET and C++ variants that has been used by [FIN7](https://attack.mitre.org/groups/G0046) since at least 2020.
