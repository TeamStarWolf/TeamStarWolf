# S0649: SMOKEDHAM

<a id="s0649"></a>

Type: malware  
ATT&CK: [S0649](https://attack.mitre.org/software/S0649)  
Platforms: Windows  

[SMOKEDHAM](https://attack.mitre.org/software/S0649) is a Powershell-based.NET backdoor that was first reported in May 2021; it has been used by at least one ransomware-as-a-service affiliate.
