# S0652: MarkiRAT

<a id="s0652"></a>

Type: malware  
ATT&CK: [S0652](https://attack.mitre.org/software/S0652)  
Platforms: Windows  

[MarkiRAT](https://attack.mitre.org/software/S0652) is a remote access Trojan (RAT) compiled with Visual Studio that has been used by [Ferocious Kitten](https://attack.mitre.org/groups/G0137) since at least 2015.
