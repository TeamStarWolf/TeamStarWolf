# S0657: BLUELIGHT

<a id="s0657"></a>

Type: malware  
ATT&CK: [S0657](https://attack.mitre.org/software/S0657)  
Platforms: Windows  

[BLUELIGHT](https://attack.mitre.org/software/S0657) is a remote access Trojan used by [APT37](https://attack.mitre.org/groups/G0067) that was first observed in early 2021.
