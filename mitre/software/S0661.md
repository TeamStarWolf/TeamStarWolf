# S0661: FoggyWeb

<a id="s0661"></a>

Type: malware  
ATT&CK: [S0661](https://attack.mitre.org/software/S0661)  
Platforms: Windows  

[FoggyWeb](https://attack.mitre.org/software/S0661) is a passive and highly-targeted backdoor capable of remotely exfiltrating sensitive information from a compromised Active Directory Federated Services (AD FS) server. It has been used by [APT29](https://attack.mitre.org/groups/G0016) since at least early April 2021.
