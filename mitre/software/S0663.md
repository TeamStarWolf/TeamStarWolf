# S0663 — SysUpdate

<a id="s0663"></a>

**Type:** malware  
**ATT&CK:** [S0663](https://attack.mitre.org/software/S0663)  
**Platforms:** Windows, Linux  
**Aliases:** HyperSSL, Soldier, FOCUSFJORD  

[SysUpdate](https://attack.mitre.org/software/S0663) is a backdoor written in C++ that has been used by [Threat Group-3390](https://attack.mitre.org/groups/G0027) since at least 2020.
