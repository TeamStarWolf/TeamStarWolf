# S0664 — Pandora

<a id="s0664"></a>

**Type:** malware  
**ATT&CK:** [S0664](https://attack.mitre.org/software/S0664)  
**Platforms:** Windows  

[Pandora](https://attack.mitre.org/software/S0664) is a multistage kernel rootkit with backdoor functionality that has been in use by [Threat Group-3390](https://attack.mitre.org/groups/G0027) since at least 2020.
