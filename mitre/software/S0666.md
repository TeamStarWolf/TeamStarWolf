# S0666 — Gelsemium

<a id="s0666"></a>

**Type:** malware  
**ATT&CK:** [S0666](https://attack.mitre.org/software/S0666)  
**Platforms:** Windows  
**Aliases:** Gelsevirine, Gelsenicine, Gelsemine  

[Gelsemium](https://attack.mitre.org/software/S0666) is a modular malware comprised of a dropper (Gelsemine), a loader (Gelsenicine), and main (Gelsevirine) plug-ins written using the Microsoft Foundation Class (MFC) framework. [Gelsemium](https://attack.mitre.org/software/S0666) has been used by the Gelsemium group since at least 2014.
