# S0668 — TinyTurla

<a id="s0668"></a>

**Type:** malware  
**ATT&CK:** [S0668](https://attack.mitre.org/software/S0668)  
**Platforms:** Windows  

[TinyTurla](https://attack.mitre.org/software/S0668) is a backdoor that has been used by [Turla](https://attack.mitre.org/groups/G0010) against targets in the US, Germany, and Afghanistan since at least 2020.
