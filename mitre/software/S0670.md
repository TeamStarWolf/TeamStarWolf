# S0670 — WarzoneRAT

<a id="s0670"></a>

**Type:** malware  
**ATT&CK:** [S0670](https://attack.mitre.org/software/S0670)  
**Platforms:** Windows  
**Aliases:** Warzone, Ave Maria  

[WarzoneRAT](https://attack.mitre.org/software/S0670) is a malware-as-a-service remote access tool (RAT) written in C++ that has been publicly available for purchase since at least late 2018.
