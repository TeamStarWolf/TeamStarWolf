# S0672: Zox

<a id="s0672"></a>

Type: malware  
ATT&CK: [S0672](https://attack.mitre.org/software/S0672)  
Platforms: Windows  
Aliases: Gresim, ZoxRPC, ZoxPNG  

[Zox](https://attack.mitre.org/software/S0672) is a remote access tool that has been used by [Axiom](https://attack.mitre.org/groups/G0001) since at least 2008.
