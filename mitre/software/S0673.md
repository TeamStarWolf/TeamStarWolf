# S0673: DarkWatchman

<a id="s0673"></a>

Type: malware  
ATT&CK: [S0673](https://attack.mitre.org/software/S0673)  
Platforms: Windows  

[DarkWatchman](https://attack.mitre.org/software/S0673) is a lightweight JavaScript-based remote access tool (RAT) that avoids file operations; it was first observed in November 2021.
