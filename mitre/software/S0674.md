# S0674 — CharmPower

<a id="s0674"></a>

**Type:** malware  
**ATT&CK:** [S0674](https://attack.mitre.org/software/S0674)  
**Platforms:** Windows  

[CharmPower](https://attack.mitre.org/software/S0674) is a PowerShell-based, modular backdoor that has been used by [Magic Hound](https://attack.mitre.org/groups/G0059) since at least 2022.
