# S0679: Ferocious

<a id="s0679"></a>

Type: malware  
ATT&CK: [S0679](https://attack.mitre.org/software/S0679)  
Platforms: Windows  

[Ferocious](https://attack.mitre.org/software/S0679) is a first stage implant composed of VBS and PowerShell scripts that has been used by [WIRTE](https://attack.mitre.org/groups/G0090) since at least 2021.
