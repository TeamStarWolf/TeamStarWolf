# S0680: LitePower

<a id="s0680"></a>

Type: malware  
ATT&CK: [S0680](https://attack.mitre.org/software/S0680)  
Platforms: Windows  

[LitePower](https://attack.mitre.org/software/S0680) is a downloader and second stage malware that has been used by [WIRTE](https://attack.mitre.org/groups/G0090) since at least 2021.
