# S0681: Lizar

<a id="s0681"></a>

Type: malware  
ATT&CK: [S0681](https://attack.mitre.org/software/S0681)  
Platforms: Windows  
Aliases: Tirion, Icebot, DiceLoader  

[Lizar](https://attack.mitre.org/software/S0681) is a modular remote access tool written using the.NET Framework that shares structural similarities to [Carbanak](https://attack.mitre.org/software/S0030). It has likely been used by [FIN7](https://attack.mitre.org/groups/G0046) since at least February 2021.
