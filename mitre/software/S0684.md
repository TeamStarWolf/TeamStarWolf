# S0684: ROADTools

<a id="s0684"></a>

Type: tool  
ATT&CK: [S0684](https://attack.mitre.org/software/S0684)  
Platforms: Identity Provider  

[ROADTools](https://attack.mitre.org/software/S0684) is a framework for enumerating Azure Active Directory environments. The tool is written in Python and publicly available on GitHub.
