# S0685 — PowerPunch

<a id="s0685"></a>

**Type:** malware  
**ATT&CK:** [S0685](https://attack.mitre.org/software/S0685)  
**Platforms:** Windows  

[PowerPunch](https://attack.mitre.org/software/S0685) is a lightweight downloader that has been used by [Gamaredon Group](https://attack.mitre.org/groups/G0047) since at least 2021.
