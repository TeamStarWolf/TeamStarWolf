# S0686: QuietSieve

<a id="s0686"></a>

Type: malware  
ATT&CK: [S0686](https://attack.mitre.org/software/S0686)  
Platforms: Windows  

[QuietSieve](https://attack.mitre.org/software/S0686) is an information stealer that has been used by [Gamaredon Group](https://attack.mitre.org/groups/G0047) since at least 2021.
