# S0687 — Cyclops Blink

<a id="s0687"></a>

**Type:** malware  
**ATT&CK:** [S0687](https://attack.mitre.org/software/S0687)  
**Platforms:** Network Devices  

[Cyclops Blink](https://attack.mitre.org/software/S0687) is a modular malware that has been used in widespread campaigns by [Sandworm Team](https://attack.mitre.org/groups/G0034) since at least 2019 to target Small/Home Office (SOHO) network devices, including WatchGuard and Asus. [Cyclops Blink](https://attack.mitre.org/software/S0687) is assessed to be a replacement for [VPNFilter](https://attack.mitre.org/software/S1010), a similar platform targeting network devices.
