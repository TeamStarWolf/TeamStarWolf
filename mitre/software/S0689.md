# S0689: WhisperGate

<a id="s0689"></a>

Type: malware  
ATT&CK: [S0689](https://attack.mitre.org/software/S0689)  
Platforms: Windows  

[WhisperGate](https://attack.mitre.org/software/S0689) is a multi-stage wiper designed to look like ransomware that has been used against multiple government, non-profit, and information technology organizations in Ukraine since at least January 2022.
