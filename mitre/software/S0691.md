# S0691 — Neoichor

<a id="s0691"></a>

**Type:** malware  
**ATT&CK:** [S0691](https://attack.mitre.org/software/S0691)  
**Platforms:** Windows  

[Neoichor](https://attack.mitre.org/software/S0691) is C2 malware used by [Ke3chang](https://attack.mitre.org/groups/G0004) since at least 2019; similar malware families used by the group include Leeson and Numbldea.
