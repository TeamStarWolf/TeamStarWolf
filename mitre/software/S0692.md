# S0692 — SILENTTRINITY

<a id="s0692"></a>

**Type:** tool  
**ATT&CK:** [S0692](https://attack.mitre.org/software/S0692)  
**Platforms:** Windows  

[SILENTTRINITY](https://attack.mitre.org/software/S0692) is an open source remote administration and post-exploitation framework primarily written in Python that includes stagers written in Powershell, C, and Boo. [SILENTTRINITY](https://attack.mitre.org/software/S0692) was used in a 2019 campaign against Croatian government agencies by unidentified cyber actors.
