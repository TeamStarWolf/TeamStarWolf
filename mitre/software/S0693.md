# S0693: CaddyWiper

<a id="s0693"></a>

Type: malware  
ATT&CK: [S0693](https://attack.mitre.org/software/S0693)  
Platforms: Windows  

[CaddyWiper](https://attack.mitre.org/software/S0693) is a destructive data wiper that has been used in attacks against organizations in Ukraine since at least March 2022.
