# S0695: Donut

<a id="s0695"></a>

Type: tool  
ATT&CK: [S0695](https://attack.mitre.org/software/S0695)  
Platforms: Windows  

[Donut](https://attack.mitre.org/software/S0695) is an open source framework used to generate position-independent shellcode. [Donut](https://attack.mitre.org/software/S0695) generated code has been used by multiple threat actors to inject and load malicious payloads into memory.
