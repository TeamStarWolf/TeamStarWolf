# S0698 — HermeticWizard

<a id="s0698"></a>

**Type:** malware  
**ATT&CK:** [S0698](https://attack.mitre.org/software/S0698)  
**Platforms:** Windows  

[HermeticWizard](https://attack.mitre.org/software/S0698) is a worm that has been used to spread [HermeticWiper](https://attack.mitre.org/software/S0697) in attacks against organizations in Ukraine since at least 2022.
