# S0699: Mythic

<a id="s0699"></a>

Type: tool  
ATT&CK: [S0699](https://attack.mitre.org/software/S0699)  
Platforms: Windows, Linux, macOS  

[Mythic](https://attack.mitre.org/software/S0699) is an open source, cross-platform post-exploitation/command and control platform. [Mythic](https://attack.mitre.org/software/S0699) is designed to "plug-n-play" with various agents and communication channels. Deployed [Mythic](https://attack.mitre.org/software/S0699) C2 servers have been observed as part of potentially malicious infrastructure.
