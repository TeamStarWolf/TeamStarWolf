# S1012 — PowerLess

<a id="s1012"></a>

**Type:** malware  
**ATT&CK:** [S1012](https://attack.mitre.org/software/S1012)  
**Platforms:** Windows  

[PowerLess](https://attack.mitre.org/software/S1012) is a PowerShell-based modular backdoor that has been used by [Magic Hound](https://attack.mitre.org/groups/G0059) since at least 2022.
