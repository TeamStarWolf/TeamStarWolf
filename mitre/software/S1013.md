# S1013 — ZxxZ

<a id="s1013"></a>

**Type:** malware  
**ATT&CK:** [S1013](https://attack.mitre.org/software/S1013)  
**Platforms:** Windows  

[ZxxZ](https://attack.mitre.org/software/S1013) is a trojan written in Visual C++ that has been used by [BITTER](https://attack.mitre.org/groups/G1002) since at least August 2021, including against Bangladeshi government personnel.
