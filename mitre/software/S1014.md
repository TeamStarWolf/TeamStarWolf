# S1014: DanBot

<a id="s1014"></a>

Type: malware  
ATT&CK: [S1014](https://attack.mitre.org/software/S1014)  
Platforms: Windows  

[DanBot](https://attack.mitre.org/software/S1014) is a first-stage remote access Trojan written in C# that has been used by [HEXANE](https://attack.mitre.org/groups/G1001) since at least 2018.
