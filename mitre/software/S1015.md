# S1015 — Milan

<a id="s1015"></a>

**Type:** malware  
**ATT&CK:** [S1015](https://attack.mitre.org/software/S1015)  
**Platforms:** Windows  
**Aliases:** James  

[Milan](https://attack.mitre.org/software/S1015) is a backdoor implant based on [DanBot](https://attack.mitre.org/software/S1014) that was written in Visual C++ and.NET. [Milan](https://attack.mitre.org/software/S1015) has been used by [HEXANE](https://attack.mitre.org/groups/G1001) since at least June 2020.
