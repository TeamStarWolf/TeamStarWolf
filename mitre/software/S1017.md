# S1017: OutSteel

<a id="s1017"></a>

Type: malware  
ATT&CK: [S1017](https://attack.mitre.org/software/S1017)  
Platforms: Windows  

[OutSteel](https://attack.mitre.org/software/S1017) is a file uploader and document stealer developed with the scripting language AutoIT that has been used by [Saint Bear](https://attack.mitre.org/groups/G1031) since at least March 2021.
