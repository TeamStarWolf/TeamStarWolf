# S1018 — Saint Bot

<a id="s1018"></a>

**Type:** malware  
**ATT&CK:** [S1018](https://attack.mitre.org/software/S1018)  
**Platforms:** Windows  

[Saint Bot](https://attack.mitre.org/software/S1018) is a.NET downloader that has been used by [Saint Bear](https://attack.mitre.org/groups/G1031) since at least March 2021.
