# S1019: Shark

<a id="s1019"></a>

Type: malware  
ATT&CK: [S1019](https://attack.mitre.org/software/S1019)  
Platforms: Windows  

[Shark](https://attack.mitre.org/software/S1019) is a backdoor malware written in C# and.NET that is an updated version of [Milan](https://attack.mitre.org/software/S1015); it has been used by [HEXANE](https://attack.mitre.org/groups/G1001) since at least July 2021.
