# S1020: Kevin

<a id="s1020"></a>

Type: malware  
ATT&CK: [S1020](https://attack.mitre.org/software/S1020)  
Platforms: Windows  

[Kevin](https://attack.mitre.org/software/S1020) is a backdoor implant written in C++ that has been used by [HEXANE](https://attack.mitre.org/groups/G1001) since at least June 2020, including in operations against organizations in Tunisia.
