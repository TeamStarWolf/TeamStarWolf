# S1021 — DnsSystem

<a id="s1021"></a>

**Type:** malware  
**ATT&CK:** [S1021](https://attack.mitre.org/software/S1021)  
**Platforms:** Windows  

[DnsSystem](https://attack.mitre.org/software/S1021) is a.NET based DNS backdoor, which is a customized version of the open source tool DIG.net, that has been used by [HEXANE](https://attack.mitre.org/groups/G1001) since at least June 2022.
