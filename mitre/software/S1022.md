# S1022 — IceApple

<a id="s1022"></a>

**Type:** malware  
**ATT&CK:** [S1022](https://attack.mitre.org/software/S1022)  
**Platforms:** Windows  

[IceApple](https://attack.mitre.org/software/S1022) is a modular Internet Information Services (IIS) post-exploitation framework, that has been used since at least 2021 against the technology, academic, and government sectors.
