# S1027 — Heyoka Backdoor

<a id="s1027"></a>

**Type:** malware  
**ATT&CK:** [S1027](https://attack.mitre.org/software/S1027)  
**Platforms:** Windows  

[Heyoka Backdoor](https://attack.mitre.org/software/S1027) is a custom backdoor--based on the Heyoka open source exfiltration tool--that has been used by [Aoqin Dragon](https://attack.mitre.org/groups/G1007) since at least 2013.
