# S1028 — Action RAT

<a id="s1028"></a>

**Type:** malware  
**ATT&CK:** [S1028](https://attack.mitre.org/software/S1028)  
**Platforms:** Windows  

[Action RAT](https://attack.mitre.org/software/S1028) is a remote access tool written in Delphi that has been used by [SideCopy](https://attack.mitre.org/groups/G1008) since at least December 2021 against Indian and Afghani government personnel.
