# S1029 — AuTo Stealer

<a id="s1029"></a>

**Type:** malware  
**ATT&CK:** [S1029](https://attack.mitre.org/software/S1029)  
**Platforms:** Windows  

[AuTo Stealer](https://attack.mitre.org/software/S1029) is malware written in C++ has been used by [SideCopy](https://attack.mitre.org/groups/G1008) since at least December 2021 to target government agencies and personnel in India and Afghanistan.
