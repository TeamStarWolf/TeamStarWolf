# S1034 — StrifeWater

<a id="s1034"></a>

**Type:** malware  
**ATT&CK:** [S1034](https://attack.mitre.org/software/S1034)  
**Platforms:** Windows  

[StrifeWater](https://attack.mitre.org/software/S1034) is a remote-access tool that has been used by [Moses Staff](https://attack.mitre.org/groups/G1009) in the initial stages of their attacks since at least November 2021.
