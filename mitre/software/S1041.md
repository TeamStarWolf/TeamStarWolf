# S1041: Chinoxy

<a id="s1041"></a>

Type: malware  
ATT&CK: [S1041](https://attack.mitre.org/software/S1041)  
Platforms: Windows  

[Chinoxy](https://attack.mitre.org/software/S1041) is a backdoor that has been used since at least November 2018, during the [FunnyDream](https://attack.mitre.org/campaigns/C0007) campaign, to gain persistence and drop additional payloads. According to security researchers, [Chinoxy](https://attack.mitre.org/software/S1041) has been used by Chinese-speaking threat actors.
