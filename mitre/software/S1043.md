# S1043: ccf32

<a id="s1043"></a>

Type: malware  
ATT&CK: [S1043](https://attack.mitre.org/software/S1043)  
Platforms: Windows  

[ccf32](https://attack.mitre.org/software/S1043) is data collection malware that has been used since at least February 2019, most notably during the [FunnyDream](https://attack.mitre.org/campaigns/C0007) campaign; there is also a similar x64 version.
