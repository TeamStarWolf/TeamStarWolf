# S1044 — FunnyDream

<a id="s1044"></a>

**Type:** malware  
**ATT&CK:** [S1044](https://attack.mitre.org/software/S1044)  
**Platforms:** Windows  

[FunnyDream](https://attack.mitre.org/software/S1044) is a backdoor with multiple components that was used during the [FunnyDream](https://attack.mitre.org/campaigns/C0007) campaign since at least 2019, primarily for execution and exfiltration.
