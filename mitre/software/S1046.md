# S1046 — PowGoop

<a id="s1046"></a>

**Type:** malware  
**ATT&CK:** [S1046](https://attack.mitre.org/software/S1046)  
**Platforms:** Windows  

[PowGoop](https://attack.mitre.org/software/S1046) is a loader that consists of a DLL loader and a PowerShell-based downloader; it has been used by [MuddyWater](https://attack.mitre.org/groups/G0069) as their main loader.
