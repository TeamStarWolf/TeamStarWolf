# S1048 — macOS.OSAMiner

<a id="s1048"></a>

**Type:** malware  
**ATT&CK:** [S1048](https://attack.mitre.org/software/S1048)  
**Platforms:** macOS  

[macOS.OSAMiner](https://attack.mitre.org/software/S1048) is a Monero mining trojan that was first observed in 2018; security researchers assessed [macOS.OSAMiner](https://attack.mitre.org/software/S1048) may have been circulating since at least 2015. [macOS.OSAMiner](https://attack.mitre.org/software/S1048) is known for embedding one run-only AppleScript into another, which helped the malware evade full analysis for five years due to a lack of Apple event (AEVT) analysis tools.
