# S1050 — PcShare

<a id="s1050"></a>

**Type:** tool  
**ATT&CK:** [S1050](https://attack.mitre.org/software/S1050)  
**Platforms:** Windows  

[PcShare](https://attack.mitre.org/software/S1050) is an open source remote access tool that has been modified and used by Chinese threat actors, most notably during the FunnyDream campaign since late 2018.
