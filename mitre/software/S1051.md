# S1051: KEYPLUG

<a id="s1051"></a>

Type: malware  
ATT&CK: [S1051](https://attack.mitre.org/software/S1051)  
Platforms: Linux, Windows  
Aliases: KEYPLUG.LINUX  

[KEYPLUG](https://attack.mitre.org/software/S1051) is a modular backdoor written in C++, with Windows and Linux variants, that has been used by [APT41](https://attack.mitre.org/groups/G0096) since at least June 2021.
