# S1059 — metaMain

<a id="s1059"></a>

**Type:** malware  
**ATT&CK:** [S1059](https://attack.mitre.org/software/S1059)  
**Platforms:** Windows  

[metaMain](https://attack.mitre.org/software/S1059) is a backdoor used by [Metador](https://attack.mitre.org/groups/G1013) to maintain long-term access to compromised machines; it has also been used to decrypt [Mafalda](https://attack.mitre.org/software/S1060) into memory.
