# S1065 — Woody RAT

<a id="s1065"></a>

**Type:** malware  
**ATT&CK:** [S1065](https://attack.mitre.org/software/S1065)  
**Platforms:** Windows  

[Woody RAT](https://attack.mitre.org/software/S1065) is a remote access trojan (RAT) that has been used since at least August 2021 against Russian organizations.
