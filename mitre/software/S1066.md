# S1066: DarkTortilla

<a id="s1066"></a>

Type: malware  
ATT&CK: [S1066](https://attack.mitre.org/software/S1066)  
Platforms: Windows  

[DarkTortilla](https://attack.mitre.org/software/S1066) is a highly configurable.NET-based crypter that has been possibly active since at least August 2015. [DarkTortilla](https://attack.mitre.org/software/S1066) has been used to deliver popular information stealers, RATs, and payloads such as [Agent Tesla](https://attack.mitre.org/software/S0331), AsyncRat, [NanoCore](https://attack.mitre.org/software/S0336), RedLine, [Cobalt Strike](https://attack.mitre.org/software/S0154), and Metasploit.
