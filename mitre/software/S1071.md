# S1071: Rubeus

<a id="s1071"></a>

Type: tool  
ATT&CK: [S1071](https://attack.mitre.org/software/S1071)  
Platforms: Windows  

[Rubeus](https://attack.mitre.org/software/S1071) is a C# toolset designed for raw Kerberos interaction that has been used since at least 2020, including in ransomware operations.
