# S1075: KOPILUWAK

<a id="s1075"></a>

Type: malware  
ATT&CK: [S1075](https://attack.mitre.org/software/S1075)  
Platforms: Windows  

[KOPILUWAK](https://attack.mitre.org/software/S1075) is a JavaScript-based reconnaissance tool that has been used for victim profiling and C2 since at least 2017.
