# S1076 — QUIETCANARY

<a id="s1076"></a>

**Type:** malware  
**ATT&CK:** [S1076](https://attack.mitre.org/software/S1076)  
**Platforms:** Windows  
**Aliases:** Tunnus  

[QUIETCANARY](https://attack.mitre.org/software/S1076) is a backdoor tool written in.NET that has been used since at least 2022 to gather and exfiltrate data from victim networks.
