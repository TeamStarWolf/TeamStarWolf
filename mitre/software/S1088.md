# S1088 — Disco

<a id="s1088"></a>

**Type:** malware  
**ATT&CK:** [S1088](https://attack.mitre.org/software/S1088)  
**Platforms:** Windows  

[Disco](https://attack.mitre.org/software/S1088) is a custom implant that has been used by [MoustachedBouncer](https://attack.mitre.org/groups/G1019) since at least 2020 including in campaigns using targeted malicious content injection for initial access and command and control.
