# S1089: SharpDisco

<a id="s1089"></a>

Type: malware  
ATT&CK: [S1089](https://attack.mitre.org/software/S1089)  
Platforms: Windows  

[SharpDisco](https://attack.mitre.org/software/S1089) is a dropper developed in C# that has been used by [MoustachedBouncer](https://attack.mitre.org/groups/G1019) since at least 2020 to load malicious plugins.
