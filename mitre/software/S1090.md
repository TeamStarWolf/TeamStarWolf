# S1090: NightClub

<a id="s1090"></a>

Type: malware  
ATT&CK: [S1090](https://attack.mitre.org/software/S1090)  
Platforms: Windows  

[NightClub](https://attack.mitre.org/software/S1090) is a modular implant written in C++ that has been used by [MoustachedBouncer](https://attack.mitre.org/groups/G1019) since at least 2014.
