# S1099 — Samurai

<a id="s1099"></a>

**Type:** malware  
**ATT&CK:** [S1099](https://attack.mitre.org/software/S1099)  
**Platforms:** Windows  

[Samurai](https://attack.mitre.org/software/S1099) is a passive backdoor that has been used by [ToddyCat](https://attack.mitre.org/groups/G1022) since at least 2020. [Samurai](https://attack.mitre.org/software/S1099) allows arbitrary C# code execution and is used with multiple modules for remote administration and lateral movement.
