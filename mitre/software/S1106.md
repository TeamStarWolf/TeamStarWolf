# S1106 — NGLite

<a id="s1106"></a>

**Type:** malware  
**ATT&CK:** [S1106](https://attack.mitre.org/software/S1106)  
**Platforms:** Windows  

[NGLite](https://attack.mitre.org/software/S1106) is a backdoor Trojan that is only capable of running commands received through its C2 channel. While the capabilities are standard for a backdoor, NGLite uses a novel C2 channel that leverages a decentralized network based on the legitimate NKN to communicate between the backdoor and the actors.
