# S1108: PULSECHECK

<a id="s1108"></a>

Type: malware  
ATT&CK: [S1108](https://attack.mitre.org/software/S1108)  
Platforms: Network Devices, Linux  

[PULSECHECK](https://attack.mitre.org/software/S1108) is a web shell written in Perl that was used by [APT5](https://attack.mitre.org/groups/G1023) as early as 2020 including against Pulse Secure VPNs at US Defense Industrial Base (DIB) companies.
