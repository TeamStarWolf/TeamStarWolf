# S1109: PACEMAKER

<a id="s1109"></a>

Type: malware  
ATT&CK: [S1109](https://attack.mitre.org/software/S1109)  
Platforms: Network Devices, Linux  

[PACEMAKER](https://attack.mitre.org/software/S1109) is a credential stealer that was used by [APT5](https://attack.mitre.org/groups/G1023) as early as 2020 including activity against US Defense Industrial Base (DIB) companies.
