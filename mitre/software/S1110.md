# S1110 — SLIGHTPULSE

<a id="s1110"></a>

**Type:** malware  
**ATT&CK:** [S1110](https://attack.mitre.org/software/S1110)  
**Platforms:** Network Devices, Linux  

[SLIGHTPULSE](https://attack.mitre.org/software/S1110) is a web shell that was used by [APT5](https://attack.mitre.org/groups/G1023) as early as 2020 including against Pulse Secure VPNs at US Defense Industrial Base (DIB) entities.
