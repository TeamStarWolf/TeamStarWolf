# S1112: STEADYPULSE

<a id="s1112"></a>

Type: malware  
ATT&CK: [S1112](https://attack.mitre.org/software/S1112)  
Platforms: Network Devices  

[STEADYPULSE](https://attack.mitre.org/software/S1112) is a web shell that infects targeted Pulse Secure VPN servers through modification of a legitimate Perl script that was used as early as 2020 including in activity against US Defense Industrial Base (DIB) entities.
