# S1113: RAPIDPULSE

<a id="s1113"></a>

Type: malware  
ATT&CK: [S1113](https://attack.mitre.org/software/S1113)  
Platforms: Network Devices, Linux  

[RAPIDPULSE](https://attack.mitre.org/software/S1113) is a web shell that exists as a modification to a legitimate Pulse Secure file that has been used by [APT5](https://attack.mitre.org/groups/G1023) since at least 2021.
