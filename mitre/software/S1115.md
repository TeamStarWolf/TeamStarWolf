# S1115: WIREFIRE

<a id="s1115"></a>

Type: malware  
ATT&CK: [S1115](https://attack.mitre.org/software/S1115)  
Platforms: Network Devices  
Aliases: GIFTEDVISITOR  

[WIREFIRE](https://attack.mitre.org/software/S1115) is a web shell written in Python that exists as trojanized logic to the visits.py component of Ivanti Connect Secure VPN appliances. [WIREFIRE](https://attack.mitre.org/software/S1115) was used during [Cutting Edge](https://attack.mitre.org/campaigns/C0029) for downloading files and command execution.
