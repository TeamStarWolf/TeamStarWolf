# S1116: WARPWIRE

<a id="s1116"></a>

Type: malware  
ATT&CK: [S1116](https://attack.mitre.org/software/S1116)  
Platforms: Network Devices  

[WARPWIRE](https://attack.mitre.org/software/S1116) is a Javascript credential stealer that targets plaintext passwords and usernames for exfiltration that was used during [Cutting Edge](https://attack.mitre.org/campaigns/C0029) to target Ivanti Connect Secure VPNs.
