# S1117: GLASSTOKEN

<a id="s1117"></a>

Type: malware  
ATT&CK: [S1117](https://attack.mitre.org/software/S1117)  
Platforms: Network Devices  

[GLASSTOKEN](https://attack.mitre.org/software/S1117) is a custom web shell used by threat actors during [Cutting Edge](https://attack.mitre.org/campaigns/C0029) to execute commands on compromised Ivanti Secure Connect VPNs.
