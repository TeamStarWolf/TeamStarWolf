# S1118: BUSHWALK

<a id="s1118"></a>

Type: malware  
ATT&CK: [S1118](https://attack.mitre.org/software/S1118)  
Platforms: Network Devices  

[BUSHWALK](https://attack.mitre.org/software/S1118) is a web shell written in Perl that was inserted into the legitimate querymanifest.cgi file on compromised Ivanti Connect Secure VPNs during [Cutting Edge](https://attack.mitre.org/campaigns/C0029).
