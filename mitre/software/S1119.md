# S1119: LIGHTWIRE

<a id="s1119"></a>

Type: malware  
ATT&CK: [S1119](https://attack.mitre.org/software/S1119)  
Platforms: Network Devices  

[LIGHTWIRE](https://attack.mitre.org/software/S1119) is a web shell written in Perl that was used during [Cutting Edge](https://attack.mitre.org/campaigns/C0029) to maintain access and enable command execution by imbedding into the legitimate compcheckresult.cgi component of Ivanti Secure Connect VPNs.
