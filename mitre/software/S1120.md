# S1120: FRAMESTING

<a id="s1120"></a>

Type: malware  
ATT&CK: [S1120](https://attack.mitre.org/software/S1120)  
Platforms: Network Devices  

[FRAMESTING](https://attack.mitre.org/software/S1120) is a Python web shell that was used during [Cutting Edge](https://attack.mitre.org/campaigns/C0029) to embed into an Ivanti Connect Secure Python package for command execution.
