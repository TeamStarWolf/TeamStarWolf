# S1123: PITSTOP

<a id="s1123"></a>

Type: malware  
ATT&CK: [S1123](https://attack.mitre.org/software/S1123)  
Platforms: Network Devices  

[PITSTOP](https://attack.mitre.org/software/S1123) is a backdoor that was deployed on compromised Ivanti Connect Secure VPNs during [Cutting Edge](https://attack.mitre.org/campaigns/C0029) to enable command execution and file read/write.
