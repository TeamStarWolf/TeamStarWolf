# S1133 — Apostle

<a id="s1133"></a>

**Type:** malware  
**ATT&CK:** [S1133](https://attack.mitre.org/software/S1133)  
**Platforms:** Windows  

[Apostle](https://attack.mitre.org/software/S1133) is malware that has functioned as both a wiper and, in more recent versions, as ransomware. [Apostle](https://attack.mitre.org/software/S1133) is written in.NET and shares various programming and functional overlaps with [IPsec Helper](https://attack.mitre.org/software/S1132).
