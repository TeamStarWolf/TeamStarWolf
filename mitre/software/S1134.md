# S1134 — DEADWOOD

<a id="s1134"></a>

**Type:** malware  
**ATT&CK:** [S1134](https://attack.mitre.org/software/S1134)  
**Platforms:** Windows  

[DEADWOOD](https://attack.mitre.org/software/S1134) is wiper malware written in C++ using Boost libraries. [DEADWOOD](https://attack.mitre.org/software/S1134) was first observed in an unattributed wiping event in Saudi Arabia in 2019, and has since been incorporated into [Agrius](https://attack.mitre.org/groups/G1030) operations.
