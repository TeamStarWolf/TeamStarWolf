# S1136 — BFG Agonizer

<a id="s1136"></a>

**Type:** malware  
**ATT&CK:** [S1136](https://attack.mitre.org/software/S1136)  
**Platforms:** Windows  

[BFG Agonizer](https://attack.mitre.org/software/S1136) is a wiper related to the open-source project CRYLINE-v.5.0. The malware is associated with wiping operations conducted by the [Agrius](https://attack.mitre.org/groups/G1030) threat actor.

## Techniques used (4)

- [T1490 — Inhibit System Recovery](/mitre/techniques/T1490.md)
- [T1529 — System Shutdown/Reboot](/mitre/techniques/T1529.md)
- [T1554 — Compromise Host Software Binary](/mitre/techniques/T1554.md)
- [T1561.002 — Disk Structure Wipe](/mitre/techniques/T1561-002.md)
