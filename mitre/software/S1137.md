# S1137: Moneybird

<a id="s1137"></a>

Type: malware  
ATT&CK: [S1137](https://attack.mitre.org/software/S1137)  
Platforms: Windows  

[Moneybird](https://attack.mitre.org/software/S1137) is a ransomware variant written in C++ associated with [Agrius](https://attack.mitre.org/groups/G1030) operations. The name "Moneybird" is contained in the malware's ransom note and as strings in the executable.

- [T1027.009: Embedded Payloads](/mitre/techniques/T1027-009.md)
- [T1486: Data Encrypted for Impact](/mitre/techniques/T1486.md)
