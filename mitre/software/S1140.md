# S1140 — Spica

<a id="s1140"></a>

**Type:** malware  
**ATT&CK:** [S1140](https://attack.mitre.org/software/S1140)  
**Platforms:** Windows  

[Spica](https://attack.mitre.org/software/S1140) is a custom backdoor written in Rust that has been used by [Star Blizzard](https://attack.mitre.org/groups/G1033) since at least 2023.
