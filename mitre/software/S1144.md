# S1144: FRP

<a id="s1144"></a>

Type: tool  
ATT&CK: [S1144](https://attack.mitre.org/software/S1144)  
Platforms: Linux, macOS, Windows  

[FRP](https://attack.mitre.org/software/S1144), which stands for Fast Reverse Proxy, is an openly available tool that is capable of exposing a server located behind a firewall or Network Address Translation (NAT) to the Internet. [FRP](https://attack.mitre.org/software/S1144) can support multiple protocols including TCP, UDP, and HTTP(S) and has been abused by threat actors to proxy command and control communications.
