# S1146 — MgBot

<a id="s1146"></a>

**Type:** malware  
**ATT&CK:** [S1146](https://attack.mitre.org/software/S1146)  
**Platforms:** Windows  

[MgBot](https://attack.mitre.org/software/S1146) is a modular malware framework exclusively associated with [Daggerfly](https://attack.mitre.org/groups/G1034) operations since at least 2012. [MgBot](https://attack.mitre.org/software/S1146) was developed in C++ and features a module design with multiple available plugins that have been under active development through 2024.
