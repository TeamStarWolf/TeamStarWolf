# S1147: Nightdoor

<a id="s1147"></a>

Type: malware  
ATT&CK: [S1147](https://attack.mitre.org/software/S1147)  
Platforms: Windows  

[Nightdoor](https://attack.mitre.org/software/S1147) is a backdoor exclusively associated with [Daggerfly](https://attack.mitre.org/groups/G1034) operations. [Nightdoor](https://attack.mitre.org/software/S1147) uses common libraries with [MgBot](https://attack.mitre.org/software/S1146) and [MacMa](https://attack.mitre.org/software/S1016), linking these malware families together.
