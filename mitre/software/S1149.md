# S1149 — CHIMNEYSWEEP

<a id="s1149"></a>

**Type:** malware  
**ATT&CK:** [S1149](https://attack.mitre.org/software/S1149)  
**Platforms:** Windows  

[CHIMNEYSWEEP](https://attack.mitre.org/software/S1149) is a backdoor malware that was deployed during [HomeLand Justice](https://attack.mitre.org/campaigns/C0038) along with [ROADSWEEP](https://attack.mitre.org/software/S1150) ransomware, and has been used to target Farsi and Arabic speakers since at least 2012.
