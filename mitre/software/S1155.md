# S1155: Covenant

<a id="s1155"></a>

Type: tool  
ATT&CK: [S1155](https://attack.mitre.org/software/S1155)  
Platforms: Linux, macOS, Windows  

[Covenant](https://attack.mitre.org/software/S1155) is a multi-platform command and control framework written in.NET. While designed for penetration testing and security research, the tool has also been used by threat actors such as [HAFNIUM](https://attack.mitre.org/groups/G0125) during operations. [Covenant](https://attack.mitre.org/software/S1155) functions through a central listener managing multiple deployed "Grunts" that communicate back to the controller.
