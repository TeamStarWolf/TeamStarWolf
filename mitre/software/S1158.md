# S1158: DUSTPAN

<a id="s1158"></a>

Type: malware  
ATT&CK: [S1158](https://attack.mitre.org/software/S1158)  
Platforms: Windows  

[DUSTPAN](https://attack.mitre.org/software/S1158) is an in-memory dropper written in C/C++ used by [APT41](https://attack.mitre.org/groups/G0096) since 2021 that decrypts and executes an embedded payload.
