# S1159: DUSTTRAP

<a id="s1159"></a>

Type: malware  
ATT&CK: [S1159](https://attack.mitre.org/software/S1159)  
Platforms: Windows  

[DUSTTRAP](https://attack.mitre.org/software/S1159) is a multi-stage plugin framework associated with [APT41](https://attack.mitre.org/groups/G0096) operations with multiple components.
