# S1166: Solar

<a id="s1166"></a>

Type: malware  
ATT&CK: [S1166](https://attack.mitre.org/software/S1166)  
Platforms: Windows  

[Solar](https://attack.mitre.org/software/S1166) is a C#/.NET backdoor that was used by [OilRig](https://attack.mitre.org/groups/G0049) during the [Outer Space](https://attack.mitre.org/campaigns/C0042) campaign to download, execute, and exfiltrate files.
