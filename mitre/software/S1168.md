# S1168 — SampleCheck5000

<a id="s1168"></a>

**Type:** malware  
**ATT&CK:** [S1168](https://attack.mitre.org/software/S1168)  
**Platforms:** Windows  
**Aliases:** SC5k  

[SampleCheck5000](https://attack.mitre.org/software/S1168) is a downloader with multiple variants that was used by [OilRig](https://attack.mitre.org/groups/G0049) including during the [Outer Space](https://attack.mitre.org/campaigns/C0042) campaign to download and execute additional payloads.
