# S1170 — ODAgent

<a id="s1170"></a>

**Type:** malware  
**ATT&CK:** [S1170](https://attack.mitre.org/software/S1170)  
**Platforms:** Windows  

[ODAgent](https://attack.mitre.org/software/S1170) is a C#/.NET downloader that has been used by [OilRig](https://attack.mitre.org/groups/G0049) since at least 2022 including against target organizations in Israel to download and execute payloads and to exfiltrate staged files.
