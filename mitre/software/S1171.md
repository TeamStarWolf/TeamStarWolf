# S1171: OilCheck

<a id="s1171"></a>

Type: malware  
ATT&CK: [S1171](https://attack.mitre.org/software/S1171)  
Platforms: Windows  

[OilCheck](https://attack.mitre.org/software/S1171) is a C#/.NET downloader that has been used by [OilRig](https://attack.mitre.org/groups/G0049) since at least 2022 including against targets in Israel. [OilCheck](https://attack.mitre.org/software/S1171) uses draft messages created in a shared email account for C2 communication.

- [T1102.002: Bidirectional Communication](/mitre/techniques/T1102-002.md)
- [T1105: Ingress Tool Transfer](/mitre/techniques/T1105.md)
- [T1567: Exfiltration Over Web Service](/mitre/techniques/T1567.md)
