# S1172 — OilBooster

<a id="s1172"></a>

**Type:** malware  
**ATT&CK:** [S1172](https://attack.mitre.org/software/S1172)  
**Platforms:** Windows  

[OilBooster](https://attack.mitre.org/software/S1172) is a downloader written in Microsoft Visual C/C++ that has been used by [OilRig](https://attack.mitre.org/groups/G0049) since at least 2022 including against target organizations in Israel to download and execute files and for exfiltration.
