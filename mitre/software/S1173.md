# S1173: PowerExchange

<a id="s1173"></a>

Type: malware  
ATT&CK: [S1173](https://attack.mitre.org/software/S1173)  
Platforms: Windows  

[PowerExchange](https://attack.mitre.org/software/S1173) is a PowerShell backdoor that has been used by [OilRig](https://attack.mitre.org/groups/G0049) since at least 2023 including against government targets in the Middle East.
