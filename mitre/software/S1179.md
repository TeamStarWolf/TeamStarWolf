# S1179 — Exbyte

<a id="s1179"></a>

**Type:** malware  
**ATT&CK:** [S1179](https://attack.mitre.org/software/S1179)  
**Platforms:** Windows  

[Exbyte](https://attack.mitre.org/software/S1179) is an exfiltration tool written in Go that is uniquely associated with [BlackByte](https://attack.mitre.org/groups/G1043) operations. Observed since 2022, [Exbyte](https://attack.mitre.org/software/S1179) transfers collected files to online file sharing and hosting services.
