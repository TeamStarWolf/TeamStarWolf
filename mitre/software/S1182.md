# S1182: MagicRAT

<a id="s1182"></a>

Type: malware  
ATT&CK: [S1182](https://attack.mitre.org/software/S1182)  
Platforms: Windows  

[MagicRAT](https://attack.mitre.org/software/S1182) is a remote access tool developed in C++ and exclusively used by the [Lazarus Group](https://attack.mitre.org/groups/G0032) threat actor in operations. [MagicRAT](https://attack.mitre.org/software/S1182) allows for arbitrary command execution on victim machines and provides basic remote access functionality.
