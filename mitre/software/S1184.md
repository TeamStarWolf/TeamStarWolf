# S1184 — BOLDMOVE

<a id="s1184"></a>

**Type:** malware  
**ATT&CK:** [S1184](https://attack.mitre.org/software/S1184)  
**Platforms:** Linux, Network Devices  

[BOLDMOVE](https://attack.mitre.org/software/S1184) is a type of backdoor malware written in C linked to People’s Republic of China operations from 2022 through 2023. [BOLDMOVE](https://attack.mitre.org/software/S1184) includes both Windows and Linux variants, with some Linux variants specifically designed for FortiGate Firewall devices. [BOLDMOVE](https://attack.mitre.org/software/S1184) is linked to zero-day exploitation of CVE-2022-42475 in FortiOSS SSL-VPNs. The record for [BOLDMOVE](https://attack.mitre.org/software/S1184) only covers known Linux variants.
