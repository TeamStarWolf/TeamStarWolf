# S1186 — Line Dancer

<a id="s1186"></a>

**Type:** malware  
**ATT&CK:** [S1186](https://attack.mitre.org/software/S1186)  
**Platforms:** Network Devices  

[Line Dancer](https://attack.mitre.org/software/S1186) is a memory-only Lua-based shellcode loader associated with the [ArcaneDoor](https://attack.mitre.org/campaigns/C0046) campaign. [Line Dancer](https://attack.mitre.org/software/S1186) allows an adversary to upload and execute arbitrary shellcode on victim devices.
