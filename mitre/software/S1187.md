# S1187: reGeorg

<a id="s1187"></a>

Type: malware  
ATT&CK: [S1187](https://attack.mitre.org/software/S1187)  
Platforms: Network Devices, Windows, macOS, Linux  

[reGeorg](https://attack.mitre.org/software/S1187) is an open-source web shell written in Python that can be used as a proxy to bypass firewall rules and tunnel data in and out of targeted networks.
