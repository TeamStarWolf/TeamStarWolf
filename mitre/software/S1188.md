# S1188: Line Runner

<a id="s1188"></a>

Type: malware  
ATT&CK: [S1188](https://attack.mitre.org/software/S1188)  
Platforms: Network Devices  

[Line Runner](https://attack.mitre.org/software/S1188) is a persistent backdoor and web shell allowing threat actors to upload and execute arbitrary Lua scripts. [Line Runner](https://attack.mitre.org/software/S1188) is associated with the [ArcaneDoor](https://attack.mitre.org/campaigns/C0046) campaign.
