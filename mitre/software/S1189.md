# S1189: Neo-reGeorg

<a id="s1189"></a>

Type: malware  
ATT&CK: [S1189](https://attack.mitre.org/software/S1189)  
Platforms: Network Devices, Windows, macOS, Linux  

[Neo-reGeorg](https://attack.mitre.org/software/S1189) is an open-source web shell designed as a restructuring of [reGeorg](https://attack.mitre.org/software/S1187) with improved usability, security, and fixes for exising [reGeorg](https://attack.mitre.org/software/S1187) bugs.
