# S1192 — NICECURL

<a id="s1192"></a>

**Type:** malware  
**ATT&CK:** [S1192](https://attack.mitre.org/software/S1192)  
**Platforms:** Windows  

[NICECURL](https://attack.mitre.org/software/S1192) is a VBScript-based backdoor used by [APT42](https://attack.mitre.org/groups/G1044) to download additional modules.
