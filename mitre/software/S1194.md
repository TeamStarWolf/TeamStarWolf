# S1194 — Akira _v2

<a id="s1194"></a>

**Type:** malware  
**ATT&CK:** [S1194](https://attack.mitre.org/software/S1194)  

[Akira _v2](https://attack.mitre.org/software/S1194) is a Rust-based variant of [Akira](https://attack.mitre.org/software/S1129) ransomware that has been in use since at least 2024. [Akira _v2](https://attack.mitre.org/software/S1194) is designed to target VMware ESXi servers and includes a new command-line argument set and other expanded capabilities.
