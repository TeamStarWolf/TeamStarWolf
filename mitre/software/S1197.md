# S1197: GoBear

<a id="s1197"></a>

Type: malware  
ATT&CK: [S1197](https://attack.mitre.org/software/S1197)  
Platforms: Windows  

[GoBear](https://attack.mitre.org/software/S1197) is a Go-based backdoor that abuses legitimate, stolen certificates for defense evasion purposes. [GoBear](https://attack.mitre.org/software/S1197) is exclusively linked to [Kimsuky](https://attack.mitre.org/groups/G0094) operations.
