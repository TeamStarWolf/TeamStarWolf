# S1198: Gomir

<a id="s1198"></a>

Type: malware  
ATT&CK: [S1198](https://attack.mitre.org/software/S1198)  
Platforms: Linux  

Gomir is a Linux backdoor variant of the Go-based malware [GoBear](https://attack.mitre.org/software/S1197), uniquely assoicated with [Kimsuky](https://attack.mitre.org/groups/G0094) operations.
