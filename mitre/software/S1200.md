# S1200 — StealBit

<a id="s1200"></a>

**Type:** malware  
**ATT&CK:** [S1200](https://attack.mitre.org/software/S1200)  
**Platforms:** Windows  

[StealBit](https://attack.mitre.org/software/S1200) is a data exfiltration tool that is developed and maintained by the operators of the the LockBit Ransomware-as-a-Service (RaaS) and offered to affiliates to exfiltrate data from compromised systems for double extortion purposes.
