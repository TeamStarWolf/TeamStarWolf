# S1203 — J-magic

<a id="s1203"></a>

**Type:** malware  
**ATT&CK:** [S1203](https://attack.mitre.org/software/S1203)  
**Platforms:** Network Devices  

[J-magic](https://attack.mitre.org/software/S1203) is a custom variant of the [cd00r](https://attack.mitre.org/software/S1204) backdoor tailored to target Juniper routers that was first observed during the [J-magic Campaign](https://attack.mitre.org/campaigns/C0050) in mid-2023. [J-magic](https://attack.mitre.org/software/S1203) monitors TCP traffic for five predefined parameters or "magic packets" to be sent by the attackers before activating on compromised devices.
