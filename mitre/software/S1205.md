# S1205: cipher.exe

<a id="s1205"></a>

Type: tool  
ATT&CK: [S1205](https://attack.mitre.org/software/S1205)  
Platforms: Windows  

[cipher.exe](https://attack.mitre.org/software/S1205) is a native Microsoft utility that manages encryption of directories and files on NTFS (New Technology File System) partitions by using the Encrypting File System (EFS).
