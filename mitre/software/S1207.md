# S1207 — XLoader

<a id="s1207"></a>

**Type:** malware  
**ATT&CK:** [S1207](https://attack.mitre.org/software/S1207)  
**Platforms:** Windows  
**Aliases:** Formbook  

[XLoader](https://attack.mitre.org/software/S1207) is an infostealer malware in use since at least 2016. Previously known and sometimes still referred to as Formbook, [XLoader](https://attack.mitre.org/software/S1207) is a Malware as a Service (MaaS) known for stealing data from web browsers, email clients and File Transfer Protocol (FTP) applications.
