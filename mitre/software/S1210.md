# S1210 — Sagerunex

<a id="s1210"></a>

**Type:** malware  
**ATT&CK:** [S1210](https://attack.mitre.org/software/S1210)  
**Platforms:** Windows  

[Sagerunex](https://attack.mitre.org/software/S1210) is a malware family exclusively associated with [Lotus Blossom](https://attack.mitre.org/groups/G0030) operations, with variants existing since at least 2016. Variations of [Sagerunex](https://attack.mitre.org/software/S1210) leverage non-traditional command and control mechanisms such as various web services.
