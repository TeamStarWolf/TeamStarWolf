# S1213 — Lumma Stealer

<a id="s1213"></a>

**Type:** malware  
**ATT&CK:** [S1213](https://attack.mitre.org/software/S1213)  
**Platforms:** Windows  
**Aliases:** LummaStealer  

[Lumma Stealer](https://attack.mitre.org/software/S1213) is an information stealer malware family in use since at least 2022. [Lumma Stealer](https://attack.mitre.org/software/S1213) is a Malware as a Service (MaaS) where captured data has been sold in criminal markets to Initial Access Brokers.
