# S1217 — VIRTUALPITA

<a id="s1217"></a>

**Type:** malware  
**ATT&CK:** [S1217](https://attack.mitre.org/software/S1217)  
**Platforms:** ESXi, Linux  

[VIRTUALPITA](https://attack.mitre.org/software/S1217) is a passive backdoor with ESXi and Linux vCenter variants capable of command execution, file transfer, and starting and stopping processes. [VIRTUALPITA](https://attack.mitre.org/software/S1217) has been in use since at least 2022 including by [UNC3886](https://attack.mitre.org/groups/G1048) who leveraged malicious vSphere Installation Bundles (VIBs) for install on ESXi hypervisors.
