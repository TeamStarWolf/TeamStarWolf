# S1220: MEDUSA

<a id="s1220"></a>

Type: malware  
ATT&CK: [S1220](https://attack.mitre.org/software/S1220)  
Platforms: Linux  

[MEDUSA](https://attack.mitre.org/software/S1220) is an open-source rootkit that is capable of dynamic linker hijacking, command execution, and logging credentials.
