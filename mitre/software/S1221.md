# S1221: MOPSLED

<a id="s1221"></a>

Type: malware  
ATT&CK: [S1221](https://attack.mitre.org/software/S1221)  
Platforms: Linux  

[MOPSLED](https://attack.mitre.org/software/S1221) is a shellcode-based modular backdoor that has been used by China-nexus cyber espionage actors including [UNC3886](https://attack.mitre.org/groups/G1048) and [APT41](https://attack.mitre.org/groups/G0096).
