# S1222: RIFLESPINE

<a id="s1222"></a>

Type: malware  
ATT&CK: [S1222](https://attack.mitre.org/software/S1222)  
Platforms: Linux  

[RIFLESPINE](https://attack.mitre.org/software/S1222) is a cross-platform backdoor that leverages Google Drive for file transfer and command execution.
