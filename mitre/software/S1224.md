# S1224: CASTLETAP

<a id="s1224"></a>

Type: malware  
ATT&CK: [S1224](https://attack.mitre.org/software/S1224)  
Platforms: Network Devices  

[CASTLETAP](https://attack.mitre.org/software/S1224) is an ICMP port knocking backdoor that has been installed on compromised FortiGate firewalls by [UNC3886](https://attack.mitre.org/groups/G1048).
