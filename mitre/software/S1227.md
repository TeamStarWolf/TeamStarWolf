# S1227: StarProxy

<a id="s1227"></a>

Type: malware  
ATT&CK: [S1227](https://attack.mitre.org/software/S1227)  
Platforms: Windows  

[StarProxy](https://attack.mitre.org/software/S1227) is custom malware used by [Mustang Panda](https://attack.mitre.org/groups/G0129) as a post-compromise tool, to enable proxying of traffic between the infected machine and other machines on the same network.
