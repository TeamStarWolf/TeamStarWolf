# S1230: HIUPAN

<a id="s1230"></a>

Type: malware  
ATT&CK: [S1230](https://attack.mitre.org/software/S1230)  
Platforms: Windows  

[HIUPAN](https://attack.mitre.org/software/S1230) (aka U2DiskWatch) is a is a worm that propagates through removable drives known to be leveraged by [Mustang Panda](https://attack.mitre.org/groups/G0129) and was first observed utilized in 2024.
