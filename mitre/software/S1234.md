# S1234 — SplatCloak

<a id="s1234"></a>

**Type:** malware  
**ATT&CK:** [S1234](https://attack.mitre.org/software/S1234)  
**Platforms:** Windows  

[SplatCloak](https://attack.mitre.org/software/S1234) is a malware that disables EDR-related routines used by Windows Defender and Kaspersky to aid in evading detection. [SplatCloak](https://attack.mitre.org/software/S1234) has been deployed by [SplatDropper](https://attack.mitre.org/software/S1232) and is known to be leveraged by [Mustang Panda](https://attack.mitre.org/groups/G0129) since 2025.
