# S1236 — CLAIMLOADER

<a id="s1236"></a>

**Type:** malware  
**ATT&CK:** [S1236](https://attack.mitre.org/software/S1236)  
**Platforms:** Windows  

[CLAIMLOADER](https://attack.mitre.org/software/S1236) is a malware variant that frequently accompanies legitimate executables that are used for DLL side-loading known to be leveraged by [Mustang Panda](https://attack.mitre.org/groups/G0129) and was first observed utilized in 2021.
