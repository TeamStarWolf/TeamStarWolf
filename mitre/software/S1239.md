# S1239 — TONESHELL

<a id="s1239"></a>

**Type:** malware  
**ATT&CK:** [S1239](https://attack.mitre.org/software/S1239)  
**Platforms:** Windows  

[TONESHELL](https://attack.mitre.org/software/S1239) is a custom backdoor that has been used since at least Q1 2021. [TONESHELL](https://attack.mitre.org/software/S1239) malware has previously been leveraged by Chinese affiliated actors identified as [Mustang Panda](https://attack.mitre.org/groups/G0129).
