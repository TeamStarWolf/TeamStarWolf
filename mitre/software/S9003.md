# S9003: evilginx2

<a id="s9003"></a>

Type: tool  
ATT&CK: [S9003](https://attack.mitre.org/software/S9003)  
Platforms: IaaS, Identity Provider, Office Suite, SaaS  

[evilginx2](https://attack.mitre.org/software/S9003) is an open-source adversary-in-the-middle (AiTM) attack framework based on the open-source nginx web server. [evilginx2](https://attack.mitre.org/software/S9003) can be used as a reverse proxy between victims and legitimate web services to intercept and capture credentials, authentication tokens, and session cookies.
