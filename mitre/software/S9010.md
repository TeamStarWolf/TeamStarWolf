# S9010 — GlassWorm

<a id="s9010"></a>

**Type:** malware  
**ATT&CK:** [S9010](https://attack.mitre.org/software/S9010)  
**Platforms:** macOS, Windows  

[GlassWorm](https://attack.mitre.org/software/S9010) is a worm that propagated through supply chain attacks by compromising repository credentials from victim environments and having malicious payloads added to those compromised accounts for distribution to victims across the various development ecosystems. [GlassWorm](https://attack.mitre.org/software/S9010) has numerous variants, including Rust binaries, encrypted JavaScript and a variant leveraging invisible Unicode characters that made reverse engineering difficult. [GlassWorm](https://attack.mitre.org/software/S9010) has employed a unique command and control (C2) methodology using Solana blockchain. [GlassWorm](https://attack.mitre.org/software/S9010) was first reported in October 2025.
