# S9016 — Caminho

<a id="s9016"></a>

**Type:** malware  
**ATT&CK:** [S9016](https://attack.mitre.org/software/S9016)  
**Platforms:** Windows  
**Aliases:** VMDetectLoader  

[Caminho](https://attack.mitre.org/software/S9016) is a downloader that has been used by threat actors since at least 2025 to deliver various strains of malware such as XWorm.
