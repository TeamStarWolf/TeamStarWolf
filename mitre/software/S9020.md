# S9020: LODEINFO

<a id="s9020"></a>

Type: malware  
ATT&CK: [S9020](https://attack.mitre.org/software/S9020)  
Platforms: Windows  

[LODEINFO](https://attack.mitre.org/software/S9020) is a fileless backdoor malware first identified in 2020 that has been used by actors including [MirrorFace](https://attack.mitre.org/groups/G1054), primarily against media, diplomatic, governmental, and public sector organizations in Japan.
