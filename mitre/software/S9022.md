# S9022: MirrorStealer

<a id="s9022"></a>

Type: malware  
ATT&CK: [S9022](https://attack.mitre.org/software/S9022)  
Platforms: Windows  

[MirrorStealer](https://attack.mitre.org/software/S9022) is a credential stealer that has been used by [MirrorFace](https://attack.mitre.org/groups/G1054) since at least 2022 to steal credentials from various applications, including browsers and email clients. [MirrorStealer](https://attack.mitre.org/software/S9022) has been delivered directly into system memory via commands issued by [LODEINFO](https://attack.mitre.org/software/S9020).
