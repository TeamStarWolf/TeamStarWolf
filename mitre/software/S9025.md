# S9025 — NOOPLDR

<a id="s9025"></a>

**Type:** malware  
**ATT&CK:** [S9025](https://attack.mitre.org/software/S9025)  
**Platforms:** Windows  

[NOOPLDR](https://attack.mitre.org/software/S9025) is a shellcode loader with XML/C# and DLL versions that has been used by [MirrorFace](https://attack.mitre.org/groups/G1054) to load [HiddenFace](https://attack.mitre.org/software/S9023).
