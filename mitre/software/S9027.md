# S9027 — ANELLDR

<a id="s9027"></a>

**Type:** malware  
**ATT&CK:** [S9027](https://attack.mitre.org/software/S9027)  
**Platforms:** Windows  

[ANELLDR](https://attack.mitre.org/software/S9027), a loader that has been in use since at least 2018, was designed to decrypt and execute [UPPERCUT](https://attack.mitre.org/software/S0275) in memory. [ANELLDR](https://attack.mitre.org/software/S9027) can use anti-analysis techniques and is known to share code overlap with [HiddenFace](https://attack.mitre.org/software/S9023).
