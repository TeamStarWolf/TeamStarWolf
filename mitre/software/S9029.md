# S9029: IronWind

<a id="s9029"></a>

Type: malware  
ATT&CK: [S9029](https://attack.mitre.org/software/S9029)  
Platforms: Windows  

[IronWind](https://attack.mitre.org/software/S9029) is a custom loader malware that has been in use since at least 2023 by actors including [WIRTE](https://attack.mitre.org/groups/G0090) to target entities in the Middle East.
