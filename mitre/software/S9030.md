# S9030: SameCoin

<a id="s9030"></a>

Type: malware  
ATT&CK: [S9030](https://attack.mitre.org/software/S9030)  
Platforms: Windows, Android  

[SameCoin](https://attack.mitre.org/software/S9030) is a multi-platform wiper with Windows and Android versions that has been used by [WIRTE](https://attack.mitre.org/groups/G0090) to target entities in the Middle East including in Israel.
