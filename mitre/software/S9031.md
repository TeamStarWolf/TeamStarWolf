# S9031: AshTag

<a id="s9031"></a>

Type: malware  
ATT&CK: [S9031](https://attack.mitre.org/software/S9031)  
Platforms: Windows  

[AshTag](https://attack.mitre.org/software/S9031) is a modular.NET backdoor with multiple features that has been used by [WIRTE](https://attack.mitre.org/groups/G0090) since at least 2025. [AshTag](https://attack.mitre.org/software/S9031) is designed for persistence and remote command execution and can masquerade as a legitimate VisualServer utility.
