# S9036 — LP-Notes

<a id="s9036"></a>

**Type:** malware  
**ATT&CK:** [S9036](https://attack.mitre.org/software/S9036)  
**Platforms:** Windows  

[LP-Notes](https://attack.mitre.org/software/S9036) is a C/C++ Windows credential stealer used by [MuddyWater](https://attack.mitre.org/groups/G0069). [LP-Notes](https://attack.mitre.org/software/S9036) was named after the `lp-notes.txt` file that is used to store stolen credentials.
