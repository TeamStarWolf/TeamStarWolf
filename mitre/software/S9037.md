# S9037: RustyWater

<a id="s9037"></a>

Type: malware  
ATT&CK: [S9037](https://attack.mitre.org/software/S9037)  
Platforms: Windows  
Aliases: Archer RAT / RUSTRIC  

[RustyWater](https://attack.mitre.org/software/S9037) is a Rust-based implant used by [MuddyWater](https://attack.mitre.org/groups/G0069). Historically, [MuddyWater](https://attack.mitre.org/groups/G0069) has used PowerShell-based tools and [RustyWater](https://attack.mitre.org/software/S9037) reflects a shift in tooling, demonstrating better techniques for defense evasion and reverse engineering.
