# S9045: BACKUPOSINT v9.0 APEX PREDATOR

<a id="s9045"></a>

Type: malware  
ATT&CK: [S9045](https://attack.mitre.org/software/S9045)  
Platforms: Linux, Windows, IaaS, Containers  

[BACKUPOSINT v9.0 APEX PREDATOR](https://attack.mitre.org/software/S9045) is a 49-module Python malware developed entirely by Anthropic’s Claude Code as part of the [AI-Assisted Breach of Mexico's Government Infrastructure](https://attack.mitre.org/campaigns/C0064) campaign. [BACKUPOSINT v9.0 APEX PREDATOR](https://attack.mitre.org/software/S9045) leverages publicly available techniques for network enumeration, credential harvesting, Active Directory interrogation, database access, privilege escalation, cloud metadata extraction, and lateral movement (Citation: AI-Mexico-Govt-Compromise).
