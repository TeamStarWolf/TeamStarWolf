# S9050: Vidar

<a id="s9050"></a>

Type: malware  
ATT&CK: [S9050](https://attack.mitre.org/software/S9050)  
Platforms: Windows  

[Vidar](https://attack.mitre.org/software/S9050) is a Windows infostealer that was first advertised in November 2018. Written in C++, [Vidar](https://attack.mitre.org/software/S9050) collects PII, cryptocurrency wallets, documents and other data within the compromised machine.
