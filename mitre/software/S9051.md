# S9051: The Gentlemen Ransomware

<a id="s9051"></a>

Type: malware  
ATT&CK: [S9051](https://attack.mitre.org/software/S9051)  
Platforms: macOS, Linux, Windows, IaaS, ESXi, Network Devices  

[The Gentlemen Ransomware](https://attack.mitre.org/software/S9051) is a ransomware-as-a-service (RaaS). [The Gentlemen Ransomware](https://attack.mitre.org/software/S9051) has been written in Go programming language and has utilized Garble to obfuscate its code to target Windows environments.
