# S9052: MiniFast

<a id="s9052"></a>

Type: malware  
ATT&CK: [S9052](https://attack.mitre.org/software/S9052)  
Platforms: Windows  

[MiniFast](https://attack.mitre.org/software/S9052) is a custom malware designed for long-term persistence and remote code execution. [MiniFast](https://attack.mitre.org/software/S9052) is a modular malware suspected of being generated using artificial intelligence (AI).
