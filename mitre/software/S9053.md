# S9053: MiniJunk

<a id="s9053"></a>

Type: malware  
ATT&CK: [S9053](https://attack.mitre.org/software/S9053)  
Platforms: Windows  

[MiniJunk](https://attack.mitre.org/software/S9053) is a custom malware designed for long-term persistence and remote code execution.(Citation: CheckPoint_NimbusManticoreEurope_Sept2025) [MiniJunk](https://attack.mitre.org/software/S9053) was first observed in 2025 and is a modified version of the [MiniBike](https://attack.mitre.org/software/S9059) framework that was first observed in June 2022.(Citation: CheckPoint_NimbusManticoreEurope_Sept2025) [MiniJunk](https://attack.mitre.org/software/S9053) has been affiliated with the cyber espionage threat group [NIMBUS MANTICORE](https://attack.mitre.org/groups/G1059).(Citation: CheckPoint_NimbusManticoreEurope_Sept2025)
