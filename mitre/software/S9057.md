# S9057: CRASHPAD

<a id="s9057"></a>

Type: malware  
ATT&CK: [S9057](https://attack.mitre.org/software/S9057)  
Platforms: Windows  

[CRASHPAD](https://attack.mitre.org/software/S9057) is a Windows executable written in C++ that gathers data from web browsers.(Citation: Mandiant_UNC1549_Nov2025) [CRASHPAD](https://attack.mitre.org/software/S9057) was first observed in 2025 and has been affiliated with the cyber espionage threat group [NIMBUS MANTICORE](https://attack.mitre.org/groups/G1059).(Citation: Mandiant_UNC1549_Nov2025)
