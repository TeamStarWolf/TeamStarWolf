# S9058: SIGHTGRAB

<a id="s9058"></a>

Type: malware  
ATT&CK: [S9058](https://attack.mitre.org/software/S9058)  
Platforms: Windows  

[SIGHTGRAB](https://attack.mitre.org/software/S9058) is a Windows executable written in C that captures and stages stolen data on victim devices.(Citation: Mandiant_UNC1549_Nov2025) [SIGHTGRAB](https://attack.mitre.org/software/S9058) was first observed in 2025 and has been affiliated with the cyber espionage threat group [NIMBUS MANTICORE](https://attack.mitre.org/groups/G1059).(Citation: Mandiant_UNC1549_Nov2025)
