# S9059: MiniBike

<a id="s9059"></a>

Type: malware  
ATT&CK: [S9059](https://attack.mitre.org/software/S9059)  
Platforms: Windows  

[MiniBike](https://attack.mitre.org/software/S9059) is a custom backdoor written in C++ designed for command execution, data discovery, gathering, and exfiltration.(Citation: Mandiant_UNC1549_Feb2024) [MiniBike](https://attack.mitre.org/software/S9059) has been known to communicate with the C2 using Azure Cloud Infrastructure. [MiniBike](https://attack.mitre.org/software/S9059) was first observed in 2022.(Citation: Mandiant_UNC1549_Feb2024) [MiniBike](https://attack.mitre.org/software/S9059) has been affiliated with the cyber espionage threat group [NIMBUS MANTICORE](https://attack.mitre.org/groups/G1059).(Citation: Mandiant_UNC1549_Feb2024)
