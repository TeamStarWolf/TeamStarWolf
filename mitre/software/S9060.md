# S9060: MiniBus

<a id="s9060"></a>

Type: malware  
ATT&CK: [S9060](https://attack.mitre.org/software/S9060)  
Platforms: Windows  

[MiniBus](https://attack.mitre.org/software/S9060) is a custom backdoor used for command execution, data discovery, gathering, and exfiltration. [MiniBus](https://attack.mitre.org/software/S9060) has utilized Azure Cloud Infrastructure and unique adversary-controlled domains for command and control.
