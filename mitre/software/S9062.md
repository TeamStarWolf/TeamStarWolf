# S9062: MiniBrowse

<a id="s9062"></a>

Type: malware  
ATT&CK: [S9062](https://attack.mitre.org/software/S9062)  
Platforms: Windows  

[MiniBrowse](https://attack.mitre.org/software/S9062) is a custom stealer designed for the theft of credentials in browsers and passwords stores. [MiniBrowse](https://attack.mitre.org/software/S9062) was first observed in late-2025.(Citation: CheckPoint_NimbusManticoreEurope_Sept2025) [MiniBrowse](https://attack.mitre.org/software/S9062) has been affiliated with the cyber espionage threat group [NIMBUS MANTICORE](https://attack.mitre.org/groups/G1059).(Citation: CheckPoint_NimbusManticoreEurope_Sept2025)
