# S9064: TRUSTTRAP

<a id="s9064"></a>

Type: malware  
ATT&CK: [S9064](https://attack.mitre.org/software/S9064)  
Platforms: Windows  

[TRUSTTRAP](https://attack.mitre.org/software/S9064) is a malware that uses a fictitious prompt to trick users to submit their credentials.(Citation: Mandiant_UNC1549_Nov2025) [TRUSTTRAP](https://attack.mitre.org/software/S9064) was first observed in 2023 and has been affiliated with the cyber espionage threat group [NIMBUS MANTICORE](https://attack.mitre.org/groups/G1059).(Citation: Mandiant_UNC1549_Nov2025)
