# S9065: DCSYNCER.SLICK

<a id="s9065"></a>

Type: malware  
ATT&CK: [S9065](https://attack.mitre.org/software/S9065)  
Platforms: Windows  

[DCSYNCER.SLICK](https://attack.mitre.org/software/S9065) is a Windows executable that is designed to gather credentials from victim devices.(Citation: Mandiant_UNC1549_Nov2025) [DCSYNCER.SLICK](https://attack.mitre.org/software/S9065) was first observed in 2025 and has been affiliated with the cyber espionage threat group [NIMBUS MANTICORE](https://attack.mitre.org/groups/G1059).(Citation: Mandiant_UNC1549_Nov2025)
