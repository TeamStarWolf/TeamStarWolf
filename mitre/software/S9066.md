# S9066: POLLBLEND

<a id="s9066"></a>

Type: malware  
ATT&CK: [S9066](https://attack.mitre.org/software/S9066)  
Platforms: Windows  

[POLLBLEND](https://attack.mitre.org/software/S9066) is a Windows tunneler written C++ that has utilized hardcoded C2 servers and leveraged hardcoded URI parameters for follow-on actions.(Citation: Mandiant_UNC1549_Nov2025) [POLLBLEND](https://attack.mitre.org/software/S9066) was first observed in 2025 and has been affiliated with the cyber espionage threat group [NIMBUS MANTICORE](https://attack.mitre.org/groups/G1059).(Citation: Mandiant_UNC1549_Nov2025)
