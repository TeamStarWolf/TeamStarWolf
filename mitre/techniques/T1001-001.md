# T1001.001 — Junk Data

<a id="t1001001"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1001.001](https://attack.mitre.org/techniques/T1001/001)  
**Sub-technique of:** [T1001 — Data Obfuscation](/mitre/techniques/T1001.md)  

Adversaries may add junk data to protocols used for command and control to make detection more difficult. By adding random or meaningless data to the protocols used for command and control, adversaries can prevent trivial methods for decoding, deciphering, or otherwise analyzing the traffic. Examples may include appending/prepending data with junk characters or writing junk characters between significant characters.

## Mitigations (1)

- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.

## Detection

**Detection strategies:**

- Detecting Junk Data in C2 Channels via Behavioral Analysis

**Analytics (4):**

- **Analytic 0030** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=10` → Process Access; `NSM:Flow TCP/UDP` → Network Traffic Content
- **Analytic 0031** (Linux) — `auditd:SYSCALL execve network tools` → Process Creation; `NSM:Flow TCP session tracking` → Network Traffic Content
- **Analytic 0032** (macOS) — `macos:unifiedlog connection attempts` → Network Connection Creation; `macos:osquery process_events` → Process Creation; `NSM:Flow session behavior` → Network Traffic Content
- **Analytic 0033** (ESXi) — `esxi:vmkernel Network activity` → Network Traffic Content; `esxi:hostd System service interactions` → Network Connection Creation
