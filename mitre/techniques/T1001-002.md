# T1001.002 — Steganography

<a id="t1001002"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1001.002](https://attack.mitre.org/techniques/T1001/002)  
**Sub-technique of:** [T1001 — Data Obfuscation](/mitre/techniques/T1001.md)  

Adversaries may use steganographic techniques to hide command and control traffic to make detection efforts more difficult. Steganographic techniques can be used to hide data in digital messages that are transferred between systems. This hidden information can be used for command and control of compromised systems. In some cases, the passing of files embedded using steganography, such as image or document files, can be used for command and control.

## Mitigations (1)

- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.

## Detection

**Detection strategies:**

- Detecting Steganographic Command and Control via File + Network Correlation

**Analytics (4):**

- **Analytic 0651** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `NSM:Flow Session Transfer Content` → Network Traffic Content
- **Analytic 0652** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Flow Captured File Content` → Network Traffic Content; `NSM:Flow Observed File Transfers` → File Metadata
- **Analytic 0653** (macOS) — `macos:unifiedlog File creation` → File Creation; `macos:osquery process_events` → Process Creation; `NSM:Flow C2 exfiltration` → Network Traffic Content
- **Analytic 0654** (ESXi) — `esxi:vmkernel Storage access and file ops` → File Metadata; `esxi:hostd Service initiated connections` → Network Connection Creation; `NSM:Flow Transferred file observations` → Network Traffic Content
