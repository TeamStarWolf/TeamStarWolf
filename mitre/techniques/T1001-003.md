# T1001.003 — Protocol or Service Impersonation

<a id="t1001003"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1001.003](https://attack.mitre.org/techniques/T1001/003)  
**Sub-technique of:** [T1001 — Data Obfuscation](/mitre/techniques/T1001.md)  

Adversaries may impersonate legitimate protocols or web service traffic to disguise command and control activity and thwart analysis efforts. By impersonating legitimate protocols or web services, adversaries can make their command and control traffic blend in with legitimate network traffic.

## Mitigations (1)

- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.

## Detection

**Detection strategies:**

- Detecting Protocol or Service Impersonation via Anomalous TLS, HTTP Header, and Port Mismatch Correlation

**Analytics (4):**

- **Analytic 1294** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `NSM:Flow SSL/TLS Handshake Analysis` → Network Traffic Content
- **Analytic 1295** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Flow Network Capture TLS/HTTP` → Network Traffic Content
- **Analytic 1296** (macOS) — `macos:unifiedlog Outbound Traffic` → Network Connection Creation; `macos:osquery Process Execution + Hash` → Process Metadata; `NSM:Content HTTP Header Metadata` → Network Traffic Content
- **Analytic 1297** (ESXi) — `esxi:hostd Service-Based Network Connection` → Network Connection Creation; `NSM:Content TLS Fingerprint and Certificate Analysis` → Network Traffic Content

## Data sources & telemetry (4)

**Network Connection Creation**, **Network Traffic Content**, **Process Creation**, **Process Metadata**
