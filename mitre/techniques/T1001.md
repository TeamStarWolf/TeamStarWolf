# T1001 — Data Obfuscation

<a id="t1001"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1001](https://attack.mitre.org/techniques/T1001)

## Detection

**Detection strategies:**

- Detect Obfuscated C2 via Network Traffic Analysis

**Analytics (3):**

- **Analytic 0144** (Windows) — `NSM:Flow HTTP ` → Network Traffic Content
- **Analytic 0145** (Linux) — `auditd:SYSCALL connect` → Network Connection Creation
- **Analytic 0146** (macOS) — `macos:unifiedlog network flow` → Network Traffic Content; `macos:unifiedlog process` → Process Creation
