# T1003.001 — LSASS Memory

<a id="t1003001"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1003.001](https://attack.mitre.org/techniques/T1003/001)  
**Sub-technique of:** [T1003 — OS Credential Dumping](/mitre/techniques/T1003.md)  

Adversaries may attempt to access credential material stored in the process memory of the Local Security Authority Subsystem Service (LSASS). After a user logs on, the system generates and stores a variety of credential materials in LSASS process memory.

## Detection

**Detection strategies:**

- Detection of Credential Dumping from LSASS Memory via Access and Dump Sequence

**Analytics (1):**

- **Analytic 1030** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=4673` → User Account Metadata; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
