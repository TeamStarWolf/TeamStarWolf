# T1003.002 — Security Account Manager

<a id="t1003002"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1003.002](https://attack.mitre.org/techniques/T1003/002)  
**Sub-technique of:** [T1003 — OS Credential Dumping](/mitre/techniques/T1003.md)  

Adversaries may attempt to extract credential material from the Security Account Manager (SAM) database either through in-memory techniques or through the Windows Registry where the SAM database is stored.

## Detection

**Detection strategies:**

- Credential Dumping from SAM via Registry Dump and Local File Access

**Analytics (1):**

- **Analytic 0235** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=2` → File Modification
