# T1003.003 — NTDS

<a id="t1003003"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1003.003](https://attack.mitre.org/techniques/T1003/003)  
**Sub-technique of:** [T1003 — OS Credential Dumping](/mitre/techniques/T1003.md)  

Adversaries may attempt to access or create a copy of the Active Directory domain database in order to steal credential information, as well as obtain other information about domain members such as devices, users, and access rights.

## Detection

**Detection strategies:**

- Detection of NTDS.dit Credential Dumping from Domain Controllers

**Analytics (1):**

- **Analytic 1611** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=2` → File Modification; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Microsoft-Windows-VSS Volume Shadow Copy Creation` → Volume Creation
