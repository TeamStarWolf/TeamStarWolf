# T1003.004 — LSA Secrets

<a id="t1003004"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1003.004](https://attack.mitre.org/techniques/T1003/004)  
**Sub-technique of:** [T1003 — OS Credential Dumping](/mitre/techniques/T1003.md)  

Adversaries with SYSTEM access to a host may attempt to access Local Security Authority (LSA) secrets, which can contain a variety of different credential materials, such as credentials for service accounts. LSA secrets are stored in the registry at <code>HKEY_LOCAL_MACHINE\SECURITY\Policy\Secrets</code>.

## Detection

**Detection strategies:**

- Detection of LSA Secrets Dumping via Registry and Memory Extraction

**Analytics (1):**

- **Analytic 1212** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Modification; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=7` → Module Load
