# T1003.005: Cached Domain Credentials

<a id="t1003005"></a>

Tactics: credential-access  
Platforms: Windows, Linux  
ATT&CK: [T1003.005](https://attack.mitre.org/techniques/T1003/005)  
Sub-technique of: [T1003: OS Credential Dumping](/mitre/techniques/T1003.md)  

Adversaries may attempt to access cached domain credentials used to allow authentication to occur in the event a domain controller is unavailable. On Windows Vista and newer, the hash format is DCC2 (Domain Cached Credentials version 2) hash, also known as MS-Cache v2 hash. The number of default cached credentials varies and can be altered per system. This hash does not allow pass-the-hash style attacks, and instead requires [Password Cracking](https://attack.mitre.org/techniques/T1110/002) to recover the plaintext password. On Linux systems, Active Directory credentials can be accessed through caches maintained by software like System Security Services Daemon (SSSD) or Quest Authentication Services (formerly VAS). Cached credential hashes are typically located at `/var/lib/sss/db/cache.[domain].ldb` for SSSD or `/var/opt/quest/vas/authcache/vas_auth.vdb` for Quest. Adversaries can use utilities, such as `tdbdump`, on these database files to dump the cached hashes and use [Password Cracking](https://attack.mitre.org/techniques/T1110/002) to obtain the plaintext password. With SYSTEM or sudo access, the tools/utilities such as [Mimikatz](https://attack.mitre.org/software/S0002), [Reg](https://attack.mitre.org/software/S0075), and secretsdump.py for Windows or Linikatz for Linux can be used to extract the cached credentials. Note: Cached credentials for Windows Vista are derived using PBKDF2.

## Mitigations (5)

- [M1015: Active Directory Configuration](/mitre/mitigations/M1015.md): Implement robust Active Directory (AD) configurations using group policies to secure user accounts, control access, and minimize the attack surface.
- [M1017: User Training](/mitre/mitigations/M1017.md): User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1026: Privileged Account Management](/mitre/mitigations/M1026.md): Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027: Password Policies](/mitre/mitigations/M1027.md): Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1028: Operating System Configuration](/mitre/mitigations/M1028.md): Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.

## D3FEND countermeasures (10)

- [Application Exception Monitoring](/mitre/d3fend/application-exception-monitoring.md) (Detect): monitors. Monitoring the failures of system counters and timers.
- [Authentication Cache Invalidation](/mitre/d3fend/authentication-cache-invalidation.md) (Evict): deletes. Removing tokens or credentials from an authentication cache to prevent further user associated account accesses.
- [Credential Compromise Scope Analysis](/mitre/d3fend/credential-compromise-scope-analysis.md) (Detect): analyzes. Determining which credentials may have been compromised by analyzing the user logon history of a particular system.
- [Credential Hardening](/mitre/d3fend/credential-hardening.md) (Harden): hardens. Credential Hardening techniques modify system or network properties in order to protect system or network/domain credentials.
- [Credential Revocation](/mitre/d3fend/credential-revocation.md) (Evict): deletes. Deleting a set of credentials permanently to prevent them from being used to authenticate.
- [Credential Rotation](/mitre/d3fend/credential-rotation.md) (Harden): regenerates. Credential rotation is a security procedure in which authentication credentials, such as passwords, API keys, or certificates, are regularly changed or replaced to minimize the risk of unauthorized access.
- [Credential Transmission Scoping](/mitre/d3fend/credential-transmission-scoping.md) (Isolate): isolates. Limiting the transmission of a credential to a scoped set of relying parties.
- [Decoy User Credential](/mitre/d3fend/decoy-user-credential.md) (Deceive): spoofs. A Credential created for the purpose of deceiving an adversary.
- [Multi-factor Authentication](/mitre/d3fend/multi-factor-authentication.md) (Harden): uses. Requiring proof of two or more pieces of evidence in order to authenticate a user.
- [Reissue Credential](/mitre/d3fend/reissue-credential.md) (Restore): restores. Issue a new credential to a user which supersedes their old credential.

## Adversary usage

_Notable groups seen using this technique:_

- [OilRig](/mitre/groups/G0049.md) (aka COBALT GYPSY, IRN2, APT34, Helix Kitten): [OilRig](https://attack.mitre.org/groups/G0049) is a suspected Iranian threat group that has targeted Middle Eastern and international victims since at least 2014.
- [APT33](/mitre/groups/G0064.md) (aka HOLMIUM, Elfin, Peach Sandstorm): [APT33](https://attack.mitre.org/groups/G0064) is a suspected Iranian threat group that has carried out operations since at least 2013.
- [MuddyWater](/mitre/groups/G0069.md) (aka Earth Vetala, MERCURY, Static Kitten, Seedworm): [MuddyWater](https://attack.mitre.org/groups/G0069) is a cyber espionage group assessed to be a subordinate element within Iran's Ministry of Intelligence and Security (MOIS).(Citation: CYBERCOM Iranian Intel Cyber January 2022) Since at least 2017, [MuddyWater](https://attack.mitre.org/groups/G0069) has targeted a range of government and private organizations across sectors, including telecommunications, local government, finance, defense, and oil and natural gas organizations, in the Middle East (specifically the UAE and Saudi Arabia), Asia, Africa, Europe, and North America.
- [Leafminer](/mitre/groups/G0077.md) (aka Raspite): [Leafminer](https://attack.mitre.org/groups/G0077) is an Iranian threat group that has targeted government organizations and business entities in the Middle East since at least early 2017.
