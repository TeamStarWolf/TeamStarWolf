# T1003.005 — Cached Domain Credentials

<a id="t1003005"></a>

**Tactics:** credential-access  
**Platforms:** Windows, Linux  
**ATT&CK:** [T1003.005](https://attack.mitre.org/techniques/T1003/005)  
**Sub-technique of:** [T1003 — OS Credential Dumping](/mitre/techniques/T1003.md)  

Adversaries may attempt to access cached domain credentials used to allow authentication to occur in the event a domain controller is unavailable. On Windows Vista and newer, the hash format is DCC2 (Domain Cached Credentials version 2) hash, also known as MS-Cache v2 hash.

## Detection

**Detection strategies:**

- Detection of Cached Domain Credential Dumping via Local Hash Cache Access

**Analytics (2):**

- **Analytic 1417** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=10` → Process Access
- **Analytic 1418** (Linux) — `auditd:SYSCALL file` → File Access; `auditd:EXECVE EXECVE` → Process Creation; `linux:osquery process_events` → Process Access
