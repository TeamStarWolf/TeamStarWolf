# T1003.006 — DCSync

<a id="t1003006"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1003.006](https://attack.mitre.org/techniques/T1003/006)  
**Sub-technique of:** [T1003 — OS Credential Dumping](/mitre/techniques/T1003.md)  

Adversaries may attempt to access credentials and other sensitive information by abusing a Windows Domain Controller's application programming interface (API) to simulate the replication process from a remote domain controller using a technique called DCSync. Members of the Administrators, Domain Admins, and Enterprise Admin groups or computer accounts on the domain controller are able to run DCSync to pull password data from Active Directory, which may include current and historical hashes of potentially useful accounts such as KRBTGT and Administrators. The hashes can then in turn be used to create a [Golden Ticket](https://attack.mitre.org/techniques/T1558/001) for use in [Pass the Ticket](https://attack.mitre.org/techniques/T1550/003) or change an account's password as noted in [Account Manipulation](https://attack.mitre.org/techniques/T1098). DCSync functionality has been included in the "lsadump" module in [Mimikatz](https://attack.mitre.org/software/S0002). Lsadump also includes NetSync, which performs DCSync over a legacy replication protocol.

## Mitigations (3)

- [M1015 — Active Directory Configuration](/mitre/mitigations/M1015.md) — Implement robust Active Directory (AD) configurations using group policies to secure user accounts, control access, and minimize the attack surface.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.

## Detection

**Detection strategies:**

- Detection of Unauthorized DCSync Operations via Replication API Abuse

**Analytics (1):**

- **Analytic 1632** (Windows) — `WinEventLog:Security EventCode=4662` → Active Directory Object Access; `WinEventLog:Security EventCode=4929` → Active Directory Object Deletion; `NSM:Content Traffic on RPC DRSUAPI` → Network Traffic Content
