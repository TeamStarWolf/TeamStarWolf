# T1003.006 — DCSync

<a id="t1003006"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1003.006](https://attack.mitre.org/techniques/T1003/006)  
**Sub-technique of:** [T1003 — OS Credential Dumping](/mitre/techniques/T1003.md)  

Adversaries may attempt to access credentials and other sensitive information by abusing a Windows Domain Controller's application programming interface (API) to simulate the replication process from a remote domain controller using a technique called DCSync.

## Mitigations (3)

- [M1015 — Active Directory Configuration](/mitre/mitigations/M1015.md) — Implement robust Active Directory (AD) configurations using group policies to secure user accounts, control access, and minimize the attack surface.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.

## Detection

**Detection strategies:**

- Detection of Unauthorized DCSync Operations via Replication API Abuse

**Analytics (1):**

- **Analytic 1632** (Windows) — `WinEventLog:Security EventCode=4662` → Active Directory Object Access; `WinEventLog:Security EventCode=4929` → Active Directory Object Deletion; `NSM:Content Traffic on RPC DRSUAPI` → Network Traffic Content

## Adversary usage

- [Mustang Panda](https://attack.mitre.org/groups/G0129) (aka TA416, RedDelta, BRONZE PRESIDENT, STATELY TAURUS) — Mustang Panda is a China-based cyber espionage threat actor that has been conducting operations since at least 2012.
- [LAPSUS$](https://attack.mitre.org/groups/G1004) (aka DEV-0537, Strawberry Tempest) — LAPSUS$ is cyber criminal threat group that has been active since at least mid-2021.
- [Earth Lusca](https://attack.mitre.org/groups/G1006) (aka TAG-22, Charcoal Typhoon, CHROMIUM, ControlX) — Earth Lusca is a suspected China-based cyber espionage group that has been active since at least April 2019.
- [Storm-0501](https://attack.mitre.org/groups/G1053) — Storm-0501 is a financially motivated cyber criminal group that uses commodity and open-source tools to conduct ransomware operations.
