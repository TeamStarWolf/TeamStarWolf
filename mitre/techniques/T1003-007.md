# T1003.007 — Proc Filesystem

<a id="t1003007"></a>

**Tactics:** credential-access  
**Platforms:** Linux  
**ATT&CK:** [T1003.007](https://attack.mitre.org/techniques/T1003/007)  
**Sub-technique of:** [T1003 — OS Credential Dumping](/mitre/techniques/T1003.md)  

Adversaries may gather credentials from the proc filesystem or `/proc`. The proc filesystem is a pseudo-filesystem used as an interface to kernel data structures for Linux based systems managing virtual memory.

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).

## Detection

**Detection strategies:**

- Detecting OS Credential Dumping via /proc Filesystem Access on Linux

**Analytics (1):**

- **Analytic 1631** (Linux) — `auditd:SYSCALL open, read` → File Access; `auditd:SYSCALL write` → File Modification; `auditd:SYSCALL ptrace or process_vm_readv` → Process Access; `linux:Sysmon EventCode=1` → Process Creation
