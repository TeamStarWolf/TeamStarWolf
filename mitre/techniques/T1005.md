# T1005 — Data from Local System

<a id="t1005"></a>

**Tactics:** collection  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1005](https://attack.mitre.org/techniques/T1005)  

Adversaries may search local system sources, such as file systems, configuration files, local databases, virtual machine files, or process memory, to find files of interest and sensitive data prior to Exfiltration.

## Mitigations (1)

- [M1057 — Data Loss Prevention](/mitre/mitigations/M1057.md) — Data Loss Prevention (DLP) involves implementing strategies and technologies to identify, categorize, monitor, and control the movement of sensitive data within an organization.

## Detection

**Detection strategies:**

- Detection of Local Data Collection Prior to Exfiltration

**Analytics (5):**

- **Analytic 1070** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 1071** (Linux) — `auditd:SYSCALL open` → File Access; `auditd:SYSCALL execve` → Process Creation
- **Analytic 1072** (macOS) — `macos:unifiedlog process:spawn` → Process Creation; `fs:fsusage read/write` → File Access
- **Analytic 1073** (Network Devices) — `networkdevice:cli command logging` → Command Execution
- **Analytic 1074** (ESXi) — `esxis:vmkernel Datastore Access` → File Access; `esxi:hostd Command Execution` → Command Execution
