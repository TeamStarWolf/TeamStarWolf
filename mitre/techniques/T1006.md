# T1006 — Direct Volume Access

<a id="t1006"></a>

**Tactics:** defense-evasion  
**Platforms:** Network Devices, Windows  
**ATT&CK:** [T1006](https://attack.mitre.org/techniques/T1006)  

Adversaries may directly access a volume to bypass file access controls and file system monitoring. Windows allows programs to have direct access to logical volumes. Programs with direct access may read and write files directly from the drive by analyzing file system data structures.

## Detection

**Detection strategies:**

- Detection of Direct Volume Access for File System Evasion

**Analytics (2):**

- **Analytic 1193** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Security EventCode=4688` → Process Creation
- **Analytic 1194** (Network Devices) — `networkdevice:cli command logging` → Command Execution
