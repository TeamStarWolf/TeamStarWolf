# T1007 — System Service Discovery

<a id="t1007"></a>

**Tactics:** discovery  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1007](https://attack.mitre.org/techniques/T1007)  

Adversaries may try to gather information about registered local system services. Adversaries may obtain information about services using tools as well as OS utility commands such as <code>sc query</code>, <code>tasklist /svc</code>, <code>systemctl --type=service</code>, and <code>net start</code>.

## D3FEND countermeasures (6)

- [Executable Allowlisting](/mitre/d3fend/executable-allowlisting.md) (Isolate) — filters. Using a digital signature to authenticate a file before opening.
- [Executable Denylisting](/mitre/d3fend/executable-denylisting.md) (Isolate) — filters. Blocking the execution of files on a host in accordance with defined application policy rules.
- [Hardware-based Process Isolation](/mitre/d3fend/hardware-based-process-isolation.md) (Isolate) — restricts. Preventing one process from writing to the memory space of another process through hardware based address manager implementations.
- [Process Spawn Analysis](/mitre/d3fend/process-spawn-analysis.md) (Detect) — analyzes. Analyzing spawn arguments or attributes of a process to detect processes that are unauthorized.
- [System Call Analysis](/mitre/d3fend/system-call-analysis.md) (Detect) — analyzes. Analyzing system calls to determine whether a process is exhibiting unauthorized behavior.
- [System Call Filtering](/mitre/d3fend/system-call-filtering.md) (Isolate) — filters. Controlling access to local computer system resources with kernel-level capabilities.

## Detection

**Detection strategies:**

- Detection of System Service Discovery Commands Across OS Platforms

**Analytics (3):**

- **Analytic 1325** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 1326** (Linux) — `auditd:EXECVE execve` → Process Creation
- **Analytic 1327** (macOS) — `macos:unifiedlog` → Command Execution; `macos:osquery process_events` → Process Creation
