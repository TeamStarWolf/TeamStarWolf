# T1007 — System Service Discovery

<a id="t1007"></a>

**Tactics:** discovery  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1007](https://attack.mitre.org/techniques/T1007)  

Adversaries may try to gather information about registered local system services. Adversaries may obtain information about services using tools as well as OS utility commands such as <code>sc query</code>, <code>tasklist /svc</code>, <code>systemctl --type=service</code>, and <code>net start</code>.

## Detection

**Detection strategies:**

- Detection of System Service Discovery Commands Across OS Platforms

**Analytics (3):**

- **Analytic 1325** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 1326** (Linux) — `auditd:EXECVE execve` → Process Creation
- **Analytic 1327** (macOS) — `macos:unifiedlog` → Command Execution; `macos:osquery process_events` → Process Creation
