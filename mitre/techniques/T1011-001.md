# T1011.001 — Exfiltration Over Bluetooth

<a id="t1011001"></a>

**Tactics:** exfiltration  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1011.001](https://attack.mitre.org/techniques/T1011/001)  
**Sub-technique of:** [T1011 — Exfiltration Over Other Network Medium](/mitre/techniques/T1011.md)  

Adversaries may attempt to exfiltrate data over Bluetooth rather than the command and control channel. If the command and control network is a wired Internet connection, an adversary may opt to exfiltrate data using a Bluetooth communication channel.

## Mitigations (2)

- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.

## Detection

**Detection strategies:**

- Detection of Bluetooth-Based Data Exfiltration

**Analytics (3):**

- **Analytic 1531** (Windows) — `WinEventLog:System EventCode=8001` → Network Connection Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1532** (Linux) — `auditd:SYSCALL` → Command Execution; `linux:syslog` → Network Connection Creation; `linux:osquery` → File Access
- **Analytic 1533** (macOS) — `macos:unifiedlog` → Command Execution; `macos:osquery` → Network Connection Creation; `macos:osquery` → File Access
