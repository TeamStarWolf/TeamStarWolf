# T1012 — Query Registry

<a id="t1012"></a>

**Tactics:** discovery  
**Platforms:** Windows  
**ATT&CK:** [T1012](https://attack.mitre.org/techniques/T1012)  

Adversaries may interact with the Windows Registry to gather information about the system, configuration, and installed software. The Registry contains a significant amount of information about the operating system, configuration, software, and security.

## D3FEND countermeasures (5)

- [Data Inventory](/mitre/d3fend/data-inventory.md) (Model) — inventories. Data inventorying identifies and records the schemas, formats, volumes, and locations of data stored and used on the organization's architecture.
- [Restore Database](/mitre/d3fend/restore-database.md) (Restore) — restores. Restoring the data in a database.
- [System Call Analysis](/mitre/d3fend/system-call-analysis.md) (Detect) — analyzes. Analyzing system calls to determine whether a process is exhibiting unauthorized behavior.
- [System Call Filtering](/mitre/d3fend/system-call-filtering.md) (Isolate) — filters. Controlling access to local computer system resources with kernel-level capabilities.
- [System Configuration Permissions](/mitre/d3fend/system-configuration-permissions.md) (Harden) — restricts. Restricting system configuration modifications to a specific user or group of users.

## Detection

**Detection strategies:**

- Detection of Registry Query for Environmental Discovery

**Analytics (1):**

- **Analytic 0589** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution

## Data sources & telemetry (3)

**Process Creation**, **Windows Registry Key Modification**, **Command Execution**
