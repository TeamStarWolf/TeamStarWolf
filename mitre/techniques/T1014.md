# T1014 — Rootkit

<a id="t1014"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1014](https://attack.mitre.org/techniques/T1014)  

Adversaries may use rootkits to hide the presence of programs, files, network connections, services, drivers, and other system components. Rootkits are programs that hide the existence of malware by intercepting/hooking and modifying operating system API calls that supply system information.

## Detection

**Detection strategies:**

- Detection of Kernel/User-Level Rootkit Behavior Across Platforms

**Analytics (3):**

- **Analytic 1061** (Windows) — `WinEventLog:Sysmon EventCode=6` → Driver Load; `WinEventLog:System EventCode=7045` → Service Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 1062** (Linux) — `auditd:EXECVE` → Process Creation; `linux:osquery file_events` → File Modification; `linux:syslog kmod` → Module Load
- **Analytic 1063** (macOS) — `macos:unifiedlog subsystem=com.apple.kextd` → Module Load; `macos:osquery launch_daemons` → Service Creation; `fs:fsevents Extensions` → File Modification

## Data sources & telemetry (6)

**Driver Load**, **Service Creation**, **File Creation**, **Process Creation**, **File Modification**, **Module Load**

## Adversary usage

**Threat groups (6):** [APT28](https://attack.mitre.org/groups/G0007), [Winnti Group](https://attack.mitre.org/groups/G0044), [APT41](https://attack.mitre.org/groups/G0096), [Rocke](https://attack.mitre.org/groups/G0106), [TeamTNT](https://attack.mitre.org/groups/G0139), [UNC3886](https://attack.mitre.org/groups/G1048)

_Notable groups seen using this technique:_

- [APT28](https://attack.mitre.org/groups/G0007) (aka IRON TWILIGHT, SNAKEMACKEREL, Swallowtail, Group 74) — APT28 is a threat group that has been attributed to Russia's General Staff Main Intelligence Directorate (GRU) 85th Main Special Service Center (GTsSS) military unit 26165.
- [Winnti Group](https://attack.mitre.org/groups/G0044) (aka Blackfly) — Winnti Group is a threat group with Chinese origins that has been active since at least 2010.
- [APT41](https://attack.mitre.org/groups/G0096) (aka Wicked Panda, Brass Typhoon, BARIUM) — APT41 is a threat group that researchers have assessed as Chinese state-sponsored espionage group that also conducts financially-motivated operations.
- [Rocke](https://attack.mitre.org/groups/G0106) — Rocke is an alleged Chinese-speaking adversary whose primary objective appeared to be cryptojacking, or stealing victim system resources for the purposes of mining cryptocurrency.
- [TeamTNT](https://attack.mitre.org/groups/G0139) — TeamTNT is a threat group that has primarily targeted cloud and containerized environments.
- [UNC3886](https://attack.mitre.org/groups/G1048) — UNC3886 is a China-nexus cyberespionage group that has been active since at least 2022, targeting defense, technology, and telecommunication organizations located in the United States and the Asia-Pacific-Japan (APJ)…
