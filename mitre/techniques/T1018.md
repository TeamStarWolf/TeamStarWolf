# T1018 — Remote System Discovery

<a id="t1018"></a>

**Tactics:** discovery  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1018](https://attack.mitre.org/techniques/T1018)  

Adversaries may attempt to get a listing of other systems by IP address, hostname, or other logical identifier on a network that may be used for Lateral Movement from the current system.

## Detection

**Detection strategies:**

- Detection Strategy for Remote System Enumeration Behavior

**Analytics (5):**

- **Analytic 1583** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1584** (Linux) — `auditd:EXECVE execve` → Process Creation; `linux:syslog network` → Network Connection Creation
- **Analytic 1585** (macOS) — `macos:unifiedlog process` → Process Creation; `macos:osquery file_events` → File Access
- **Analytic 1586** (ESXi) — `esxi:hostd` → Command Execution
- **Analytic 1587** (Network Devices) — `networkdevice:syslog syslog facility LOCAL7 or trap messages` → Command Execution

## Data sources & telemetry (4)

**Process Creation**, **Network Connection Creation**, **File Access**, **Command Execution**
