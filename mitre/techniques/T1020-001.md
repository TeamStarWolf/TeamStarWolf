# T1020.001 — Traffic Duplication

<a id="t1020001"></a>

**Tactics:** exfiltration  
**Platforms:** Network Devices, IaaS  
**ATT&CK:** [T1020.001](https://attack.mitre.org/techniques/T1020/001)  
**Sub-technique of:** [T1020 — Automated Exfiltration](/mitre/techniques/T1020.md)  

Adversaries may leverage traffic mirroring in order to automate data exfiltration over compromised infrastructure. Traffic mirroring is a native feature for some devices, often used for network analysis.

## Detection

**Detection strategies:**

- Detection Strategy for Traffic Duplication via Mirroring in IaaS and Network Devices

**Analytics (2):**

- **Analytic 1131** (IaaS) — `AWS:CloudTrail CreateTrafficMirrorSession or ModifyTrafficMirrorTarget` → Network Traffic Flow; `AWS:VPCFlowLogs Traffic observed on mirror destination instance` → Network Connection Creation
- **Analytic 1132** (Network Devices) — `networkdevice:syslog Config change: CLI/NETCONF/SNMP – 'monitor session', 'mirror port'` → Network Traffic Flow; `networkdevice:Flow Traffic from mirrored interface to mirror target IP` → Network Connection Creation

## Data sources & telemetry (2)
