# T1020 — Automated Exfiltration

<a id="t1020"></a>

**Tactics:** exfiltration  
**Platforms:** Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1020](https://attack.mitre.org/techniques/T1020)  

Adversaries may exfiltrate data, such as sensitive documents, through the use of automated processing after being gathered during Collection.

**Detection strategies:**

- Automated Exfiltration Detection Strategy

**Analytics (3):**

- **Analytic 1113** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1114** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Flow Outbound Connections` → Network Connection Creation
- **Analytic 1115** (macOS) — `macos:unifiedlog process: exec` → Process Creation; `macos:unifiedlog network` → Network Connection Creation; `macos:cron cron/launchd` → Scheduled Job Creation
