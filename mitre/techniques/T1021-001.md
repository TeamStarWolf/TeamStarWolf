# T1021.001 — Remote Desktop Protocol

<a id="t1021001"></a>

**Tactics:** lateral-movement  
**Platforms:** Windows  
**ATT&CK:** [T1021.001](https://attack.mitre.org/techniques/T1021/001)  
**Sub-technique of:** [T1021](/mitre/techniques/T1021.md)

Adversaries may use Valid Accounts to log into a computer using the Remote Desktop Protocol (RDP). The adversary may then perform actions as the logged-on user. Remote desktop is a common feature in operating systems.


**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **32 machines (6.0%)** — Linux 0 / Windows 29. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.
