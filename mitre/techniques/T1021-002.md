# T1021.002 — SMB/Windows Admin Shares

<a id="t1021002"></a>

**Tactics:** lateral-movement  
**Platforms:** Windows  
**ATT&CK:** [T1021.002](https://attack.mitre.org/techniques/T1021/002)  
**Sub-technique of:** [T1021 — Remote Services](/mitre/techniques/T1021.md)  

Adversaries may use Valid Accounts to interact with a remote network share using Server Message Block (SMB). The adversary may then perform actions as the logged-on user. SMB is a file, printer, and serial port sharing protocol for Windows machines on the same network or domain.

## Mitigations (4)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1035 — Limit Access to Resource Over Network](/mitre/mitigations/M1035.md) — Restrict access to network resources, such as file shares, remote systems, and services, to only those users, accounts, or systems with a legitimate business requirement.
- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection
