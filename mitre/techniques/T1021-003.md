# T1021.003 — Distributed Component Object Model

<a id="t1021003"></a>

**Tactics:** lateral-movement  
**Platforms:** Windows  
**ATT&CK:** [T1021.003](https://attack.mitre.org/techniques/T1021/003)  
**Sub-technique of:** [T1021 — Remote Services](/mitre/techniques/T1021.md)  

Adversaries may use Valid Accounts to interact with remote machines by taking advantage of Distributed Component Object Model (DCOM). The adversary may then perform actions as the logged-on user.

## Mitigations (4)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.
- [M1048 — Application Isolation and Sandboxing](/mitre/mitigations/M1048.md) — Application Isolation and Sandboxing refers to the technique of restricting the execution of code to a controlled and isolated environment (e.g., a virtual environment, container, or sandbox).

## Detection

**Detection strategies:**

- Multi-Event Behavioral Detection for DCOM-Based Remote Code Execution

**Analytics (1):**

- **Analytic 0791** (Windows) — `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load
