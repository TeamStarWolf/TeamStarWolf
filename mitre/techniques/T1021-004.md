# T1021.004 — SSH

<a id="t1021004"></a>

**Tactics:** lateral-movement  
**Platforms:** ESXi, Linux, macOS  
**ATT&CK:** [T1021.004](https://attack.mitre.org/techniques/T1021/004)  
**Sub-technique of:** [T1021 — Remote Services](/mitre/techniques/T1021.md)  

Adversaries may use Valid Accounts to log into remote machines using Secure Shell (SSH). The adversary may then perform actions as the logged-on user. SSH is a protocol that allows authorized users to open remote shells on other computers.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **129 machines (24.4%)** — Linux 114 / Windows 5. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Detection

**Detection strategies:**

- Behavioral Detection of Remote SSH Logins Followed by Post-Login Execution

**Analytics (3):**

- **Analytic 1638** (Linux) — `auditd:EXECVE EXECVE` → Process Creation; `linux:syslog` → Logon Session Creation; `NSM:Flow TCP port 22 traffic` → Network Traffic Flow
- **Analytic 1639** (macOS) — `macos:unifiedlog process = 'sshd'` → Logon Session Metadata; `macos:unifiedlog process = 'ssh' OR eventMessage CONTAINS 'ssh'` → Network Traffic Content; `macos:osquery process_events` → Process Creation
- **Analytic 1640** (ESXi) — `esxi:auth` → Logon Session Metadata; `esxi:shell` → Command Execution; `esxi:vmkernel port 22 access` → Network Traffic Flow
