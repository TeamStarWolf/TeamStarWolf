# T1021.006 — Windows Remote Management

<a id="t1021006"></a>

**Tactics:** lateral-movement  
**Platforms:** Windows  
**ATT&CK:** [T1021.006](https://attack.mitre.org/techniques/T1021/006)  
**Sub-technique of:** [T1021 — Remote Services](/mitre/techniques/T1021.md)  

Adversaries may use Valid Accounts to interact with remote systems using Windows Remote Management (WinRM). The adversary may then perform actions as the logged-on user.

## Mitigations (3)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.

## Detection

**Detection strategies:**

- Behavioral Detection of WinRM-Based Remote Access

**Analytics (1):**

- **Analytic 1313** (Windows) — `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:WinRM EventCode=6` → Service Metadata; `NSM:Connections Inbound on ports 5985/5986` → Network Traffic Flow
