# T1021.007 — Cloud Services

<a id="t1021007"></a>

**Tactics:** lateral-movement  
**Platforms:** IaaS, Identity Provider, Office Suite, SaaS  
**ATT&CK:** [T1021.007](https://attack.mitre.org/techniques/T1021/007)  
**Sub-technique of:** [T1021 — Remote Services](/mitre/techniques/T1021.md)  

Adversaries may log into accessible cloud services within a compromised environment using Valid Accounts that are synchronized with or federated to on-premises user identities. The adversary may then perform management actions or access cloud-hosted resources as the logged-on user.

## Mitigations (2)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md)
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md)

## Detection

**Detection strategies:**

- Behavioral Detection of Remote Cloud Logins via Valid Accounts

**Analytics (4):**

- **Analytic 0017** (IaaS) — `AWS:CloudTrail ConsoleLogin, AssumeRole, ListResources` → Logon Session Creation; `gcp:audit` → Command Execution
- **Analytic 0018** (Identity Provider) — `Okta:SystemLog user.authentication.sso, app.oauth.grant` → Logon Session Creation
- **Analytic 0019** (Office Suite) — `m365:unified FileAccessed, MailboxAccessed` → File Access; `m365:unified UserLoggedIn` → Logon Session Creation
- **Analytic 0020** (SaaS) — `saas:auth LoginSuccess, APIKeyUse, AdminAction` → Logon Session Creation
