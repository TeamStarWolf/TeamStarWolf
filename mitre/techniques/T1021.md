# T1021 — Remote Services

<a id="t1021"></a>

**Tactics:** lateral-movement  
**Platforms:** Linux, macOS, Windows, IaaS, ESXi  
**ATT&CK:** [T1021](https://attack.mitre.org/techniques/T1021)  

Adversaries may use Valid Accounts to log into a service that accepts remote connections, such as telnet, SSH, and VNC. The adversary may then perform actions as the logged-on user. In an enterprise environment, servers and workstations can be organized into domains.

## Mitigations (6)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1035 — Limit Access to Resource Over Network](/mitre/mitigations/M1035.md) — Restrict access to network resources, such as file shares, remote systems, and services, to only those users, accounts, or systems with a legitimate business requirement.
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Behavioral Detection Strategy for Remote Service Logins and Post-Access Activity

**Analytics (5):**

- **Analytic 0750** (Windows) — `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0751** (Linux) — `linux:syslog sshd: Accepted password/publickey` → Logon Session Creation; `auditd:SYSCALL execve, USER_CMD` → Command Execution
- **Analytic 0752** (macOS) — `macos:unifiedlog eventMessage CONTAINS 'screensharingd' or 'AuthorizationRefCreate'` → Logon Session Creation; `macos:osquery process_events` → Process Creation
- **Analytic 0753** (IaaS) — `AWS:CloudTrail AWS ConsoleLogin, StartSession` → Logon Session Creation; `AWS:VPCFlowLogs Outbound connections to port 22, 3389` → Network Connection Creation
- **Analytic 0754** (ESXi) — `esxi:vmkernel vim.fault.*, DCUI login, SSH shell` → Logon Session Creation; `esxi:shell Command execution trace` → Command Execution

## Sub-techniques (8)
