# T1025 — Data from Removable Media

<a id="t1025"></a>

**Tactics:** collection  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1025](https://attack.mitre.org/techniques/T1025)  

Adversaries may search connected removable media on computers they have compromised to find files of interest. Sensitive data can be collected from any removable media (optical disk drive, USB memory, etc.) connected to the compromised system prior to Exfiltration.

## Mitigations (1)

- [M1057 — Data Loss Prevention](/mitre/mitigations/M1057.md) — Data Loss Prevention (DLP) involves implementing strategies and technologies to identify, categorize, monitor, and control the movement of sensitive data within an organization.

## Detection

**Detection strategies:**

- Detection of Data Access and Collection from Removable Media

**Analytics (3):**

- **Analytic 1410** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `WinEventLog:System EventCode=2003` → Drive Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1411** (Linux) — `auditd:SYSCALL open, read, mount` → File Access; `journald:systemd udisks2 or udevd logs` → Drive Creation; `auditd:SYSCALL execve` → Process Creation
- **Analytic 1412** (macOS) — `macos:unifiedlog log stream --predicate 'eventMessage contains "USBMSC"'` → Drive Creation; `fs:fsusage file reads/writes from /Volumes/` → File Access; `macos:osquery process_events` → Process Creation

## Data sources & telemetry (3)

## Adversary usage

**Threat groups (4):** [APT28](https://attack.mitre.org/groups/G0007), [Turla](https://attack.mitre.org/groups/G0010), [Gamaredon Group](https://attack.mitre.org/groups/G0047), [OilRig](https://attack.mitre.org/groups/G0049)

_Notable groups seen using this technique:_

- [APT28](https://attack.mitre.org/groups/G0007) (aka IRON TWILIGHT, SNAKEMACKEREL, Swallowtail, Group 74) — APT28 is a threat group that has been attributed to Russia's General Staff Main Intelligence Directorate (GRU) 85th Main Special Service Center (GTsSS) military unit 26165.
- [Turla](https://attack.mitre.org/groups/G0010) (aka IRON HUNTER, Group 88, Waterbug, WhiteBear) — Turla is a cyber espionage threat group that has been attributed to Russia's Federal Security Service (FSB).
- [Gamaredon Group](https://attack.mitre.org/groups/G0047) (aka IRON TILDEN, Primitive Bear, ACTINIUM, Armageddon) — Gamaredon Group is a suspected Russian cyber espionage group that has targeted military, law enforcement, judiciary, non-profit, and non-governmental organizations in Ukraine since at least 2013.
- [OilRig](https://attack.mitre.org/groups/G0049) (aka COBALT GYPSY, IRN2, APT34, Helix Kitten) — OilRig is a suspected Iranian threat group that has targeted Middle Eastern and international victims since at least 2014.
