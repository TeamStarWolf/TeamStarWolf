# T1027.003 — Steganography

<a id="t1027003"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1027.003](https://attack.mitre.org/techniques/T1027/003)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may use steganography techniques in order to prevent the detection of hidden information. Steganographic techniques can be used to hide data in digital media such as images, audio tracks, video clips, or text files. Duqu was an early example of malware that used steganography.

## Detection

**Detection strategies:**

- Detection Strategy for Steganographic Abuse in File & Script Execution

**Analytics (3):**

- **Analytic 0331** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access
- **Analytic 0332** (Linux) — `auditd:SYSCALL open` → File Access; `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL connect` → Network Connection Creation
- **Analytic 0333** (macOS) — `macos:osquery file_events` → File Access; `macos:osquery process_events` → Process Creation; `macos:unifiedlog network connection events` → Network Connection Creation

_Notable groups seen using this technique:_

- [BRONZE BUTLER](https://attack.mitre.org/groups/G0060) (aka REDBALDKNIGHT, Tick) — BRONZE BUTLER is a cyber espionage group with likely Chinese origins that has been active since at least 2008.
- [Leviathan](https://attack.mitre.org/groups/G0065) (aka MUDCARP, Kryptonite Panda, Gadolinium, BRONZE MOHAWK) — Leviathan is a Chinese state-sponsored cyber espionage group that has been attributed to the Ministry of State Security's (MSS) Hainan State Security Department and an affiliated front company.
- [APT37](https://attack.mitre.org/groups/G0067) (aka InkySquid, ScarCruft, Reaper, Group123) — APT37 is a North Korean state-sponsored cyber espionage group that has been active since at least 2012.
- [MuddyWater](https://attack.mitre.org/groups/G0069) (aka Earth Vetala, MERCURY, Static Kitten, Seedworm) — MuddyWater is a cyber espionage group assessed to be a subordinate element within Iran's Ministry of Intelligence and Security (MOIS).
- [Tropic Trooper](https://attack.mitre.org/groups/G0081) (aka Pirate Panda, KeyBoy) — Tropic Trooper is an unaffiliated threat group that has led targeted campaigns against targets in Taiwan, the Philippines, and Hong Kong.
- [TA551](https://attack.mitre.org/groups/G0127) (aka GOLD CABIN, Shathak) — TA551 is a financially-motivated threat group that has been active since at least 2018.
