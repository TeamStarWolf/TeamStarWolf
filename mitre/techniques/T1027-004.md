# T1027.004 — Compile After Delivery

<a id="t1027004"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1027.004](https://attack.mitre.org/techniques/T1027/004)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may attempt to make payloads difficult to discover and analyze by delivering files to victims as uncompiled code. Text-based source code files may subvert analysis and scrutiny from protections targeting executables/binaries.

## Detection

**Detection strategies:**

- Detection Strategy for Compile After Delivery - Source Code to Executable Transformation

**Analytics (3):**

- **Analytic 1381** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1382** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL open,create` → File Creation; `NSM:Flow conn.log` → Network Connection Creation
- **Analytic 1383** (macOS) — `macos:unifiedlog process activity, exec events` → Process Creation; `macos:osquery file_events` → File Creation; `macos:unifiedlog networkd or socket` → Network Connection Creation

## Adversary usage

**Threat groups (4):** [Gamaredon Group](https://attack.mitre.org/groups/G0047), [MuddyWater](https://attack.mitre.org/groups/G0069), [Rocke](https://attack.mitre.org/groups/G0106), [Sea Turtle](https://attack.mitre.org/groups/G1041)

_Notable groups seen using this technique:_

- [Gamaredon Group](https://attack.mitre.org/groups/G0047) (aka IRON TILDEN, Primitive Bear, ACTINIUM, Armageddon) — Gamaredon Group is a suspected Russian cyber espionage group that has targeted military, law enforcement, judiciary, non-profit, and non-governmental organizations in Ukraine since at least 2013.
- [MuddyWater](https://attack.mitre.org/groups/G0069) (aka Earth Vetala, MERCURY, Static Kitten, Seedworm) — MuddyWater is a cyber espionage group assessed to be a subordinate element within Iran's Ministry of Intelligence and Security (MOIS).
- [Rocke](https://attack.mitre.org/groups/G0106) — Rocke is an alleged Chinese-speaking adversary whose primary objective appeared to be cryptojacking, or stealing victim system resources for the purposes of mining cryptocurrency.
- [Sea Turtle](https://attack.mitre.org/groups/G1041) (aka Teal Kurma, Marbled Dust, Cosmic Wolf, SILICON) — Sea Turtle is a Türkiye-linked threat actor active since at least 2017 performing espionage and service provider compromise operations against victims in Asia, Europe, and North America.
