# T1027.004 — Compile After Delivery

<a id="t1027004"></a>

**Tactics:** stealth  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1027.004](https://attack.mitre.org/techniques/T1027/004)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may attempt to make payloads difficult to discover and analyze by delivering files to victims as uncompiled code. Text-based source code files may subvert analysis and scrutiny from protections targeting executables/binaries. These payloads will need to be compiled before execution; typically via native utilities such as ilasm.exe, csc.exe, or GCC/MinGW. Source code payloads may also be encrypted, encoded, and/or embedded within other files, such as those delivered as a [Phishing](https://attack.mitre.org/techniques/T1566). Payloads may also be delivered in formats unrecognizable and inherently benign to the native OS (ex: EXEs on macOS/Linux) before later being (re)compiled into a proper executable binary with a bundled compiler and execution framework.

## Detection

**Detection strategies:**

- Detection Strategy for Compile After Delivery - Source Code to Executable Transformation

**Analytics (3):**

- **Analytic 1381** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1382** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL open,create` → File Creation; `NSM:Flow conn.log` → Network Connection Creation
- **Analytic 1383** (macOS) — `macos:unifiedlog process activity, exec events` → Process Creation; `macos:osquery file_events` → File Creation; `macos:unifiedlog networkd or socket` → Network Connection Creation

## Adversary usage

**Threat groups (4):** [Gamaredon Group](/mitre/groups/G0047.md), [MuddyWater](/mitre/groups/G0069.md), [Rocke](/mitre/groups/G0106.md), [Sea Turtle](/mitre/groups/G1041.md)

_Notable groups seen using this technique:_

- [Gamaredon Group](/mitre/groups/G0047.md) (aka IRON TILDEN, Primitive Bear, ACTINIUM, Armageddon) — [Gamaredon Group](https://attack.mitre.org/groups/G0047) is a suspected Russian cyber espionage group that has targeted military, law enforcement, judiciary, non-profit, and non-governmental organizations in Ukraine since at least 2013.
- [MuddyWater](/mitre/groups/G0069.md) (aka Earth Vetala, MERCURY, Static Kitten, Seedworm) — [MuddyWater](https://attack.mitre.org/groups/G0069) is a cyber espionage group assessed to be a subordinate element within Iran's Ministry of Intelligence and Security (MOIS).(Citation: CYBERCOM Iranian Intel Cyber January 2022) Since at least 2017, [MuddyWater](https://attack.mitre.org/groups/G0069) has targeted a range of government and private organizations across sectors, including telecommunications, local government, finance, defense, and oil and natural gas organizations, in the Middle East (specifically the UAE and Saudi Arabia), Asia, Africa, Europe, and North America.
- [Rocke](/mitre/groups/G0106.md) — [Rocke](https://attack.mitre.org/groups/G0106) is an alleged Chinese-speaking adversary whose primary objective appeared to be cryptojacking, or stealing victim system resources for the purposes of mining cryptocurrency.
- [Sea Turtle](/mitre/groups/G1041.md) (aka Teal Kurma, Marbled Dust, Cosmic Wolf, SILICON) — [Sea Turtle](https://attack.mitre.org/groups/G1041) is a Türkiye-linked threat actor active since at least 2017 performing espionage and service provider compromise operations against victims in Asia, Europe, and North America.
