# T1027.007 — Dynamic API Resolution

<a id="t1027007"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1027.007](https://attack.mitre.org/techniques/T1027/007)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may obfuscate then dynamically resolve API functions called by their malware in order to conceal malicious functionalities and impair defensive analysis.

## Detection

**Detection strategies:**

- Detection Strategy for Dynamic API Resolution via Hash-Based Function Lookups

**Analytics (1):**

- **Analytic 0250** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `etw:Microsoft-Windows-Kernel-Process API tracing / stack tracing via ETW or telemetry-based EDR` → OS API Execution

## Data sources & telemetry (3)

**Process Creation**, **Module Load**, **OS API Execution**
