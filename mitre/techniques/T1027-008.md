# T1027.008 — Stripped Payloads

<a id="t1027008"></a>

**Tactics:** defense-evasion  
**Platforms:** macOS, Linux, Windows, Network Devices  
**ATT&CK:** [T1027.008](https://attack.mitre.org/techniques/T1027/008)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may attempt to make a payload difficult to analyze by removing symbols, strings, and other human readable information. Scripts and executables may contain variables names and other strings that help developers document code functionality.

## Detection

**Detection strategies:**

- Detection Strategy for Stripped Payloads Across Platforms

**Analytics (4):**

- **Analytic 0055** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `EDR:file File Metadata Inspection (Low String Entropy, Missing PDB)` → File Metadata
- **Analytic 0056** (Linux) — `auditd:EXECVE EXECVE` → Process Creation; `auditd:SYSCALL open, write` → File Modification; `linux:osquery hash, elf_info, file_metadata` → File Metadata
- **Analytic 0057** (macOS) — `macos:unifiedlog file write` → File Creation; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation; `macos:osquery code_signing, file_metadata` → File Metadata
- **Analytic 0058** (Network Devices) — `NSM:Flow http.log, files.log` → Network Traffic Content
