# T1027.009 — Embedded Payloads

<a id="t1027009"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1027.009](https://attack.mitre.org/techniques/T1027/009)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may embed payloads within other files to conceal malicious content from defenses. Otherwise seemingly benign files (such as scripts and executables) may be abused to carry and obfuscate malicious payloads and content.

## Mitigations (2)

- [M1040 — Behavior Prevention on Endpoint](/mitre/mitigations/M1040.md) — Behavior Prevention on Endpoint refers to the use of technologies and strategies to detect and block potentially malicious activities by analyzing the behavior of processes, files, API calls, and other endpoint events.
- [M1049 — Antivirus/Antimalware](/mitre/mitigations/M1049.md) — Antivirus/Antimalware solutions utilize signatures, heuristics, and behavioral analysis to detect, block, and remediate malicious software, including viruses, trojans, ransomware, and spyware.

**Analytics (3):**

- **Analytic 0599** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `EDR:file File Metadata Analysis (PE overlays, entropy)` → File Metadata
- **Analytic 0600** (Linux) — `auditd:SYSCALL open, write` → File Modification; `linux:osquery elf_info, hash, yara_matches` → File Metadata; `ebpf:syscalls container_file_activity` → File Access
- **Analytic 0601** (macOS) — `macos:unifiedlog logd:file write` → File Creation; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation; `macos:osquery mach_o_info, file_metadata` → File Metadata

## Adversary usage

**Threat groups (3):** [Lazarus Group](https://attack.mitre.org/groups/G0032), [Moonstone Sleet](https://attack.mitre.org/groups/G1036), [TA577](https://attack.mitre.org/groups/G1037)

_Notable groups seen using this technique:_

- [Lazarus Group](https://attack.mitre.org/groups/G0032) (aka Labyrinth Chollima, HIDDEN COBRA, Guardians of Peace, ZINC) — Lazarus Group is a North Korean state-sponsored cyber threat group attributed to the Reconnaissance General Bureau (RGB).
- [Moonstone Sleet](https://attack.mitre.org/groups/G1036) (aka Storm-1789) — Moonstone Sleet is a North Korean-linked threat actor executing both financially motivated attacks and espionage operations.
- [TA577](https://attack.mitre.org/groups/G1037) — TA577 is an initial access broker (IAB) that has distributed QakBot and Pikabot, and was among the first observed groups distributing Latrodectus in 2023.
