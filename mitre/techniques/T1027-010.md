# T1027.010 — Command Obfuscation

<a id="t1027010"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1027.010](https://attack.mitre.org/techniques/T1027/010)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may obfuscate content during command execution to impede detection. Command-line obfuscation is a method of making strings and patterns within commands and scripts more difficult to signature and analyze.

## Mitigations (2)

- [M1040 — Behavior Prevention on Endpoint](/mitre/mitigations/M1040.md) — Behavior Prevention on Endpoint refers to the use of technologies and strategies to detect and block potentially malicious activities by analyzing the behavior of processes, files, API calls, and other endpoint events.
- [M1049 — Antivirus/Antimalware](/mitre/mitigations/M1049.md) — Antivirus/Antimalware solutions utilize signatures, heuristics, and behavioral analysis to detect, block, and remediate malicious software, including viruses, trojans, ransomware, and spyware.

## Detection

**Detection strategies:**

- Detection Strategy for Command Obfuscation

**Analytics (3):**

- **Analytic 1394** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation
- **Analytic 1395** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:osquery process_events.command_line` → Command Execution
- **Analytic 1396** (macOS) — `macos:unifiedlog process:spawn, process:exec` → Command Execution; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation
