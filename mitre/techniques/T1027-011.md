# T1027.011 — Fileless Storage

<a id="t1027011"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows, Linux  
**ATT&CK:** [T1027.011](https://attack.mitre.org/techniques/T1027/011)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may store data in "fileless" formats to conceal malicious activity from defenses. Fileless storage can be broadly defined as any format other than a file. Common examples of non-volatile fileless storage in Windows systems include the Windows Registry, event logs, or WMI repository.

## Mitigations (1)

- [M1047 — Audit](/mitre/mitigations/M1047.md)

## Detection

**Detection strategies:**

- Detection Strategy for Fileless Storage via Registry, WMI, and Shared Memory

**Analytics (2):**

- **Analytic 0973** (Windows) — `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification; `WinEventLog:Application WMI Object Creation Events` → WMI Creation
- **Analytic 0974** (Linux) — `auditd:SYSCALL open, write, unlink` → File Creation; `linux:osquery file_events.path` → File Metadata
