# T1027.012 — LNK Icon Smuggling

<a id="t1027012"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1027.012](https://attack.mitre.org/techniques/T1027/012)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may smuggle commands to download malicious payloads past content filters by hiding them within otherwise seemingly benign windows shortcut files.
