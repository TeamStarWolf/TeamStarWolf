# T1027.014 — Polymorphic Code

<a id="t1027014"></a>

**Tactics:** stealth  
**Platforms:** Windows, macOS, Linux  
**ATT&CK:** [T1027.014](https://attack.mitre.org/techniques/T1027/014)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may utilize polymorphic code (also known as metamorphic or mutating code) to evade detection. Polymorphic code is a type of software capable of changing its runtime footprint during code execution. With each execution of the software, the code is mutated into a different version of itself that achieves the same purpose or objective as the original. This functionality enables the malware to evade traditional signature-based defenses, such as antivirus and antimalware tools. Other obfuscation techniques can be used in conjunction with polymorphic code to accomplish the intended effects, including using mutation engines to conduct actions such as [Software Packing](https://attack.mitre.org/techniques/T1027/002), [Command Obfuscation](https://attack.mitre.org/techniques/T1027/010), or [Encrypted/Encoded File](https://attack.mitre.org/techniques/T1027/013).

## Detection

**Detection strategies:**

- Detection Strategy for Polymorphic Code Mutation and Execution

**Analytics (3):**

- **Analytic 0919** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=10` → Process Access
- **Analytic 0920** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL mmap` → Module Load; `auditd:SYSCALL chmod` → File Modification
- **Analytic 0921** (macOS) — `macos:unifiedlog code signature/memory protection` → Process Metadata; `fs:fsusage file open/write` → File Creation; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_MMAP` → Process Modification
