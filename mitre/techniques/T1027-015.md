# T1027.015 — Compression

<a id="t1027015"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, Windows, macOS  
**ATT&CK:** [T1027.015](https://attack.mitre.org/techniques/T1027/015)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may use compression to obfuscate their payloads or files. Compressed file formats such as ZIP, gzip, 7z, and RAR can compress and archive multiple files together to make it easier and faster to transfer files.

## Mitigations (1)

- [M1049 — Antivirus/Antimalware](/mitre/mitigations/M1049.md)

## Detection

**Detection strategies:**

- Detection Strategy for Compressed Payload Creation and Execution

**Analytics (3):**

- **Analytic 0782** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 0783** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL write` → File Creation; `auditd:SYSCALL openat` → File Access; `auditd:SYSCALL chmod` → File Modification
- **Analytic 0784** (macOS) — `macos:unifiedlog Process launch` → Process Creation; `macos:unifiedlog filesystem events` → File Metadata; `fs:fsusage file open/write` → File Creation
