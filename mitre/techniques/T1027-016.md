# T1027.016 — Junk Code Insertion

<a id="t1027016"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1027.016](https://attack.mitre.org/techniques/T1027/016)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may use junk code / dead code to obfuscate a malware’s functionality. Junk code is code that either does not execute, or if it does execute, does not change the functionality of the code.

## Mitigations (1)

- [M1049 — Antivirus/Antimalware](/mitre/mitigations/M1049.md) — Antivirus/Antimalware solutions utilize signatures, heuristics, and behavioral analysis to detect, block, and remediate malicious software, including viruses, trojans, ransomware, and spyware.

## Detection

**Detection strategies:**

- Detection Strategy for Junk Code Obfuscation with Suspicious Execution Patterns

**Analytics (3):**

- **Analytic 0913** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0914** (Linux) — `auditd:SYSCALL write` → File Creation; `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL SYSCALL ptrace/mprotect` → Process Modification
- **Analytic 0915** (macOS) — `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_MMAP` → Process Modification; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_OPEN` → Process Access

## Adversary usage

_Notable groups seen using this technique:_

- [FIN7](https://attack.mitre.org/groups/G0046) (aka GOLD NIAGARA, ITG14, Carbon Spider, ELBRUS) — FIN7 is a financially-motivated threat group that has been active since 2013.
- [Gamaredon Group](https://attack.mitre.org/groups/G0047) (aka IRON TILDEN, Primitive Bear, ACTINIUM, Armageddon) — Gamaredon Group is a suspected Russian cyber espionage group that has targeted military, law enforcement, judiciary, non-profit, and non-governmental organizations in Ukraine since at least 2013.
- [APT32](https://attack.mitre.org/groups/G0050) (aka SeaLotus, OceanLotus, APT-C-00, Canvas Cyclone) — APT32 is a suspected Vietnam-based threat group that has been active since at least 2014.
- [Kimsuky](https://attack.mitre.org/groups/G0094) (aka Black Banshee, Velvet Chollima, Emerald Sleet, THALLIUM) — Kimsuky is a North Korea-based cyber espionage group that has been active since at least 2012.
- [Mustang Panda](https://attack.mitre.org/groups/G0129) (aka TA416, RedDelta, BRONZE PRESIDENT, STATELY TAURUS) — Mustang Panda is a China-based cyber espionage threat actor that has been conducting operations since at least 2012.
