# T1027.017 — SVG Smuggling

<a id="t1027017"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1027.017](https://attack.mitre.org/techniques/T1027/017)  
**Sub-technique of:** [T1027 — Obfuscated Files or Information](/mitre/techniques/T1027.md)  

Adversaries may smuggle data and files past content filters by hiding malicious payloads inside of seemingly benign SVG files. SVGs, or Scalable Vector Graphics, are vector-based image files constructed using XML.

## Mitigations (1)

- [M1048 — Application Isolation and Sandboxing](/mitre/mitigations/M1048.md) — Application Isolation and Sandboxing refers to the technique of restricting the execution of code to a controlled and isolated environment (e.g., a virtual environment, container, or sandbox).

**Analytics (3):**

- **Analytic 1407** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1408** (Linux) — `auditd:SYSCALL open, write` → File Modification; `auditd:SYSCALL execve` → Process Creation; `NSM:Flow Outbound HTTP/S` → Network Traffic Content
- **Analytic 1409** (macOS) — `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation; `macos:unifiedlog subsystem: com.apple.WebKit or com.apple.WebKit.Networking` → Network Traffic Content
