# T1027 — Obfuscated Files or Information

<a id="t1027"></a>

**Tactics:** defense-evasion  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1027](https://attack.mitre.org/techniques/T1027)  

Adversaries may attempt to make an executable or file difficult to discover or analyze by encrypting, encoding, or otherwise obfuscating its contents on the system or in transit. This is common behavior that can be used across different platforms and the network to evade defenses.

## Mitigations (4)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1040 — Behavior Prevention on Endpoint](/mitre/mitigations/M1040.md) — Behavior Prevention on Endpoint refers to the use of technologies and strategies to detect and block potentially malicious activities by analyzing the behavior of processes, files, API calls, and other endpoint events.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.
- [M1049 — Antivirus/Antimalware](/mitre/mitigations/M1049.md) — Antivirus/Antimalware solutions utilize signatures, heuristics, and behavioral analysis to detect, block, and remediate malicious software, including viruses, trojans, ransomware, and spyware.

## Detection

**Detection strategies:**

- Behavioral Detection of Obfuscated Files or Information

**Analytics (5):**

- **Analytic 1064** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1065** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL open, write` → File Modification; `linux:cli Shell history logs` → Command Execution
- **Analytic 1066** (macOS) — `macos:unifiedlog log stream --predicate 'processImagePath contains "zip" OR "base64"'` → Command Execution; `macos:osquery file_events` → File Creation
- **Analytic 1067** (Network Devices) — `networkdevice:IDS content inspection / PCAP / HTTP body` → Network Traffic Content
- **Analytic 1068** (ESXi) — `esxi:vmkernel Datastore modification events` → File Metadata; `esxi:hostd Remote access API calls and file uploads` → OS API Execution

## Sub-techniques (17)

- [T1027.001 — Binary Padding](/mitre/techniques/T1027-001.md) — Adversaries may use binary padding to add junk data and change the on-disk representation of malware.
- [T1027.002 — Software Packing](/mitre/techniques/T1027-002.md) — Adversaries may perform software packing or virtual machine software protection to conceal their code.
- [T1027.003 — Steganography](/mitre/techniques/T1027-003.md) — Adversaries may use steganography techniques in order to prevent the detection of hidden information.
- [T1027.004 — Compile After Delivery](/mitre/techniques/T1027-004.md) — Adversaries may attempt to make payloads difficult to discover and analyze by delivering files to victims as uncompiled code.
- [T1027.005 — Indicator Removal from Tools](/mitre/techniques/T1027-005.md) — Adversaries may remove indicators from tools if they believe their malicious tool was detected, quarantined, or otherwise curtailed.
- [T1027.006 — HTML Smuggling](/mitre/techniques/T1027-006.md) — Adversaries may smuggle data and files past content filters by hiding malicious payloads inside of seemingly benign HTML files.
- [T1027.007 — Dynamic API Resolution](/mitre/techniques/T1027-007.md) — Adversaries may obfuscate then dynamically resolve API functions called by their malware in order to conceal malicious functionalities and impair defensive analysis.
- [T1027.008 — Stripped Payloads](/mitre/techniques/T1027-008.md) — Adversaries may attempt to make a payload difficult to analyze by removing symbols, strings, and other human readable information.
- [T1027.009 — Embedded Payloads](/mitre/techniques/T1027-009.md) — Adversaries may embed payloads within other files to conceal malicious content from defenses.
- [T1027.010 — Command Obfuscation](/mitre/techniques/T1027-010.md) — Adversaries may obfuscate content during command execution to impede detection.
- [T1027.011 — Fileless Storage](/mitre/techniques/T1027-011.md) — Adversaries may store data in "fileless" formats to conceal malicious activity from defenses.
- [T1027.012 — LNK Icon Smuggling](/mitre/techniques/T1027-012.md) — Adversaries may smuggle commands to download malicious payloads past content filters by hiding them within otherwise seemingly benign windows shortcut files.
- [T1027.013 — Encrypted/Encoded File](/mitre/techniques/T1027-013.md) — Adversaries may encrypt or encode files to obfuscate strings, bytes, and other specific patterns to impede detection.
- [T1027.014 — Polymorphic Code](/mitre/techniques/T1027-014.md) — Adversaries may utilize polymorphic code (also known as metamorphic or mutating code) to evade detection.
- [T1027.015 — Compression](/mitre/techniques/T1027-015.md) — Adversaries may use compression to obfuscate their payloads or files.
- [T1027.016 — Junk Code Insertion](/mitre/techniques/T1027-016.md) — Adversaries may use junk code / dead code to obfuscate a malware’s functionality.
- [T1027.017 — SVG Smuggling](/mitre/techniques/T1027-017.md) — Adversaries may smuggle data and files past content filters by hiding malicious payloads inside of seemingly benign SVG files.
