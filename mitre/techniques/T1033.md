# T1033 — System Owner/User Discovery

<a id="t1033"></a>

**Tactics:** discovery  
**Platforms:** Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1033](https://attack.mitre.org/techniques/T1033)  

Adversaries may attempt to identify the primary user, currently logged in user, set of users that commonly uses a system, or whether a user is actively using the system. They may do this, for example, by retrieving account usernames or by using OS Credential Dumping.

## Detection

**Detection strategies:**

- Behavioral Detection of User Discovery via Local and Remote Enumeration

**Analytics (4):**

- **Analytic 0254** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 0255** (Linux) — `auditd:SYSCALL execve` → Process Creation
- **Analytic 0256** (macOS) — `macos:unifiedlog subsystem:com.apple.Terminal` → Command Execution; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation
- **Analytic 0257** (Network Devices) — `networkdevice:syslog aaa privilege_exec` → OS API Execution; `networkdevice:syslog eventlog` → Command Execution
