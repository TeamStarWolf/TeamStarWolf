# T1036.001 — Invalid Code Signature

<a id="t1036001"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows, macOS  
**ATT&CK:** [T1036.001](https://attack.mitre.org/techniques/T1036/001)  
**Sub-technique of:** [T1036 — Masquerading](/mitre/techniques/T1036.md)  

Adversaries may attempt to mimic features of valid code signatures to increase the chance of deceiving a user, analyst, or tool. Code signing provides a level of authenticity on a binary from the developer and a guarantee that the binary has not been tampered with.

## Mitigations (1)

- [M1045 — Code Signing](/mitre/mitigations/M1045.md) — Code Signing is a security process that ensures the authenticity and integrity of software by digitally signing executables, scripts, and other code artifacts.

## Detection

**Detection strategies:**

- Invalid Code Signature Execution Detection via Metadata and Behavioral Context

**Analytics (2):**

- **Analytic 0089** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Windows Defender Operational log` → File Metadata; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 0090** (macOS) — `macos:unifiedlog subsystem:syspolicyd` → File Metadata; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation; `fs:fileevents /var/log/install.log` → File Modification
