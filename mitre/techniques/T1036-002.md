# T1036.002 — Right-to-Left Override

<a id="t1036002"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1036.002](https://attack.mitre.org/techniques/T1036/002)  
**Sub-technique of:** [T1036 — Masquerading](/mitre/techniques/T1036.md)  

Adversaries may abuse the right-to-left override (RTLO or RLO) character (U+202E) to disguise a string and/or file name to make it appear benign. RTLO is a non-printing Unicode character that causes the text that follows it to be displayed in reverse.

## Detection

**Detection strategies:**

- Right-to-Left Override Masquerading Detection via Filename and Execution Context

**Analytics (3):**

- **Analytic 1461** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `WinEventLog:Windows Defender Operational` → File Metadata
- **Analytic 1462** (macOS) — `macos:unifiedlog subsystem=com.apple.lsd` → File Metadata; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation; `fs:quarantine /var/log/quarantine.log` → File Access
- **Analytic 1463** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:osquery event-based` → File Metadata; `desktop:file_manager nautilus, dolphin, or gvfs logs` → File Access

## Data sources & telemetry (4)

**Process Creation**, **Command Execution**, **File Metadata**, **File Access**
