# T1036.003 — Rename Legitimate Utilities

<a id="t1036003"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1036.003](https://attack.mitre.org/techniques/T1036/003)  
**Sub-technique of:** [T1036 — Masquerading](/mitre/techniques/T1036.md)  

Adversaries may rename legitimate / system utilities to try to evade security mechanisms concerning the usage of those utilities.

## Mitigations (1)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.

## Detection

**Detection strategies:**

- Renamed Legitimate Utility Execution with Metadata Mismatch and Suspicious Path

**Analytics (3):**

- **Analytic 0012** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `EDR:AMSI` → Command Execution
- **Analytic 0013** (macOS) — `macos:unifiedlog subsystem=com.apple.process` → Process Metadata; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation; `fs:fileevents /var/log/quarantine.log` → File Modification
- **Analytic 0014** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:osquery event-based` → File Metadata; `linux:syslog cron activity` → Command Execution
