# T1036.005 — Match Legitimate Resource Name or Location

<a id="t1036005"></a>

**Tactics:** defense-evasion  
**Platforms:** Containers, ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1036.005](https://attack.mitre.org/techniques/T1036/005)  
**Sub-technique of:** [T1036 — Masquerading](/mitre/techniques/T1036.md)  

Adversaries may match or approximate the name or location of legitimate files, Registry keys, or other resources when naming/placing them. This is done for the sake of evading defenses and observation.

## Mitigations (3)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.
- [M1045 — Code Signing](/mitre/mitigations/M1045.md) — Code Signing is a security process that ensures the authenticity and integrity of software by digitally signing executables, scripts, and other code artifacts.

## Detection

**Detection strategies:**

- Detection Strategy for Masquerading via Legitimate Resource Name or Location

**Analytics (5):**

- **Analytic 0983** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 0984** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL open` → File Access; `auditd:SYSCALL rename` → Process Modification; `linux:osquery Filesystem modifications to trusted paths` → File Metadata
- **Analytic 0985** (macOS) — `macos:unifiedlog log collect from launchd and process start` → Process Metadata; `fs:fsusage filesystem monitoring of exec/open` → File Metadata
- **Analytic 0986** (Containers) — `kubernetes:apiserver Resource creation and update logs` → Image Metadata; `containerd:events Docker or containerd image pulls and process executions` → Process Metadata
- **Analytic 0987** (ESXi) — `esxi:vmkernel Exec` → Process Creation; `esxi:vmkernel module load` → Module Load; `esxi:hostd Service events` → Service Metadata; `esxi:hostd task creation events` → Scheduled Job Creation
