# T1036.006 — Space after Filename

<a id="t1036006"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1036.006](https://attack.mitre.org/techniques/T1036/006)  
**Sub-technique of:** [T1036 — Masquerading](/mitre/techniques/T1036.md)  

Adversaries can hide a program's true filetype by changing the extension of a file. With certain file types (specifically this does not work with .app extensions), appending a space to the end of a filename will change how the file is processed by the operating system.

**Detection strategies:**

- Masquerading via Space After Filename - Behavioral Detection Strategy

**Analytics (2):**

- **Analytic 0812** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:syslog application or system execution logs` → File Metadata
- **Analytic 0813** (macOS) — `macos:unifiedlog process events` → Process Creation; `fs:fsusage filesystem activity` → File Access
