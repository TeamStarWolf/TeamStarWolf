# T1036.009 — Break Process Trees

<a id="t1036009"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1036.009](https://attack.mitre.org/techniques/T1036/009)  
**Sub-technique of:** [T1036 — Masquerading](/mitre/techniques/T1036.md)  

An adversary may attempt to evade process tree-based analysis by modifying executed malware's parent process ID (PPID).

## Detection

**Detection strategies:**

- Detection Strategy for Masquerading via Breaking Process Trees

**Analytics (2):**

- **Analytic 1223** (Linux) — `auditd:SYSCALL fork/clone/daemon syscall tracing` → OS API Execution; `auditd:SYSCALL execve of re-parented process` → Process Creation
- **Analytic 1224** (macOS) — `macos:unifiedlog Process creation with parent PID of 1 (launchd)` → Process Creation; `fs:fsusage Detached process execution with no associated parent` → OS API Execution

## Data sources & telemetry (2)

**OS API Execution**, **Process Creation**
