# T1036.011 — Overwrite Process Arguments

<a id="t1036011"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux  
**ATT&CK:** [T1036.011](https://attack.mitre.org/techniques/T1036/011)  
**Sub-technique of:** [T1036 — Masquerading](/mitre/techniques/T1036.md)  

Adversaries may modify a process's in-memory arguments to change its name in order to appear as a legitimate or benign process. On Linux, the operating system stores command-line arguments in the process’s stack and passes them to the `main()` function as the `argv` array.

## Detection

**Detection strategies:**

- Detection Strategy for Overwritten Process Arguments Masquerading

**Analytics (1):**

- **Analytic 0466** (Linux) — `auditd:SYSCALL execve, prctl, or ptrace activity affecting process memory or command-line arguments` → Process Metadata; `ebpf:tracepoints Runtime memory overwrite of argv[] memory region` → Process Modification
