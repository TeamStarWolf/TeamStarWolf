# T1037.001 — Logon Script (Windows)

<a id="t1037001"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1037.001](https://attack.mitre.org/techniques/T1037/001)  
**Sub-technique of:** [T1037 — Boot or Logon Initialization Scripts](/mitre/techniques/T1037.md)  

Adversaries may use Windows logon scripts automatically executed at logon initialization to establish persistence. Windows allows logon scripts to be run whenever a specific user or group of users log into a system.

## Detection

**Detection strategies:**

- Detect Logon Script Modifications and Execution

**Analytics (1):**

- **Analytic 0199** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `WinEventLog:System EventCode=1502, 1503` → Script Execution; `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:Security EventCode=4688` → Process Creation
