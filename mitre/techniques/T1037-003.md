# T1037.003 — Network Logon Script

<a id="t1037003"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1037.003](https://attack.mitre.org/techniques/T1037/003)  
**Sub-technique of:** [T1037 — Boot or Logon Initialization Scripts](/mitre/techniques/T1037.md)  

Adversaries may use network logon scripts automatically executed at logon initialization to establish persistence. Network logon scripts can be assigned using Active Directory or Group Policy Objects. These logon scripts run with the privileges of the user they are assigned to.

## Mitigations (1)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.

## Detection

**Detection strategies:**

- Detect Network Logon Script Abuse via Multi-Event Correlation on Windows

**Analytics (1):**

- **Analytic 1034** (Windows) — `WinEventLog:Security EventCode=5145` → Network Share Access; `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:System EventCode=4016, 5312` → Script Execution
