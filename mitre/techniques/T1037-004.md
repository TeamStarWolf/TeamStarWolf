# T1037.004 — RC Scripts

<a id="t1037004"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** macOS, Linux, Network Devices, ESXi  
**ATT&CK:** [T1037.004](https://attack.mitre.org/techniques/T1037/004)  
**Sub-technique of:** [T1037 — Boot or Logon Initialization Scripts](/mitre/techniques/T1037.md)  

Adversaries may establish persistence by modifying RC scripts, which are executed during a Unix-like system’s startup. These files allow system administrators to map and start custom services at startup for different run levels. RC scripts require root privileges to modify.

## Mitigations (1)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.

**Analytics (4):**

- **Analytic 0658** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:syslog boot logs` → Script Execution
- **Analytic 0659** (macOS) — `macos:unifiedlog process events` → Process Creation; `fs:fsusage file activity` → File Creation
- **Analytic 0660** (ESXi) — `esxi:syslog boot logs` → Command Execution; `esxi:shell admin command usage` → File Modification
- **Analytic 0661** (Network Devices) — `networkdevice:syslog startup-config` → File Modification; `networkdevice:syslog system boot logs` → Command Execution
