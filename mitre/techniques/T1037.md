# T1037 — Boot or Logon Initialization Scripts

<a id="t1037"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** macOS, Windows, Linux, Network Devices, ESXi  
**ATT&CK:** [T1037](https://attack.mitre.org/techniques/T1037)  

Adversaries may use scripts automatically executed at boot or logon initialization to establish persistence. Initialization scripts can be used to perform administrative functions, which may often execute other programs or send information to an internal logging server.

**Analytics (5):**

- **Analytic 0311** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification; `WinEventLog:TaskScheduler EventCode=106` → Scheduled Job Creation
- **Analytic 0312** (Linux) — `auditd:SYSCALL EXECVE` → Process Creation; `auditd:PATH PATH` → File Metadata; `linux:osquery file_events` → File Modification
- **Analytic 0313** (macOS) — `macos:unifiedlog log` → Script Execution; `fs:fsusage file` → File Access; `macos:osquery launchd` → Service Metadata
- **Analytic 0314** (ESXi) — `esxi:vmkernel boot` → Script Execution; `esxi:hostd boot` → File Modification
- **Analytic 0315** (Network Devices) — `networkdevice:syslog config` → File Modification
