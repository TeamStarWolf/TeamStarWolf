# T1039 — Data from Network Shared Drive

<a id="t1039"></a>

**Tactics:** collection  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1039](https://attack.mitre.org/techniques/T1039)  

Adversaries may search network shares on computers they have compromised to find files of interest. Sensitive data can be collected from remote systems via shared network drives (host shared directory, network file server, etc.) that are accessible from the current system prior to Exfiltration.

## D3FEND countermeasures (2)

- [Decoy Network Resource](/mitre/d3fend/decoy-network-resource.md) (Deceive) — spoofs
- [Network Resource Access Mediation](/mitre/d3fend/network-resource-access-mediation.md) (Isolate) — isolates

## Detection

**Detection strategies:**

- Detection Strategy for Data from Network Shared Drive

**Analytics (3):**

- **Analytic 1145** (Windows) — `WinEventLog:Security EventCode=5145` → Network Share Access; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 1146** (Linux) — `auditd:SYSCALL open,read` → File Access; `linux:syslog mount/umount or file copy logs` → Drive Access
- **Analytic 1147** (macOS) — `macos:unifiedlog filesystem and process events` → File Access; `fs:fsusage open/read/mount operations` → Drive Access
