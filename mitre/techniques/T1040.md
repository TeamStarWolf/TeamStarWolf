# T1040 — Network Sniffing

<a id="t1040"></a>

**Tactics:** credential-access, discovery  
**Platforms:** Linux, macOS, Windows, Network Devices, IaaS  
**ATT&CK:** [T1040](https://attack.mitre.org/techniques/T1040)  

Adversaries may passively sniff network traffic to capture information about an environment, including authentication material passed over the network. Network sniffing refers to using the network interface on a system to monitor or capture information sent over a wired or wireless connection.

## Mitigations (4)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1041 — Encrypt Sensitive Information](/mitre/mitigations/M1041.md) — Protect sensitive information at rest, in transit, and during processing by using strong encryption algorithms.

## Detection

**Detection strategies:**

- Detection Strategy for Network Sniffing Across Platforms

**Analytics (5):**

- **Analytic 0875** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:System EventCode=7045` → Service Creation
- **Analytic 0876** (Linux) — `auditd:SYSCALL execve, setifflags` → Process Creation; `auditd:SYSCALL promiscuous mode transitions (ioctl or ifconfig)` → Command Execution; `networkconfig  interface flag PROMISC, netstat | ip link | ethtool` → Network Traffic Content
- **Analytic 0877** (macOS) — `macos:unifiedlog eventMessage = 'promiscuous'` → Network Traffic Content; `macos:osquery process_events where path like '%tcpdump%'` → Process Creation; `fs:fsusage access to BPF devices or interface IOCTLs` → Command Execution
- **Analytic 0878** (IaaS) — `AWS:CloudTrail CreateTrafficMirrorSession / ModifyTrafficMirrorTarget` → Cloud Service Modification
- **Analytic 0879** (Network Devices) — `networkdevice:syslog admin login events` → User Account Authentication; `networkdevice:syslog exec command='monitor capture'` → Command Execution; `networkdevice:syslog config change (e.g., logging buffered, pcap buffers)` → Network Traffic Content
