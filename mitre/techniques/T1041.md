# T1041 — Exfiltration Over C2 Channel

<a id="t1041"></a>

**Tactics:** exfiltration  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1041](https://attack.mitre.org/techniques/T1041)  

Adversaries may steal data by exfiltrating it over an existing command and control channel. Stolen data is encoded into the normal communications channel using the same protocol as command and control communications.

## Mitigations (2)

- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.
- [M1057 — Data Loss Prevention](/mitre/mitigations/M1057.md) — Data Loss Prevention (DLP) involves implementing strategies and technologies to identify, categorize, monitor, and control the movement of sensitive data within an organization.

**Analytics (4):**

- **Analytic 0988** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `NSM:Flow Flow/PCAP analysis for outbound payloads` → Network Traffic Content; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access
- **Analytic 0989** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL connect` → Network Connection Creation; `NSM:Flow conn.log + files.log + ssl.log` → Network Traffic Content; `NSM:Flow session stats with bytes_out > bytes_in` → Network Traffic Flow
- **Analytic 0990** (macOS) — `macos:unifiedlog eventMessage = 'open', 'sendto', 'connect'` → Network Traffic Content; `macos:osquery socket_events` → Network Traffic Flow; `macos:osquery process_events` → Process Creation
- **Analytic 0991** (ESXi) — `esxi:vpxa connection attempts and data transmission logs` → Network Traffic Flow; `esxi:vmkernel network stack module logs` → Network Traffic Content; `esxi:syslog guest OS outbound transfer logs` → File Access
