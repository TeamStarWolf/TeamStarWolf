# T1048.002 — Exfiltration Over Asymmetric Encrypted Non-C2 Protocol

<a id="t1048002"></a>

**Tactics:** exfiltration  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1048.002](https://attack.mitre.org/techniques/T1048/002)  
**Sub-technique of:** [T1048 — Exfiltration Over Alternative Protocol](/mitre/techniques/T1048.md)  

Adversaries may steal data by exfiltrating it over an asymmetrically encrypted network protocol other than that of the existing command and control channel. The data may also be sent to an alternate network location from the main command and control server.

## Mitigations (4)

- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.
- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.
- [M1057 — Data Loss Prevention](/mitre/mitigations/M1057.md) — Data Loss Prevention (DLP) involves implementing strategies and technologies to identify, categorize, monitor, and control the movement of sensitive data within an organization.

## Detection

**Detection strategies:**

- Detection of Exfiltration Over Asymmetric Encrypted Non-C2 Protocol

**Analytics (4):**

- **Analytic 1413** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `NSM:Flow ssl.log - Certificate Analysis` → Network Traffic Content
- **Analytic 1414** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL connect` → Network Connection Creation; `NSM:Flow ssl.log, conn.log` → Network Traffic Content; `auditd:SYSCALL open, read` → File Access
- **Analytic 1415** (macOS) — `macos:osquery socket_events` → Network Traffic Flow; `macos:osquery process_events` → Process Creation; `macos:unifiedlog log stream - file provider subsystem` → File Access; `NSM:Flow ssl.log, x509.log` → Network Traffic Content
- **Analytic 1416** (ESXi) — `esxi:hostd event stream` → Command Execution; `esxi:vmkernel egress logs` → Network Traffic Flow

## Adversary usage

**Threat groups (3):** [APT28](https://attack.mitre.org/groups/G0007), [CURIUM](https://attack.mitre.org/groups/G1012), [Storm-1811](https://attack.mitre.org/groups/G1046)

_Notable groups seen using this technique:_

- [APT28](https://attack.mitre.org/groups/G0007) (aka IRON TWILIGHT, SNAKEMACKEREL, Swallowtail, Group 74) — APT28 is a threat group that has been attributed to Russia's General Staff Main Intelligence Directorate (GRU) 85th Main Special Service Center (GTsSS) military unit 26165.
- [CURIUM](https://attack.mitre.org/groups/G1012) (aka Crimson Sandstorm, TA456, Tortoise Shell, Yellow Liderc) — CURIUM is an Iranian threat group, first reported in September 2019 and active since at least July 2018, targeting IT service providers in the Middle East.
- [Storm-1811](https://attack.mitre.org/groups/G1046) — Storm-1811 is a financially-motivated entity linked to Black Basta ransomware deployment.

**Software/tools (2):** [IcedID](https://attack.mitre.org/software/S0483), [Rclone](https://attack.mitre.org/software/S1040)
