# T1048 — Exfiltration Over Alternative Protocol

<a id="t1048"></a>

**Tactics:** exfiltration  
**Platforms:** ESXi, IaaS, Linux, macOS, Network Devices, Office Suite, SaaS, Windows  
**ATT&CK:** [T1048](https://attack.mitre.org/techniques/T1048)  

Adversaries may steal data by exfiltrating it over a different protocol than that of the existing command and control channel. The data may also be sent to an alternate network location from the main command and control server.

## Mitigations (6)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.
- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.
- [M1057 — Data Loss Prevention](/mitre/mitigations/M1057.md) — Data Loss Prevention (DLP) involves implementing strategies and technologies to identify, categorize, monitor, and control the movement of sensitive data within an organization.

**Analytics (5):**

- **Analytic 0367** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=4688` → Process Creation
- **Analytic 0368** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL connect` → Network Connection Creation; `auditd:SYSCALL open` → File Access; `auditd:SYSCALL write` → File Modification; `NSM:Flow NetFlow/Zeek conn.log` → Network Traffic Flow
- **Analytic 0369** (macOS) — `macos:unifiedlog log stream (subsystem: com.apple.system.networking)` → Network Traffic Content; `macos:osquery process_events` → Process Creation; `macos:osquery file_events` → File Creation
- **Analytic 0370** (IaaS) — `AWS:CloudTrail GetObject, CopyObject` → Cloud Storage Access; `AWS:VPCFlowLogs Outbound data flows` → Network Traffic Flow
- **Analytic 0371** (ESXi) — `esxi:hostd logline inspection` → Command Execution; `esxi:vmkernel protocol egress` → Network Connection Creation
