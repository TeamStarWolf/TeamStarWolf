# T1049 — System Network Connections Discovery

<a id="t1049"></a>

**Tactics:** discovery  
**Platforms:** Windows, IaaS, Linux, macOS, Network Devices, ESXi  
**ATT&CK:** [T1049](https://attack.mitre.org/techniques/T1049)  

Adversaries may attempt to get a listing of network connections to or from the compromised system they are currently accessing or from remote systems by querying for information over the network.

## D3FEND countermeasures (2)

- [System Call Analysis](/mitre/d3fend/system-call-analysis.md) (Detect) — analyzes
- [System Call Filtering](/mitre/d3fend/system-call-filtering.md) (Isolate) — filters

## Detection

**Detection strategies:**

- Detection of System Network Connections Discovery Across Platforms

**Analytics (6):**

- **Analytic 0903** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 0904** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:cli command logging` → Command Execution
- **Analytic 0905** (macOS) — `macos:osquery process_events` → Process Creation
- **Analytic 0906** (ESXi) — `esxi:hostd command log` → Command Execution
- **Analytic 0907** (Network Devices) — `networkdevice:cli command logs` → Command Execution; `snmp:trap management queries` → OS API Execution
- **Analytic 0908** (IaaS) — `AWS:CloudTrail Describe* or List* API calls` → OS API Execution; `azure:activity networkInsightsLogs` → Network Traffic Content

## Data sources & telemetry (4)

**Process Creation**, **Command Execution**, **OS API Execution**, **Network Traffic Content**
