# T1052.001 — Exfiltration over USB

<a id="t1052001"></a>

**Tactics:** exfiltration  
**Platforms:** Linux, Windows, macOS  
**ATT&CK:** [T1052.001](https://attack.mitre.org/techniques/T1052/001)  
**Sub-technique of:** [T1052 — Exfiltration Over Physical Medium](/mitre/techniques/T1052.md)  

Adversaries may attempt to exfiltrate data over a USB connected physical device. In certain circumstances, such as an air-gapped network compromise, exfiltration could occur via a USB device introduced by a user.

## Detection

**Detection strategies:**

- Detection of USB-Based Data Exfiltration

**Analytics (3):**

- **Analytic 0616** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `WinEventLog:System EventCode=2003` → Drive Creation
- **Analytic 0617** (Linux) — `auditd:SYSCALL open, read` → File Access; `auditd:SYSCALL Kernel Device Events - USB Block Devices` → Drive Creation
- **Analytic 0618** (macOS) — `macos:unifiedlog Volume Mount + Process Trace + File Read` → Drive Creation; `fs:fsusage Disk Activity Tracing` → File Access; `macos:osquery process_events` → Process Creation
