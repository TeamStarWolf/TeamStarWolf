# T1053.002 — At

<a id="t1053002"></a>

**Tactics:** execution, persistence, privilege-escalation  
**Platforms:** Windows, Linux, macOS  
**ATT&CK:** [T1053.002](https://attack.mitre.org/techniques/T1053/002)  
**Sub-technique of:** [T1053 — Scheduled Task/Job](/mitre/techniques/T1053.md)  

Adversaries may abuse the at utility to perform task scheduling for initial or recurring execution of malicious code. The at utility exists as an executable within Windows, Linux, and macOS for scheduling tasks at a specified time and date.

## Mitigations (4)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Cross-Platform Detection of Scheduled Task/Job Abuse via `at` Utility

**Analytics (3):**

- **Analytic 0943** (Windows) — `WinEventLog:Security EventCode=4698` → Scheduled Job Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0944** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL write` → File Modification
- **Analytic 0945** (macOS) — `macos:unifiedlog process: at, job runner` → Command Execution; `fs:fsusage file access to /usr/lib/cron/at and job execution path` → File Modification; `macos:osquery process_events` → Process Creation

## Adversary usage

**Threat groups (3):** [APT18](https://attack.mitre.org/groups/G0026), [Threat Group-3390](https://attack.mitre.org/groups/G0027), [BRONZE BUTLER](https://attack.mitre.org/groups/G0060)

_Notable groups seen using this technique:_

- [APT18](https://attack.mitre.org/groups/G0026) (aka TG-0416, Dynamite Panda, Threat Group-0416) — APT18 is a threat group that has operated since at least 2009 and has targeted a range of industries, including technology, manufacturing, human rights groups, government, and medical.
- [Threat Group-3390](https://attack.mitre.org/groups/G0027) (aka Earth Smilodon, TG-3390, Emissary Panda, BRONZE UNION) — Threat Group-3390 is a Chinese threat group that has extensively used strategic Web compromises to target victims.
- [BRONZE BUTLER](https://attack.mitre.org/groups/G0060) (aka REDBALDKNIGHT, Tick) — BRONZE BUTLER is a cyber espionage group with likely Chinese origins that has been active since at least 2008.
