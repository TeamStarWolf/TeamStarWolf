# T1053.003 — Cron

<a id="t1053003"></a>

**Tactics:** execution, persistence, privilege-escalation  
**Platforms:** Linux, macOS, ESXi  
**ATT&CK:** [T1053.003](https://attack.mitre.org/techniques/T1053/003)  
**Sub-technique of:** [T1053 — Scheduled Task/Job](/mitre/techniques/T1053.md)  

Adversaries may abuse the <code>cron</code> utility to perform task scheduling for initial or recurring execution of malicious code. The <code>cron</code> utility is a time-based job scheduler for Unix-like operating systems.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **55 machines (10.4%)** — Linux 54 / Windows 0. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Detection

**Detection strategies:**

- Cross-Platform Detection of Cron Job Abuse for Persistence and Execution

**Analytics (3):**

- **Analytic 0805** (Linux) — `auditd:SYSCALL write` → File Modification; `auditd:SYSCALL execve` → Process Creation
- **Analytic 0806** (macOS) — `macos:unifiedlog process: crontab edits, launch of cron job` → Scheduled Job Creation; `fs:fsusage file access to /usr/lib/cron/tabs/ and cron output files` → File Modification
- **Analytic 0807** (ESXi) — `esxi:hostd modification of crontab or local.sh entries` → File Modification; `esxi:cron execution of scheduled job` → Scheduled Job Creation; `esxi:vmkernel spawned shell or execution environment activity` → Process Creation
