# T1055.009 — Proc Memory

<a id="t1055009"></a>

**Tactics:** defense-evasion, privilege-escalation  
**Platforms:** Linux  
**ATT&CK:** [T1055.009](https://attack.mitre.org/techniques/T1055/009)  
**Sub-technique of:** [T1055 — Process Injection](/mitre/techniques/T1055.md)  

Adversaries may inject malicious code into processes via the /proc filesystem in order to evade process-based defenses as well as possibly elevate privileges. Proc memory injection is a method of executing arbitrary code in the address space of a separate live process.

**Analytics (1):**

- **Analytic 1494** (Linux) — `auditd:SYSCALL open/write to /proc/*/mem or /proc/*/maps` → File Modification; `auditd:SYSCALL execve of dd or sed targeting /proc/*/mem` → OS API Execution; `linux:osquery /proc/*/maps access` → File Access
