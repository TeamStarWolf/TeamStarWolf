# T1055.011 — Extra Window Memory Injection

<a id="t1055011"></a>

**Tactics:** defense-evasion, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1055.011](https://attack.mitre.org/techniques/T1055/011)  
**Sub-technique of:** [T1055 — Process Injection](/mitre/techniques/T1055.md)  

Adversaries may inject malicious code into process via Extra Window Memory (EWM) in order to evade process-based defenses as well as possibly elevate privileges. EWM injection is a method of executing arbitrary code in the address space of a separate live process.

## Mitigations (1)

- [M1040 — Behavior Prevention on Endpoint](/mitre/mitigations/M1040.md)

## Detection

**Detection strategies:**

- Detection Strategy for Extra Window Memory (EWM) Injection on Windows

**Analytics (1):**

- **Analytic 0608** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `etw:Microsoft-Windows-Win32k SetWindowLong, SetClassLong, NtUserMessageCall, SendNotifyMessage, PostMessage` → OS API Execution; `WinEventLog:Security EventCode=4688` → Process Creation
