# T1055.013 — Process Doppelgänging

<a id="t1055013"></a>

**Tactics:** defense-evasion, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1055.013](https://attack.mitre.org/techniques/T1055/013)  
**Sub-technique of:** [T1055 — Process Injection](/mitre/techniques/T1055.md)  

Adversaries may inject malicious code into process via process doppelgänging in order to evade process-based defenses as well as possibly elevate privileges. Process doppelgänging is a method of executing arbitrary code in the address space of a separate live process.

## Mitigations (1)

- [M1040 — Behavior Prevention on Endpoint](/mitre/mitigations/M1040.md) — Behavior Prevention on Endpoint refers to the use of technologies and strategies to detect and block potentially malicious activities by analyzing the behavior of processes, files, API calls, and other endpoint events.

**Analytics (1):**

- **Analytic 1501** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=11` → File Creation; `etw:Microsoft-Windows-Kernel-Process CreateTransaction, CreateFileTransacted, RollbackTransaction, NtCreateProcessEx, NtCreateThreadEx` → OS API Execution
