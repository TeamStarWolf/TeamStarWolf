# T1055 — Process Injection

<a id="t1055"></a>

**Tactics:** defense-evasion, privilege-escalation  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1055](https://attack.mitre.org/techniques/T1055)  

Adversaries may inject code into processes in order to evade process-based defenses as well as possibly elevate privileges. Process injection is a method of executing arbitrary code in the address space of a separate live process.

## Mitigations (2)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1040 — Behavior Prevention on Endpoint](/mitre/mitigations/M1040.md) — Behavior Prevention on Endpoint refers to the use of technologies and strategies to detect and block potentially malicious activities by analyzing the behavior of processes, files, API calls, and other endpoint events.

## Detection

**Detection strategies:**

- Behavioral Detection of Process Injection Across Platforms

**Analytics (3):**

- **Analytic 1399** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `etw:Microsoft-Windows-Kernel-Process API calls` → OS API Execution
- **Analytic 1400** (Linux) — `auditd:SYSCALL ptrace, mmap, process_vm_writev` → OS API Execution; `auditd:SYSCALL open` → File Access; `linux:procfs /proc/[pid]/maps, /proc/[pid]/mem` → Process Modification
- **Analytic 1401** (macOS) — `macos:unifiedlog subsystem=com.apple.security, library=libsystem_kernel.dylib` → Process Access; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC, ES_EVENT_TYPE_NOTIFY_MMAP` → Process Metadata; `macos:syslog DYLD_INSERT_LIBRARIES anomalies` → Module Load
