# T1056.001 — Keylogging

<a id="t1056001"></a>

**Tactics:** collection, credential-access  
**Platforms:** Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1056.001](https://attack.mitre.org/techniques/T1056/001)  
**Sub-technique of:** [T1056 — Input Capture](/mitre/techniques/T1056.md)  

Adversaries may log user keystrokes to intercept credentials as the user types them.

## D3FEND countermeasures (4)

- [Hardware Component Inventory](/mitre/d3fend/hardware-component-inventory.md) (Model) — inventories. Hardware component inventorying identifies and records the hardware items in the organization's architecture.
- [IO Port Restriction](/mitre/d3fend/io-port-restriction.md) (Isolate) — filters. Limiting access to computer input/output (IO) ports to restrict unauthorized devices.
- [Input Device Analysis](/mitre/d3fend/input-device-analysis.md) (Detect) — analyzes. Operating system level mechanisms to prevent abusive input device exploitation.
- [Radiation Hardening](/mitre/d3fend/radiation-hardening.md) (Harden) — hardens. Radiation hardening is the process of making electronic components and circuits resistant to damage or malfunction caused by high levels of ionizing radiation.

## Detection

**Detection strategies:**

- Behavioral Detection of Keylogging Activity Across Platforms

**Analytics (4):**

- **Analytic 0243** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `WinEventLog:System EventCode=7045` → Service Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 0244** (Linux) — `auditd:SYSCALL open, read` → File Access; `auditd:SYSCALL ptrace, ioctl` → OS API Execution
- **Analytic 0245** (macOS) — `macos:unifiedlog subsystem=com.apple.TCC` → Process Metadata; `macos:osquery process_events OR launchd` → Process Creation
- **Analytic 0246** (Network Devices) — `networkdevice:syslog Image Upgrade / Configuration Change` → Firmware Modification; `NSM:Flow packet capture or DPI logs` → Network Traffic Content
