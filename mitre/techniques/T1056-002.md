# T1056.002 — GUI Input Capture

<a id="t1056002"></a>

**Tactics:** collection, credential-access  
**Platforms:** macOS, Windows, Linux  
**ATT&CK:** [T1056.002](https://attack.mitre.org/techniques/T1056/002)  
**Sub-technique of:** [T1056 — Input Capture](/mitre/techniques/T1056.md)  

Adversaries may mimic common operating system GUI components to prompt users for credentials with a seemingly legitimate prompt.

## Mitigations (1)

- [M1017 — User Training](/mitre/mitigations/M1017.md)

## Detection

**Detection strategies:**

- Behavioral Detection of Spoofed GUI Credential Prompts

**Analytics (3):**

- **Analytic 1440** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 1441** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:cli Terminal Command History` → Command Execution
- **Analytic 1442** (macOS) — `macos:unifiedlog subsystem=com.apple.Security or com.apple.applescript` → Script Execution; `macos:osquery process_events` → Process Creation
