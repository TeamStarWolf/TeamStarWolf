# T1056.003 — Web Portal Capture

<a id="t1056003"></a>

**Tactics:** collection, credential-access  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1056.003](https://attack.mitre.org/techniques/T1056/003)  
**Sub-technique of:** [T1056 — Input Capture](/mitre/techniques/T1056.md)  

Adversaries may install code on externally facing portals, such as a VPN login page, to capture and transmit credentials of users who attempt to log into the service. For example, a compromised login page may log provided user credentials before logging the user in to the service.

## Mitigations (1)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).

**Detection strategies:**

**Analytics (3):**

- **Analytic 1320** (Linux) — `auditd:SYSCALL write` → File Modification; `NSM:Flow HTTP Request Logging` → Network Traffic Content
