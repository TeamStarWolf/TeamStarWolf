# T1056 — Input Capture

<a id="t1056"></a>

**Tactics:** collection, credential-access  
**Platforms:** Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1056](https://attack.mitre.org/techniques/T1056)  

Adversaries may use methods of capturing user input to obtain credentials or collect information. During normal system usage, users often provide credentials to various different locations, such as login pages/portals or system dialog boxes. ## Detection

**Detection strategies:**

- Behavioral Detection of Input Capture Across Platforms

**Analytics (4):**

- **Analytic 0282** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access
- **Analytic 0283** (Linux) — `auditd:SYSCALL open, read` → File Access; `auditd:SYSCALL write` → File Modification; `auditd:SYSCALL ptrace, ioctl` → OS API Execution
- **Analytic 0284** (macOS) — `macos:unifiedlog subsystem=com.apple.TCC` → Process Metadata; `macos:osquery launchd or process_events` → Process Creation
- **Analytic 0285** (Network Devices) — `NSM:Flow http.log` → Network Traffic Content; `NSM:Firewall proxy or TLS inspection logs` → Network Connection Creation

## Adversary usage

**Threat groups (3):** [APT39](https://attack.mitre.org/groups/G0087), [APT42](https://attack.mitre.org/groups/G1044), [Storm-1811](https://attack.mitre.org/groups/G1046)

_Notable groups seen using this technique:_

- [APT39](https://attack.mitre.org/groups/G0087) (aka ITG07, Chafer, Remix Kitten) — APT39 is one of several names for cyber espionage activity conducted by the Iranian Ministry of Intelligence and Security (MOIS) through the front company Rana Intelligence Computing since at least 2014.
- [APT42](https://attack.mitre.org/groups/G1044) — APT42 is an Iranian-sponsored threat group that conducts cyber espionage and surveillance.
- [Storm-1811](https://attack.mitre.org/groups/G1046) — Storm-1811 is a financially-motivated entity linked to Black Basta ransomware deployment.

**Software/tools (7):** [FlawedAmmyy](https://attack.mitre.org/software/S0381), [Chaes](https://attack.mitre.org/software/S0631), [Kobalos](https://attack.mitre.org/software/S0641), [metaMain](https://attack.mitre.org/software/S1059), [Mafalda](https://attack.mitre.org/software/S1060), [NPPSPY](https://attack.mitre.org/software/S1131), [InvisibleFerret](https://attack.mitre.org/software/S1245)

**Campaigns:** 2 (per MITRE ATT&CK)

## Sub-techniques (4)

- [T1056.001 — Keylogging](/mitre/techniques/T1056-001.md) — Adversaries may log user keystrokes to intercept credentials as the user types them.
- [T1056.002 — GUI Input Capture](/mitre/techniques/T1056-002.md) — Adversaries may mimic common operating system GUI components to prompt users for credentials with a seemingly legitimate prompt.
- [T1056.003 — Web Portal Capture](/mitre/techniques/T1056-003.md) — Adversaries may install code on externally facing portals, such as a VPN login page, to capture and transmit credentials of users who attempt to log into the service.
- [T1056.004 — Credential API Hooking](/mitre/techniques/T1056-004.md) — Adversaries may hook into Windows application programming interface (API) functions and Linux system functions to collect user credentials.
