# T1057 — Process Discovery

<a id="t1057"></a>

**Tactics:** discovery  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1057](https://attack.mitre.org/techniques/T1057)  

Adversaries may attempt to get information about running processes on a system. Information obtained could be used to gain an understanding of common software/applications running on systems within the network. Administrator or otherwise elevated access may provide better process details.

## D3FEND countermeasures (6)

- [Executable Allowlisting](/mitre/d3fend/executable-allowlisting.md) (Isolate) — filters. Using a digital signature to authenticate a file before opening.
- [Executable Denylisting](/mitre/d3fend/executable-denylisting.md) (Isolate) — filters. Blocking the execution of files on a host in accordance with defined application policy rules.
- [Hardware-based Process Isolation](/mitre/d3fend/hardware-based-process-isolation.md) (Isolate) — restricts. Preventing one process from writing to the memory space of another process through hardware based address manager implementations.
- [Process Spawn Analysis](/mitre/d3fend/process-spawn-analysis.md) (Detect) — analyzes. Analyzing spawn arguments or attributes of a process to detect processes that are unauthorized.
- [System Call Analysis](/mitre/d3fend/system-call-analysis.md) (Detect) — analyzes. Analyzing system calls to determine whether a process is exhibiting unauthorized behavior.
- [System Call Filtering](/mitre/d3fend/system-call-filtering.md) (Isolate) — filters. Controlling access to local computer system resources with kernel-level capabilities.

## Detection

**Detection strategies:**

- Detection of Adversarial Process Discovery Behavior

**Analytics (5):**

- **Analytic 0095** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=10` → Process Access
- **Analytic 0096** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL openat` → File Access; `linux:osquery Process State` → Process Access
- **Analytic 0097** (macOS) — `macos:unifiedlog process launch` → Process Creation; `macos:osquery Process Context` → Process Metadata
- **Analytic 0098** (ESXi) — `esxi:shell interactive shell` → Command Execution; `esxi:auth user session` → Process Metadata
- **Analytic 0099** (Network Devices) — `networkdevice:cli CLI command` → Command Execution; `networkdevice:syslog Admin activity` → Process Metadata
