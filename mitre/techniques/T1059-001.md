# T1059.001 — PowerShell

<a id="t1059001"></a>

**Tactics:** execution  
**Platforms:** Windows  
**ATT&CK:** [T1059.001](https://attack.mitre.org/techniques/T1059/001)  
**Sub-technique of:** [T1059](/mitre/techniques/T1059.md)

Adversaries may abuse PowerShell commands and scripts for execution. PowerShell is a powerful interactive command-line interface and scripting environment included in the Windows operating system. Adversaries can use PowerShell to perform a number of actions, including discovery of information and execution of code.


**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **98 machines (18.5%)** — Linux 4 / Windows 83. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.
