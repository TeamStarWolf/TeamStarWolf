# T1059.006 — Python

<a id="t1059006"></a>

**Tactics:** execution  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1059.006](https://attack.mitre.org/techniques/T1059/006)  
**Sub-technique of:** [T1059 — Command and Scripting Interpreter](/mitre/techniques/T1059.md)  

Adversaries may abuse Python commands and scripts for execution. Python is a very popular scripting/programming language, with capabilities to perform many functions.

## Detection

**Detection strategies:**

- Cross-Platform Behavioral Detection of Python Execution

**Analytics (4):**

- **Analytic 0172** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `EDR:hunting Advanced Hunting: DeviceProcessEvents + DeviceNetworkEvents` → Network Traffic Content
- **Analytic 0173** (macOS) — `macos:unifiedlog log stream --predicate 'eventMessage contains "python"'` → Script Execution; `macos:osquery process_events` → Process Creation; `macos:syslog system.log` → Command Execution
- **Analytic 0174** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:syslog /var/log/syslog` → Script Execution
- **Analytic 0175** (ESXi) — `esxi:vobd /var/log/vobd.log` → Process Creation; `esxi:hostd /var/log/hostd.log` → Command Execution
