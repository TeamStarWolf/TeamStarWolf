# T1059.011 — Lua

<a id="t1059011"></a>

**Tactics:** execution  
**Platforms:** Linux, Network Devices, Windows, macOS  
**ATT&CK:** [T1059.011](https://attack.mitre.org/techniques/T1059/011)  
**Sub-technique of:** [T1059 — Command and Scripting Interpreter](/mitre/techniques/T1059.md)  

Adversaries may abuse Lua commands and scripts for execution. Lua is a cross-platform scripting and programming language primarily designed for embedded use in applications.
