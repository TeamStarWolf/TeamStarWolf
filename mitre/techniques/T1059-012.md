# T1059.012 — Hypervisor CLI

<a id="t1059012"></a>

**Tactics:** execution  
**Platforms:** ESXi  
**ATT&CK:** [T1059.012](https://attack.mitre.org/techniques/T1059/012)  
**Sub-technique of:** [T1059 — Command and Scripting Interpreter](/mitre/techniques/T1059.md)  

Adversaries may abuse hypervisor command line interpreters (CLIs) to execute malicious commands. Hypervisor CLIs typically enable a wide variety of functionality for managing both the hypervisor itself and the guest virtual machines it hosts.

## Detection

**Detection strategies:**

- Detection Strategy for ESXi Hypervisor CLI Abuse

**Analytics (1):**

- **Analytic 1537** (ESXi) — `esxi:vmkernel esxcli, vim-cmd invocation` → Command Execution; `esxi:auth SSH session/login` → User Account Authentication
