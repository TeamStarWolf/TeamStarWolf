# T1068 — Exploitation for Privilege Escalation

<a id="t1068"></a>

**Tactics:** privilege-escalation  
**Platforms:** Containers, Linux, macOS, Windows  
**ATT&CK:** [T1068](https://attack.mitre.org/techniques/T1068)  

Adversaries may exploit software vulnerabilities in an attempt to elevate privileges. Exploitation of a software vulnerability occurs when an adversary takes advantage of a programming error in a program, service, or within the operating system software or kernel itself to execute adversary-controlled code.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **8 machines (1.5%)** — Linux 6 / Windows 2. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

- **Analytic 1420** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL ACCESS` → Process Access; `auditd:SYSCALL dmesg` → Module Load
- **Analytic 1421** (macOS) — `macos:unifiedlog process:exec and kext load events` → Process Creation; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_KEXTLOAD` → Module Load
