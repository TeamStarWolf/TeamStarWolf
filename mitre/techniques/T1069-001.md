# T1069.001 — Local Groups

<a id="t1069001"></a>

**Tactics:** discovery  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1069.001](https://attack.mitre.org/techniques/T1069/001)  
**Sub-technique of:** [T1069 — Permission Groups Discovery](/mitre/techniques/T1069.md)  

Adversaries may attempt to find local system groups and permission settings. The knowledge of local system permission groups can help adversaries determine which groups exist and which users belong to a particular group.

## Detection

**Detection strategies:**

- Behavioral Detection of Local Group Enumeration Across OS Platforms
