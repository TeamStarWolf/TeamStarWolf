# T1069.002 — Domain Groups

<a id="t1069002"></a>

**Tactics:** discovery  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1069.002](https://attack.mitre.org/techniques/T1069/002)  
**Sub-technique of:** [T1069 — Permission Groups Discovery](/mitre/techniques/T1069.md)  

Adversaries may attempt to find domain-level groups and permission settings. The knowledge of domain-level permission groups can help adversaries determine which groups exist and which users belong to a particular group.

## Detection

**Detection strategies:**

- Behavioral Detection of Domain Group Discovery

**Analytics (3):**

- **Analytic 1025** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution

- **Analytic 1027** (macOS) — `macos:unifiedlog process events` → Process Creation
