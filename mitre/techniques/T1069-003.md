# T1069.003 — Cloud Groups

<a id="t1069003"></a>

**Tactics:** discovery  
**Platforms:** SaaS, IaaS, Office Suite, Identity Provider  
**ATT&CK:** [T1069.003](https://attack.mitre.org/techniques/T1069/003)  
**Sub-technique of:** [T1069](/mitre/techniques/T1069.md)

Adversaries may attempt to find cloud groups and permission settings. The knowledge of cloud permission groups can help adversaries determine the particular roles of users and groups within an environment, as well as which users are associated with a particular group.



## Detection

- Behavioral Detection of Cloud Group Enumeration via API and CLI Access


**Observed use:** 3 software/tool(s), 1 campaign(s) (per MITRE ATT&CK).
