# T1069.003 — Cloud Groups

<a id="t1069003"></a>

**Tactics:** discovery  
**Platforms:** SaaS, IaaS, Office Suite, Identity Provider  
**ATT&CK:** [T1069.003](https://attack.mitre.org/techniques/T1069/003)  
**Sub-technique of:** [T1069 — Permission Groups Discovery](/mitre/techniques/T1069.md)  

Adversaries may attempt to find cloud groups and permission settings. The knowledge of cloud permission groups can help adversaries determine the particular roles of users and groups within an environment, as well as which users are associated with a particular group.

## Detection

**Detection strategies:**

- Behavioral Detection of Cloud Group Enumeration via API and CLI Access

**Analytics (3):**

- **Analytic 0695** (IaaS) — `AWS:CloudTrail ListGroups, ListAttachedRolePolicies` → Group Enumeration
- **Analytic 0696** (Office Suite) — `m365:exchange Get-RoleGroup, Get-DistributionGroup` → Command Execution; `m365:sharepoint Enumerate ACLs/role bindings` → Group Metadata
- **Analytic 0697** (SaaS) — `saas:salesforce GET /services/data/vXX.X/groups` → Group Enumeration

## Data sources & telemetry (3)

**Group Enumeration**, **Command Execution**, **Group Metadata**

## Adversary usage

**Software/tools (3):** [AADInternals](https://attack.mitre.org/software/S0677), [ROADTools](https://attack.mitre.org/software/S0684), [Pacu](https://attack.mitre.org/software/S1091)
