# T1070.001 — Clear Windows Event Logs

<a id="t1070001"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1070.001](https://attack.mitre.org/techniques/T1070/001)  
**Sub-technique of:** [T1070 — Indicator Removal](/mitre/techniques/T1070.md)  

Adversaries may clear Windows Event Logs to hide the activity of an intrusion. Windows Event Logs are a record of a computer's alerts and notifications.

## Mitigations (3)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1029 — Remote Data Storage](/mitre/mitigations/M1029.md) — Remote Data Storage focuses on moving critical data, such as security logs and sensitive files, to secure, off-host locations to minimize unauthorized access, tampering, or destruction by adversaries.
- [M1041 — Encrypt Sensitive Information](/mitre/mitigations/M1041.md) — Protect sensitive information at rest, in transit, and during processing by using strong encryption algorithms.

## D3FEND countermeasures (2)

- [Application Exception Monitoring](/mitre/d3fend/application-exception-monitoring.md) (Detect) — monitors. Monitoring the failures of system counters and timers.
- [Operational Process Monitoring](/mitre/d3fend/operational-process-monitoring.md) (Detect) — monitors. Monitoring physical parameters and operator actions related to an operational environment.

## Detection

**Detection strategies:**

- Detection of Event Log Clearing on Windows via Behavioral Chain

**Analytics (1):**

- **Analytic 1472** (Windows) — `WinEventLog:Security EventCode=1102` → Application Log Content; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=23` → File Deletion

## Data sources & telemetry (3)

**Application Log Content**, **Process Creation**, **File Deletion**
