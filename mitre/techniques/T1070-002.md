# T1070.002 — Clear Linux or Mac System Logs

<a id="t1070002"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1070.002](https://attack.mitre.org/techniques/T1070/002)  
**Sub-technique of:** [T1070 — Indicator Removal](/mitre/techniques/T1070.md)  

Adversaries may clear system logs to hide evidence of an intrusion. macOS and Linux both keep track of system or user-initiated actions via system logs. The majority of native system logging is stored under the <code>/var/log/</code> directory.

## Detection

**Detection strategies:**

- Behavioral Detection of Log File Clearing on Linux and macOS

**Analytics (2):**

- **Analytic 1438** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL PATH` → File Deletion
- **Analytic 1439** (macOS) — `macos:unifiedlog process` → Process Creation; `fs:fsusage truncate, unlink, write` → File Modification
