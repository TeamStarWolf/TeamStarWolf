# T1070.003 — Clear Command History

<a id="t1070003"></a>

**Tactics:** defense-evasion  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1070.003](https://attack.mitre.org/techniques/T1070/003)  
**Sub-technique of:** [T1070 — Indicator Removal](/mitre/techniques/T1070.md)  

In addition to clearing system logs, an adversary may clear the command history of a compromised account to conceal the actions undertaken during an intrusion. Various command interpreters keep track of the commands users type in their terminal so that users can retrace what they've done.

## Mitigations (3)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1029 — Remote Data Storage](/mitre/mitigations/M1029.md) — Remote Data Storage focuses on moving critical data, such as security logs and sensitive files, to secure, off-host locations to minimize unauthorized access, tampering, or destruction by adversaries.
- [M1039 — Environment Variable Permissions](/mitre/mitigations/M1039.md) — Restrict the modification of environment variables to authorized users and processes by enforcing strict permissions and policies.

## Detection

**Detection strategies:**

- Behavioral Detection of Command History Clearing

**Analytics (5):**

- **Analytic 0467** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL PATH` → File Deletion
- **Analytic 0468** (macOS) — `macos:unifiedlog process` → Process Creation; `fs:fsusage unlink, write` → File Modification
- **Analytic 0469** (Windows) — `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `WinEventLog:Sysmon EventCode=23` → File Deletion; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Modification
- **Analytic 0470** (ESXi) — `esxi:shell /var/log/shell.log` → File Deletion
- **Analytic 0471** (Network Devices) — `networkdevice:syslog CLI command audit` → Command Execution
