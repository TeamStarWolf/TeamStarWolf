# T1070.004 — File Deletion

<a id="t1070004"></a>

**Tactics:** defense-evasion  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1070.004](https://attack.mitre.org/techniques/T1070/004)  
**Sub-technique of:** [T1070 — Indicator Removal](/mitre/techniques/T1070.md)  

Adversaries may delete files left behind by the actions of their intrusion activity. Malware, tools, or other non-native files dropped or created on a system by an adversary (ex: [Ingress Tool Transfer](https://attack.mitre.org/techniques/T1105)) may leave traces to indicate to what was done within a network and how. Removal of these files can occur during an intrusion, or as part of a post-intrusion process to minimize the adversary's footprint. There are tools available from the host operating system to perform cleanup, but adversaries may use other tools as well. Examples of built-in [Command and Scripting Interpreter](https://attack.mitre.org/techniques/T1059) functions include <code>del</code> on Windows, <code>rm</code> or <code>unlink</code> on Linux and macOS, and `rm` on ESXi.

## Detection

**Detection strategies:**

- Behavioral Detection of Malicious File Deletion

**Analytics (4):**

- **Analytic 0392** (Windows) — `WinEventLog:Sysmon EventCode=23` → File Deletion; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 0393** (Linux) — `auditd:SYSCALL PATH` → File Deletion; `auditd:SYSCALL execve` → Process Creation
- **Analytic 0394** (macOS) — `fs:fsusage unlink, write` → File Modification; `macos:unifiedlog process` → Process Creation
- **Analytic 0395** (ESXi) — `esxi:shell /var/log/shell.log` → File Deletion
