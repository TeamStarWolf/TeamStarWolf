# T1070.005 — Network Share Connection Removal

<a id="t1070005"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1070.005](https://attack.mitre.org/techniques/T1070/005)  
**Sub-technique of:** [T1070 — Indicator Removal](/mitre/techniques/T1070.md)  

Adversaries may remove share connections that are no longer useful in order to clean up traces of their operation. Windows shared drive and [SMB/Windows Admin Shares](https://attack.mitre.org/techniques/T1021/002) connections can be removed when no longer needed. [Net](https://attack.mitre.org/software/S0039) is an example utility that can be used to remove network share connections with the <code>net use \\system\share /delete</code> command.
