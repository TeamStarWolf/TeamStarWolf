# T1070.005 — Network Share Connection Removal

<a id="t1070005"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1070.005](https://attack.mitre.org/techniques/T1070/005)  
**Sub-technique of:** [T1070](/mitre/techniques/T1070.md)

Adversaries may remove share connections that are no longer useful in order to clean up traces of their operation. Windows shared drive and SMB/Windows Admin Shares connections can be removed when no longer needed.



## D3FEND countermeasures (2)

- **Decoy Network Resource** (Deceive) — spoofs
- **Network Resource Access Mediation** (Isolate) — isolates


## Detection

- Behavioral Detection of Network Share Connection Removal via CLI and SMB Disconnects


**Observed use:** 1 threat group(s), 4 software/tool(s) (per MITRE ATT&CK).
