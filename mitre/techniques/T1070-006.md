# T1070.006 — Timestomp

<a id="t1070006"></a>

**Tactics:** defense-evasion  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1070.006](https://attack.mitre.org/techniques/T1070/006)  
**Sub-technique of:** [T1070 — Indicator Removal](/mitre/techniques/T1070.md)  

Adversaries may modify file time attributes to hide new files or changes to existing files. Timestomping is a technique that modifies the timestamps of a file (the modify, access, create, and change times), often to mimic files that are in the same folder and blend malicious files with legitimate files.

## Detection

**Detection strategies:**

- Cross-Platform Behavioral Detection of File Timestomping via Metadata Tampering

**Analytics (4):**

- **Analytic 1626** (Windows) — `WinEventLog:Sysmon EventCode=15` → File Metadata; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `EDR:file SetFileTime` → OS API Execution
- **Analytic 1627** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:osquery file_events` → File Metadata
- **Analytic 1628** (macOS) — `macos:unifiedlog log stream --predicate` → Command Execution; `macos:osquery file_events` → File Metadata
- **Analytic 1629** (ESXi) — `esxi:vmkernel /var/log/vmkernel.log` → File Modification

## Data sources & telemetry (6)
