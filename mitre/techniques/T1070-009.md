# T1070.009 — Clear Persistence

<a id="t1070009"></a>

**Tactics:** defense-evasion  
**Platforms:** ESXi, Linux, Windows, macOS  
**ATT&CK:** [T1070.009](https://attack.mitre.org/techniques/T1070/009)  
**Sub-technique of:** [T1070 — Indicator Removal](/mitre/techniques/T1070.md)  

Adversaries may clear artifacts associated with previously established persistence on a host system to remove evidence of their activity.

## Mitigations (2)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1029 — Remote Data Storage](/mitre/mitigations/M1029.md) — Remote Data Storage focuses on moving critical data, such as security logs and sensitive files, to secure, off-host locations to minimize unauthorized access, tampering, or destruction by adversaries.

## Detection

**Detection strategies:**

- Detection of Persistence Artifact Removal Across Host Platforms

**Analytics (4):**

- **Analytic 0113** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Security EventCode=4726, 4657` → User Account Deletion; `WinEventLog:TaskScheduler EventCode=106` → Scheduled Job Creation; `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification
- **Analytic 0114** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL file deletion` → File Deletion
- **Analytic 0115** (macOS) — `macos:unifiedlog log stream` → Command Execution; `macos:osquery file_events` → File Deletion
- **Analytic 0116** (ESXi) — `esxi:vmkernel /var/log/vmkernel.log` → Command Execution; `esxi:shell shell history` → File Deletion
