# T1070.010 — Relocate Malware

<a id="t1070010"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows, Network Devices  
**ATT&CK:** [T1070.010](https://attack.mitre.org/techniques/T1070/010)  
**Sub-technique of:** [T1070 — Indicator Removal](/mitre/techniques/T1070.md)  

Once a payload is delivered, adversaries may reproduce copies of the same malware on the victim system to remove evidence of their presence and/or avoid defenses. Copying malware payloads to new locations may also be combined with File Deletion to cleanup older artifacts.

## Detection

**Detection strategies:**

- Detection of Malware Relocation via Suspicious File Movement

**Analytics (4):**

- **Analytic 1216** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=23` → File Deletion
- **Analytic 1217** (Linux) — `auditd:SYSCALL PATH` → File Modification
- **Analytic 1218** (macOS) — `macos:unifiedlog log stream` → Command Execution; `macos:osquery file_events` → File Modification
- **Analytic 1219** (Network Devices) — `networkdevice:syslog command audit` → Command Execution

## Data sources & telemetry (4)

**File Creation**, **File Deletion**, **File Modification**, **Command Execution**
