# T1070 — Indicator Removal

<a id="t1070"></a>

**Tactics:** defense-evasion  
**Platforms:** Containers, ESXi, Linux, macOS, Network Devices, Office Suite, Windows  
**ATT&CK:** [T1070](https://attack.mitre.org/techniques/T1070)  

Adversaries may delete or modify artifacts generated within systems to remove evidence of their presence or hinder defenses. Various artifacts may be created by an adversary or something that can be attributed to an adversary’s actions.

## Mitigations (3)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1029 — Remote Data Storage](/mitre/mitigations/M1029.md) — Remote Data Storage focuses on moving critical data, such as security logs and sensitive files, to secure, off-host locations to minimize unauthorized access, tampering, or destruction by adversaries.
- [M1041 — Encrypt Sensitive Information](/mitre/mitigations/M1041.md) — Protect sensitive information at rest, in transit, and during processing by using strong encryption algorithms.

## Detection

**Detection strategies:**

- Behavioral Detection of Indicator Removal Across Platforms

**Analytics (6):**

- **Analytic 0520** (Windows) — `WinEventLog:Sysmon EventCode=23` → File Deletion; `WinEventLog:Security EventCode=1102` → Application Log Content; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 0521** (Linux) — `auditd:SYSCALL unlink, rename, open` → File Deletion; `linux:cli cleared or truncated .bash_history` → Application Log Content
- **Analytic 0522** (macOS) — `macos:unifiedlog log stream cleared or truncated` → Application Log Content; `fs:fsusage unlink, fs_delete` → File Deletion; `macos:osquery File modifications in ~/Library/Preferences/` → File Modification
- **Analytic 0523** (Containers) — `docker:daemon container file operations` → File Deletion; `ebpf:syscalls Unexpected container volume unmount + file deletion` → File Metadata
- **Analytic 0524** (ESXi) — `esxi:hostd rm, clearlogs, logrotate` → File Deletion
- **Analytic 0525** (Office Suite) — `m365:exchange Remove-InboxRule, Clear-Mailbox` → Scheduled Job Modification; `m365:unified PurgeAuditLogs, Remove-MailboxAuditLog` → Application Log Content
