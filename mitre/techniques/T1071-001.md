# T1071.001: Web Protocols

<a id="t1071001"></a>

Tactics: command-and-control  
Platforms: ESXi, Linux, macOS, Network Devices, Windows  
ATT&CK: [T1071.001](https://attack.mitre.org/techniques/T1071/001)  
Sub-technique of: [T1071: Application Layer Protocol](/mitre/techniques/T1071.md)  

Live exposure: [Open T1071.001 in ATTACK-Navi](https://teamstarwolf.github.io/ATTACK-Navi/#/matrix?tech=T1071.001) for its CVEs (CTID CVE-to-ATT&CK mappings), KEV/EPSS priority, detection analytics and candidate defenses.

Adversaries may communicate using application layer protocols associated with web traffic to avoid detection/network filtering by blending in with existing traffic. Commands to the remote system, and often the results of those commands, will be embedded within the protocol traffic between the client and server. Protocols such as HTTP/S and WebSocket that carry web traffic may be very common in environments. HTTP/S packets have many fields and headers in which data can be concealed. An adversary may abuse these protocols to communicate with systems under their control within a victim network while also mimicking normal, expected traffic.

## Mitigations (2)

- [M1031: Network Intrusion Prevention](/mitre/mitigations/M1031.md): Use intrusion detection signatures to block traffic at network boundaries.
- [M1037: Filter Network Traffic](/mitre/mitigations/M1037.md): Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

Detection strategies:

- Detection of Web Protocol-Based C2 Over HTTP, HTTPS, or WebSockets

Analytics (5):

- Analytic 0075 (Windows): `NSM:Flow http.log, ssl.log` -> Network Traffic Content; `WinEventLog:Sysmon EventCode=3, 22` -> Network Connection Creation
- Analytic 0076 (Linux): `NSM:Flow http.log, conn.log` -> Network Traffic Content; `auditd:SYSCALL execve` -> Process Creation
- Analytic 0077 (macOS): `macos:osquery socket_events` -> Network Traffic Flow; `macos:unifiedlog log stream --predicate` -> Command Execution
- Analytic 0078 (ESXi): `NSM:Flow SPAN or port-mirrored HTTP/S` -> Network Traffic Content; `esxi:shell /root/.ash_history or /etc/init.d/*` -> Process Creation
- Analytic 0079 (Network Devices): `NSM:Flow http.log, ssl.log, websocket.log` -> Network Traffic Content
