# T1071.003 — Mail Protocols

<a id="t1071003"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1071.003](https://attack.mitre.org/techniques/T1071/003)  
**Sub-technique of:** [T1071 — Application Layer Protocol](/mitre/techniques/T1071.md)  

Adversaries may communicate using application layer protocols associated with electronic mail delivery to avoid detection/network filtering by blending in with existing traffic.

## Detection

**Detection strategies:**

- Detection of Mail Protocol-Based C2 Activity (SMTP, IMAP, POP3)

**Analytics (4):**

- **Analytic 0379** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `NSM:Flow smtp.log` → Network Traffic Content
- **Analytic 0380** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Flow smtp.log, conn.log` → Network Traffic Content
- **Analytic 0381** (macOS) — `macos:unifiedlog log stream --predicate 'processImagePath CONTAINS "curl" OR "osascript"'` → Process Creation; `macos:osquery socket_events` → Network Traffic Flow
- **Analytic 0382** (Network Devices) — `NSM:Flow smtp.log, conn.log` → Network Traffic Content
