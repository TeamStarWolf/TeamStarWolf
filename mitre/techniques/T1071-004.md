# T1071.004 — DNS

<a id="t1071004"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows, Network Devices, ESXi  
**ATT&CK:** [T1071.004](https://attack.mitre.org/techniques/T1071/004)  
**Sub-technique of:** [T1071 — Application Layer Protocol](/mitre/techniques/T1071.md)  

Adversaries may communicate using the Domain Name System (DNS) application layer protocol to avoid detection/network filtering by blending in with existing traffic. Commands to the remote system, and often the results of those commands, will be embedded within the protocol traffic between the client and server.

## Mitigations (2)

- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.
- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Behavioral Detection of DNS Tunneling and Application Layer Abuse

**Analytics (5):**

- **Analytic 1121** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `NSM:Flow dns.log` → Network Traffic Content
- **Analytic 1122** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Flow dns.log` → Network Traffic Content
- **Analytic 1123** (macOS) — `macos:unifiedlog log stream 'eventMessage contains "dns_request"'` → Network Traffic Flow
- **Analytic 1124** (Network Devices) — `NSM:Flow dns.log` → Network Traffic Content
- **Analytic 1125** (ESXi) — `esxi:syslog /var/log/syslog.log` → Network Traffic Flow; `NSM:FLow dns.log` → Network Traffic Content
