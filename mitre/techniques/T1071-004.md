# T1071.004: DNS

<a id="t1071004"></a>

Tactics: command-and-control  
Platforms: Linux, macOS, Windows, Network Devices, ESXi  
ATT&CK: [T1071.004](https://attack.mitre.org/techniques/T1071/004)  
Sub-technique of: [T1071: Application Layer Protocol](/mitre/techniques/T1071.md)  

Adversaries may communicate using the Domain Name System (DNS) application layer protocol to avoid detection/network filtering by blending in with existing traffic. Commands to the remote system, and often the results of those commands, will be embedded within the protocol traffic between the client and server. The DNS protocol serves an administrative function in computer networking and thus may be very common in environments. DNS traffic may also be allowed even before network authentication is completed. DNS packets contain many fields and headers in which data can be concealed. Often known as DNS tunneling, adversaries may abuse DNS to communicate with systems under their control within a victim network while also mimicking normal, expected traffic. DNS beaconing may be used to send commands to remote systems via DNS queries. A DNS beacon is created by tunneling DNS traffic (i.e. [Protocol Tunneling](https://attack.mitre.org/techniques/T1572)). The commands may be embedded into different DNS records, for example, TXT or A records. DNS beacons may be difficult to detect because the beacons infrequently communicate with infected devices. Infrequent communication conceals the malicious DNS traffic with normal DNS traffic.

## Mitigations (2)

- [M1031: Network Intrusion Prevention](/mitre/mitigations/M1031.md): Use intrusion detection signatures to block traffic at network boundaries.
- [M1037: Filter Network Traffic](/mitre/mitigations/M1037.md): Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## D3FEND countermeasures (16)

- [Application Protocol Command Analysis](/mitre/d3fend/application-protocol-command-analysis.md) (Detect): monitors. Analyzing application protocol level remote commands to detect unauthorized activity.
- [Client-server Payload Profiling](/mitre/d3fend/client-server-payload-profiling.md) (Detect): analyzes. Comparing client-server request and response payloads to a baseline profile to identify outliers.
- [DNS Allowlisting](/mitre/d3fend/dns-allowlisting.md) (Isolate): blocks. Permitting only approved domains and their subdomains to be resolved.
- [DNS Denylisting](/mitre/d3fend/dns-denylisting.md) (Isolate): blocks. Blocking DNS Network Traffic based on criteria such as IP address, domain name, or DNS query type.
- [DNS Traffic Analysis](/mitre/d3fend/dns-traffic-analysis.md) (Detect): analyzes. Analysis of domain name metadata, including name and DNS records, to determine whether the domain is likely to resolve to an undesirable host.
- [Forward Resolution Domain Denylisting](/mitre/d3fend/forward-resolution-domain-denylisting.md) (Isolate): blocks. Blocking a lookup based on the query's domain name value.
- [Network Traffic Community Deviation](/mitre/d3fend/network-traffic-community-deviation.md) (Detect): analyzes. Establishing baseline communities of network hosts and identifying statistically divergent inter-community communication.
- [Network Traffic Filtering](/mitre/d3fend/network-traffic-filtering.md) (Isolate): filters. Restricting network traffic originating from any location.
- [Network Traffic Signature Analysis](/mitre/d3fend/network-traffic-signature-analysis.md) (Detect): analyzes. Analyzing network traffic and compares it to known signatures
- [Outbound Traffic Filtering](/mitre/d3fend/outbound-traffic-filtering.md) (Isolate): filters. Restricting network traffic originating from a private host or enclave destined towards untrusted networks.
- [Per Host Download-Upload Ratio Analysis](/mitre/d3fend/per-host-download-upload-ratio-analysis.md) (Detect): analyzes. Detecting anomalies that indicate malicious activity by comparing the amount of data downloaded versus data uploaded by a host.
- [Protocol Metadata Anomaly Detection](/mitre/d3fend/protocol-metadata-anomaly-detection.md) (Detect): analyzes. Collecting network communication protocol metadata and identifying statistical outliers.
- [Relay Pattern Analysis](/mitre/d3fend/relay-pattern-analysis.md) (Detect): analyzes. The detection of an internal host relaying traffic between the internal network and the external network.
- [Remote Terminal Session Detection](/mitre/d3fend/remote-terminal-session-detection.md) (Detect): analyzes. Detection of an unauthorized remote live terminal console session by examining network traffic to a network host.
- [Reverse Resolution IP Denylisting](/mitre/d3fend/reverse-resolution-ip-denylisting.md) (Isolate): blocks. Blocking a reverse lookup based on the query's IP address value.
- [User Geolocation Logon Pattern Analysis](/mitre/d3fend/user-geolocation-logon-pattern-analysis.md) (Detect): analyzes. Monitoring geolocation data of user logon attempts and comparing it to a baseline user behavior profile to identify anomalies in logon location.
