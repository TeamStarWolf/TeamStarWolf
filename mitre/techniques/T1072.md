# T1072 — Software Deployment Tools

<a id="t1072"></a>

**Tactics:** execution, lateral-movement  
**Platforms:** Linux, macOS, Network Devices, SaaS, Windows  
**ATT&CK:** [T1072](https://attack.mitre.org/techniques/T1072)  

Adversaries may gain access to and use centralized software suites installed within an enterprise to execute commands and move laterally through the network. Configuration management and software deployment applications may be used in an enterprise network or cloud environment for routine administration purposes.

## Mitigations (10)

- [M1015 — Active Directory Configuration](/mitre/mitigations/M1015.md) — Implement robust Active Directory (AD) configurations using group policies to secure user accounts, control access, and minimize the attack surface.
- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1029 — Remote Data Storage](/mitre/mitigations/M1029.md) — Remote Data Storage focuses on moving critical data, such as security logs and sensitive files, to secure, off-host locations to minimize unauthorized access, tampering, or destruction by adversaries.
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1033 — Limit Software Installation](/mitre/mitigations/M1033.md) — Prevent users or groups from installing unauthorized or unapproved software to reduce the risk of introducing malicious or vulnerable applications.
- [M1051 — Update Software](/mitre/mitigations/M1051.md) — Software updates ensure systems are protected against known vulnerabilities by applying patches and upgrades provided by vendors.
