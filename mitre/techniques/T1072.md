# T1072 — Software Deployment Tools

<a id="t1072"></a>

**Tactics:** execution, lateral-movement  
**Platforms:** Linux, macOS, Network Devices, SaaS, Windows  
**ATT&CK:** [T1072](https://attack.mitre.org/techniques/T1072)  

Adversaries may gain access to and use centralized software suites installed within an enterprise to execute commands and move laterally through the network. Configuration management and software deployment applications may be used in an enterprise network or cloud environment for routine administration purposes.

## Detection

**Detection strategies:**

- Detection of Adversary Abuse of Software Deployment Tools

**Analytics (5):**

- **Analytic 0623** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Application SCCM, Intune logs` → Application Log Content
- **Analytic 0624** (Linux) — `auditd:SYSCALL execve` → Process Creation
- **Analytic 0625** (macOS) — `macos:unifiedlog process and signing chain events` → Process Creation; `macos:jamf RemoteCommandExecution` → Application Log Content
- **Analytic 0626** (SaaS) — `AWS:CloudTrail SSM RunCommand` → Command Execution
- **Analytic 0627** (Network Devices) — `networkdevice:syslog config push events` → Application Log Content; `NSM:Flow Device-to-Device Deployment Flows` → Network Traffic Flow
