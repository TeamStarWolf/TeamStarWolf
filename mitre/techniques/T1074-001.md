# T1074.001: Local Data Staging

<a id="t1074001"></a>

Tactics: collection  
Platforms: ESXi, Linux, macOS, Windows  
ATT&CK: [T1074.001](https://attack.mitre.org/techniques/T1074/001)  
Sub-technique of: [T1074: Data Staged](/mitre/techniques/T1074.md)  

Adversaries may stage collected data in a central location or directory on the local system prior to Exfiltration. Data may be kept in separate files or combined into one file through techniques such as [Archive Collected Data](https://attack.mitre.org/techniques/T1560). Interactive command shells may be used, and common functionality within [cmd](https://attack.mitre.org/software/S0106) and bash may be used to copy data into a staging location. Adversaries may also stage collected data in various available formats/locations of a system, including local storage databases/repositories or the Windows Registry.

## Detection

Detection strategies:

- Detection of Local Data Staging Prior to Exfiltration

Analytics (4):

- Analytic 0724 (Windows): `WinEventLog:Sysmon EventCode=11` -> File Creation; `WinEventLog:Sysmon EventCode=1` -> Process Creation; `WinEventLog:Security EventCode=4663, 4670, 4656` -> File Access
- Analytic 0725 (Linux): `auditd:SYSCALL open` -> File Access; `auditd:SYSCALL execve` -> Process Creation
- Analytic 0726 (macOS): `macos:unifiedlog file events` -> File Access; `macos:unifiedlog exec logs` -> Process Creation
- Analytic 0727 (ESXi): `esxi:vmkernel snapshot create/write events` -> Snapshot Creation; `esxi:shell CLI usage logs` -> Command Execution
