# T1074.002 — Remote Data Staging

<a id="t1074002"></a>

**Tactics:** collection  
**Platforms:** Windows, IaaS, Linux, macOS, ESXi  
**ATT&CK:** [T1074.002](https://attack.mitre.org/techniques/T1074/002)  
**Sub-technique of:** [T1074 — Data Staged](/mitre/techniques/T1074.md)  

Adversaries may stage data collected from multiple systems in a central location or directory on one system prior to Exfiltration. Data may be kept in separate files or combined into one file through techniques such as Archive Collected Data.

## D3FEND countermeasures (2)

- [Decoy Network Resource](/mitre/d3fend/decoy-network-resource.md) (Deceive) — spoofs
- [Network Resource Access Mediation](/mitre/d3fend/network-resource-access-mediation.md) (Isolate) — isolates

## Detection

**Detection strategies:**

- Detection of Remote Data Staging Prior to Exfiltration

**Analytics (5):**

- **Analytic 0194** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Microsoft-Windows-SMBClient/Security EventCode=31001` → Network Share Access; `WinEventLog:PowerShell CommandLine=copy-item or robocopy from UNC path` → Command Execution
- **Analytic 0195** (Linux) — `auditd:SYSCALL open` → File Access; `auditd:SYSCALL execve` → Process Creation; `NSM:Flow SSH logins or scp activity` → Network Traffic Content
- **Analytic 0196** (macOS) — `macos:unifiedlog exec logs` → Process Creation; `macos:unifiedlog file events` → File Creation; `NSM:Flow remote login and transfer` → Network Traffic Content
- **Analytic 0197** (ESXi) — `esxi:vmkernel VMFS file creation` → File Creation; `esxi:vob NFS/remote access logs` → Network Traffic Content; `esxi:shell invoked remote scripts (esxcli)` → Command Execution
- **Analytic 0198** (IaaS) — `AWS:CloudTrail GetObject, CopyObject` → Cloud Storage Access; `AWS:VPCFlowLogs Traffic between instances` → Network Traffic Content; `esxi:hostd process execution across cloud VM` → Process Creation
