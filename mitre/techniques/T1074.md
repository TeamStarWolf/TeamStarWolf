# T1074 — Data Staged

<a id="t1074"></a>

**Tactics:** collection  
**Platforms:** Windows, IaaS, Linux, macOS, ESXi  
**ATT&CK:** [T1074](https://attack.mitre.org/techniques/T1074)  

Adversaries may stage collected data in a central location or directory prior to Exfiltration. Data may be kept in separate files or combined into one file through techniques such as Archive Collected Data.

## Detection

**Detection strategies:**

- Detection of Data Staging Prior to Exfiltration

**Analytics (5):**

- **Analytic 0040** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0041** (Linux) — `auditd:SYSCALL creat` → File Creation; `auditd:SYSCALL execve` → Process Creation
- **Analytic 0042** (macOS) — `macos:unifiedlog file events` → File Access; `macos:unifiedlog exec logs` → Process Creation
- **Analytic 0043** (IaaS) — `AWS:CloudTrail GetObject, CopyObject` → Cloud Storage Access; `gcp:audit Write operations to storage` → File Access
- **Analytic 0044** (ESXi) — `esxi:vmkernel VMFS access logs` → File Access; `esxi:shell snapshot create/copy, esxcli` → Command Execution

## Data sources & telemetry (5)

**File Access**, **File Creation**, **Process Creation**, **Cloud Storage Access**, **Command Execution**
