# T1078.002 — Domain Accounts

<a id="t1078002"></a>

**Tactics:** defense-evasion, persistence, privilege-escalation, initial-access  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1078.002](https://attack.mitre.org/techniques/T1078/002)  
**Sub-technique of:** [T1078 — Valid Accounts](/mitre/techniques/T1078.md)  

Adversaries may obtain and abuse credentials of a domain account as a means of gaining Initial Access, Persistence, Privilege Escalation, or Defense Evasion.

## Detection

**Detection strategies:**

- Abuse of Domain Accounts

**Analytics (4):**

- **Analytic 0590** (Windows) — `WinEventLog:Security EventCode=4624, 4625, 4768, 4769` → Logon Session Metadata; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0591** (Linux) — `auditd:SYSCALL pam_authenticate, sshd` → User Account Authentication; `linux:syslog sssd / sudo logs` → Logon Session Metadata
- **Analytic 0592** (macOS) — `macos:unifiedlog log show --predicate 'eventMessage contains "Authentication"'` → User Account Authentication
- **Analytic 0593** (ESXi) — `esxi:vpxd /var/log/vmware/vpxd.log` → User Account Authentication; `esxi:hostd /var/log/hostd.log` → Logon Session Metadata
