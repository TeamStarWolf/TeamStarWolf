# T1078.002 — Domain Accounts

<a id="t1078002"></a>

**Tactics:** defense-evasion, persistence, privilege-escalation, initial-access  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1078.002](https://attack.mitre.org/techniques/T1078/002)  
**Sub-technique of:** [T1078 — Valid Accounts](/mitre/techniques/T1078.md)  

Adversaries may obtain and abuse credentials of a domain account as a means of gaining Initial Access, Persistence, Privilege Escalation, or Defense Evasion. Domain accounts are those managed by Active Directory Domain Services where access and permissions are configured across systems and services that are part of that domain. Domain accounts can cover users, administrators, and services. Adversaries may compromise domain accounts, some with a high level of privileges, through various means such as [OS Credential Dumping](https://attack.mitre.org/techniques/T1003) or password reuse, allowing access to privileged resources of the domain.

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.

**Analytics (4):**

- **Analytic 0590** (Windows) — `WinEventLog:Security EventCode=4624, 4625, 4768, 4769` → Logon Session Metadata; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0591** (Linux) — `auditd:SYSCALL pam_authenticate, sshd` → User Account Authentication; `linux:syslog sssd / sudo logs` → Logon Session Metadata
- **Analytic 0592** (macOS) — `macos:unifiedlog log show --predicate 'eventMessage contains "Authentication"'` → User Account Authentication
- **Analytic 0593** (ESXi) — `esxi:vpxd /var/log/vmware/vpxd.log` → User Account Authentication; `esxi:hostd /var/log/hostd.log` → Logon Session Metadata
