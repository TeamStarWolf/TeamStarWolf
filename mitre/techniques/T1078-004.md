# T1078.004 — Cloud Accounts

<a id="t1078004"></a>

**Tactics:** defense-evasion, persistence, privilege-escalation, initial-access  
**Platforms:** IaaS, Identity Provider, Office Suite, SaaS  
**ATT&CK:** [T1078.004](https://attack.mitre.org/techniques/T1078/004)  
**Sub-technique of:** [T1078 — Valid Accounts](/mitre/techniques/T1078.md)  

Valid accounts in cloud environments may allow adversaries to perform actions to achieve Initial Access, Persistence, Privilege Escalation, or Defense Evasion.

## Detection

**Detection strategies:**

- Detection of Abused or Compromised Cloud Accounts for Access and Persistence

**Analytics (4):**

- **Analytic 1503** (Identity Provider) — `azure:signinlogs Sign-in activity` → User Account Authentication; `saas:okta user.authentication.sso` → Logon Session Metadata
- **Analytic 1504** (IaaS) — `AWS:CloudTrail ConsoleLogin, AssumeRole, ListAccessKeys, CreateUser` → User Account Authentication; `gcp:audit admin.googleapis.com` → Logon Session Creation
- **Analytic 1505** (SaaS) — `m365:unified FileAccessed, SharingSet` → Logon Session Metadata; `gcp:audit drive.activity` → User Account Authentication
- **Analytic 1506** (Office Suite) — `m365:signinlogs UserLogin` → Logon Session Metadata; `gcp:audit login.event` → User Account Authentication
