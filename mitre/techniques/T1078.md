# T1078 — Valid Accounts

<a id="t1078"></a>

**Tactics:** defense-evasion, persistence, privilege-escalation, initial-access  
**Platforms:** Containers, ESXi, IaaS, Identity Provider, Linux, macOS, Network Devices, Office Suite, SaaS, Windows  
**ATT&CK:** [T1078](https://attack.mitre.org/techniques/T1078)  

Adversaries may obtain and abuse credentials of existing accounts as a means of gaining Initial Access, Persistence, Privilege Escalation, or Defense Evasion.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **58 machines (11.0%)** — Linux 27 / Windows 24. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Detection

**Detection strategies:**

- Detection of Valid Account Abuse Across Platforms

**Analytics (5):**

- **Analytic 1543** (Windows) — `WinEventLog:Security EventCode=4624` → Logon Session Creation; `WinEventLog:Security EventCode=4776, 4625` → User Account Authentication; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1544** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Connections sshd or PAM logins` → User Account Authentication
- **Analytic 1545** (macOS) — `macos:unifiedlog loginwindow, sshd` → Logon Session Metadata; `macos:unifiedlog exec logs` → Process Creation
- **Analytic 1546** (Identity Provider) — `saas:okta Sign-in logs / audit events` → User Account Authentication
- **Analytic 1547** (Containers) — `kubernetes:audit authentication.k8s.io` → User Account Authentication
