# T1080 — Taint Shared Content

<a id="t1080"></a>

**Tactics:** lateral-movement  
**Platforms:** Windows, SaaS, Linux, macOS, Office Suite  
**ATT&CK:** [T1080](https://attack.mitre.org/techniques/T1080)  

Adversaries may deliver payloads to remote systems by adding content to shared storage locations, such as network drives or internal code repositories. Content stored on network drives or in other shared locations may be tainted by adding malicious programs, scripts, or exploit code to otherwise valid files.

## Detection

**Detection strategies:**

- Detection of Tainted Content Written to Shared Storage

**Analytics (5):**

- **Analytic 1298** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=5145` → Network Share Access
- **Analytic 1299** (Linux) — `auditd:SYSCALL write` → File Modification; `NSM:Flow smb_files.log` → Network Share Access
- **Analytic 1300** (macOS) — `fs:fsevents Directory events (kFSEventStreamEventFlagItemCreated)` → File Creation; `macos:unifiedlog file writes` → File Modification
- **Analytic 1301** (SaaS) — `gcp:workspaceaudit drive.activity logs` → File Creation; `m365:unified FileUploaded, FileAccessed` → Network Share Access
- **Analytic 1302** (Office Suite) — `m365:defender OfficeTelemetry or DLP` → File Modification
