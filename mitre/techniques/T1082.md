# T1082 — System Information Discovery

<a id="t1082"></a>

**Tactics:** discovery  
**Platforms:** ESXi, IaaS, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1082](https://attack.mitre.org/techniques/T1082)  

An adversary may attempt to get detailed information about the operating system and hardware, including version, patches, hotfixes, service packs, and architecture.

## D3FEND countermeasures (7)

- [Decoy Environment](/mitre/d3fend/decoy-environment.md) (Deceive) — manages. A Decoy Environment comprises hosts and networks for the purposes of deceiving an attacker.
- [Executable Allowlisting](/mitre/d3fend/executable-allowlisting.md) (Isolate) — filters. Using a digital signature to authenticate a file before opening.
- [Executable Denylisting](/mitre/d3fend/executable-denylisting.md) (Isolate) — filters. Blocking the execution of files on a host in accordance with defined application policy rules.
- [Hardware-based Process Isolation](/mitre/d3fend/hardware-based-process-isolation.md) (Isolate) — restricts. Preventing one process from writing to the memory space of another process through hardware based address manager implementations.
- [Process Spawn Analysis](/mitre/d3fend/process-spawn-analysis.md) (Detect) — analyzes. Analyzing spawn arguments or attributes of a process to detect processes that are unauthorized.
- [System Call Analysis](/mitre/d3fend/system-call-analysis.md) (Detect) — analyzes. Analyzing system calls to determine whether a process is exhibiting unauthorized behavior.
- [System Call Filtering](/mitre/d3fend/system-call-filtering.md) (Isolate) — filters. Controlling access to local computer system resources with kernel-level capabilities.

## Detection

**Detection strategies:**

- System Discovery via Native and Remote Utilities

**Analytics (6):**

- **Analytic 1452** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 1453** (Linux) — `auditd:SYSCALL execve` → Process Creation
- **Analytic 1454** (macOS) — `macos:unifiedlog log show --predicate 'process == <utility>'` → Command Execution
- **Analytic 1455** (ESXi) — `esxi:vmkernel /var/log/vmkernel.log` → Command Execution
- **Analytic 1456** (IaaS) — `AWS:CloudTrail DescribeInstances, GetConsoleOutput, DescribeImages` → Instance Enumeration
- **Analytic 1457** (Network Devices) — `networkdevice:syslog Privilege-level command execution` → Command Execution

## Data sources & telemetry (3)

**Process Creation**, **Command Execution**, **Instance Enumeration**
