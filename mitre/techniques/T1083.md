# T1083 — File and Directory Discovery

<a id="t1083"></a>

**Tactics:** discovery  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1083](https://attack.mitre.org/techniques/T1083)  

Adversaries may enumerate files and directories or may search in specific locations of a host or network share for certain information within a file system.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **148 machines (28.0%)** — Linux 119 / Windows 20. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Detection

**Detection strategies:**

- Recursive Enumeration of Files and Directories Across Privilege Contexts

**Analytics (5):**

- **Analytic 1040** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 1041** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:PATH PATH` → File Access
- **Analytic 1042** (macOS) — `macos:unifiedlog log collect --predicate` → Process Creation; `fs:fsusage Filesystem Call Monitoring` → File Access
- **Analytic 1043** (ESXi) — `esxi:shell Shell Access/Command Execution` → Command Execution; `esxi:hostd vSphere File API Access` → File Access
- **Analytic 1044** (Network Devices) — `networkdevice:syslog CLI Command Logging` → Command Execution

## Data sources & telemetry (4)

**Process Creation**, **File Creation**, **File Access**, **Command Execution**
