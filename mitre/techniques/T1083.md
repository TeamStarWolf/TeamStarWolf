# T1083: File and Directory Discovery

<a id="t1083"></a>

Tactics: discovery  
Platforms: ESXi, Linux, macOS, Network Devices, Windows  
ATT&CK: [T1083](https://attack.mitre.org/techniques/T1083)  

Adversaries may enumerate files and directories or may search in specific locations of a host or network share for certain information within a file system. Adversaries may use the information from [File and Directory Discovery](https://attack.mitre.org/techniques/T1083) during automated discovery to shape follow-on behaviors, including whether or not the adversary fully infects the target and/or attempts specific actions. Many command shell utilities can be used to obtain this information. Examples include <code>dir</code>, <code>tree</code>, <code>ls</code>, <code>find</code>, and <code>locate</code>. Custom tools may also be used to gather file and directory information and interact with the [Native API](https://attack.mitre.org/techniques/T1106). Adversaries may also leverage a [Network Device CLI](https://attack.mitre.org/techniques/T1059/008) on network devices to gather file and directory information (e.g. <code>dir</code>, <code>show flash</code>, and/or <code>nvram</code>). Some files and directories may require elevated or specific user permissions to access.

Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines): observed on 148 machines (28.0%) — Linux 119 / Windows 20. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## D3FEND countermeasures (11)

- [Content Filtering](/mitre/d3fend/content-filtering.md) (Isolate): filters. Content Filtering techniques aid in the process of analyzing an input file for malicious or erroneous content and outputting a sanitized version.
- [Content Modification](/mitre/d3fend/content-modification.md) (Isolate): modifies. Modify content that does not comply with policy.
- [Content Quarantine](/mitre/d3fend/content-quarantine.md) (Isolate): quarantines. Transfer content that does not comply with policy to a quarantine zone.
- [Decoy File](/mitre/d3fend/decoy-file.md) (Deceive): spoofs. A file created for the purposes of deceiving an adversary.
- [File Analysis](/mitre/d3fend/file-analysis.md) (Detect): analyzes. File Analysis is an analytic process to determine a file's status.
- [File Encryption](/mitre/d3fend/file-encryption.md) (Harden): encrypts. Encrypting a file using a cryptographic key.
- [File Eviction](/mitre/d3fend/file-eviction.md) (Evict): deletes. File eviction techniques delete files from system storage.
- [File Integrity Monitoring](/mitre/d3fend/file-integrity-monitoring.md) (Detect): analyzes. Detecting any suspicious changes to files in a computer system.
- [Local File Permissions](/mitre/d3fend/local-file-permissions.md) (Isolate): restricts. Local file permissions is the systematic process of defining, implementing, and managing access control policies that dictate user permissions for accessing files on a local system through the configuration of operating system functionality.
- [Remote File Access Mediation](/mitre/d3fend/remote-file-access-mediation.md) (Isolate): isolates. Remote file access mediation is the process of managing and securing access to file systems over a network to ensure that only authorized users or processes can interact with remote files.
- [Restore File](/mitre/d3fend/restore-file.md) (Restore): restores. Restoring a file for an entity to access.

## Detection

Detection strategies:

- Recursive Enumeration of Files and Directories Across Privilege Contexts

Analytics (5):

- Analytic 1040 (Windows): `WinEventLog:Security EventCode=4688` -> Process Creation; `WinEventLog:Sysmon EventCode=11` -> File Creation
- Analytic 1041 (Linux): `auditd:SYSCALL execve` -> Process Creation; `auditd:PATH PATH` -> File Access
- Analytic 1042 (macOS): `macos:unifiedlog log collect --predicate` -> Process Creation; `fs:fsusage Filesystem Call Monitoring` -> File Access
- Analytic 1043 (ESXi): `esxi:shell Shell Access/Command Execution` -> Command Execution; `esxi:hostd vSphere File API Access` -> File Access
- Analytic 1044 (Network Devices): `networkdevice:syslog CLI Command Logging` -> Command Execution
