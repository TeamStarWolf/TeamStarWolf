# T1087.001 — Local Account

<a id="t1087001"></a>

**Tactics:** discovery  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1087.001](https://attack.mitre.org/techniques/T1087/001)  
**Sub-technique of:** [T1087 — Account Discovery](/mitre/techniques/T1087.md)  

Adversaries may attempt to get a listing of local system accounts. This information can help adversaries determine which local accounts exist on a system to aid in follow-on behavior.

## Mitigations (1)

- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.
