# T1087.002 — Domain Account

<a id="t1087002"></a>

**Tactics:** discovery  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1087.002](https://attack.mitre.org/techniques/T1087/002)  
**Sub-technique of:** [T1087 — Account Discovery](/mitre/techniques/T1087.md)  

Adversaries may attempt to get a listing of domain accounts. This information can help adversaries determine which domain accounts exist to aid in follow-on behavior such as targeting specific accounts which possess particular privileges.

## Mitigations (1)

- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.

## Detection

**Detection strategies:**

- Domain Account Enumeration Across Platforms

**Analytics (3):**

- **Analytic 0363** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `NSM:Flow LDAP Bind/Search` → Network Traffic Content
- **Analytic 0364** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linuxsyslog nslcd or winbind logs` → Command Execution; `NSM:Flow LDAP Query` → Network Traffic Content
- **Analytic 0365** (macOS) — `macos:unifiedlog Process Execution` → Process Creation; `macos:unifiedlog DS daemon log entries` → Command Execution
