# T1087.004 — Cloud Account

<a id="t1087004"></a>

**Tactics:** discovery  
**Platforms:** IaaS, Identity Provider, Office Suite, SaaS  
**ATT&CK:** [T1087.004](https://attack.mitre.org/techniques/T1087/004)  
**Sub-technique of:** [T1087 — Account Discovery](/mitre/techniques/T1087.md)  

Adversaries may attempt to get a listing of cloud accounts. Cloud accounts are those created and configured by an organization for use by users, remote support, services, or for administration of resources within a cloud service provider or SaaS application.

## Detection

**Detection strategies:**

- Cloud Account Enumeration via API, CLI, and Scripting Interfaces

**Analytics (4):**

- **Analytic 1087** (Identity Provider) — `Microsoft Entra ID Audit Logs RoleManagement.Read.Directory or Directory.Read.All` → User Account Metadata; `azure:signinlogs Interactive/Non-Interactive Sign-In` → User Account Authentication; `m365:defender Activity Log: Command Invocation` → Command Execution
- **Analytic 1088** (IaaS) — `AWS:CloudTrail AWS IAM: ListUsers, ListRoles` → User Account Authentication; `azure:activity Azure CLI Operation: Microsoft.Graph/users/read` → User Account Metadata
- **Analytic 1089** (Office Suite) — `WinEventLog:PowerShell CmdletName: Get-Recipient, Get-User` → Command Execution; `Microsoft Graph API Logs users.list, directoryObjects.getByIds` → User Account Metadata
- **Analytic 1090** (SaaS) — `Google Admin Audit users.list, groups.list` → User Account Metadata; `saas:okta System API Call: user.read, group.read` → Application Log Content
