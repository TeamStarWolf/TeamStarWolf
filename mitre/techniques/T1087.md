# T1087 — Account Discovery

<a id="t1087"></a>

**Tactics:** discovery  
**Platforms:** ESXi, IaaS, Identity Provider, Linux, macOS, Office Suite, SaaS, Windows  
**ATT&CK:** [T1087](https://attack.mitre.org/techniques/T1087)  

Adversaries may attempt to get a listing of valid accounts, usernames, or email addresses on a system or within a compromised environment.

## Mitigations (2)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.

## Detection

**Detection strategies:**

- Enumeration of User or Account Information Across Platforms

**Analytics (8):**

- **Analytic 1612** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1613** (Linux) — `auditd:SYSCALL PATH` → File Access; `linux:Sysmon EventCode=1` → Process Creation
- **Analytic 1614** (macOS) — `macos:unifiedlog process event` → Process Creation
- **Analytic 1615** (IaaS) — `AWS:CloudTrail DescribeUsers / ListUsers / GetUser` → Cloud Service Enumeration
- **Analytic 1616** (Identity Provider) — `azure:signinlogs Graph API Query` → Cloud Service Enumeration; `saas:okta User Enumeration Events` → User Account Metadata
- **Analytic 1617** (ESXi) — `esxi:vpxd vCenter Management` → Command Execution
- **Analytic 1618** (SaaS) — `gcp:audit Directory API Access` → User Account Metadata
- **Analytic 1619** (Office Suite) — `m365:unified Scripted Activity` → Script Execution

## Data sources & telemetry (6)

**Process Creation**, **File Access**, **Cloud Service Enumeration**, **User Account Metadata**, **Command Execution**, **Script Execution**

## Adversary usage

**Threat groups (3):** [Aquatic Panda](https://attack.mitre.org/groups/G0143), [Scattered Spider](https://attack.mitre.org/groups/G1015), [FIN13](https://attack.mitre.org/groups/G1016)

_Notable groups seen using this technique:_

- [Aquatic Panda](https://attack.mitre.org/groups/G0143) — Aquatic Panda is a suspected China-based threat group with a dual mission of intelligence collection and industrial espionage.
- [Scattered Spider](https://attack.mitre.org/groups/G1015) (aka Roasted 0ktapus, Octo Tempest, Storm-0875, UNC3944) — Scattered Spider is a native English-speaking cybercriminal group active since at least 2022.
- [FIN13](https://attack.mitre.org/groups/G1016) (aka Elephant Beetle) — FIN13 is a financially motivated cyber threat group that has targeted the financial, retail, and hospitality industries in Mexico and Latin America, as early as 2016.

**Software/tools (5):** [ShimRatReporter](https://attack.mitre.org/software/S0445), [XCSSET](https://attack.mitre.org/software/S0658), [Woody RAT](https://attack.mitre.org/software/S1065), [Havoc](https://attack.mitre.org/software/S1229), [TONESHELL](https://attack.mitre.org/software/S1239)
