# T1090.001 — Internal Proxy

<a id="t1090001"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, Network Devices, Windows, macOS, ESXi  
**ATT&CK:** [T1090.001](https://attack.mitre.org/techniques/T1090/001)  
**Sub-technique of:** [T1090 — Proxy](/mitre/techniques/T1090.md)  

Adversaries may use an internal proxy to direct command and control traffic between two or more systems in a compromised environment. Many tools exist that enable traffic redirection through proxies or port redirection, including HTRAN, ZXProxy, and ZXPortMap.

## Mitigations (1)

- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.

## Detection

**Detection strategies:**

- Internal Proxy Behavior via Lateral Host-to-Host C2 Relay

**Analytics (5):**

- **Analytic 0204** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `Windows Firewall Log SMB over high port` → Network Traffic Flow
- **Analytic 0205** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Connections Internal connection logging` → Network Traffic Flow; `NSM:Flow conn.log` → Network Traffic Content
- **Analytic 0206** (macOS) — `macos:unifiedlog` → Process Creation; `NSM:Flow pf firewall logs` → Network Traffic Flow; `macos:osquery Process Events and Launch Daemons` → Service Creation
- **Analytic 0207** (ESXi) — `esxi:shell /var/log/shell.log` → Process Creation; `esxi:vmkernel /var/log/vmkernel.log` → Network Traffic Flow; `NSM:Flow conn.log` → Network Connection Creation
- **Analytic 0208** (Network Devices) — `Firewall Audit Logs Config Change` → Firewall Rule Modification; `NSM:Flow Inter-segment traffic` → Network Traffic Flow; `networkdevice:cli Policy Update` → Command Execution

_Notable groups seen using this technique:_

- [Turla](https://attack.mitre.org/groups/G0010) (aka IRON HUNTER, Group 88, Waterbug, WhiteBear) — Turla is a cyber espionage threat group that has been attributed to Russia's Federal Security Service (FSB).
- [Lotus Blossom](https://attack.mitre.org/groups/G0030) (aka DRAGONFISH, Spring Dragon, RADIUM, Raspberry Typhoon) — Lotus Blossom is a long-standing threat group largely targeting various entities in Asia since at least 2009.
- [Lazarus Group](https://attack.mitre.org/groups/G0032) (aka Labyrinth Chollima, HIDDEN COBRA, Guardians of Peace, ZINC) — Lazarus Group is a North Korean state-sponsored cyber threat group attributed to the Reconnaissance General Bureau (RGB).
- [Strider](https://attack.mitre.org/groups/G0041) (aka ProjectSauron) — Strider is a threat group that has been active since at least 2011 and has targeted victims in Russia, China, Sweden, Belgium, Iran, and Rwanda.
- [APT39](https://attack.mitre.org/groups/G0087) (aka ITG07, Chafer, Remix Kitten) — APT39 is one of several names for cyber espionage activity conducted by the Iranian Ministry of Intelligence and Security (MOIS) through the front company Rana Intelligence Computing since at least 2014.
- [Higaisa](https://attack.mitre.org/groups/G0126) — Higaisa is a threat group suspected to have South Korean origins.
