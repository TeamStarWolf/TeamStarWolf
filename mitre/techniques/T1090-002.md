# T1090.002 — External Proxy

<a id="t1090002"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, Network Devices, Windows, macOS  
**ATT&CK:** [T1090.002](https://attack.mitre.org/techniques/T1090/002)  
**Sub-technique of:** [T1090 — Proxy](/mitre/techniques/T1090.md)  

Adversaries may use an external proxy to act as an intermediary for network communications to a command and control server to avoid direct connections to their infrastructure. Many tools exist that enable traffic redirection through proxies or port redirection, including HTRAN, ZXProxy, and ZXPortMap.

## Mitigations (1)

- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.

## Detection

**Detection strategies:**

- External Proxy Behavior via Outbound Relay to Intermediate Infrastructure

**Analytics (5):**

- **Analytic 0922** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Microsoft-Windows-Windows Defender/Operational Unusual external domain access` → Network Traffic Content
- **Analytic 0923** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Flow conn.log or http.log` → Network Traffic Content; `NSM:Flow alert log` → Network Traffic Flow
- **Analytic 0924** (macOS) — `macos:unifiedlog process logs` → Process Creation; `NSM:Flow pf firewall logs` → Network Traffic Flow; `macos:osquery launchd or network_events` → Network Connection Creation
- **Analytic 0925** (ESXi) — `esxi:shell` → Process Creation; `esxi:vmkernel` → Network Traffic Flow; `NSM:Flow conn.log` → Network Connection Creation
- **Analytic 0926** (Network Devices) — `Firewall Audit Logs Outbound NAT Rule Changes` → Firewall Rule Modification; `NSM:Flow Outbound flow records` → Network Traffic Flow; `networkdevice:syslog Dynamic route changes` → Network Connection Creation
