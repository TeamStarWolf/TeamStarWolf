# T1090.003 — Multi-hop Proxy

<a id="t1090003"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1090.003](https://attack.mitre.org/techniques/T1090/003)  
**Sub-technique of:** [T1090 — Proxy](/mitre/techniques/T1090.md)  

Adversaries may chain together multiple proxies to disguise the source of malicious traffic. Typically, a defender will be able to identify the last proxy traffic traversed before it enters their network; the defender may or may not be able to identify any previous proxies before the last-hop proxy.

## Mitigations (1)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Multi-hop Proxy Behavior via Relay Node Chaining, Onion Routing, and Network Tunneling

**Analytics (5):**

- **Analytic 1020** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `dns:query Outbound resolution to hidden service domains (e.g., `.onion`)` → Network Traffic Flow
- **Analytic 1021** (Linux) — `auditd:SYSCALL execve for proxy tools` → Process Creation; `NSM:Flow conn.log + ssl.log with Tor fingerprinting` → Network Traffic Flow; `Netfilter/iptables Forwarded packets log` → Network Traffic Content
- **Analytic 1022** (macOS) — `macos:unifiedlog process, socket, and DNS logs` → Process Creation; `macos:osquery process_events + launchd` → Network Connection Creation; `macos:unifiedlog forwarded encrypted traffic` → Network Traffic Flow
- **Analytic 1023** (ESXi) — `esxi:esxupdate /var/log/esxupdate.log or /var/log/vmksummary.log` → Network Connection Creation; `esxi:vmkernel /var/log/vmkernel.log` → Network Traffic Flow; `NSM:Flow Relay patterns across IP hops` → Network Traffic Content
- **Analytic 1024** (Network Devices) — `NSM:Flow Relayed session pathing (multi-hop)` → Network Traffic Flow; `NSM:Firewall Outbound encrypted traffic` → Network Traffic Content; `networkdevice:syslog Custom firmware or routing changes` → Firmware Modification
