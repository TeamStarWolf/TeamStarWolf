# T1090.004 — Domain Fronting

<a id="t1090004"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1090.004](https://attack.mitre.org/techniques/T1090/004)  
**Sub-technique of:** [T1090 — Proxy](/mitre/techniques/T1090.md)  

Adversaries may take advantage of routing schemes in Content Delivery Networks (CDNs) and other services which host multiple domains to obfuscate the intended destination of HTTPS traffic or traffic tunneled through HTTPS.

## Mitigations (1)

- [M1020 — SSL/TLS Inspection](/mitre/mitigations/M1020.md) — SSL/TLS inspection involves decrypting encrypted network traffic to examine its content for signs of malicious activity.

## Detection

**Detection strategies:**

- Domain Fronting Behavior via Mismatched TLS SNI and HTTP Host Headers

**Analytics (4):**

- **Analytic 0564** (Windows) — `NSM:Connections TLS handshake + HTTP headers` → Network Traffic Content; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0565** (Linux) — `NSM:Flow ssl.log + http.log` → Network Traffic Content; `auditd:SYSCALL execve` → Process Creation
- **Analytic 0566** (macOS) — `macos:unifiedlog network, socket, and http logs` → Network Traffic Content; `macos:osquery process_events` → Process Creation
- **Analytic 0567** (ESXi) — `NSM:Firewall TLS/HTTP inspection` → Network Traffic Content; `esxi:shell /var/log/vmkernel.log, /var/log/vmkwarning.log` → Process Creation
