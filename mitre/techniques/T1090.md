# T1090 — Proxy

<a id="t1090"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1090](https://attack.mitre.org/techniques/T1090)  

Adversaries may use a connection proxy to direct network traffic between systems or act as an intermediary for network communications to a command and control server to avoid direct connections to their infrastructure.

## Mitigations (3)

- [M1020 — SSL/TLS Inspection](/mitre/mitigations/M1020.md) — SSL/TLS inspection involves decrypting encrypted network traffic to examine its content for signs of malicious activity.
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.
- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection
