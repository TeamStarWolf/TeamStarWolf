# T1095 — Non-Application Layer Protocol

<a id="t1095"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1095](https://attack.mitre.org/techniques/T1095)  

Adversaries may use an OSI non-application layer protocol for communication between host and C2 server or among infected hosts within a network. The list of possible protocols is extensive.

## Detection

**Detection strategies:**

- Detection of Non-Application Layer Protocols for C2

**Analytics (5):**

- **Analytic 1254** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `NSM:Flow ICMP/UDP traffic (Wireshark, Suricata, Zeek)` → Network Traffic Content
- **Analytic 1255** (Linux) — `auditd:SYSCALL sendto/connect` → Network Connection Creation; `NSM:Flow icmp.log, weird.log` → Network Traffic Content
- **Analytic 1256** (macOS) — `macos:unifiedlog com.apple.network` → Network Traffic Flow; `NSM:Flow ICMP/UDP monitoring (tcpdump, Wireshark, Zeek)` → Network Traffic Content
- **Analytic 1257** (ESXi) — `esxi:vmkernel VMCI syslog entries` → Network Traffic Content
- **Analytic 1258** (Network Devices) — `NSM:Firewall ICMP/UDP protocol anomaly` → Network Traffic Content; `NSM:Flow conn.log, icmp.log` → Network Traffic Flow
