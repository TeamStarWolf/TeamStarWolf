# T1098.001 — Additional Cloud Credentials

<a id="t1098001"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** IaaS, Identity Provider, SaaS  
**ATT&CK:** [T1098.001](https://attack.mitre.org/techniques/T1098/001)  
**Sub-technique of:** [T1098 — Account Manipulation](/mitre/techniques/T1098.md)  

Adversaries may add adversary-controlled credentials to a cloud account to maintain persistent access to victim accounts and instances within the environment. For example, adversaries may add credentials for Service Principals and Applications in addition to existing legitimate credentials in Azure / Entra ID.

## Mitigations (5)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.

## Detection

**Detection strategies:**

- Detection Strategy for Additional Cloud Credentials in IaaS/IdP/SaaS

**Analytics (3):**

- **Analytic 1469** (Identity Provider) — `azure:audit Add service principal credentials, app password added, app role assignment` → User Account Modification
- **Analytic 1470** (IaaS) — `AWS:CloudTrail CreateAccessKey, ImportKeyPair, CreateLoginProfile, CreateKeyPair` → Active Directory Object Creation; `gcp:audit iam.serviceAccounts.keys.create, os-login.sshPublicKeys.add` → User Account Modification
- **Analytic 1471** (SaaS) — `gcp:audit API Key Created, OAuth Client Registered` → User Account Modification; `m365:unified Set-Mailbox, Set-AppPassword, Add-MailboxPermission` → Active Directory Object Modification
