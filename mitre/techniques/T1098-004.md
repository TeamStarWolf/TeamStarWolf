# T1098.004 — SSH Authorized Keys

<a id="t1098004"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Linux, macOS, IaaS, Network Devices, ESXi  
**ATT&CK:** [T1098.004](https://attack.mitre.org/techniques/T1098/004)  
**Sub-technique of:** [T1098 — Account Manipulation](/mitre/techniques/T1098.md)  

Adversaries may modify the SSH <code>authorized_keys</code> file to maintain persistence on a victim host. Linux distributions, macOS, and ESXi hypervisors commonly use key-based authentication to secure the authentication process of SSH sessions for remote management.

## Mitigations (3)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.

**Analytics (5):**

- **Analytic 0350** (Linux) — `auditd:SYSCALL write | PATH=/home/*/.ssh/authorized_keys` → File Modification; `auditd:SYSCALL execve` → Process Creation
- **Analytic 0351** (macOS) — `macos:unifiedlog process: exec + filewrite: ~/.ssh/authorized_keys` → Process Creation; `macos:auth ~/.ssh/authorized_keys` → File Modification
- **Analytic 0352** (IaaS) — `gcp:audit compute.instances.setMetadata` → File Modification
- **Analytic 0353** (ESXi) — `esxi:shell file write or edit` → File Modification
- **Analytic 0354** (Network Devices) — `networkdevice:cli ip ssh pubkey-chain` → Command Execution
