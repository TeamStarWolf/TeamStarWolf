# T1098.006 — Additional Container Cluster Roles

<a id="t1098006"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Containers  
**ATT&CK:** [T1098.006](https://attack.mitre.org/techniques/T1098/006)  
**Sub-technique of:** [T1098 — Account Manipulation](/mitre/techniques/T1098.md)  

An adversary may add additional roles or permissions to an adversary-controlled user or service account to maintain persistent access to a container orchestration system.

## Mitigations (2)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md)
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md)

## Detection

**Detection strategies:**

- Suspicious RoleBinding or ClusterRoleBinding Assignment in Kubernetes

**Analytics (1):**

- **Analytic 1579** (Containers) — `kubernetes:audit create or update events for RoleBinding or ClusterRoleBinding objects` → User Account Modification
