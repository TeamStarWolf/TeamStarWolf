# T1098: Account Manipulation

<a id="t1098"></a>

Tactics: persistence, privilege-escalation  
Platforms: Containers, ESXi, IaaS, Identity Provider, Linux, macOS, Network Devices, Office Suite, SaaS, Windows  
ATT&CK: [T1098](https://attack.mitre.org/techniques/T1098)  

Adversaries may manipulate accounts to maintain and/or elevate access to victim systems. Account manipulation may consist of any action that preserves or modifies adversary access to a compromised account, such as modifying credentials or permission groups. These actions could also include account activity designed to subvert security policies, such as performing iterative password updates to bypass password duration policies and preserve the life of compromised credentials. In order to create or manipulate accounts, the adversary must already have sufficient permissions on systems or the domain. However, account manipulation may also lead to privilege escalation where modifications grant access to additional roles, permissions, or higher-privileged [Valid Accounts](https://attack.mitre.org/techniques/T1078).

## Mitigations (7)

- [M1018: User Account Management](/mitre/mitigations/M1018.md): User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1022: Restrict File and Directory Permissions](/mitre/mitigations/M1022.md): Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1026: Privileged Account Management](/mitre/mitigations/M1026.md): Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1028: Operating System Configuration](/mitre/mitigations/M1028.md): Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.
- [M1030: Network Segmentation](/mitre/mitigations/M1030.md): Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1032: Multi-factor Authentication](/mitre/mitigations/M1032.md): Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1042: Disable or Remove Feature or Program](/mitre/mitigations/M1042.md): Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.

## D3FEND countermeasures (7)

- [Agent Authentication](/mitre/d3fend/agent-authentication.md) (Harden): strengthens. Agent authentication is the process of verifying the identities of agents to ensure they are authorized and trustworthy participants within a system.
- [Account Locking](/mitre/d3fend/account-locking.md) (Evict): disables. The process of temporarily disabling user accounts on a system or domain.
- [Access Modeling](/mitre/d3fend/access-modeling.md) (Model): maps. Access modeling captures and records the access permissions granted to identities (e.g., administrators, users, groups, systems) and optionally includes details on how these identities are stored, managed, and shared across systems.
- [Change Default Password](/mitre/d3fend/change-default-password.md) (Harden): strengthens. Changing the default password means replacing the factory-set credentials with a strong, unique password before the device is deployed, preventing unauthorized access.
- [Restore User Account Access](/mitre/d3fend/restore-user-account-access.md) (Restore): restores. Restoring a user account's access to resources.
- [User Account Permissions](/mitre/d3fend/user-account-permissions.md) (Isolate): restricts. Restricting a user account's access to resources.
- [Unlock Account](/mitre/d3fend/unlock-account.md) (Restore): restores. Restoring a user account's access to resources by unlocking a locked User Account.

## Detection

Detection strategies:

- Account Manipulation Behavior Chain Detection

Analytics (6):

- Analytic 0265 (Windows): `WinEventLog:Security EventCode=4738, 4728, 4670` -> User Account Modification; `WinEventLog:Sysmon EventCode=1` -> Process Creation
- Analytic 0266 (Linux): `auditd:SYSCALL usermod, groupmod, passwd` -> User Account Modification; `auditd:PATH /etc/passwd or /etc/group file write` -> File Modification
- Analytic 0267 (macOS): `macos:unifiedlog com.apple.accountsd, com.apple.opendirectoryd` -> User Account Modification
- Analytic 0268 (Identity Provider): `saas:okta User Attribute Modified / Role Assignment Changed` -> User Account Modification
- Analytic 0269 (ESXi): `esxi:vpxa vim.SessionManager.login / vim.AccountManager.createUser` -> Active Directory Object Modification
- Analytic 0270 (SaaS): `m365:unified Admin Activity > Role Change or Sharing Change` -> User Account Modification

## Sub-techniques (7)

- [T1098.002: Additional Email Delegate Permissions](/mitre/techniques/T1098-002.md): Adversaries may grant additional permission levels to maintain persistent access to an adversary-controlled email account.
- [T1098.003: Additional Cloud Roles](/mitre/techniques/T1098-003.md): An adversary may add additional roles or permissions to an adversary-controlled cloud account to maintain persistent access to a tenant.
- [T1098.004: SSH Authorized Keys](/mitre/techniques/T1098-004.md): Adversaries may modify the SSH <code>authorized_keys</code> file to maintain persistence on a victim host.
- [T1098.005: Device Registration](/mitre/techniques/T1098-005.md): Adversaries may register a device to an adversary-controlled account.
- [T1098.006: Additional Container Cluster Roles](/mitre/techniques/T1098-006.md): An adversary may add additional roles or permissions to an adversary-controlled user or service account to maintain persistent access to a container orchestration system.
