# T1098 — Account Manipulation

<a id="t1098"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Containers, ESXi, IaaS, Identity Provider, Linux, macOS, Network Devices, Office Suite, SaaS, Windows  
**ATT&CK:** [T1098](https://attack.mitre.org/techniques/T1098)  

Adversaries may manipulate accounts to maintain and/or elevate access to victim systems. Account manipulation may consist of any action that preserves or modifies adversary access to a compromised account, such as modifying credentials or permission groups.

## Detection

**Detection strategies:**

- Account Manipulation Behavior Chain Detection

**Analytics (6):**

- **Analytic 0265** (Windows) — `WinEventLog:Security EventCode=4738, 4728, 4670` → User Account Modification; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0266** (Linux) — `auditd:SYSCALL usermod, groupmod, passwd` → User Account Modification; `auditd:PATH /etc/passwd or /etc/group file write` → File Modification
- **Analytic 0267** (macOS) — `macos:unifiedlog com.apple.accountsd, com.apple.opendirectoryd` → User Account Modification
- **Analytic 0268** (Identity Provider) — `saas:okta User Attribute Modified / Role Assignment Changed` → User Account Modification
- **Analytic 0269** (ESXi) — `esxi:vpxa vim.SessionManager.login / vim.AccountManager.createUser` → Active Directory Object Modification
- **Analytic 0270** (SaaS) — `m365:unified Admin Activity > Role Change or Sharing Change` → User Account Modification
