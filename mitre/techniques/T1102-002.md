# T1102.002 — Bidirectional Communication

<a id="t1102002"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1102.002](https://attack.mitre.org/techniques/T1102/002)  
**Sub-technique of:** [T1102 — Web Service](/mitre/techniques/T1102.md)  

Adversaries may use an existing, legitimate external Web service as a means for sending commands to and receiving output from a compromised system over the Web service channel. Compromised systems may leverage popular websites and social media to host command and control (C2) instructions.

## Mitigations (2)

- [M1021 — Restrict Web-Based Content](/mitre/mitigations/M1021.md) — Restricting web-based content involves enforcing policies and technologies that limit access to potentially malicious websites, unsafe downloads, and unauthorized browser behaviors.
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.

## Detection

**Detection strategies:**

- Detect Bidirectional Web Service C2 Channels via Process & Network Correlation

**Analytics (3):**

- **Analytic 0100** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `etw:Microsoft-Windows-WinINet HTTPS Inspection` → Network Traffic Content
- **Analytic 0101** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Flow conn.log` → Network Traffic Flow; `NSM:Flow ssl.log` → Network Traffic Content
- **Analytic 0102** (macOS) — `macos:unifiedlog log stream --info --predicate 'subsystem == "com.apple.cfprefsd"'` → Process Creation; `NSM:Connections web domain alerts` → Network Connection Creation
