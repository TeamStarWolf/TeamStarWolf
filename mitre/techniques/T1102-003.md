# T1102.003 — One-Way Communication

<a id="t1102003"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1102.003](https://attack.mitre.org/techniques/T1102/003)  
**Sub-technique of:** [T1102 — Web Service](/mitre/techniques/T1102.md)  

Adversaries may use an existing, legitimate external Web service as a means for sending commands to a compromised system without receiving return output over the Web service channel. Compromised systems may leverage popular websites and social media to host command and control (C2) instructions.

## Mitigations (2)

- [M1021 — Restrict Web-Based Content](/mitre/mitigations/M1021.md)
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md)

## Detection

**Detection strategies:**

- Detect One-Way Web Service Command Channels

**Analytics (4):**

- **Analytic 1599** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `etw:Microsoft-Windows-WinINet WinINet API telemetry` → Network Traffic Content
- **Analytic 1600** (Linux) — `auditd:SYSCALL execve` → Process Creation; `iptables:LOG OUTBOUND` → Network Traffic Flow
- **Analytic 1601** (macOS) — `macos:unifiedlog process, network` → Network Traffic Content; `macos:endpointsecurity exec events` → Process Creation
- **Analytic 1602** (ESXi) — `esxi:hostd CLI network calls` → Network Traffic Flow
