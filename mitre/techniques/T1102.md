# T1102 — Web Service

<a id="t1102"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, Windows, macOS  
**ATT&CK:** [T1102](https://attack.mitre.org/techniques/T1102)  

Adversaries may use an existing, legitimate external Web service as a means for relaying data to/from a compromised system.

## Mitigations (2)

- [M1021 — Restrict Web-Based Content](/mitre/mitigations/M1021.md) — Restricting web-based content involves enforcing policies and technologies that limit access to potentially malicious websites, unsafe downloads, and unauthorized browser behaviors.
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.

## Detection

**Detection strategies:**

- Suspicious Use of Web Services for C2

**Analytics (4):**

- **Analytic 1189** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `NSM:Flow SSL/TLS Inspection or PCAP` → Network Traffic Content
- **Analytic 1190** (Linux) — `auditd:SYSCALL connect/sendto` → Network Connection Creation; `NSM:Flow conn.log, ssl.log` → Network Traffic Content
- **Analytic 1191** (macOS) — `macos:unifiedlog process + network activity` → Network Traffic Content; `macos:osquery process_events, socket_events` → Network Connection Creation
- **Analytic 1192** (ESXi) — `esxi:vmkernel network activity` → Network Connection Creation; `vpxd.log API communication` → Network Traffic Flow

## Sub-techniques (3)

- [T1102.001 — Dead Drop Resolver](/mitre/techniques/T1102-001.md) — Adversaries may use an existing, legitimate external Web service to host information that points to additional command and control (C2) infrastructure.
- [T1102.002 — Bidirectional Communication](/mitre/techniques/T1102-002.md) — Adversaries may use an existing, legitimate external Web service as a means for sending commands to and receiving output from a compromised system over the Web service channel.
- [T1102.003 — One-Way Communication](/mitre/techniques/T1102-003.md) — Adversaries may use an existing, legitimate external Web service as a means for sending commands to a compromised system without receiving return output over the Web service channel.
