# T1104 — Multi-Stage Channels

<a id="t1104"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1104](https://attack.mitre.org/techniques/T1104)  

Adversaries may create multiple stages for command and control that are employed under different conditions or for certain functions. Use of multiple stages may obfuscate the command and control channel to make detection more difficult.

## Detection

**Detection strategies:**

- Detect Multi-Stage Command and Control Channels

**Analytics (4):**

- **Analytic 0637** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0638** (Linux) — `auditd:SYSCALL execve, connect` → Process Creation; `iptables:LOG OUTBOUND` → Network Traffic Flow
- **Analytic 0639** (macOS) — `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation; `macos:unifiedlog tcp/udp` → Network Traffic Flow
- **Analytic 0640** (ESXi) — `esxi:hostd CLI network calls` → Network Traffic Flow; `esxi:cron process or cron activity` → Process Creation
