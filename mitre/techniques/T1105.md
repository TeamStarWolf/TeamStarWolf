# T1105 — Ingress Tool Transfer

<a id="t1105"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1105](https://attack.mitre.org/techniques/T1105)  

Adversaries may transfer tools or other files from an external system into a compromised environment. Tools or files may be copied from an external adversary-controlled system to the victim network through the command and control channel or through alternate protocols such as ftp.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **230 machines (43.5%)** — Linux 164 / Windows 52. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Mitigations (2)

- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.
- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Detect Ingress Tool Transfers via Behavioral Chain

**Analytics (5):**

- **Analytic 0165** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0166** (Linux) — `auditd:SYSCALL connect, execve, write` → Command Execution; `auditd:SYSCALL file creation/modification` → File Creation; `iptables:LOG TCP connections` → Network Traffic Flow
- **Analytic 0167** (macOS) — `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC` → Process Creation; `macos:unifiedlog file write/create` → File Creation; `macos:unifiedlog connection open` → Network Connection Creation
- **Analytic 0168** (ESXi) — `esxi:hostd command execution` → Command Execution; `esxi:vmkernel file write` → File Creation
- **Analytic 0169** (Network Devices) — `NSM:Flow connection metadata` → Network Traffic Flow; `snmp:syslog firmware write/log event` → File Creation
