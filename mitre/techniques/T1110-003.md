# T1110.003 — Password Spraying

<a id="t1110003"></a>

**Tactics:** credential-access  
**Platforms:** Containers, ESXi, IaaS, Identity Provider, Linux, Network Devices, Office Suite, SaaS, Windows, macOS  
**ATT&CK:** [T1110.003](https://attack.mitre.org/techniques/T1110/003)  
**Sub-technique of:** [T1110 — Brute Force](/mitre/techniques/T1110.md)  

Adversaries may use a single or small list of commonly used passwords against many different accounts to attempt to acquire valid account credentials. Password spraying uses one password (e.g. 'Password01'), or a small list of commonly used passwords, that may match the complexity policy of the domain.

## Detection

**Detection strategies:**

- Distributed Password Spraying via Authentication Failures Across Multiple Accounts

**Analytics (8):**

- **Analytic 1336** (Windows) — `WinEventLog:Security EventCode=4625, 4771, 4648` → User Account Authentication
- **Analytic 1337** (Linux) — `linux:syslog Failed password for invalid user` → User Account Authentication
- **Analytic 1338** (macOS) — `macos:unifiedlog Login Window and Authd errors` → User Account Authentication
- **Analytic 1339** (Identity Provider) — `azure:signinlogs Failure Reason + UserPrincipalName` → User Account Authentication
- **Analytic 1340** (Network Devices) — `networkdevice:syslog AAA or TACACS authentication failures` → User Account Authentication
- **Analytic 1341** (Containers) — `kubernetes:audit Failed login` → User Account Authentication
- **Analytic 1342** (Office Suite) — `m365:exchange FailedLogin` → User Account Authentication
- **Analytic 1343** (SaaS) — `saas:auth signin_failed` → User Account Authentication
