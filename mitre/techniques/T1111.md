# T1111 — Multi-Factor Authentication Interception

<a id="t1111"></a>

**Tactics:** credential-access  
**Platforms:** Linux, Windows, macOS  
**ATT&CK:** [T1111](https://attack.mitre.org/techniques/T1111)  

Adversaries may target multi-factor authentication (MFA) mechanisms, (i.e., smart cards, token generators, etc.) to gain access to credentials that can be used to access systems, services, and network resources.

## Mitigations (1)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.

## Detection

**Detection strategies:**

- Detection Strategy for MFA Interception via Input Capture and Smart Card Proxying

**Analytics (3):**

- **Analytic 0687** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 0688** (Linux) — `linux:syslog syscalls (open, read, ioctl) on /dev/input or /proc/*/fd/*` → Process Access; `linux:syslog dmesg or syslog for module loads` → Driver Load
- **Analytic 0689** (macOS) — `macos:unifiedlog com.apple.securityd, com.apple.tccd` → OS API Execution; `macos:osquery query: process_events, launchd, and tcc.db access` → Process Creation

## Adversary usage

**Threat groups (4):** [Kimsuky](https://attack.mitre.org/groups/G0094), [Chimera](https://attack.mitre.org/groups/G0114), [LAPSUS$](https://attack.mitre.org/groups/G1004), [APT42](https://attack.mitre.org/groups/G1044)

_Notable groups seen using this technique:_

- [Kimsuky](https://attack.mitre.org/groups/G0094) (aka Black Banshee, Velvet Chollima, Emerald Sleet, THALLIUM) — Kimsuky is a North Korea-based cyber espionage group that has been active since at least 2012.
- [Chimera](https://attack.mitre.org/groups/G0114) — Chimera is a suspected China-based threat group that has been active since at least 2018 targeting the semiconductor industry in Taiwan as well as data from the airline industry.
- [LAPSUS$](https://attack.mitre.org/groups/G1004) (aka DEV-0537, Strawberry Tempest) — LAPSUS$ is cyber criminal threat group that has been active since at least mid-2021.
- [APT42](https://attack.mitre.org/groups/G1044) — APT42 is an Iranian-sponsored threat group that conducts cyber espionage and surveillance.

**Software/tools (2):** [Sykipot](https://attack.mitre.org/software/S0018), [SLOWPULSE](https://attack.mitre.org/software/S1104)
