# T1113: Screen Capture

<a id="t1113"></a>

Tactics: collection  
Platforms: Linux, Windows, macOS  
ATT&CK: [T1113](https://attack.mitre.org/techniques/T1113)  

Adversaries may attempt to take screen captures of the desktop to gather information over the course of an operation. Screen capturing functionality may be included as a feature of a remote access tool used in post-compromise operations. Taking a screenshot is also typically possible through native utilities or API calls, such as <code>CopyFromScreen</code>, <code>xwd</code>, or <code>screencapture</code>.

## D3FEND countermeasures (2)

- [System Call Analysis](/mitre/d3fend/system-call-analysis.md) (Detect): analyzes. Analyzing system calls to determine whether a process is exhibiting unauthorized behavior.
- [System Call Filtering](/mitre/d3fend/system-call-filtering.md) (Isolate): filters. Controlling access to local computer system resources with kernel-level capabilities.

## Detection

Detection strategies:

- Detect Screen Capture via Commands and API Calls

Analytics (3):

- Analytic 0980 (Windows): `WinEventLog:Sysmon EventCode=1` -> Process Creation; `WinEventLog:Sysmon EventCode=7` -> Module Load
- Analytic 0981 (macOS): `macos:unifiedlog process: exec` -> Process Creation
- Analytic 0982 (Linux): `auditd:SYSCALL execve` -> Process Creation
