# T1114.002 — Remote Email Collection

<a id="t1114002"></a>

**Tactics:** collection  
**Platforms:** Windows, Office Suite  
**ATT&CK:** [T1114.002](https://attack.mitre.org/techniques/T1114/002)  
**Sub-technique of:** [T1114 — Email Collection](/mitre/techniques/T1114.md)  

Adversaries may target an Exchange server, Office 365, or Google Workspace to collect sensitive information. Adversaries may leverage a user's credentials and interact directly with the Exchange server to acquire information from within a network. Adversaries may also access externally facing Exchange services, Office 365, or Google Workspace to access email using credentials or access tokens. Tools such as [MailSniper](https://attack.mitre.org/software/S0413) can be used to automate searches for specific keywords.

## Mitigations (3)

- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1041 — Encrypt Sensitive Information](/mitre/mitigations/M1041.md) — Protect sensitive information at rest, in transit, and during processing by using strong encryption algorithms.
- [M1060 — Out-of-Band Communications Channel](/mitre/mitigations/M1060.md) — Establish secure out-of-band communication channels to ensure the continuity of critical communications during security incidents, data integrity attacks, or in-network communication failures.

## Detection

**Detection strategies:**

- Detect Remote Email Collection via Abnormal Login and Programmatic Access

**Analytics (2):**

- **Analytic 0131** (Windows) — `azure:signinlogs Abnormal sign-in from scripting tools (PowerShell, AADInternals)` → Logon Session Creation; `m365:purview MailItemsAccessed & Exchange Audit` → Application Log Content; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0132** (Office Suite) — `m365:purview MailItemsAccessed, Search-Mailbox events` → Application Log Content; `azure:signinlogs Suspicious login to cloud mailbox system` → Logon Session Creation; `m365:unified Search-Mailbox, Get-MessageTrace, eDiscovery requests` → Command Execution
