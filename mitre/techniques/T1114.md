# T1114 — Email Collection

<a id="t1114"></a>

**Tactics:** collection  
**Platforms:** Windows, macOS, Linux, Office Suite  
**ATT&CK:** [T1114](https://attack.mitre.org/techniques/T1114)  

Adversaries may target user email to collect sensitive information. Emails may contain sensitive data, including trade secrets or personal information, that can prove valuable to adversaries.

## Detection

**Detection strategies:**

- Email Collection via Local Email Access and Auto-Forwarding Behavior

**Analytics (4):**

- **Analytic 1309** (Windows) — `WinEventLog:Security EventCode=5145` → Network Share Access; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `WinEventLog:Application Exchange logs or header artifacts` → Application Log Content; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1310** (Linux) — `auditd:SYSCALL open` → File Access; `linux:syslog postfix/smtpd` → Network Connection Creation; `linux:osquery process_events` → Process Creation
- **Analytic 1311** (macOS) — `macos:unifiedlog Mail or AppleScript subsystem` → Application Log Content; `macos:endpointsecurity es_event_open, es_event_exec` → File Access
- **Analytic 1312** (Office Suite) — `m365:unified Set-Mailbox, New-InboxRule` → Command Execution; `m365:exchange MessageTrace logs` → Application Log Content; `azure:ad SignInEvents` → Logon Session Creation
