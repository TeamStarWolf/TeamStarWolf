# T1114 — Email Collection

<a id="t1114"></a>

**Tactics:** collection  
**Platforms:** Windows, macOS, Linux, Office Suite  
**ATT&CK:** [T1114](https://attack.mitre.org/techniques/T1114)  

Adversaries may target user email to collect sensitive information. Emails may contain sensitive data, including trade secrets or personal information, that can prove valuable to adversaries.

## Mitigations (4)

- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1041 — Encrypt Sensitive Information](/mitre/mitigations/M1041.md) — Protect sensitive information at rest, in transit, and during processing by using strong encryption algorithms.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.
- [M1060 — Out-of-Band Communications Channel](/mitre/mitigations/M1060.md) — Establish secure out-of-band communication channels to ensure the continuity of critical communications during security incidents, data integrity attacks, or in-network communication failures.

## Detection

**Detection strategies:**

- Email Collection via Local Email Access and Auto-Forwarding Behavior

**Analytics (4):**

- **Analytic 1309** (Windows) — `WinEventLog:Security EventCode=5145` → Network Share Access; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `WinEventLog:Application Exchange logs or header artifacts` → Application Log Content; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1310** (Linux) — `auditd:SYSCALL open` → File Access; `linux:syslog postfix/smtpd` → Network Connection Creation; `linux:osquery process_events` → Process Creation
- **Analytic 1311** (macOS) — `macos:unifiedlog Mail or AppleScript subsystem` → Application Log Content; `macos:endpointsecurity es_event_open, es_event_exec` → File Access
- **Analytic 1312** (Office Suite) — `m365:unified Set-Mailbox, New-InboxRule` → Command Execution; `m365:exchange MessageTrace logs` → Application Log Content; `azure:ad SignInEvents` → Logon Session Creation

## Adversary usage

**Threat groups (4):** [Magic Hound](https://attack.mitre.org/groups/G0059), [Silent Librarian](https://attack.mitre.org/groups/G0122), [Ember Bear](https://attack.mitre.org/groups/G1003), [Scattered Spider](https://attack.mitre.org/groups/G1015)

_Notable groups seen using this technique:_

- [Magic Hound](https://attack.mitre.org/groups/G0059) (aka TA453, COBALT ILLUSION, Charming Kitten, ITG18) — Magic Hound is an Iranian-sponsored threat group that conducts long term, resource-intensive cyber espionage operations, likely on behalf of the Islamic Revolutionary Guard Corps.
- [Silent Librarian](https://attack.mitre.org/groups/G0122) (aka TA407, COBALT DICKENS) — Silent Librarian is a group that has targeted research and proprietary data at universities, government agencies, and private sector companies worldwide since at least 2013.
- [Ember Bear](https://attack.mitre.org/groups/G1003) (aka UNC2589, Bleeding Bear, DEV-0586, Cadet Blizzard) — Ember Bear is a Russian state-sponsored cyber espionage group that has been active since at least 2020, linked to Russia's General Staff Main Intelligence Directorate (GRU) 161st Specialist Training Center (Unit 29155).
- [Scattered Spider](https://attack.mitre.org/groups/G1015) (aka Roasted 0ktapus, Octo Tempest, Storm-0875, UNC3944) — Scattered Spider is a native English-speaking cybercriminal group active since at least 2022.
