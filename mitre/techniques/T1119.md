# T1119: Automated Collection

<a id="t1119"></a>

Tactics: collection  
Platforms: IaaS, Linux, macOS, Office Suite, SaaS, Windows  
ATT&CK: [T1119](https://attack.mitre.org/techniques/T1119)  

Once established within a system or network, an adversary may use automated techniques for collecting internal data. Methods for performing this technique could include use of a [Command and Scripting Interpreter](https://attack.mitre.org/techniques/T1059) to search for and copy information fitting set criteria such as file type, location, or name at specific time intervals. In cloud-based environments, adversaries may also use cloud APIs, data pipelines, command line interfaces, or extract, transform, and load (ETL) services to automatically collect data. This functionality could also be built into remote access tools. This technique may incorporate use of other techniques such as [File and Directory Discovery](https://attack.mitre.org/techniques/T1083) and [Lateral Tool Transfer](https://attack.mitre.org/techniques/T1570) to identify and move files, as well as [Cloud Service Dashboard](https://attack.mitre.org/techniques/T1538) and [Cloud Storage Object Discovery](https://attack.mitre.org/techniques/T1619) to identify resources in cloud environments.

## Mitigations (2)

- [M1029: Remote Data Storage](/mitre/mitigations/M1029.md): Remote Data Storage focuses on moving critical data, such as security logs and sensitive files, to secure, off-host locations to minimize unauthorized access, tampering, or destruction by adversaries.
- [M1041: Encrypt Sensitive Information](/mitre/mitigations/M1041.md): Protect sensitive information at rest, in transit, and during processing by using strong encryption algorithms.

## D3FEND countermeasures (11)

- [Content Filtering](/mitre/d3fend/content-filtering.md) (Isolate): filters. Content Filtering techniques aid in the process of analyzing an input file for malicious or erroneous content and outputting a sanitized version.
- [Content Modification](/mitre/d3fend/content-modification.md) (Isolate): modifies. Modify content that does not comply with policy.
- [Content Quarantine](/mitre/d3fend/content-quarantine.md) (Isolate): quarantines. Transfer content that does not comply with policy to a quarantine zone.
- [Decoy File](/mitre/d3fend/decoy-file.md) (Deceive): spoofs. A file created for the purposes of deceiving an adversary.
- [File Analysis](/mitre/d3fend/file-analysis.md) (Detect): analyzes. File Analysis is an analytic process to determine a file's status.
- [File Encryption](/mitre/d3fend/file-encryption.md) (Harden): encrypts. Encrypting a file using a cryptographic key.
- [File Eviction](/mitre/d3fend/file-eviction.md) (Evict): deletes. File eviction techniques delete files from system storage.
- [File Integrity Monitoring](/mitre/d3fend/file-integrity-monitoring.md) (Detect): analyzes. Detecting any suspicious changes to files in a computer system.

- [Remote File Access Mediation](/mitre/d3fend/remote-file-access-mediation.md) (Isolate): isolates. Remote file access mediation is the process of managing and securing access to file systems over a network to ensure that only authorized users or processes can interact with remote files.

## Detection

Detection strategies:

- Automated File and API Collection Detection Across Platforms

Analytics (4):

- Analytic 0531 (Windows): `WinEventLog:Sysmon EventCode=1` -> Process Creation; `WinEventLog:Sysmon EventCode=11` -> File Creation
- Analytic 0532 (Linux): `auditd:SYSCALL execve` -> Process Creation; `auditd:SYSCALL open` -> File Access
- Analytic 0533 (macOS): `macos:unifiedlog logMessage contains pbpaste or osascript` -> Process Creation; `macos:unifiedlog subsystem=launchservices` -> Script Execution
- Analytic 0534 (SaaS): `azure:signinlogs Operation=UserLogin` -> User Account Authentication
