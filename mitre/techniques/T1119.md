<a id="t1119"></a>

**Tactics:** collection

## Detection

**Detection strategies:**

- Automated File and API Collection Detection Across Platforms

**Analytics (4):**

- **Analytic 0531** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 0532** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL open` → File Access
- **Analytic 0533** (macOS) — `macos:unifiedlog logMessage contains pbpaste or osascript` → Process Creation; `macos:unifiedlog subsystem=launchservices` → Script Execution
- **Analytic 0534** (SaaS) — `azure:signinlogs Operation=UserLogin` → User Account Authentication
