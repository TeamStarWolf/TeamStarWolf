# T1123 — Audio Capture

<a id="t1123"></a>

**Tactics:** collection  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1123](https://attack.mitre.org/techniques/T1123)  

An adversary can leverage a computer's peripheral devices (e.g., microphones and webcams) or applications (e.g., voice and video call services) to capture audio recordings for the purpose of listening into sensitive conversations to gather information.

## D3FEND countermeasures (4)

- [Hardware Component Inventory](/mitre/d3fend/hardware-component-inventory.md) (Model) — inventories. Hardware component inventorying identifies and records the hardware items in the organization's architecture.
- [IO Port Restriction](/mitre/d3fend/io-port-restriction.md) (Isolate) — filters. Limiting access to computer input/output (IO) ports to restrict unauthorized devices.
- [Input Device Analysis](/mitre/d3fend/input-device-analysis.md) (Detect) — analyzes. Operating system level mechanisms to prevent abusive input device exploitation.
- [Radiation Hardening](/mitre/d3fend/radiation-hardening.md) (Harden) — hardens. Radiation hardening is the process of making electronic components and circuits resistant to damage or malfunction caused by high levels of ionizing radiation.

## Detection

**Detection strategies:**

- Behavioral Detection Strategy for T1123 Audio Capture Across Windows, Linux, macOS

**Analytics (3):**

- **Analytic 0619** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=4688` → Process Creation
- **Analytic 0620** (Linux) — `auditd:SYSCALL open` → File Access; `linux:Sysmon EventCode=1` → Process Creation; `auditd:SYSCALL write` → File Creation
- **Analytic 0621** (macOS) — `macos:unifiedlog audio APIs` → OS API Execution; `Apple TCC Logs Microphone Access Events` → Process Access; `fs:fsusage File IO` → File Creation
