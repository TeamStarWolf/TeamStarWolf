# T1125 — Video Capture

<a id="t1125"></a>

**Tactics:** collection  
**Platforms:** Windows, macOS, Linux  
**ATT&CK:** [T1125](https://attack.mitre.org/techniques/T1125)  

An adversary can leverage a computer's peripheral devices (e.g., integrated cameras or webcams) or applications (e.g., video call services) to capture video recordings for the purpose of gathering information.

## Detection

**Detection strategies:**

- Behavior-chain, platform-aware detection strategy for T1125 Video Capture

**Analytics (3):**

- **Analytic 0568** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=4663, 4670, 4656` → OS API Execution; `WinEventLog:Microsoft-Windows-Windows Camera Frame Server/Operational Process session start/stop events for camera pipeline by unexpected executables` → Process Metadata
- **Analytic 0569** (Linux) — `auditd:SYSCALL openat/read/ioctl: openat/read/ioctl on /dev/video* by uncommon user/process` → OS API Execution; `auditd:SYSCALL PATH records referencing /dev/video*` → File Access; `linux:osquery select: path LIKE '/dev/video%'` → Process Metadata; `linux:syslog sudo execution of ffmpeg/gst-launch/v4l2-ctl by non-standard user` → Command Execution; `NSM:Flow http/file-xfer: Outbound transfer of large video-like MIME types soon after capture` → Network Traffic Content
- **Analytic 0570** (macOS) — `macos:unifiedlog Access decisions to kTCCServiceCamera for unexpected binaries` → OS API Execution; `macos:endpointsecurity open: Process opens AppleCamera/IOUSB device nodes or AVFoundation frameworks` → File Access; `macos:endpointsecurity exec: Exec of ffmpeg, avfoundation-based binaries, or custom signed apps accessing camera` → Process Creation; `macos:unifiedlog Process wrote large .mov/.mp4 in user temp/hidden dirs` → File Creation

## Adversary usage

_Notable groups seen using this technique:_

- [FIN7](https://attack.mitre.org/groups/G0046) (aka GOLD NIAGARA, ITG14, Carbon Spider, ELBRUS) — FIN7 is a financially-motivated threat group that has been active since 2013.
- [Silence](https://attack.mitre.org/groups/G0091) (aka Whisper Spider) — Silence is a financially motivated threat actor targeting financial institutions in different countries.
- [Ember Bear](https://attack.mitre.org/groups/G1003) (aka UNC2589, Bleeding Bear, DEV-0586, Cadet Blizzard) — Ember Bear is a Russian state-sponsored cyber espionage group that has been active since at least 2020, linked to Russia's General Staff Main Intelligence Directorate (GRU) 161st Specialist Training Center (Unit 29155).
