# T1129 — Shared Modules

<a id="t1129"></a>

**Tactics:** execution  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1129](https://attack.mitre.org/techniques/T1129)  

Adversaries may execute malicious payloads via loading shared modules. Shared modules are executable files that are loaded into processes to provide access to reusable code, such as specific custom functions or invoking OS API functions (i.e., Native API).

## Mitigations (1)

- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.

## Detection

**Detection strategies:**

- Behavior-chain, platform-aware detection strategy for T1129 Shared Modules

**Analytics (3):**

- **Analytic 0052** (Windows) — `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Microsoft-Windows-CodeIntegrity/Operational CodeIntegrity/WDAC events indicating unsigned/invalid DLL loads` → Process Metadata
- **Analytic 0053** (Linux) — `auditd:SYSCALL openat/read/mmap: Open/mmap .so files from non-standard paths` → Module Load; `auditd:EXECVE execve: Processes launched with LD_PRELOAD/LD_LIBRARY_PATH pointing to non-system dirs` → Process Creation; `linux:syslog sudo or service accounts invoking loaders with suspicious env vars` → Process Metadata; `NSM:Flow http/file-xfer: Inbound/outbound transfer of ELF shared objects` → Network Traffic Content
- **Analytic 0054** (macOS) — `macos:unifiedlog dyld/unified log entries indicating image load from non-system paths` → Module Load; `macos:endpointsecurity exec: Process execution context for loaders calling dlopen/dlsym` → Process Creation; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_OPEN: Open of .dylib/.so in user-writable locations` → File Access
