# T1132.002 — Non-Standard Encoding

<a id="t1132002"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1132.002](https://attack.mitre.org/techniques/T1132/002)  
**Sub-technique of:** [T1132 — Data Encoding](/mitre/techniques/T1132.md)  

Adversaries may encode data with a non-standard data encoding system to make the content of command and control traffic more difficult to detect. Command and control (C2) information can be encoded using a non-standard data encoding system that diverges from existing protocol specifications.

## Mitigations (1)

- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md)

## Detection

**Detection strategies:**

- Behavior-chain detection for T1132.002 Data Encoding: Non-Standard Encoding across Windows, Linux, macOS, ESXi

**Analytics (4):**

- **Analytic 0927** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Script Execution; `m365:defender NetworkConnection: high out:in ratio, periodic beacons, protocol mismatch` → Network Traffic Flow
- **Analytic 0928** (Linux) — `auditd:SYSCALL execve of interpreters (python, perl), custom binaries, or shell utilities with long arguments containing non-standard tokens` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `NSM:Flow http: HTTP bodies/headers contain long tokens with non-standard alphabets or constant-size periodic POSTs` → Network Traffic Content
- **Analytic 0929** (macOS) — `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_EXEC: arguments contain long, non-standard tokens / custom alphabets` → Process Creation; `PF:Logs high out:in ratio or fixed-size periodic flows` → Network Traffic Flow; `NSM:Flow http: suspicious long tokens with custom alphabets in body/headers` → Network Traffic Content
- **Analytic 0930** (ESXi) — `esxi:shell commands containing long non-standard tokens or custom lookup tables` → Process Creation; `esxi:hostd unexpected script invocations producing long encoded strings` → Application Log Content; `NSM:Flow network_flow: bytes_out >> bytes_in, fixed packet sizes/intervals to non-approved CIDRs` → Network Traffic Flow; `NSM:Flow http: HTTP bodies from ESXi host IPs containing long, non-standard tokens` → Network Traffic Content
