# T1133 — External Remote Services

<a id="t1133"></a>

**Tactics:** persistence, initial-access  
**Platforms:** Containers, Linux, macOS, Windows  
**ATT&CK:** [T1133](https://attack.mitre.org/techniques/T1133)  

Adversaries may leverage external-facing remote services to initially access and/or persist within a network. Remote services such as VPNs, Citrix, and other access mechanisms allow users to connect to internal enterprise network resources from external locations.

## Mitigations (5)

- [M1021 — Restrict Web-Based Content](/mitre/mitigations/M1021.md) — Restricting web-based content involves enforcing policies and technologies that limit access to potentially malicious websites, unsafe downloads, and unauthorized browser behaviors.
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1035 — Limit Access to Resource Over Network](/mitre/mitigations/M1035.md) — Restrict access to network resources, such as file shares, remote systems, and services, to only those users, accounts, or systems with a legitimate business requirement.
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.

## Detection

**Detection strategies:**

- Behavior-chain detection for T1133 External Remote Services across Windows, Linux, macOS, Containers

**Analytics (4):**

- **Analytic 1004** (Windows) — `WinEventLog:Security EventCode=4776, 4625` → User Account Authentication; `WinEventLog:Application VPN, Citrix, or remote access gateway logs showing external IP addresses` → Application Log Content; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1005** (Linux) — `auditd:SYSCALL ssh logins or execve of remote commands` → Logon Session Metadata; `NSM:Connections Failed password or accepted password for SSH users` → Application Log Content; `NSM:Flow connection: Inbound connections to SSH or VPN ports` → Network Connection Creation
- **Analytic 1006** (macOS) — `macos:unifiedlog Remote login (ssh) or screen sharing authentication attempts` → Logon Session Metadata; `macos:unifiedlog Inbound connections to VNC/SSH ports` → Network Connection Creation; `PF:Logs External traffic to remote access services` → Network Traffic Flow
- **Analytic 1007** (Containers) — `ApplicationLog:API Docker/Kubernetes API access from external sources` → Application Log Content; `kubernetes:audit Unauthorized container creation or kubelet exec logs` → Logon Session Metadata; `NSM:Flow External access to container ports (2375, 6443)` → Network Connection Creation
