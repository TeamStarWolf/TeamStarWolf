# T1134.001 — Token Impersonation/Theft

<a id="t1134001"></a>

**Tactics:** defense-evasion, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1134.001](https://attack.mitre.org/techniques/T1134/001)  
**Sub-technique of:** [T1134 — Access Token Manipulation](/mitre/techniques/T1134.md)  

Adversaries may duplicate then impersonate another user's existing token to escalate privileges and bypass access controls. For example, an adversary can duplicate an existing token using `DuplicateToken` or `DuplicateTokenEx`.

## Mitigations (2)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
