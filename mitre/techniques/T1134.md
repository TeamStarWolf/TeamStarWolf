# T1134 — Access Token Manipulation

<a id="t1134"></a>

**Tactics:** defense-evasion, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1134](https://attack.mitre.org/techniques/T1134)  

Adversaries may modify access tokens to operate under a different user or system security context to perform actions and bypass access controls. Windows uses access tokens to determine the ownership of a running process.

## Mitigations (2)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).

## Detection

- Behavior-chain detection for T1134 Access Token Manipulation on Windows

**Analytics (1):**

- **Analytic 0786** (Windows) — `WinEventLog:Security EventCode=4672, 4634` → Logon Session Metadata; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=10` → Process Access; `ETW:Token token_analysis: API calls such as DuplicateTokenEx or ImpersonateLoggedOnUser` → OS API Execution; `WinEventLog:Security EventCode=5136` → Active Directory Object Modification

## Sub-techniques (5)

- [T1134.001 — Token Impersonation/Theft](/mitre/techniques/T1134-001.md) — Adversaries may duplicate then impersonate another user's existing token to escalate privileges and bypass access controls.
- [T1134.002 — Create Process with Token](/mitre/techniques/T1134-002.md) — Adversaries may create a new process with an existing token to escalate privileges and bypass access controls.
- [T1134.003 — Make and Impersonate Token](/mitre/techniques/T1134-003.md) — Adversaries may make new tokens and impersonate users to escalate privileges and bypass access controls.
- [T1134.004 — Parent PID Spoofing](/mitre/techniques/T1134-004.md) — Adversaries may spoof the parent process identifier (PPID) of a new process to evade process-monitoring defenses or to elevate privileges.
- [T1134.005 — SID-History Injection](/mitre/techniques/T1134-005.md) — Adversaries may use SID-History Injection to escalate privileges and bypass access controls.
