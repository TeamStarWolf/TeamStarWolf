# T1136.001 — Local Account

<a id="t1136001"></a>

**Tactics:** persistence  
**Platforms:** Linux, macOS, Windows, Network Devices, Containers, ESXi  
**ATT&CK:** [T1136.001](https://attack.mitre.org/techniques/T1136/001)  
**Sub-technique of:** [T1136 — Create Account](/mitre/techniques/T1136.md)  

Adversaries may create a local account to maintain access to victim systems. Local accounts are those configured by an organization for use by users, remote support, services, or for administration on a single system or service.

## Mitigations (2)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.

## Detection

**Detection strategies:**

- T1136.001 Detection Strategy - Local Account Creation Across Platforms

**Analytics (6):**

- **Analytic 1235** (Windows) — `WinEventLog:Security EventCode=4720` → User Account Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1236** (Linux) — `auditd:SYSCALL useradd or adduser executed` → User Account Creation; `auditd:SYSCALL write operation on /etc/passwd or /etc/shadow` → File Modification
- **Analytic 1237** (macOS) — `macos:unifiedlog dscl -create` → Command Execution; `macos:unifiedlog modification to /var/db/dslocal/nodes/Default/users/` → File Modification
- **Analytic 1238** (ESXi) — `esxi:vmkernel esxcli system account add` → Command Execution
- **Analytic 1239** (Containers) — `ebpf:syscalls useradd or /etc/passwd modified inside container` → Command Execution
- **Analytic 1240** (Network Devices) — `networkdevice:syslog username <user> privilege <level>` → User Account Creation

_Notable groups seen using this technique:_

- [APT3](https://attack.mitre.org/groups/G0022) (aka Gothic Panda, Pirpi, UPS Team, Buckeye) — APT3 is a China-based threat group that researchers have attributed to China's Ministry of State Security.
- [Dragonfly](https://attack.mitre.org/groups/G0035) (aka TEMP.Isotope, DYMALLOY, Berserk Bear, TG-4192) — Dragonfly is a cyber espionage group that has been attributed to Russia's Federal Security Service (FSB) Center 16.
- [Magic Hound](https://attack.mitre.org/groups/G0059) (aka TA453, COBALT ILLUSION, Charming Kitten, ITG18) — Magic Hound is an Iranian-sponsored threat group that conducts long term, resource-intensive cyber espionage operations, likely on behalf of the Islamic Revolutionary Guard Corps.
- [Leafminer](https://attack.mitre.org/groups/G0077) (aka Raspite) — Leafminer is an Iranian threat group that has targeted government organizations and business entities in the Middle East since at least early 2017.
- [APT39](https://attack.mitre.org/groups/G0087) (aka ITG07, Chafer, Remix Kitten) — APT39 is one of several names for cyber espionage activity conducted by the Iranian Ministry of Intelligence and Security (MOIS) through the front company Rana Intelligence Computing since at least 2014.
- [Kimsuky](https://attack.mitre.org/groups/G0094) (aka Black Banshee, Velvet Chollima, Emerald Sleet, THALLIUM) — Kimsuky is a North Korea-based cyber espionage group that has been active since at least 2012.
