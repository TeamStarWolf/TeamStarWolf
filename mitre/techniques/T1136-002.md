# T1136.002 — Domain Account

<a id="t1136002"></a>

**Tactics:** persistence  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1136.002](https://attack.mitre.org/techniques/T1136/002)  
**Sub-technique of:** [T1136 — Create Account](/mitre/techniques/T1136.md)  

Adversaries may create a domain account to maintain access to victim systems. Domain accounts are those managed by Active Directory Domain Services where access and permissions are configured across systems and services that are part of that domain. Domain accounts can cover user, administrator, and service accounts.

## Mitigations (4)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.

## Detection

**Detection strategies:**

- T1136.002 Detection Strategy - Domain Account Creation Across Platforms

**Analytics (3):**

- **Analytic 0006** (Windows) — `WinEventLog:Security EventCode=4720` → User Account Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0007** (Linux) — `auditd:SYSCALL execution of realmd, samba-tool, or ldapmodify with user-related arguments` → Command Execution; `NSM:Flow TGS-REQ and AS-REQ seen for new user shortly after domain-modifying process` → User Account Authentication
- **Analytic 0008** (macOS) — `macos:unifiedlog dsconfigad or dscl with create or append options for AD-bound users` → Command Execution; `macos:unifiedlog UserLoggedIn` → Logon Session Creation
