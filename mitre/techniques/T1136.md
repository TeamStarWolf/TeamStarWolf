# T1136 — Create Account

<a id="t1136"></a>

**Tactics:** persistence  
**Platforms:** Windows, IaaS, Linux, macOS, Network Devices, Containers, SaaS, Office Suite, Identity Provider, ESXi  
**ATT&CK:** [T1136](https://attack.mitre.org/techniques/T1136)  

Adversaries may create an account to maintain access to victim systems. With a sufficient level of access, creating such accounts may be used to establish secondary credentialed access that do not require persistent remote access tools to be deployed on the system. Accounts may be created on the local system or within a domain or cloud tenant. In cloud environments, adversaries may create accounts that only have access to specific services, which can reduce the chance of detection.

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.

## Detection

**Detection strategies:**

- Detection Strategy for T1136 - Create Account across platforms

**Analytics (5):**

- **Analytic 1604** (Windows) — `WinEventLog:Security EventCode=4720` → User Account Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1605** (Linux) — `auditd:SYSCALL useradd or adduser executed` → User Account Creation; `auditd:SYSCALL chmod/chown to /etc/passwd or /etc/shadow` → File Modification
- **Analytic 1606** (macOS) — `macos:unifiedlog dscl . -create` → Command Execution; `macos:unifiedlog modification to /var/db/dslocal/nodes/Default/users/` → File Modification
- **Analytic 1607** (Identity Provider) — `azure:audit Add user` → User Account Creation
- **Analytic 1608** (IaaS) — `AWS:CloudTrail CreateUser` → User Account Creation; `AWS:CloudTrail AttachUserPolicy` → User Account Modification
