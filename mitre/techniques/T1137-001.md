# T1137.001 — Office Template Macros

<a id="t1137001"></a>

**Tactics:** persistence  
**Platforms:** Windows, Office Suite  
**ATT&CK:** [T1137.001](https://attack.mitre.org/techniques/T1137/001)  
**Sub-technique of:** [T1137 — Office Application Startup](/mitre/techniques/T1137.md)  

Adversaries may abuse Microsoft Office templates to obtain persistence on a compromised system. Microsoft Office contains templates that are part of common Office applications and are used to customize styles. The base templates within the application are used each time an application starts.

## Detection

**Detection strategies:**

- Detect Persistence via Office Template Macro Injection or Registry Hijack

**Analytics (2):**

- **Analytic 1436** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=15` → File Metadata; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `WinEventLog:Microsoft-Office-Alerts Office application warning or alert on macro execution from template` → Command Execution
- **Analytic 1437** (Office Suite) — `m365:unified Set-Mailbox, Set-MailboxPolicy, Set-TrustedLocation` → Command Execution
