# T1137.003 — Outlook Forms

<a id="t1137003"></a>

**Tactics:** persistence  
**Platforms:** Windows, Office Suite  
**ATT&CK:** [T1137.003](https://attack.mitre.org/techniques/T1137/003)  
**Sub-technique of:** [T1137 — Office Application Startup](/mitre/techniques/T1137.md)  

Adversaries may abuse Microsoft Outlook forms to obtain persistence on a compromised system. Outlook forms are used as templates for presentation and functionality in Outlook messages.

## Detection

**Detection strategies:**

- Detect Persistence via Outlook Custom Forms Triggered by Malicious Email

**Analytics (2):**

- **Analytic 0085** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Application Outlook errors loading or processing custom form templates` → Application Log Content; `WinEventLog:PowerShell Execution of Microsoft script to enumerate custom forms in Outlook mailbox` → Command Execution
- **Analytic 0086** (Office Suite) — `m365:unified Unusual form activity within Outlook client, including load of non-default forms` → Application Log Content; `m365:messagetrace Inbound email triggers execution of mailbox-stored custom form` → Command Execution
