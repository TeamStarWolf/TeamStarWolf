# T1137.004 — Outlook Home Page

<a id="t1137004"></a>

**Tactics:** persistence  
**Platforms:** Windows, Office Suite  
**ATT&CK:** [T1137.004](https://attack.mitre.org/techniques/T1137/004)  
**Sub-technique of:** [T1137 — Office Application Startup](/mitre/techniques/T1137.md)  

Adversaries may abuse Microsoft Outlook's Home Page feature to obtain persistence on a compromised system. Outlook Home Page is a legacy feature used to customize the presentation of Outlook folders. This feature allows for an internal or external URL to be loaded and presented whenever a folder is opened. A malicious HTML page can be crafted that will execute code when loaded by Outlook Home Page. Once malicious home pages have been added to the user’s mailbox, they will be loaded when Outlook is started. Malicious Home Pages will execute when the right Outlook folder is loaded/reloaded.

## Detection

**Detection strategies:**

- Detect Persistence via Outlook Home Page Exploitation

**Analytics (2):**

- **Analytic 0502** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Application Outlook logs indicating failure to load or render HTML page in Home Page view` → Application Log Content; `WinEventLog:PowerShell Execution of PowerShell script to enumerate or remove malicious Home Page folder config` → Command Execution
- **Analytic 0503** (Office Suite) — `m365:unified Folder configuration updated with external or HTML-formatted Home Page via Set-MailboxFolder` → Application Log Content; `m365:messagetrace Inbound email triggering Outlook to auto-access folder tied to malicious Home Page` → Command Execution
