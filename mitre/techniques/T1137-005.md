# T1137.005 — Outlook Rules

<a id="t1137005"></a>

**Tactics:** persistence  
**Platforms:** Windows, Office Suite  
**ATT&CK:** [T1137.005](https://attack.mitre.org/techniques/T1137/005)  
**Sub-technique of:** [T1137 — Office Application Startup](/mitre/techniques/T1137.md)  

Adversaries may abuse Microsoft Outlook rules to obtain persistence on a compromised system. Outlook rules allow a user to define automated behavior to manage email messages.

## Detection

**Detection strategies:**

- Detect Persistence via Malicious Outlook Rules

**Analytics (2):**

- **Analytic 0263** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Application Outlook rule execution failure or abnormal rule execution context` → Application Log Content; `WinEventLog:PowerShell PowerShell launched from outlook.exe or triggered without user invocation` → Command Execution
- **Analytic 0264** (Office Suite) — `m365:unified Creation or modification of inbox rule outside of normal user behavior` → Application Log Content; `m365:messagetrace Inbound email matches crafted rule trigger pattern tied to persistence logic` → Command Execution
