# T1137.006 — Add-ins

<a id="t1137006"></a>

**Tactics:** persistence  
**Platforms:** Windows, Office Suite  
**ATT&CK:** [T1137.006](https://attack.mitre.org/techniques/T1137/006)  
**Sub-technique of:** [T1137 — Office Application Startup](/mitre/techniques/T1137.md)  

Adversaries may abuse Microsoft Office add-ins to obtain persistence on a compromised system. Office add-ins can be used to add functionality to Office programs.

## Mitigations (1)

## Detection

**Detection strategies:**

- Detect Persistence via Malicious Office Add-ins

**Analytics (2):**

- **Analytic 0137** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=2` → File Modification; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 0138** (Office Suite) — `WinEventLog:Application Office Add-in load errors, abnormal loading context, or unsigned add-in warnings` → Application Log Content; `WinEventLog:Microsoft-Office/OutlookAddinMonitor Outlook loading add-in via unexpected load path or non-default profile context` → Command Execution
