# T1176.001 — Browser Extensions

<a id="t1176001"></a>

**Tactics:** persistence  
**Platforms:** Linux, Windows, macOS  
**ATT&CK:** [T1176.001](https://attack.mitre.org/techniques/T1176/001)  
**Sub-technique of:** [T1176 — Software Extensions](/mitre/techniques/T1176.md)  

Adversaries may abuse internet browser extensions to establish persistent access to victim systems. Browser extensions or plugins are small programs that can add functionality to and customize aspects of internet browsers.

## Detection

**Detection strategies:**

- Detecting Malicious Browser Extensions Across Platforms

**Analytics (3):**

- **Analytic 0123** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 0124** (macOS) — `macos:unifiedlog profiles install -type=configuration` → Command Execution; `macos:unifiedlog Creation or modification of browser extension .plist files` → File Creation; `macos:unifiedlog Unexpected child process of Safari or Chrome` → Process Creation
- **Analytic 0125** (Linux) — `auditd:SYSCALL open` → File Access; `NSM:Flow Browser connections to known C2 or dynamic DNS domains` → Network Traffic Content; `auditd:SYSCALL execve` → Process Creation
