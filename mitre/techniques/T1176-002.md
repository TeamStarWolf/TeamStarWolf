# T1176.002 — IDE Extensions

<a id="t1176002"></a>

**Tactics:** persistence  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1176.002](https://attack.mitre.org/techniques/T1176/002)  
**Sub-technique of:** [T1176 — Software Extensions](/mitre/techniques/T1176.md)  

Adversaries may abuse an integrated development environment (IDE) extension to establish persistent access to victim systems.

## Detection

**Detection strategies:**

- Detect malicious IDE extension install/usage and IDE tunneling

**Analytics (3):**

- **Analytic 1548** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 1549** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL open,creat,rename,write` → File Creation; `NSM:Flow Connections from IDE hosts to marketplace/tunnel domains` → Network Traffic Flow
- **Analytic 1550** (macOS) — `macos:unifiedlog Execution of Code.app, idea, JetBrainsToolbox, eclipse with install/extension flags` → Process Creation; `macos:unifiedlog Writes under ~/Library/Application Support/Code*/extensions or JetBrains plugins` → File Creation; `macos:unifiedlog Outbound connections from IDE processes to marketplace/tunnel domains` → Network Traffic Flow

## Data sources & telemetry (4)

**Process Creation**, **Network Connection Creation**, **File Creation**, **Network Traffic Flow**
