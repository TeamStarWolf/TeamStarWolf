# T1176 — Software Extensions

<a id="t1176"></a>

**Tactics:** persistence  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1176](https://attack.mitre.org/techniques/T1176)  

Adversaries may abuse software extensions to establish persistent access to victim systems. Software extensions are modular components that enhance or customize the functionality of software applications, including web browsers, Integrated Development Environments (IDEs), and other platforms.

## Mitigations (5)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1033 — Limit Software Installation](/mitre/mitigations/M1033.md) — Prevent users or groups from installing unauthorized or unapproved software to reduce the risk of introducing malicious or vulnerable applications.
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.
- [M1051 — Update Software](/mitre/mitigations/M1051.md) — Software updates ensure systems are protected against known vulnerabilities by applying patches and upgrades provided by vendors.

## Detection

**Detection strategies:**

- Detection of Malicious or Unauthorized Software Extensions

**Analytics (3):**

- **Analytic 0251** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0252** (macOS) — `macos:unifiedlog Execution of 'profiles install -type=configuration'` → Command Execution; `macos:unifiedlog Creation of .plist under /Library/Managed Preferences/` → File Creation; `macos:unifiedlog Suspicious outbound traffic from browser binary to non-standard domains` → Network Traffic Flow
- **Analytic 0253** (Linux) — `auditd:SYSCALL execve` → Process Creation; `fs:fileevents creat` → File Creation; `NSM:Flow Abnormal browser traffic volume or destination` → Network Traffic Flow
