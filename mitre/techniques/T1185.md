# T1185 — Browser Session Hijacking

<a id="t1185"></a>

**Tactics:** collection  
**Platforms:** Windows  
**ATT&CK:** [T1185](https://attack.mitre.org/techniques/T1185)  

Adversaries may take advantage of security vulnerabilities and inherent functionality in browser software to change content, modify user-behaviors, and intercept information as part of various browser session hijacking techniques.

## Mitigations (2)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.

## Detection

**Detection strategies:**

- Detect browser session hijacking via privilege, handle access, and remote thread into browsers

**Analytics (1):**

- **Analytic 1398** (Windows) — `WinEventLog:Security EventCode=4672` → Logon Session Metadata; `WinEventLog:Security EventCode=4673` → User Account Metadata; `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=8` → Process Modification; `WinEventLog:Sysmon EventCode=7` → Module Load (+1 more)
