# T1187 — Forced Authentication

<a id="t1187"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1187](https://attack.mitre.org/techniques/T1187)  

Adversaries may gather credential material by invoking or forcing a user to automatically provide authentication information through a mechanism in which they can intercept.

## Detection

**Detection strategies:**

- Detect Forced SMB/WebDAV Authentication via lure files and outbound NTLM

**Analytics (1):**

- **Analytic 0065** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Modification; `NSM:Flow HTTP/WebDAV requests that contain NTLMSSP or PROPFIND/MOVE/OPTIONS with Authorization: NTLM` → Network Traffic Content; `NSM:Flow Outbound connections to TCP 139,445 and HTTP/HTTPS to WebDAV endpoints from workstation subnets` → Network Traffic Flow
