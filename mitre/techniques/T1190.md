# T1190 — Exploit Public-Facing Application

<a id="t1190"></a>

**Tactics:** initial-access  
**Platforms:** Containers, ESXi, IaaS, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1190](https://attack.mitre.org/techniques/T1190)  

Adversaries may attempt to exploit a weakness in an Internet-facing host or system to initially access a network. The weakness in the system can be a software bug, a temporary glitch, or a misconfiguration.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **232 machines (43.9%)** — Linux 168 / Windows 48. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Mitigations (8)

- [M1016 — Vulnerability Scanning](/mitre/mitigations/M1016.md) — Vulnerability scanning involves the automated or manual assessment of systems, applications, and networks to identify misconfigurations, unpatched software, or other security weaknesses.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1035 — Limit Access to Resource Over Network](/mitre/mitigations/M1035.md) — Restrict access to network resources, such as file shares, remote systems, and services, to only those users, accounts, or systems with a legitimate business requirement.
- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.
- [M1048 — Application Isolation and Sandboxing](/mitre/mitigations/M1048.md) — Application Isolation and Sandboxing refers to the technique of restricting the execution of code to a controlled and isolated environment (e.g., a virtual environment, container, or sandbox).
- [M1050 — Exploit Protection](/mitre/mitigations/M1050.md) — Deploy capabilities that detect, block, and mitigate conditions indicative of software exploits.
- [M1051 — Update Software](/mitre/mitigations/M1051.md) — Software updates ensure systems are protected against known vulnerabilities by applying patches and upgrades provided by vendors.

## Detection

**Detection strategies:**

- Exploit Public-Facing Application – multi-signal correlation (request → error → post-exploit process/egress)

**Analytics (7):**

- **Analytic 0219** (Windows) — `ApplicationLog:IIS IIS W3C logs in C:\inetpub\logs\LogFiles\W3SVC* (spikes in 5xx, RCE/SQLi/path traversal/JNDI patterns)` → Application Log Content; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0220** (Linux) — `ApplicationLog:WebServer /var/log/httpd/access_log, /var/log/apache2/access.log, /var/log/nginx/access.log with exploit indicators and burst errors` → Application Log Content; `auditd:SYSCALL execve` → Process Creation; `NSM:Flow HTTP payloads with SQLi/LFI/JNDI/deserialization indicators` → Network Traffic Content
- **Analytic 0221** (macOS) — `macos:unifiedlog App/web server logs ingested via unified logging or filebeat (nginx/apache/node).` → Application Log Content; `macos:unifiedlog exec events where web process starts a shell/tooling` → Process Creation; `NSM:Flow outbound egress from web host after suspicious request` → Network Traffic Content
- **Analytic 0222** (Containers) — `ApplicationLog:Ingress Kubernetes NGINX/Envoy ingress controller logs with anomalous payloads and 5xx spikes` → Application Log Content; `docker:events Docker/Kubernetes audit of exec/attach (kubectl exec) or unexpected child processes inside container` → Process Creation; `NSM:Flow Requests towards cloud metadata or command & control from pod IPs` → Network Traffic Content
- **Analytic 0223** (IaaS) — `ALB:HTTPLogs AWS ALB/ELB/GCP/Azure Application Gateway HTTP logs with unusual methods, long URIs, serialized payloads, 4xx/5xx bursts` → Network Traffic Content; `AWS:VPCFlowLogs VPC/NSG flow logs for pod/instance egress to Internet or metadata` → Network Traffic Flow
- **Analytic 0224** (ESXi) — `esxi:hostd /var/log/hostd.log anomalies (faults, crashes, restarts) around inbound connections` → Application Log Content; `NSM:Flow Connections to TCP 427 (SLP) or vCenter web services from untrusted sources` → Network Traffic Content
- **Analytic 0225** (Network Devices) — `networkdevice:controlplane Syslog from edge devices with HTTP 500s on mgmt portal, SmartInstall events, unexpected CLI commands` → Application Log Content; `NSM:Flow NetFlow/sFlow for odd egress to Internet from mgmt plane` → Network Traffic Content
