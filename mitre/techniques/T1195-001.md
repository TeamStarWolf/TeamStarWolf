# T1195.001 — Compromise Software Dependencies and Development Tools

<a id="t1195001"></a>

**Tactics:** initial-access  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1195.001](https://attack.mitre.org/techniques/T1195/001)  
**Sub-technique of:** [T1195 — Supply Chain Compromise](/mitre/techniques/T1195.md)  

Adversaries may manipulate software dependencies and development tools prior to receipt by a final consumer for the purpose of data or system compromise. Applications often depend on external software to function properly.

## Detection

**Detection strategies:**

- Supply-chain tamper in dependencies/dev-tools (manager→write/install→first-run→egress)

**Analytics (3):**

- **Analytic 0021** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `WinEventLog:Microsoft-Windows-CodeIntegrity/Operational Invalid/Unsigned image when developer tool launches newly installed binaries` → File Metadata; `NSM:Flow First-time outbound connections to package registries or unknown hosts immediately after restore/build` → Network Traffic Flow
- **Analytic 0022** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL rename, chmod` → Process Modification; `journald:package dpkg/apt or yum/dnf transaction logs (install/update of build tools)` → File Metadata; `NSM:Flow First-time egress to new registries/CDNs post-install/build` → Network Traffic Flow
- **Analytic 0023** (macOS) — `macos:unifiedlog softwareupdated/homebrew/install logs, pkginstalld events` → File Metadata; `macos:endpointsecurity exec` → Process Creation; `NSM:Flow First-time egress to non-approved registries after dependency install` → Network Traffic Flow
