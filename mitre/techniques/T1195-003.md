# T1195.003: Compromise Hardware Supply Chain

<a id="t1195003"></a>

Tactics: initial-access  
Platforms: Linux, macOS, Windows  
ATT&CK: [T1195.003](https://attack.mitre.org/techniques/T1195/003)  
Sub-technique of: [T1195: Supply Chain Compromise](/mitre/techniques/T1195.md)  

Adversaries may manipulate hardware components in products prior to receipt by a final consumer for the purpose of data or system compromise. By modifying hardware or firmware in the supply chain, adversaries can insert a backdoor into consumer networks that may be difficult to detect and give the adversary a high degree of control over the system. Hardware backdoors may be inserted into various devices, such as servers, workstations, network infrastructure, or peripherals.

## Mitigations (1)

- [M1046: Boot Integrity](/mitre/mitigations/M1046.md): Boot Integrity ensures that a system starts securely by verifying the integrity of its boot process, operating system, and associated components.

## D3FEND countermeasures (2)

- [Hardware Component Inventory](/mitre/d3fend/hardware-component-inventory.md) (Model): inventories. Hardware component inventorying identifies and records the hardware items in the organization's architecture.
- [Radiation Hardening](/mitre/d3fend/radiation-hardening.md) (Harden): hardens. Radiation hardening is the process of making electronic components and circuits resistant to damage or malfunction caused by high levels of ionizing radiation.

## Detection

Detection strategies:

- Hardware Supply Chain Compromise Detection via Host Status & Boot Integrity Checks

Analytics (3):

- Analytic 1035 (Windows): `WinEventLog:Security EventCode=1166, 7045` -> Host Status; `WinEventLog:Microsoft-Windows-CodeIntegrity/Operational Code integrity violations in boot-start drivers or firmware` -> File Metadata; `WinEventLog:Sysmon EventCode=6` -> Driver Load; `WinEventLog:Sysmon EventCode=7` -> Module Load; `WinEventLog:Sysmon EventCode=10` -> Process Access
- Analytic 1036 (Linux): `auditd:SYSCALL firmware_update, kexec_load` -> Host Status; `fwupd:logs Firmware updates applied or failed` -> File Metadata
- Analytic 1037 (macOS): `macos:unifiedlog EFI firmware integrity check failed` -> Host Status; `macos:endpointsecurity es_event_authentication` -> File Metadata

Host Status, File Metadata, Driver Load, Module Load, Process Access
