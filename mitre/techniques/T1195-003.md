# T1195.003 — Compromise Hardware Supply Chain

<a id="t1195003"></a>

**Tactics:** initial-access  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1195.003](https://attack.mitre.org/techniques/T1195/003)  
**Sub-technique of:** [T1195 — Supply Chain Compromise](/mitre/techniques/T1195.md)  

Adversaries may manipulate hardware components in products prior to receipt by a final consumer for the purpose of data or system compromise.

## Mitigations (1)

- [M1046 — Boot Integrity](/mitre/mitigations/M1046.md)

## Detection

**Detection strategies:**

- Hardware Supply Chain Compromise Detection via Host Status & Boot Integrity Checks

**Analytics (3):**

- **Analytic 1035** (Windows) — `WinEventLog:Security EventCode=1166, 7045` → Host Status; `WinEventLog:Microsoft-Windows-CodeIntegrity/Operational Code integrity violations in boot-start drivers or firmware` → File Metadata; `WinEventLog:Sysmon EventCode=6` → Driver Load; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=10` → Process Access
- **Analytic 1036** (Linux) — `auditd:SYSCALL firmware_update, kexec_load` → Host Status; `fwupd:logs Firmware updates applied or failed` → File Metadata
- **Analytic 1037** (macOS) — `macos:unifiedlog EFI firmware integrity check failed` → Host Status; `macos:endpointsecurity es_event_authentication` → File Metadata
