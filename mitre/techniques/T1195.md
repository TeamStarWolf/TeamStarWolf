# T1195 — Supply Chain Compromise

<a id="t1195"></a>

**Tactics:** initial-access  
**Platforms:** Linux, Windows, macOS, SaaS  
**ATT&CK:** [T1195](https://attack.mitre.org/techniques/T1195)  

Adversaries may manipulate products or product delivery mechanisms prior to receipt by a final consumer for the purpose of data or system compromise.

## Detection

**Detection strategies:**

- Behavioral detection for Supply Chain Compromise (package/update tamper → install → first-run)

**Analytics (3):**

- **Analytic 1480** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Microsoft-Windows-CodeIntegrity/Operational CodeIntegrity reports 'Invalid image hash' or 'Unsigned image' for new/updated binaries` → File Metadata; `NSM:Flow First-time egress from host after new install to unknown update endpoints` → Network Traffic Flow
- **Analytic 1481** (Linux) — `auditd:SYSCALL execve, unlink` → Process Creation; `auditd:SYSCALL open, rename` → Process Modification; `journald:package dpkg/apt install, remove, upgrade events` → File Metadata; `NSM:Flow First-time egress to unknown registries/mirrors immediately after install` → Network Traffic Flow
- **Analytic 1482** (macOS) — `macos:unifiedlog installer or system_installd 'PackageKit: install succeeded/failed' with non-notarized or unknown signer` → File Metadata; `macos:osquery launchd, processes` → Process Creation; `macos:endpointsecurity write, rename` → File Modification; `NSM:Flow New egress from app just installed to unknown update endpoints` → Network Traffic Flow
