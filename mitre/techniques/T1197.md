# T1197 — BITS Jobs

<a id="t1197"></a>

**Tactics:** defense-evasion, persistence  
**Platforms:** Windows  
**ATT&CK:** [T1197](https://attack.mitre.org/techniques/T1197)  

Adversaries may abuse BITS jobs to persistently execute code and perform various background tasks. Windows Background Intelligent Transfer Service (BITS) is a low-bandwidth, asynchronous file transfer mechanism exposed through Component Object Model (COM).

## Detection

**Detection strategies:**

- Detect abuse of Windows BITS Jobs for download, execution and persistence

**Analytics (1):**

- **Analytic 0274** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `WinEventLog:System EventCode=7036` → Service Creation

## Adversary usage

**Threat groups (5):** [Patchwork](https://attack.mitre.org/groups/G0040), [Leviathan](https://attack.mitre.org/groups/G0065), [APT39](https://attack.mitre.org/groups/G0087), [APT41](https://attack.mitre.org/groups/G0096), [Wizard Spider](https://attack.mitre.org/groups/G0102)

_Notable groups seen using this technique:_

- [Patchwork](https://attack.mitre.org/groups/G0040) (aka Hangover Group, Dropping Elephant, Chinastrats, MONSOON) — Patchwork is a cyber espionage group that was first observed in December 2015.
- [Leviathan](https://attack.mitre.org/groups/G0065) (aka MUDCARP, Kryptonite Panda, Gadolinium, BRONZE MOHAWK) — Leviathan is a Chinese state-sponsored cyber espionage group that has been attributed to the Ministry of State Security's (MSS) Hainan State Security Department and an affiliated front company.
- [APT39](https://attack.mitre.org/groups/G0087) (aka ITG07, Chafer, Remix Kitten) — APT39 is one of several names for cyber espionage activity conducted by the Iranian Ministry of Intelligence and Security (MOIS) through the front company Rana Intelligence Computing since at least 2014.
- [APT41](https://attack.mitre.org/groups/G0096) (aka Wicked Panda, Brass Typhoon, BARIUM) — APT41 is a threat group that researchers have assessed as Chinese state-sponsored espionage group that also conducts financially-motivated operations.
- [Wizard Spider](https://attack.mitre.org/groups/G0102) (aka UNC1878, TEMP.MixMaster, Grim Spider, FIN12) — Wizard Spider is a Russia-based financially motivated threat group originally known for the creation and deployment of TrickBot since at least 2016.
