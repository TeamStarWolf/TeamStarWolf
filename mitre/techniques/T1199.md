# T1199 — Trusted Relationship

<a id="t1199"></a>

**Tactics:** initial-access  
**Platforms:** Windows, SaaS, IaaS, Linux, macOS, Identity Provider, Office Suite  
**ATT&CK:** [T1199](https://attack.mitre.org/techniques/T1199)  

Adversaries may breach or otherwise leverage organizations who have access to intended victims. Access through trusted third party relationship abuses an existing connection that may not be protected or receives less scrutiny than standard mechanisms of gaining access to a network.

## Mitigations (3)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.

## D3FEND countermeasures (11)

- [Application Protocol Command Analysis](/mitre/d3fend/application-protocol-command-analysis.md) (Detect) — monitors. Analyzing application protocol level remote commands to detect unauthorized activity.

- [Connection Attempt Analysis](/mitre/d3fend/connection-attempt-analysis.md) (Detect) — analyzes. Analyzing failed connections in a network to detect unauthorized activity.
- [Network Traffic Community Deviation](/mitre/d3fend/network-traffic-community-deviation.md) (Detect) — analyzes. Establishing baseline communities of network hosts and identifying statistically divergent inter-community communication.
- [Network Traffic Filtering](/mitre/d3fend/network-traffic-filtering.md) (Isolate) — filters. Restricting network traffic originating from any location.
- [Network Traffic Signature Analysis](/mitre/d3fend/network-traffic-signature-analysis.md) (Detect) — analyzes. Analyzing network traffic and compares it to known signatures
- [Per Host Download-Upload Ratio Analysis](/mitre/d3fend/per-host-download-upload-ratio-analysis.md) (Detect) — analyzes. Detecting anomalies that indicate malicious activity by comparing the amount of data downloaded versus data uploaded by a host.
- [Protocol Metadata Anomaly Detection](/mitre/d3fend/protocol-metadata-anomaly-detection.md) (Detect) — analyzes. Collecting network communication protocol metadata and identifying statistical outliers.
- [Remote Terminal Session Detection](/mitre/d3fend/remote-terminal-session-detection.md) (Detect) — analyzes. Detection of an unauthorized remote live terminal console session by examining network traffic to a network host.
- [Session Termination](/mitre/d3fend/session-termination.md) (Evict) — deletes. Forcefully end all active sessions associated with compromised accounts or devices.
- [User Geolocation Logon Pattern Analysis](/mitre/d3fend/user-geolocation-logon-pattern-analysis.md) (Detect) — analyzes. Monitoring geolocation data of user logon attempts and comparing it to a baseline user behavior profile to identify anomalies in logon location.

## Detection

**Detection strategies:**

- Detect abuse of Trusted Relationships (third-party and delegated admin access)

**Analytics (7):**

- **Analytic 1344** (Windows) — `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:Security EventCode=4776, 4771, 4770` → Logon Session Metadata; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Security EventCode=4663, 4670, 4656` → Application Log Content
- **Analytic 1345** (Linux) — `auditd:SYSCALL execve,socket,connect,openat` → Logon Session Metadata; `linux:syslog Accepted publickey/password for * from * port * ssh2` → Logon Session Creation; `NSM:Flow ssh connections originating from third-party CIDRs` → Network Traffic Content
- **Analytic 1346** (macOS) — `macos:unifiedlog loginwindow or sshd successful login events` → Logon Session Creation; `macos:unifiedlog Group membership change for admin or wheel` → Logon Session Metadata; `NSM:Flow ssh/smb connections to internal resources from third-party devices` → Network Traffic Content
- **Analytic 1347** (Identity Provider) — `azure:signinlogs InteractiveUser, ServicePrincipalSignIn` → Logon Session Creation; `azure:audit Add delegated admin / Assign admin roles / Update application consent` → Logon Session Metadata; `m365:unified Set-PartnerOfRecord / CompanyAdministrator role assignments / New-DelegatedAdminRelationship` → Application Log Content
- **Analytic 1348** (IaaS) — `AWS:CloudTrail AssumeRole,AssumeRoleWithSAML,AssumeRoleWithWebIdentity` → Logon Session Creation; `AWS:CloudTrail CreateUser|AttachRolePolicy|CreateAccessKey|UpdateAssumeRolePolicy|CreateLoginProfile` → Application Log Content; `gcp:audit google.iam.credentials.generateAccessToken / serviceAccountTokenCreator` → Logon Session Metadata
- **Analytic 1349** (SaaS) — `saas:googleworkspace OAuth2 authorization grants / Admin role assignments` → Application Log Content; `saas:salesforce ConnectedApp OAuth policy change / Login as user` → Logon Session Metadata
- **Analytic 1350** (Office Suite) — `m365:unified Add-DelegatedAdmin, Set-PartnerOfRecord, Add-MailboxPermission, Set-OrganizationRelationship` → Application Log Content; `azure:signinlogs InteractiveUser, NonInteractiveUser` → Logon Session Creation
