## Detection

**Detection strategies:**

- Detect unauthorized or suspicious Hardware Additions (USB/Thunderbolt/Network)

**Analytics (3):**

- **Analytic 0185** (Windows) — `WinEventLog:Security EventCode=6416` → Application Log Content; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=6` → Driver Load; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation (+2 more)
- **Analytic 0186** (Linux) — `auditd:SYSCALL mknod,open,openat` → Drive Creation; `linux:syslog usb * new|thunderbolt|pci .* added|block.*: new .* device` → Application Log Content; `NSM:Flow LEASE_GRANTED` → Network Traffic Flow
- **Analytic 0187** (macOS) — `macos:unifiedlog Device attached|enumerated VID/PID` → Application Log Content; `macos:unifiedlog mounted|appeared|DA: disk* attached` → Drive Creation; `NSM:Flow MAC not in allow-list acquiring IP (DHCP)` → Network Traffic Flow
