# T1204.004 — Malicious Copy and Paste

<a id="t1204004"></a>

**Tactics:** execution  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1204.004](https://attack.mitre.org/techniques/T1204/004)  
**Sub-technique of:** [T1204](/mitre/techniques/T1204.md)

An adversary may rely upon a user copying and pasting code in order to gain execution. Users may be subjected to social engineering to get them to copy and paste code directly into a Command and Scripting Interpreter.



## Mitigations (3)

- [M1021 — Restrict Web-Based Content](/mitre/mitigations/M1021.md)
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md)
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md)


## Detection

- User Execution – Malicious Copy & Paste (browser/email → shell with obfuscated one-liner) – T1204.004
