# T1204.005 — Malicious Library

<a id="t1204005"></a>

**Tactics:** execution  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1204.005](https://attack.mitre.org/techniques/T1204/005)  
**Sub-technique of:** [T1204 — User Execution](/mitre/techniques/T1204.md)  

Adversaries may rely on a user installing a malicious library to facilitate execution. Threat actors may [Upload Malware](https://attack.mitre.org/techniques/T1608/001) to package managers such as NPM and PyPi, as well as to public code repositories such as GitHub. User may install libraries without realizing they are malicious, thus bypassing techniques that specifically achieve Initial Access. This can lead to the execution of malicious code, such as code that establishes persistence, steals data, or mines cryptocurrency. In some cases, threat actors may compromise and backdoor existing popular libraries (i.e., [Compromise Software Dependencies and Development Tools](https://attack.mitre.org/techniques/T1195/001)). Alternatively, they may create entirely new packages and leverage behaviors such as typosquatting to encourage users to install them.

## Mitigations (3)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.
- [M1033 — Limit Software Installation](/mitre/mitigations/M1033.md) — Prevent users or groups from installing unauthorized or unapproved software to reduce the risk of introducing malicious or vulnerable applications.

## Detection

**Detection strategies:**

- User-Initiated Malicious Library Installation via Package Manager (T1204.005)

**Analytics (3):**

- **Analytic 0698** (Linux) — `auditd:SYSCALL execve: Execution of pip, npm, gem, or similar package managers` → Process Creation; `auditd:PATH New .py/.js/.sh files written to ~/.local/, ~/.cache/, or /tmp/ within 5 min of package install` → File Creation; `NSM:Flow http::request: Network connection to package registry or C2 from interpreter shortly after install` → Network Traffic Content
- **Analytic 0699** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 0700** (macOS) — `macos:unifiedlog Command line invocation of pip3, brew install, npm install from interactive Terminal` → Process Creation; `macos:unifiedlog Creation of new LaunchAgent or LoginItem plist files in ~/Library/LaunchAgents/` → File Metadata; `NSM:Flow Outbound HTTP/S initiated by newly installed interpreter process` → Network Connection Creation
