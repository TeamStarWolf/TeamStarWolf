# T1204 — User Execution

<a id="t1204"></a>

**Tactics:** execution  
**Platforms:** Linux, Windows, macOS, IaaS, Containers  
**ATT&CK:** [T1204](https://attack.mitre.org/techniques/T1204)  

An adversary may rely upon specific actions by a user in order to gain execution. Users may be subjected to social engineering to get them to execute malicious code by, for example, opening a malicious document file or link. These user actions will typically be observed as follow-on behavior from forms of Phishing.

## Mitigations (6)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1021 — Restrict Web-Based Content](/mitre/mitigations/M1021.md) — Restricting web-based content involves enforcing policies and technologies that limit access to potentially malicious websites, unsafe downloads, and unauthorized browser behaviors.
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.
- [M1033 — Limit Software Installation](/mitre/mitigations/M1033.md) — Prevent users or groups from installing unauthorized or unapproved software to reduce the risk of introducing malicious or vulnerable applications.
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.
- [M1040 — Behavior Prevention on Endpoint](/mitre/mitigations/M1040.md) — Behavior Prevention on Endpoint refers to the use of technologies and strategies to detect and block potentially malicious activities by analyzing the behavior of processes, files, API calls, and other endpoint events.

## Detection

**Detection strategies:**

- User Execution – multi-surface behavior chain (documents/links → helper/unpacker → LOLBIN/child → egress)

**Analytics (5):**

- **Analytic 1314** (Windows) — `WinEventLog:Application EventCode=1000` → Application Log Content; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1315** (Linux) — `linux:syslog opened document|clicked link|segfault|abnormal termination|sandbox` → Application Log Content; `auditd:SYSCALL open` → File Access; `auditd:SYSCALL creat` → File Creation; `auditd:SYSCALL rename,chmod` → File Modification; `auditd:SYSCALL execve` → Process Creation; `NSM:Flow new outbound connection from browser/office lineage` → Network Connection Creation
- **Analytic 1316** (macOS) — `macos:unifiedlog opened document|clicked link|EXC_BAD_ACCESS|abort|LSQuarantine` → Application Log Content; `fs:fileevents create/write/rename in user-writable paths` → File Creation; `macos:osquery exec` → Process Creation; `NSM:Flow new outbound connection from exploited lineage` → Network Connection Creation
- **Analytic 1317** (Containers) — `docker:events created,started: new container from untrusted registry or unexpected entrypoint` → Container Creation; `docker:events start` → Container Start; `NSM:Flow container egress to unknown IPs/domains` → Network Traffic Content
- **Analytic 1318** (IaaS) — `AWS:CloudTrail RunInstances,CreateImage` → Instance Creation; `AWS:CloudTrail StartInstances` → Instance Start; `gcp:vpcflow first 5m egress to unknown ASNs` → Network Traffic Content

## Adversary usage

**Threat groups (2):** [LAPSUS$](https://attack.mitre.org/groups/G1004), [Scattered Spider](https://attack.mitre.org/groups/G1015)

_Notable groups seen using this technique:_

- [LAPSUS$](https://attack.mitre.org/groups/G1004) (aka DEV-0537, Strawberry Tempest) — LAPSUS$ is cyber criminal threat group that has been active since at least mid-2021.
- [Scattered Spider](https://attack.mitre.org/groups/G1015) (aka Roasted 0ktapus, Octo Tempest, Storm-0875, UNC3944) — Scattered Spider is a native English-speaking cybercriminal group active since at least 2022.
