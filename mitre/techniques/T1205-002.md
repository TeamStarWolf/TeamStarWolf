# T1205.002 — Socket Filters

<a id="t1205002"></a>

**Tactics:** defense-evasion, persistence, command-and-control  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1205.002](https://attack.mitre.org/techniques/T1205/002)  
**Sub-technique of:** [T1205 — Traffic Signaling](/mitre/techniques/T1205.md)  

Adversaries may attach filters to a network socket to monitor then activate backdoors used for persistence or command and control.

## Mitigations (1)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Socket-filter trigger → on-host raw-socket activity → reverse connection (T1205.002)

**Analytics (3):**

- **Analytic 0462** (Windows) — `WinEventLog:System EventCode=7045` → Service Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=6` → Driver Load; `WinEventLog:Sysmon EventCode=7` → Module Load; `NSM:Flow Single, low-volume inbound packet (REJ/S0/OTH or uncommon dport/protocol) from src_ip followed by outbound SF connection to src_ip.` → Network Traffic Content
- **Analytic 0463** (Linux) — `auditd:SYSCALL socket(AF_PACKET|AF_INET, SOCK_RAW, *), setsockopt(… SO_ATTACH_FILTER|SO_ATTACH_BPF …), bpf(cmd=BPF_PROG_LOAD), open/openat path="/dev/bpf*" (BSD/macOS-like) or setcap cap_net_raw.` → Process Creation; `linux:osquery family=AF_PACKET or protocol raw; process name not in allowlist.` → Network Connection Creation; `NSM:Flow Rare inbound packet characteristics (ICMP/UDP/TCP to uncommon port) from src_ip followed ≤TimeWindow by outbound SF from same host to src_ip.` → Network Traffic Content
- **Analytic 0464** (macOS) — `OpenBSM:AuditTrail open/openat of /dev/bpf*; ioctl BIOCSETF-like operations.` → Process Creation; `macos:unifiedlog First outbound connection from the same PID/user shortly after an inbound trigger.` → Network Connection Creation; `NSM:Flow Inbound one-off packet to uncommon port → outbound SF to same src_ip within TimeWindow.` → Network Traffic Content
