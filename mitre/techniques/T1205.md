# T1205 — Traffic Signaling

<a id="t1205"></a>

**Tactics:** defense-evasion, persistence, command-and-control  
**Platforms:** Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1205](https://attack.mitre.org/techniques/T1205)  

Adversaries may use traffic signaling to hide open ports or other malicious functionality used for persistence or command and control.

## Mitigations (2)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.

## Detection

**Detection strategies:**

- Traffic Signaling (Port-knock / magic-packet → firewall or service activation) – T1205

**Analytics (4):**

- **Analytic 1448** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Microsoft-Windows-Windows Firewall With Advanced Security/Firewall EventCode=2004, 2005, 2006` → Network Traffic Flow; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 1449** (Linux) — `auditd:SYSCALL execve: Commands altering firewall or enabling listeners (iptables, nft, ufw, firewall-cmd, systemctl start *ssh*/*telnet*, ip route add, tcpdump, tshark)` → Process Creation; `auditd:SYSCALL socket/bind: Process binds to a new local port shortly after knock` → Network Connection Creation; `NSM:Flow Knock pattern: multiple REJ/S0 to distinct closed ports then successful connection to service_port` → Network Traffic Flow; `NSM:Flow Packets with unusual flags or payloads outside established flows (e.g., WoL magic FF×6 + 16×MAC)` → Network Traffic Content
- **Analytic 1450** (macOS) — `macos:unifiedlog exec: Execution of /sbin/pfctl, /usr/libexec/ApplicationFirewall/socketfilterfw, ifconfig, tcpdump, npcap/libpcap consumers` → Process Creation; `macos:unifiedlog Firewall rule enable/disable or listen socket changes` → Network Traffic Flow; `NSM:Flow Closed-port hits followed by success from same src_ip` → Network Connection Creation
- **Analytic 1451** (Network Devices) — `networkdevice:syslog Config/ACL/line vty changes, service enable (telnet/ssh/http(s)), module reloads` → Network Traffic Flow; `NSM:Flow Port-knock pattern from one src to device unicast,broadcast,network addresses on same port within TimeWindowKnock` → Network Connection Creation
