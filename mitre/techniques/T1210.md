# T1210 — Exploitation of Remote Services

<a id="t1210"></a>

**Tactics:** lateral-movement  
**Platforms:** Linux, Windows, macOS, ESXi  
**ATT&CK:** [T1210](https://attack.mitre.org/techniques/T1210)  

Adversaries may exploit remote services to gain unauthorized access to internal systems once inside of a network. Exploitation of a software vulnerability occurs when an adversary takes advantage of a programming error in a program, service, or within the operating system software or kernel itself to execute adversary-controlled code. A common goal for post-compromise exploitation of remote services is for lateral movement to enable access to a remote system. An adversary may need to determine if the remote system is in a vulnerable state, which may be done through [Network Service Discovery](https://attack.mitre.org/techniques/T1046) or other Discovery methods looking for common, vulnerable software that may be deployed in the network, the lack of certain patches that may indicate vulnerabilities, or security software that may be used to detect or contain remote exploitation. Servers are likely a high value target for lateral movement exploitation, but endpoint systems may also be at risk if they provide an advantage or access to additional resources. There are several well-known vulnerabilities that exist in common services such as SMB and RDP as well as applications that may be used within internal networks such as MySQL and web server services. Additionally, there have been a number of vulnerabilities in VMware vCenter installations, which may enable threat actors to move laterally from the compromised vCenter server to virtual machines or even to ESXi hypervisors. Depending on the permissions level of the vulnerable remote service an adversary may achieve [Exploitation for Privilege Escalation](https://attack.mitre.org/techniques/T1068) as a result of lateral movement exploitation as well.

## D3FEND countermeasures (16)

- [Application Protocol Command Analysis](/mitre/d3fend/application-protocol-command-analysis.md) (Detect) — monitors. Analyzing application protocol level remote commands to detect unauthorized activity.
- [Client-server Payload Profiling](/mitre/d3fend/client-server-payload-profiling.md) (Detect) — analyzes. Comparing client-server request and response payloads to a baseline profile to identify outliers.
- [Connection Attempt Analysis](/mitre/d3fend/connection-attempt-analysis.md) (Detect) — analyzes. Analyzing failed connections in a network to detect unauthorized activity.
- [Memory Boundary Tracking](/mitre/d3fend/memory-boundary-tracking.md) (Detect) — analyzes. Analyzing a call stack for return addresses which point to unexpected memory locations.
- [Network Traffic Community Deviation](/mitre/d3fend/network-traffic-community-deviation.md) (Detect) — analyzes. Establishing baseline communities of network hosts and identifying statistically divergent inter-community communication.
- [Network Traffic Filtering](/mitre/d3fend/network-traffic-filtering.md) (Isolate) — filters. Restricting network traffic originating from any location.
- [Network Traffic Signature Analysis](/mitre/d3fend/network-traffic-signature-analysis.md) (Detect) — analyzes. Analyzing network traffic and compares it to known signatures
- [Per Host Download-Upload Ratio Analysis](/mitre/d3fend/per-host-download-upload-ratio-analysis.md) (Detect) — analyzes. Detecting anomalies that indicate malicious activity by comparing the amount of data downloaded versus data uploaded by a host.
- [Process Code Segment Verification](/mitre/d3fend/process-code-segment-verification.md) (Detect) — verifies. Comparing the "text" or "code" memory segments to a source of truth.
- [Process Segment Execution Prevention](/mitre/d3fend/process-segment-execution-prevention.md) (Harden) — neutralizes. Preventing execution of any address in a memory region other than the code segment.
- [Protocol Metadata Anomaly Detection](/mitre/d3fend/protocol-metadata-anomaly-detection.md) (Detect) — analyzes. Collecting network communication protocol metadata and identifying statistical outliers.
- [Remote Terminal Session Detection](/mitre/d3fend/remote-terminal-session-detection.md) (Detect) — analyzes. Detection of an unauthorized remote live terminal console session by examining network traffic to a network host.
- [Segment Address Offset Randomization](/mitre/d3fend/segment-address-offset-randomization.md) (Harden) — obfuscates. Randomizing the base (start) address of one or more segments of memory during the initialization of a process.
- [Shadow Stack Comparisons](/mitre/d3fend/shadow-stack-comparisons.md) (Detect) — analyzes. Comparing a call stack in system memory with a shadow call stack maintained by the processor to determine unauthorized shellcode activity.
- [Stack Frame Canary Validation](/mitre/d3fend/stack-frame-canary-validation.md) (Harden) — validates. Comparing a value stored in a stack frame with a known good value in order to prevent or detect a memory segment overwrite.
- [User Geolocation Logon Pattern Analysis](/mitre/d3fend/user-geolocation-logon-pattern-analysis.md) (Detect) — analyzes. Monitoring geolocation data of user logon attempts and comparing it to a baseline user behavior profile to identify anomalies in logon location.

## Detection

**Detection strategies:**

- Exploitation of Remote Services – multi-platform lateral movement detection

**Analytics (4):**

- **Analytic 0327** (Windows) — `WinEventLog:System EventCode=1000` → Application Log Content; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=11` → File Creation (+1 more)
- **Analytic 0328** (Linux) — `linux:syslog kernel|systemd messages indicating 'segmentation fault'|'core dumped'|'service terminated unexpectedly' for sshd, smbd, vsftpd, mysqld, httpd, etc.` → Application Log Content; `auditd:SYSCALL execve of /bin/sh,/bin/bash,/usr/bin/curl,/usr/bin/python by service accounts (e.g., apache, mysql, nobody) immediately after inbound network activity.` → Process Creation; `NSM:Flow Inbound connections to monitored service ports from external or unusual internal sources; rapid follow-on lateral connections from the same host.` → Network Traffic Content
- **Analytic 0329** (ESXi) — `esxi:hostd Keywords: 'Backtrace','Signal 11','PANIC','hostd restarted','assert' or 'Service terminated unexpectedly' in /var/log/hostd.log, /var/log/vmkernel.log, /var/log/syslog.log.` → Application Log Content; `NSM:Flow Inbound to tcp/427 (OpenSLP), tcp/443 (vSphere APIs), tcp/902, tcp/5989 followed by new unexpected outbound sessions from the ESXi/vCenter host.` → Network Traffic Content
- **Analytic 0330** (macOS) — `macos:unifiedlog process 'crashed'|'EXC_BAD_ACCESS' for sshd, screensharingd, httpd; launchd restarts of these daemons.` → Application Log Content; `macos:osquery parent_name in ('sshd','httpd','screensharingd') spawning shells or scripting runtimes.` → Process Creation; `NSM:Flow Inbound to 22/5900/8080 and follow-on internal connections.` → Network Traffic Content
