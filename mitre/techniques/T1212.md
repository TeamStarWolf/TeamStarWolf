# T1212 — Exploitation for Credential Access

<a id="t1212"></a>

**Tactics:** credential-access  
**Platforms:** Linux, Windows, macOS, Identity Provider  
**ATT&CK:** [T1212](https://attack.mitre.org/techniques/T1212)  

Adversaries may exploit software vulnerabilities in an attempt to collect credentials. Exploitation of a software vulnerability occurs when an adversary takes advantage of a programming error in a program, service, or within the operating system software or kernel itself to execute adversary-controlled code.

## Detection

**Detection strategies:**

**Analytics (4):**

- **Analytic 0493** (Windows) — `WinEventLog:Security EventCode=4768, 4769, 4770` → User Account Authentication; `WinEventLog:Sysmon EventCode=10` → Process Access
- **Analytic 0494** (Linux) — `auditd:SYSCALL execve: Suspicious binaries or scripts interacting with authentication binaries (sshd, gdm, login)` → Process Creation; `NSM:Connections Repeated failed authentication attempts or replay patterns` → User Account Authentication
- **Analytic 0495** (macOS) — `macos:unifiedlog opendirectoryd crashes or abnormal authentication errors` → Application Log Content; `macos:osquery execve: Processes unexpectedly invoking Keychain or authentication APIs` → Process Creation
- **Analytic 0496** (Identity Provider) — `azure:signinlogs TokenIssued, TokenRenewed: Unexpected or anomalous token issuance events` → User Account Authentication; `m365:unified ConsentGranted: Abuse of application integrations to mint tokens bypassing MFA` → Application Log Content
