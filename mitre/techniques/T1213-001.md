# T1213.001 — Confluence

<a id="t1213001"></a>

**Tactics:** collection  
**Platforms:** SaaS  
**ATT&CK:** [T1213.001](https://attack.mitre.org/techniques/T1213/001)  
**Sub-technique of:** [T1213 — Data from Information Repositories](/mitre/techniques/T1213.md)  

Adversaries may leverage Confluence repositories to mine valuable information.

## Mitigations (3)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## D3FEND countermeasures (2)

- [Decoy Network Resource](/mitre/d3fend/decoy-network-resource.md) (Deceive) — spoofs. Deploying a network resource for the purposes of deceiving an adversary.
- [Network Resource Access Mediation](/mitre/d3fend/network-resource-access-mediation.md) (Isolate) — isolates. Control of access to organizational systems and services by users or processes over a network.

## Detection

**Detection strategies:**

- Programmatic and Excessive Access to Confluence Documentation

**Analytics (1):**

- **Analytic 1019** (SaaS) — `saas:confluence access.content` → Application Log Content; `saas:confluence logon` → Logon Session Creation; `saas:confluence REST API access from non-browser agents` → Network Traffic Content
