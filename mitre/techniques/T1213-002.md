# T1213.002 — Sharepoint

<a id="t1213002"></a>

**Tactics:** collection  
**Platforms:** Windows, Office Suite  
**ATT&CK:** [T1213.002](https://attack.mitre.org/techniques/T1213/002)  
**Sub-technique of:** [T1213 — Data from Information Repositories](/mitre/techniques/T1213.md)  

Adversaries may leverage the SharePoint repository as a source to mine valuable information. SharePoint will often contain useful information for an adversary to learn about the structure and functionality of the internal network and systems.

## Mitigations (3)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Detecting Abnormal SharePoint Data Mining by Privileged or Rare Users

**Analytics (1):**

- **Analytic 1380** (Windows) — `m365:unified FileAccessed, FileDownloaded, SearchQueried` → Application Log Content; `azure:signinlogs UserLogin, ConditionalAccessPolicyEvaluated` → Logon Session Creation; `m365:sharepoint Multiple file download operations on a site by a privileged account in a short time window` → Cloud Service Metadata

## Adversary usage

**Threat groups (6):** [Ke3chang](https://attack.mitre.org/groups/G0004), [APT28](https://attack.mitre.org/groups/G0007), [Chimera](https://attack.mitre.org/groups/G0114), [HAFNIUM](https://attack.mitre.org/groups/G0125), [LAPSUS$](https://attack.mitre.org/groups/G1004), [Akira](https://attack.mitre.org/groups/G1024)

_Notable groups seen using this technique:_

- [Ke3chang](https://attack.mitre.org/groups/G0004) (aka APT15, Mirage, Vixen Panda, GREF) — Ke3chang is a threat group attributed to actors operating out of China.
- [APT28](https://attack.mitre.org/groups/G0007) (aka IRON TWILIGHT, SNAKEMACKEREL, Swallowtail, Group 74) — APT28 is a threat group that has been attributed to Russia's General Staff Main Intelligence Directorate (GRU) 85th Main Special Service Center (GTsSS) military unit 26165.
- [Chimera](https://attack.mitre.org/groups/G0114) — Chimera is a suspected China-based threat group that has been active since at least 2018 targeting the semiconductor industry in Taiwan as well as data from the airline industry.
- [HAFNIUM](https://attack.mitre.org/groups/G0125) (aka Operation Exchange Marauder, Silk Typhoon) — HAFNIUM is a likely state-sponsored cyber espionage group operating out of China that has been active since at least January 2021.
- [LAPSUS$](https://attack.mitre.org/groups/G1004) (aka DEV-0537, Strawberry Tempest) — LAPSUS$ is cyber criminal threat group that has been active since at least mid-2021.
- [Akira](https://attack.mitre.org/groups/G1024) (aka GOLD SAHARA, PUNK SPIDER, Howling Scorpius) — Akira is a ransomware variant and ransomware deployment entity active since at least March 2023.
