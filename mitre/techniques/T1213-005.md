# T1213.005 — Messaging Applications

<a id="t1213005"></a>

**Tactics:** collection  
**Platforms:** SaaS, Office Suite  
**ATT&CK:** [T1213.005](https://attack.mitre.org/techniques/T1213/005)  
**Sub-technique of:** [T1213 — Data from Information Repositories](/mitre/techniques/T1213.md)  

Adversaries may leverage chat and messaging applications, such as Microsoft Teams, Google Chat, and Slack, to mine valuable information.

## Detection

**Detection strategies:**

- Detecting Unauthorized Collection from Messaging Applications in SaaS and Office Environments

**Analytics (2):**

- **Analytic 1565** (SaaS) — `saas:slack conversations.history, files.list, users.info, audit_logs` → Application Log Content; `m365:signinlogs UserLoggedIn` → Logon Session Creation
- **Analytic 1566** (Office Suite) — `m365:unified TeamsMessagesAccessedViaEDiscovery, TeamsGraphMessageExport` → Application Log Content; `m365:signinlogs UserLoggedIn` → Logon Session Creation
