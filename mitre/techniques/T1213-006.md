# T1213.006 — Databases

<a id="t1213006"></a>

**Tactics:** collection  
**Platforms:** Linux, Windows, macOS, IaaS, SaaS  
**ATT&CK:** [T1213.006](https://attack.mitre.org/techniques/T1213/006)  
**Sub-technique of:** [T1213](/mitre/techniques/T1213.md)
