# T1213 — Data from Information Repositories

<a id="t1213"></a>

**Tactics:** collection  
**Platforms:** Linux, Windows, macOS, SaaS, IaaS, Office Suite  
**ATT&CK:** [T1213](https://attack.mitre.org/techniques/T1213)  

Adversaries may leverage information repositories to mine valuable information.

## Detection

**Detection strategies:**

- Abuse of Information Repositories for Data Collection

**Analytics (4):**

- **Analytic 1160** (Windows) — `WinEventLog:Security EventCode=5145` → Network Share Access; `m365:unified Accessed SharePoint files or pages` → Cloud Storage Access
- **Analytic 1161** (Linux) — `auditd:SYSCALL execve of curl, rsync, wget with internal knowledge base or IPs` → Command Execution; `linux:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1162** (SaaS) — `saas:confluence access.content` → Application Log Content; `saas:slack Exported file or accessed admin API` → Cloud Service Modification
- **Analytic 1163** (macOS) — `macos:unifiedlog access to /Volumes/SharePoint or network mount` → File Access; `macos:osquery curl, python scripts, rsync with internal share URLs` → Process Creation
