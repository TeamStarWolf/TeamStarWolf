# T1217 — Browser Information Discovery

<a id="t1217"></a>

**Tactics:** discovery  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1217](https://attack.mitre.org/techniques/T1217)  

Adversaries may enumerate information about browsers to learn more about compromised environments.

## Detection

**Detection strategies:**

- Detection of Local Browser Artifact Access for Reconnaissance

**Analytics (3):**

- **Analytic 0037** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 0038** (Linux) — `auditd:SYSCALL open, read, or stat of browser config files` → File Access; `linux:syslog Suspicious script or command execution targeting browser folders` → Command Execution
- **Analytic 0039** (macOS) — `macos:unifiedlog Access to ~/Library/*/Safari or Chrome directories by non-browser processes` → File Access; `macos:osquery process reading browser configuration paths` → Process Creation

## Data sources & telemetry (4)

**Process Creation**, **File Creation**, **Command Execution**, **File Access**

## Adversary usage

**Threat groups (6):** [APT38](https://attack.mitre.org/groups/G0082), [Chimera](https://attack.mitre.org/groups/G0114), [Fox Kitten](https://attack.mitre.org/groups/G0117), [Scattered Spider](https://attack.mitre.org/groups/G1015), [Volt Typhoon](https://attack.mitre.org/groups/G1017), [Moonstone Sleet](https://attack.mitre.org/groups/G1036)

_Notable groups seen using this technique:_

- [APT38](https://attack.mitre.org/groups/G0082) (aka NICKEL GLADSTONE, BeagleBoyz, Bluenoroff, Stardust Chollima) — APT38 is a North Korean state-sponsored threat group that specializes in financial cyber operations; it has been attributed to the Reconnaissance General Bureau.
- [Chimera](https://attack.mitre.org/groups/G0114) — Chimera is a suspected China-based threat group that has been active since at least 2018 targeting the semiconductor industry in Taiwan as well as data from the airline industry.
- [Fox Kitten](https://attack.mitre.org/groups/G0117) (aka UNC757, Parisite, Pioneer Kitten, RUBIDIUM) — Fox Kitten is threat actor with a suspected nexus to the Iranian government that has been active since at least 2017 against entities in the Middle East, North Africa, Europe, Australia, and North America.
- [Scattered Spider](https://attack.mitre.org/groups/G1015) (aka Roasted 0ktapus, Octo Tempest, Storm-0875, UNC3944) — Scattered Spider is a native English-speaking cybercriminal group active since at least 2022.
- [Volt Typhoon](https://attack.mitre.org/groups/G1017) (aka BRONZE SILHOUETTE, Vanguard Panda, DEV-0391, UNC3236) — Volt Typhoon is a People's Republic of China (PRC) state-sponsored actor that has been active since at least 2021 primarily targeting critical infrastructure organizations in the US and its territories including Guam.
- [Moonstone Sleet](https://attack.mitre.org/groups/G1036) (aka Storm-1789) — Moonstone Sleet is a North Korean-linked threat actor executing both financially motivated attacks and espionage operations.
