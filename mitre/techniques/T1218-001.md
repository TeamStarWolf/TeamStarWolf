# T1218.001 — Compiled HTML File

<a id="t1218001"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1218.001](https://attack.mitre.org/techniques/T1218/001)  
**Sub-technique of:** [T1218 — System Binary Proxy Execution](/mitre/techniques/T1218.md)  

Adversaries may abuse Compiled HTML files (.chm) to conceal malicious code. CHM files are commonly distributed as part of the Microsoft HTML Help system.

## Detection

**Detection strategies:**

- Detection of Suspicious Compiled HTML File Execution via hh.exe

**Analytics (1):**

- **Analytic 0968** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
