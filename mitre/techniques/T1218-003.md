# T1218.003 — CMSTP

<a id="t1218003"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1218.003](https://attack.mitre.org/techniques/T1218/003)  
**Sub-technique of:** [T1218 — System Binary Proxy Execution](/mitre/techniques/T1218.md)  

Adversaries may abuse CMSTP to proxy execution of malicious code. The Microsoft Connection Manager Profile Installer (CMSTP.exe) is a command-line program used to install Connection Manager service profiles.

## Detection

**Detection strategies:**

- Detection of Malicious Profile Installation via CMSTP.exe

**Analytics (1):**

- **Analytic 0932** (Windows) — `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=12` → Windows Registry Key Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification (+1 more)
