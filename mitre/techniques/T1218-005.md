# T1218.005 — Mshta

<a id="t1218005"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1218.005](https://attack.mitre.org/techniques/T1218/005)  
**Sub-technique of:** [T1218 — System Binary Proxy Execution](/mitre/techniques/T1218.md)  

Adversaries may abuse mshta.exe to proxy execution of malicious .hta files and Javascript or VBScript through a trusted Windows utility.

## Detection

**Detection strategies:**

- Detecting Mshta-based Proxy Execution via Suspicious HTA or Script Invocation

**Analytics (1):**

- **Analytic 1397** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
