# T1218.005 — Mshta

<a id="t1218005"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1218.005](https://attack.mitre.org/techniques/T1218/005)  
**Sub-technique of:** [T1218](/mitre/techniques/T1218.md)

Adversaries may abuse mshta.exe to proxy execution of malicious .hta files and Javascript or VBScript through a trusted Windows utility.
