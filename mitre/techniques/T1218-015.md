# T1218.015 — Electron Applications

<a id="t1218015"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1218.015](https://attack.mitre.org/techniques/T1218/015)  
**Sub-technique of:** [T1218 — System Binary Proxy Execution](/mitre/techniques/T1218.md)  

Adversaries may abuse components of the Electron framework to execute malicious code. The Electron framework hosts many common applications such as Signal, Slack, and Microsoft Teams.

## Mitigations (3)

- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.
- [M1050 — Exploit Protection](/mitre/mitigations/M1050.md) — Deploy capabilities that detect, block, and mitigate conditions indicative of software exploits.

## Detection

**Detection strategies:**

- Detecting Electron Application Abuse for Proxy Execution

**Analytics (3):**

- **Analytic 0071** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0072** (Linux) — `auditd:SYSCALL execve: Electron-based binary spawning shell or script interpreter` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 0073** (macOS) — `macos:unifiedlog Electron app spawning unexpected child process` → Process Creation; `macos:osquery CREATE/MODIFY: Modification of app.asar inside .app bundle` → File Creation
