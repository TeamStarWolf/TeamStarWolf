# T1218 — System Binary Proxy Execution

<a id="t1218"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows, Linux, macOS  
**ATT&CK:** [T1218](https://attack.mitre.org/techniques/T1218)  

Adversaries may bypass process and/or signature-based defenses by proxying execution of malicious content with signed, or otherwise trusted, binaries.

## Detection

**Detection strategies:**

- Detection of Proxy Execution via Trusted Signed Binaries Across Platforms

**Analytics (3):**

- **Analytic 0226** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=7` → Module Load
- **Analytic 0227** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL connect` → Network Connection Creation
- **Analytic 0228** (macOS) — `macos:unifiedlog exec of osascript, bash, curl with suspicious parameters` → Process Creation; `macos:osquery execution of trusted tools interacting with external endpoints` → Network Connection Creation
