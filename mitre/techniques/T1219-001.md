# T1219.001 — IDE Tunneling

<a id="t1219001"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1219.001](https://attack.mitre.org/techniques/T1219/001)  
**Sub-technique of:** [T1219 — Remote Access Tools](/mitre/techniques/T1219.md)  

Adversaries may abuse Integrated Development Environment (IDE) software with remote development features to establish an interactive command and control channel on target systems within a network.

## Mitigations (1)

- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md)

## Detection

**Detection strategies:**

- IDE Tunneling Detection via Process, File, and Network Behaviors

**Analytics (3):**

- **Analytic 0375** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `NSM:Flow Outbound connection to *.tunnels.api.visualstudio.com or *.devtunnels.ms` → Network Connection Creation
- **Analytic 0376** (Linux) — `auditd:SYSCALL execve on code or jetbrains-gateway with remote flags` → Process Creation; `auditd:SYSCALL open: Write to ~/.vscode-cli/code_tunnel.json` → File Creation; `NSM:Flow Connections to *.devtunnels.ms or tunnels.api.visualstudio.com` → Network Connection Creation
- **Analytic 0377** (macOS) — `macos:unifiedlog process: code or jetbrains-gateway launching with --tunnel or --remote` → Process Creation; `macos:unifiedlog creation of ~/.vscode-cli/code_tunnel.json` → File Creation; `NSM:Flow HTTPs connection to tunnels.api.visualstudio.com` → Network Connection Creation
