# T1219.002 — Remote Desktop Software

<a id="t1219002"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1219.002](https://attack.mitre.org/techniques/T1219/002)  
**Sub-technique of:** [T1219 — Remote Access Tools](/mitre/techniques/T1219.md)  

An adversary may use legitimate desktop support software to establish an interactive command and control channel to target systems within networks.

## Mitigations (3)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md)
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md)
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md)

## Detection

**Detection strategies:**

- Remote Desktop Software Execution and Beaconing Detection

**Analytics (3):**

- **Analytic 0714** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Microsoft-Windows-Windows Firewall With Advanced Security/Firewall new rule allowing inbound or outbound connections for remote desktop software` → Firewall Rule Modification
- **Analytic 0715** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Flow outbound connections to RMM services or to unusual destination ports` → Network Connection Creation
- **Analytic 0716** (macOS) — `macos:unifiedlog launch of remote desktop app or helper binary` → Process Creation; `macos:unifiedlog network sessions initiated by remote desktop apps` → Network Connection Creation
