# T1219.002 — Remote Desktop Software

<a id="t1219002"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1219.002](https://attack.mitre.org/techniques/T1219/002)  
**Sub-technique of:** [T1219 — Remote Access Tools](/mitre/techniques/T1219.md)  

An adversary may use legitimate desktop support software to establish an interactive command and control channel to target systems within networks.

## Mitigations (3)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.

## Detection

**Detection strategies:**

- Remote Desktop Software Execution and Beaconing Detection

**Analytics (3):**

- **Analytic 0714** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Microsoft-Windows-Windows Firewall With Advanced Security/Firewall new rule allowing inbound or outbound connections for remote desktop software` → Firewall Rule Modification
- **Analytic 0715** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Flow outbound connections to RMM services or to unusual destination ports` → Network Connection Creation
- **Analytic 0716** (macOS) — `macos:unifiedlog launch of remote desktop app or helper binary` → Process Creation; `macos:unifiedlog network sessions initiated by remote desktop apps` → Network Connection Creation

## Adversary usage

**Threat groups (9):** [RTM](https://attack.mitre.org/groups/G0048), [Thrip](https://attack.mitre.org/groups/G0076), [Kimsuky](https://attack.mitre.org/groups/G0094), [Evilnum](https://attack.mitre.org/groups/G0120), [Mustang Panda](https://attack.mitre.org/groups/G0129), [Scattered Spider](https://attack.mitre.org/groups/G1015), [Storm-1811](https://attack.mitre.org/groups/G1046), [Contagious Interview](https://attack.mitre.org/groups/G1052), [Storm-0501](https://attack.mitre.org/groups/G1053)

_Notable groups seen using this technique:_

- [RTM](https://attack.mitre.org/groups/G0048) — RTM is a cybercriminal group that has been active since at least 2015 and is primarily interested in users of remote banking systems in Russia and neighboring countries.
- [Thrip](https://attack.mitre.org/groups/G0076) — Thrip is an espionage group that has targeted satellite communications, telecoms, and defense contractor companies in the U.S.
- [Kimsuky](https://attack.mitre.org/groups/G0094) (aka Black Banshee, Velvet Chollima, Emerald Sleet, THALLIUM) — Kimsuky is a North Korea-based cyber espionage group that has been active since at least 2012.
- [Evilnum](https://attack.mitre.org/groups/G0120) — Evilnum is a financially motivated threat group that has been active since at least 2018.
- [Mustang Panda](https://attack.mitre.org/groups/G0129) (aka TA416, RedDelta, BRONZE PRESIDENT, STATELY TAURUS) — Mustang Panda is a China-based cyber espionage threat actor that has been conducting operations since at least 2012.
- [Scattered Spider](https://attack.mitre.org/groups/G1015) (aka Roasted 0ktapus, Octo Tempest, Storm-0875, UNC3944) — Scattered Spider is a native English-speaking cybercriminal group active since at least 2022.
