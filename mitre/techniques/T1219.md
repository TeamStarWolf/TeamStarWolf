# T1219 — Remote Access Tools

<a id="t1219"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1219](https://attack.mitre.org/techniques/T1219)  

An adversary may use legitimate remote access tools to establish an interactive command and control channel within a network.

## Detection

- Behavior-Chain Detection for Remote Access Tools (Tool-Agnostic)

**Analytics (3):**

- **Analytic 1366** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:System EventCode=7045` → Service Creation; `WinEventLog:Sysmon EventCode=12` → Windows Registry Key Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1367** (Linux) — `auditd:SYSCALL execve: Agent/headless flags (listen/connect/reverse/tunnel) or remote-control binaries spawning shells` → Process Creation; `auditd:PATH WRITE: Drop of binaries/scripts in ~/.local, /tmp, or /opt tool dirs` → File Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1368** (macOS) — `macos:unifiedlog Process exec of remote-control apps or binaries with headless/connect flags` → Process Creation; `macos:osquery CREATE/MODIFY: Creation of LaunchAgents/Daemons plists in user/system locations` → File Creation; `macos:osquery CONNECT: Long-lived connections from remote-control parents to external IPs/domains` → Network Connection Creation
