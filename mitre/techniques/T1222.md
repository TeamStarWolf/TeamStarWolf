# T1222 — File and Directory Permissions Modification

<a id="t1222"></a>

**Tactics:** defense-evasion  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1222](https://attack.mitre.org/techniques/T1222)  

Adversaries may modify file or directory permissions/attributes to evade access control lists (ACLs) and access protected files. File and directory permissions are commonly managed by ACLs configured by the file or directory owner, or users with the appropriate permissions.

## Detection

**Detection strategies:**

- Multi-Platform File and Directory Permissions Modification Detection Strategy

**Analytics (4):**

- **Analytic 0834** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Metadata; `WinEventLog:Security EventCode=4663, 4670, 4656` → Active Directory Object Modification; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution
- **Analytic 0835** (Linux) — `auditd:SYSCALL syscall in (chmod, fchmod, fchmodat, chown, fchown, fchownat, setxattr, lsetxattr, fsetxattr)` → File Metadata; `auditd:PROCTITLE proctitle contains chmod, chown, setfacl, or attr commands with suspicious parameters` → Command Execution
- **Analytic 0836** (macOS) — `macos:unifiedlog process execution events for chmod, chown, chflags with unusual parameters or targets` → Process Creation; `fs:fsevents file system events indicating permission or attribute changes` → File Metadata
- **Analytic 0837** (ESXi) — `esxi:shell shell command execution for chmod, chown, or file permission modification on VMFS or system files` → Command Execution; `esxi:hostd host daemon events related to file or VM permission changes` → File Metadata; `esxi:vpxd permission change operations on datastores or VMs` → Active Directory Object Modification
