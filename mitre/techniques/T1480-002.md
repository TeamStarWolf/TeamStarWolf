# T1480.002 — Mutual Exclusion

<a id="t1480002"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1480.002](https://attack.mitre.org/techniques/T1480/002)  
**Sub-technique of:** [T1480 — Execution Guardrails](/mitre/techniques/T1480.md)  

Adversaries may constrain execution or actions based on the presence of a mutex associated with malware. A mutex is a locking mechanism used to synchronize access to a resource. Only one thread or process can acquire a mutex at a given time.

## Mitigations (1)

- [M1055 — Do Not Mitigate](/mitre/mitigations/M1055.md)

## Detection

**Detection strategies:**

- Detection of Mutex-Based Execution Guardrails Across Platforms

**Analytics (3):**

- **Analytic 0372** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 0373** (Linux) — `auditd:SYSCALL open, flock, fcntl, unlink` → File Access; `auditd:SYSCALL exit_group` → Process Termination
- **Analytic 0374** (macOS) — `macos:unifiedlog flock|NSDistributedLock|FileHandle.*lockForWriting` → OS API Execution; `macos:unifiedlog process.*exit.*code` → Process Termination
