# T1484.001 — Group Policy Modification

<a id="t1484001"></a>

**Tactics:** defense-evasion, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1484.001](https://attack.mitre.org/techniques/T1484/001)  
**Sub-technique of:** [T1484 — Domain or Tenant Policy Modification](/mitre/techniques/T1484.md)  

Adversaries may modify Group Policy Objects (GPOs) to subvert the intended discretionary access controls for a domain, usually with the intention of escalating privileges on the domain. Group policy allows for centralized management of user and computer settings in Active Directory (AD).

## Mitigations (2)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md)
- [M1047 — Audit](/mitre/mitigations/M1047.md)

## Detection

**Detection strategies:**

- Detection of Group Policy Modifications via AD Object Changes and File Activity

**Analytics (1):**

- **Analytic 0854** (Windows) — `WinEventLog:Security EventCode=5136` → Active Directory Object Modification; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Modification; `WinEventLog:Security EventCode=4704` → User Account Modification; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
