# T1486 — Data Encrypted for Impact

<a id="t1486"></a>

**Tactics:** impact  
**Platforms:** ESXi, IaaS, Linux, macOS, Windows  
**ATT&CK:** [T1486](https://attack.mitre.org/techniques/T1486)  

Adversaries may encrypt data on target systems or on large numbers of systems in a network to interrupt availability to system and network resources. They can attempt to render stored data inaccessible by encrypting files or data on local and remote drives and withholding access to a decryption key.

## Detection

**Detection strategies:**

- Detection of Multi-Platform File Encryption for Impact

**Analytics (5):**

- **Analytic 0602** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=2` → File Modification
- **Analytic 0603** (Linux) — `auditd:SYSCALL openat, write, rename, unlink` → File Modification; `auditd:SYSCALL execve` → Process Creation
- **Analytic 0604** (macOS) — `macos:unifiedlog file encrypted|new file with .encrypted extension|disk write burst` → File Modification; `macos:unifiedlog exec srm|exec openssl|exec gpg` → Process Creation
- **Analytic 0605** (ESXi) — `esxi:vmkernel rename .vmdk to .*.locked|datastore write spike` → File Modification; `esxi:shell openssl|tar|dd` → Command Execution
- **Analytic 0606** (IaaS) — `AWS:CloudTrail PutObject (with SSE-C), UploadPart (SSE-C)` → Cloud Storage Modification
