# T1490 — Inhibit System Recovery

<a id="t1490"></a>

**Tactics:** impact  
**Platforms:** Containers, ESXi, IaaS, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1490](https://attack.mitre.org/techniques/T1490)  

Adversaries may delete or remove built-in data and turn off services designed to aid in the recovery of a corrupted system to prevent recovery. This may deny access to available backups and recovery options.

## Mitigations (4)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.
- [M1053 — Data Backup](/mitre/mitigations/M1053.md) — Data Backup involves taking and securely storing backups of data from end-user systems and critical servers.

## Detection

**Detection strategies:**

- Behavioral Detection for T1490 - Inhibit System Recovery

**Analytics (5):**

- **Analytic 0933** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Microsoft-Windows-Backup Windows Backup Catalog deletion or catalog corruption` → File Deletion; `WinEventLog:System Service stopped or RecoveryDisabled set via REAgentC` → Service Metadata; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 0934** (Linux) — `auditd:SYSCALL chattr, rm, shred, dd run on recovery directories or partitions` → Command Execution; `auditd:CONFIG_CHANGE /etc/fstab, /etc/systemd/*` → File Deletion
- **Analytic 0935** (ESXi) — `esxi:hostd snapshot.removeall or snapshot file deletion` → Snapshot Deletion
- **Analytic 0936** (Network Devices) — `networkdevice:syslog command sequence: erase → format → reload` → Command Execution
- **Analytic 0937** (IaaS) — `AWS:CloudTrail DeleteSnapshot` → Snapshot Deletion; `AWS:CloudTrail DeleteBucket, DeleteDBCluster, DeleteSnapshot, TerminateInstances` → Cloud Storage Deletion

- [Sandworm Team](https://attack.mitre.org/groups/G0034) (aka ELECTRUM, Telebots, IRON VIKING, BlackEnergy (Group)) — Sandworm Team is a destructive threat group that has been attributed to Russia's General Staff Main Intelligence Directorate (GRU) Main Center for Special Technologies (GTsST) military unit 74455.
- [Wizard Spider](https://attack.mitre.org/groups/G0102) (aka UNC1878, TEMP.MixMaster, Grim Spider, FIN12) — Wizard Spider is a Russia-based financially motivated threat group originally known for the creation and deployment of TrickBot since at least 2016.
- [Scattered Spider](https://attack.mitre.org/groups/G1015) (aka Roasted 0ktapus, Octo Tempest, Storm-0875, UNC3944) — Scattered Spider is a native English-speaking cybercriminal group active since at least 2022.
- [BlackByte](https://attack.mitre.org/groups/G1043) (aka Hecamede) — BlackByte is a ransomware threat actor operating since at least 2021.
- [Medusa Group](https://attack.mitre.org/groups/G1051) — Medusa Group has been active since at least 2021 and was initially operated as a closed ransomware group before evolving into a Ransomware-as-a-Service (RaaS) operation.
- [Storm-0501](https://attack.mitre.org/groups/G1053) — Storm-0501 is a financially motivated cyber criminal group that uses commodity and open-source tools to conduct ransomware operations.
