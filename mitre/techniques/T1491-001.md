# T1491.001 — Internal Defacement

<a id="t1491001"></a>

**Tactics:** impact  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1491.001](https://attack.mitre.org/techniques/T1491/001)  
**Sub-technique of:** [T1491 — Defacement](/mitre/techniques/T1491.md)  

An adversary may deface systems internal to an organization in an attempt to intimidate or mislead users, thus discrediting the integrity of the systems. This may take the form of modifications to internal websites or server login messages, or directly to user systems with the replacement of the desktop wallpaper.

## Mitigations (1)

- [M1053 — Data Backup](/mitre/mitigations/M1053.md) — Data Backup involves taking and securely storing backups of data from end-user systems and critical servers.

## Detection

**Detection strategies:**

- Internal Website and System Content Defacement via UI or Messaging Modifications

**Analytics (4):**

- **Analytic 0229** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=2` → File Modification; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0230** (Linux) — `auditd:SYSCALL open/write/unlink` → File Modification; `auditd:SYSCALL execve` → Process Creation; `linux:syslog sudo or su access prior to content change` → User Account Modification
- **Analytic 0231** (macOS) — `macos:unifiedlog loginwindow or desktopservices modified settings or files` → File Modification; `macos:unifiedlog osascript or AppleScript invocation modifying UI` → Script Execution
- **Analytic 0232** (ESXi) — `ESXiLogs:messages changes to /etc/motd or /etc/vmware/welcome` → File Modification; `esxi:hostd modification of config files or shell command execution` → Command Execution

## Adversary usage

**Threat groups (3):** [Lazarus Group](https://attack.mitre.org/groups/G0032), [Gamaredon Group](https://attack.mitre.org/groups/G0047), [BlackByte](https://attack.mitre.org/groups/G1043)

_Notable groups seen using this technique:_

- [Lazarus Group](https://attack.mitre.org/groups/G0032) (aka Labyrinth Chollima, HIDDEN COBRA, Guardians of Peace, ZINC) — Lazarus Group is a North Korean state-sponsored cyber threat group attributed to the Reconnaissance General Bureau (RGB).
- [Gamaredon Group](https://attack.mitre.org/groups/G0047) (aka IRON TILDEN, Primitive Bear, ACTINIUM, Armageddon) — Gamaredon Group is a suspected Russian cyber espionage group that has targeted military, law enforcement, judiciary, non-profit, and non-governmental organizations in Ukraine since at least 2013.
- [BlackByte](https://attack.mitre.org/groups/G1043) (aka Hecamede) — BlackByte is a ransomware threat actor operating since at least 2021.

**Software/tools (9):** [Diavol](https://attack.mitre.org/software/S0659), [Meteor](https://attack.mitre.org/software/S0688), [BlackCat](https://attack.mitre.org/software/S1068), [Black Basta](https://attack.mitre.org/software/S1070), [INC Ransomware](https://attack.mitre.org/software/S1139), [ROADSWEEP](https://attack.mitre.org/software/S1150), [ShrinkLocker](https://attack.mitre.org/software/S1178), [RansomHub](https://attack.mitre.org/software/S1212), [Qilin](https://attack.mitre.org/software/S1242)
