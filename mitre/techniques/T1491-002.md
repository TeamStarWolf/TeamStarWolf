# T1491.002 — External Defacement

<a id="t1491002"></a>

**Tactics:** impact  
**Platforms:** Windows, IaaS, Linux, macOS  
**ATT&CK:** [T1491.002](https://attack.mitre.org/techniques/T1491/002)  
**Sub-technique of:** [T1491 — Defacement](/mitre/techniques/T1491.md)  

An adversary may deface systems external to an organization in an attempt to deliver messaging, intimidate, or otherwise mislead an organization or users. External Defacement may ultimately cause users to distrust the systems and to question/discredit the system’s integrity.

## Mitigations (1)

- [M1053 — Data Backup](/mitre/mitigations/M1053.md) — Data Backup involves taking and securely storing backups of data from end-user systems and critical servers.

## D3FEND countermeasures (2)

- [Decoy Network Resource](/mitre/d3fend/decoy-network-resource.md) (Deceive) — spoofs

## Detection

**Detection strategies:**

- Behavioral Detection of External Website Defacement across Platforms

**Analytics (4):**

- **Analytic 1622** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Modification; `NSM:Connections Unusual POST requests to admin or upload endpoints` → Network Traffic Content; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1623** (Linux) — `auditd:SYSCALL open/write syscalls targeting web directory files` → File Modification; `NSM:Connections Successful sudo or ssh from unknown IPs` → Logon Session Metadata; `NSM:Flow Suspicious POSTs to upload endpoints` → Network Traffic Content
- **Analytic 1624** (macOS) — `macos:unifiedlog Terminal/Editor processes modifying web folder` → File Modification; `macos:unifiedlog loginwindow or sshd events with external IP` → Logon Session Metadata
- **Analytic 1625** (IaaS) — `AWS:CloudTrail PutObject` → File Creation; `AWS:CloudTrail ListBuckets` → Cloud Storage Enumeration; `AWS:CloudTrail GetObject, CopyObject` → Cloud Storage Access

## Adversary usage

**Threat groups (2):** [Sandworm Team](https://attack.mitre.org/groups/G0034), [Ember Bear](https://attack.mitre.org/groups/G1003)

_Notable groups seen using this technique:_

- [Sandworm Team](https://attack.mitre.org/groups/G0034) (aka ELECTRUM, Telebots, IRON VIKING, BlackEnergy (Group)) — Sandworm Team is a destructive threat group that has been attributed to Russia's General Staff Main Intelligence Directorate (GRU) Main Center for Special Technologies (GTsST) military unit 74455.
- [Ember Bear](https://attack.mitre.org/groups/G1003) (aka UNC2589, Bleeding Bear, DEV-0586, Cadet Blizzard) — Ember Bear is a Russian state-sponsored cyber espionage group that has been active since at least 2020, linked to Russia's General Staff Main Intelligence Directorate (GRU) 161st Specialist Training Center (Unit 29155).
