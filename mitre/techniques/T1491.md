# T1491 — Defacement

<a id="t1491"></a>

**Tactics:** impact  
**Platforms:** Windows, IaaS, Linux, macOS, ESXi  
**ATT&CK:** [T1491](https://attack.mitre.org/techniques/T1491)  

Adversaries may modify visual content available internally or externally to an enterprise network, thus affecting the integrity of the original content. Reasons for Defacement include delivering messaging, intimidation, or claiming (possibly false) credit for an intrusion.

## Mitigations (1)

- [M1053 — Data Backup](/mitre/mitigations/M1053.md) — Data Backup involves taking and securely storing backups of data from end-user systems and critical servers.

## Detection

**Detection strategies:**

- Defacement via File and Web Content Modification Across Platforms

**Analytics (5):**

- **Analytic 0662** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Modification; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Application Unexpected web application errors or CMS logs showing modification to index.html, default.aspx, or other public-facing files` → Application Log Content
- **Analytic 0663** (Linux) — `auditd:SYSCALL write` → File Modification; `apache:access_log Unusual HTTP POST or PUT requests to paths such as '/uploads/', '/admin/', or CMS plugin folders` → Network Traffic Content; `linux:syslog Unauthorized sudo or shell access, especially leading to file changes in /var/www or /srv/http` → Process Creation
- **Analytic 0664** (macOS) — `macos:unifiedlog Execution of unexpected terminal or web scripts modifying /Library/WebServer/Documents` → Process Creation; `macos:unifiedlog File creation or overwrite in common web-hosting folders` → File Modification
- **Analytic 0665** (ESXi) — `esxi:vmkernel Unauthorized file modifications within datastore volumes via shell access or vCLI` → File Modification
- **Analytic 0666** (IaaS) — `CloudTrail:PutObject PutObject` → File Creation; `AWS:CloudTrail GetObject, CopyObject` → Cloud Storage Access

## Data sources & telemetry (6)

**File Modification**, **Process Creation**, **Application Log Content**, **Network Traffic Content**, **File Creation**, **Cloud Storage Access**

## Sub-techniques (2)

- [T1491.001 — Internal Defacement](/mitre/techniques/T1491-001.md) — An adversary may deface systems internal to an organization in an attempt to intimidate or mislead users, thus discrediting the integrity of the systems.
- [T1491.002 — External Defacement](/mitre/techniques/T1491-002.md) — An adversary may deface systems external to an organization in an attempt to deliver messaging, intimidate, or otherwise mislead an organization or users.
