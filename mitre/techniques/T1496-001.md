# T1496.001 — Compute Hijacking

<a id="t1496001"></a>

**Tactics:** impact  
**Platforms:** Windows, IaaS, Linux, macOS, Containers  
**ATT&CK:** [T1496.001](https://attack.mitre.org/techniques/T1496/001)  
**Sub-technique of:** [T1496 — Resource Hijacking](/mitre/techniques/T1496.md)  

Adversaries may leverage the compute resources of co-opted systems to complete resource-intensive tasks, which may impact system and/or hosted service availability. One common purpose for Compute Hijacking is to validate transactions of cryptocurrency networks and earn virtual currency.

## Detection

**Detection strategies:**

- Multi-Platform Behavioral Detection for Compute Hijacking

**Analytics (5):**

- **Analytic 1489** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Security EventCode=4698` → Scheduled Job Creation
- **Analytic 1490** (Linux) — `auditd:SYSCALL execve` → Process Creation; `NSM:Flow Outbound connection to mining pool port (3333, 4444, 5555)` → Network Traffic Flow; `linux:cron Scheduled execution of unknown or unusual script/binary` → Scheduled Job Creation
- **Analytic 1491** (macOS) — `macos:unifiedlog launchd or cron spawning mining binaries` → Process Creation; `macos:unifiedlog Persistent outbound connections with consistent periodicity` → Network Traffic Content
- **Analytic 1492** (Containers) — `containerd:events create` → Container Creation; `auditd:SYSCALL execve` → Process Creation; `NSM:Flow Outbound traffic to mining pool upon container launch` → Network Traffic Flow
- **Analytic 1493** (IaaS) — `AWS:CloudTrail RunInstances` → Instance Start; `AWS:CloudWatch Unusual CPU burst or metric anomalies` → Host Status

## Data sources & telemetry (8)

**Process Creation**, **Network Connection Creation**, **Scheduled Job Creation**, **Network Traffic Flow**, **Network Traffic Content**, **Container Creation**, **Instance Start**, **Host Status**
