# T1496.001: Compute Hijacking

<a id="t1496001"></a>

Tactics: impact  
Platforms: Windows, IaaS, Linux, macOS, Containers  
ATT&CK: [T1496.001](https://attack.mitre.org/techniques/T1496/001)  
Sub-technique of: [T1496: Resource Hijacking](/mitre/techniques/T1496.md)  

Adversaries may leverage the compute resources of co-opted systems to complete resource-intensive tasks, which may impact system and/or hosted service availability. One common purpose for [Compute Hijacking](https://attack.mitre.org/techniques/T1496/001) is to validate transactions of cryptocurrency networks and earn virtual currency. Adversaries may consume enough system resources to negatively impact and/or cause affected machines to become unresponsive. Servers and cloud-based systems are common targets because of the high potential for available resources, but user endpoint systems may also be compromised and used for [Compute Hijacking](https://attack.mitre.org/techniques/T1496/001) and cryptocurrency mining. Containerized environments may also be targeted due to the ease of deployment via exposed APIs and the potential for scaling mining activities by deploying or compromising multiple containers within an environment or cluster. Additionally, some cryptocurrency mining malware identify then kill off processes for competing malware to ensure it’s not competing for resources.

## Detection

Detection strategies:

- Multi-Platform Behavioral Detection for Compute Hijacking

Analytics (5):

- Analytic 1489 (Windows): `WinEventLog:Sysmon EventCode=1` -> Process Creation; `WinEventLog:Sysmon EventCode=3, 22` -> Network Connection Creation; `WinEventLog:Security EventCode=4698` -> Scheduled Job Creation
- Analytic 1490 (Linux): `auditd:SYSCALL execve` -> Process Creation; `NSM:Flow Outbound connection to mining pool port (3333, 4444, 5555)` -> Network Traffic Flow; `linux:cron Scheduled execution of unknown or unusual script/binary` -> Scheduled Job Creation
- Analytic 1491 (macOS): `macos:unifiedlog launchd or cron spawning mining binaries` -> Process Creation; `macos:unifiedlog Persistent outbound connections with consistent periodicity` -> Network Traffic Content
- Analytic 1492 (Containers): `containerd:events create` -> Container Creation; `auditd:SYSCALL execve` -> Process Creation; `NSM:Flow Outbound traffic to mining pool upon container launch` -> Network Traffic Flow
- Analytic 1493 (IaaS): `AWS:CloudTrail RunInstances` -> Instance Start; `AWS:CloudWatch Unusual CPU burst or metric anomalies` -> Host Status

## Data sources & telemetry (8)

Process Creation, Network Connection Creation, Scheduled Job Creation, Network Traffic Flow, Network Traffic Content, Container Creation, Instance Start, Host Status

## Adversary usage

Threat groups (4): [APT41](/mitre/groups/G0096.md), [Rocke](/mitre/groups/G0106.md), [Blue Mockingbird](/mitre/groups/G0108.md), [TeamTNT](/mitre/groups/G0139.md)

_Notable groups seen using this technique:_

- [APT41](/mitre/groups/G0096.md) (aka Wicked Panda, Brass Typhoon, BARIUM): [APT41](https://attack.mitre.org/groups/G0096) is a threat group that researchers have assessed as Chinese state-sponsored espionage group that also conducts financially-motivated operations.
- [Rocke](/mitre/groups/G0106.md): [Rocke](https://attack.mitre.org/groups/G0106) is an alleged Chinese-speaking adversary whose primary objective appeared to be cryptojacking, or stealing victim system resources for the purposes of mining cryptocurrency.
- [Blue Mockingbird](/mitre/groups/G0108.md): [Blue Mockingbird](https://attack.mitre.org/groups/G0108) is a cluster of observed activity involving Monero cryptocurrency-mining payloads in dynamic-link library (DLL) form on Windows systems.
- [TeamTNT](/mitre/groups/G0139.md): [TeamTNT](https://attack.mitre.org/groups/G0139) is a threat group that has primarily targeted cloud and containerized environments.

Software/tools (9): [Imminent Monitor](/mitre/software/S0434.md), [LoudMiner](/mitre/software/S0451.md), [Skidmap](/mitre/software/S0468.md), [Bonadan](/mitre/software/S0486.md), [CookieMiner](/mitre/software/S0492.md), [Lucifer](/mitre/software/S0532.md), [Kinsing](/mitre/software/S0599.md), [Hildegard](/mitre/software/S0601.md), [DarkGate](/mitre/software/S1111.md)
