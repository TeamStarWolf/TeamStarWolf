# T1496.002 — Bandwidth Hijacking

<a id="t1496002"></a>

**Tactics:** impact  
**Platforms:** Linux, Windows, macOS, IaaS, Containers  
**ATT&CK:** [T1496.002](https://attack.mitre.org/techniques/T1496/002)  
**Sub-technique of:** [T1496 — Resource Hijacking](/mitre/techniques/T1496.md)  

Adversaries may leverage the network bandwidth resources of co-opted systems to complete resource-intensive tasks, which may impact system and/or hosted service availability.

## Detection

**Detection strategies:**

- Detect Excessive or Unauthorized Bandwidth Usage for Botnet, Proxyjacking, or Scanning Purposes

**Analytics (5):**

- **Analytic 0080** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0081** (Linux) — `auditd:SYSCALL execve calls with high-frequency or known bandwidth-intensive tools` → Process Creation; `NSM:Flow large outbound data flows or long-duration connections` → Network Traffic Flow
- **Analytic 0082** (macOS) — `macos:unifiedlog process + network metrics correlation for bandwidth saturation` → Network Traffic Content; `macos:unifiedlog exec or spawn calls to proxy tools or torrent clients` → Process Creation
- **Analytic 0083** (Containers) — `containers:osquery bandwidth-intensive command execution from within a container namespace` → Process Creation; `docker:stats unusual network TX/RX byte deltas` → Network Traffic Content
- **Analytic 0084** (IaaS) — `AWS:CloudTrail StartInstances` → Instance Start; `AWS:VPCFlowLogs egress > 90th percentile or frequent connection reuse` → Network Traffic Flow

## Data sources & telemetry (5)

**Network Connection Creation**, **Process Creation**, **Network Traffic Flow**, **Network Traffic Content**, **Instance Start**
