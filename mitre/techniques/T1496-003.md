# T1496.003 — SMS Pumping

<a id="t1496003"></a>

**Tactics:** impact  
**Platforms:** SaaS  
**ATT&CK:** [T1496.003](https://attack.mitre.org/techniques/T1496/003)  
**Sub-technique of:** [T1496 — Resource Hijacking](/mitre/techniques/T1496.md)  

Adversaries may leverage messaging services for SMS pumping, which may impact system and/or hosted service availability.

## Mitigations (1)

- [M1013 — Application Developer Guidance](/mitre/mitigations/M1013.md)

## Detection

**Detection strategies:**

- Detection Strategy for Resource Hijacking: SMS Pumping via SaaS Application Logs

**Analytics (1):**

- **Analytic 0443** (SaaS) — `saas:application High-frequency invocation of SMS-related API endpoints from publicly accessible OTP or verification forms (e.g., Twilio: SendMessage, Cognito: AdminCreateUser) with irregular destination patterns.` → Application Log Content; `saas:audit Repeated requests to SMS-generating endpoints using anomalous or new user agents, IP ranges, or geographies.` → User Account Authentication
