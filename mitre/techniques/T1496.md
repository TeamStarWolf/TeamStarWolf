# T1496 — Resource Hijacking

<a id="t1496"></a>

**Tactics:** impact  
**Platforms:** Windows, IaaS, Linux, macOS, Containers, SaaS  
**ATT&CK:** [T1496](https://attack.mitre.org/techniques/T1496)  

Adversaries may leverage the resources of co-opted systems to complete resource-intensive tasks, which may impact system and/or hosted service availability. Resource hijacking may take a number of different forms. For example, adversaries may: * Leverage compute resources in order to mine cryptocurrency * Sell network bandwidth to proxy networks * Generate SMS traffic for profit * Abuse cloud-based messaging services to send large quantities of spam messages In some cases, adversaries may leverage multiple types of Resource Hijacking at once.

## Detection

**Detection strategies:**

- Resource Hijacking Detection Strategy

**Analytics (6):**

- **Analytic 0741** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `Windows:perfmon High sustained CPU usage by a single process` → Host Status; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0742** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:procfs Sustained high /proc/[pid]/stat usage` → Host Status; `NSM:Flow Outbound traffic to mining pools or proxies` → Network Traffic Flow
- **Analytic 0743** (macOS) — `macos:unifiedlog launchctl activity and process creation` → Process Creation; `macos:unifiedlog Persistent outbound traffic to mining domains` → Network Traffic Content
- **Analytic 0744** (IaaS) — `AWS:CloudTrail RunInstances` → Instance Start; `AWS:CloudWatch Sustained EC2 CPU usage above normal baseline` → Host Status; `AWS:VPCFlowLogs Outbound flow logs to known mining pools` → Network Traffic Flow
- **Analytic 0745** (Containers) — `containerd:events New container with suspicious image name or high resource usage` → Process Creation; `prometheus:metrics Container CPU/Memory usage exceeding threshold` → Host Status; `container:cni Outbound network traffic to mining proxies` → Network Traffic Flow
- **Analytic 0746** (SaaS) — `m365:unified SendMessage` → Cloud Service Modification; `saas:application High-volume API calls or traffic via messaging or webhook service` → Application Log Content
