# T1498.001 — Direct Network Flood

<a id="t1498001"></a>

**Tactics:** impact  
**Platforms:** Windows, IaaS, Linux, macOS  
**ATT&CK:** [T1498.001](https://attack.mitre.org/techniques/T1498/001)  
**Sub-technique of:** [T1498 — Network Denial of Service](/mitre/techniques/T1498.md)  

Adversaries may attempt to cause a denial of service (DoS) by directly sending a high-volume of network traffic to a target. This DoS attack may also reduce the availability and functionality of the targeted system(s) and network.

## Detection

**Detection strategies:**

- Direct Network Flood Detection across IaaS, Linux, Windows, and macOS

**Analytics (4):**

- **Analytic 0969** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Security EventCode=4688` → Process Creation
- **Analytic 0970** (Linux) — `auditd:SYSCALL connect or sendto system call with burst pattern` → Network Traffic Flow; `auditd:SYSCALL execve` → Process Creation
- **Analytic 0971** (macOS) — `macos:unifiedlog process created with repeated ICMP or UDP flood behavior` → Process Creation; `macos:unifiedlog sudden burst in outgoing packets from same PID` → Network Traffic Flow
- **Analytic 0972** (IaaS) — `AWS:VPCFlowLogs source instance sends large volume of traffic in short window` → Network Traffic Flow; `AWS:CloudWatch NetworkOut spike beyond baseline` → Host Status
