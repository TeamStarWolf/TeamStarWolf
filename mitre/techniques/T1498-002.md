# T1498.002 — Reflection Amplification

<a id="t1498002"></a>

**Tactics:** impact  
**Platforms:** Windows, IaaS, Linux, macOS  
**ATT&CK:** [T1498.002](https://attack.mitre.org/techniques/T1498/002)  
**Sub-technique of:** [T1498 — Network Denial of Service](/mitre/techniques/T1498.md)  

Adversaries may attempt to cause a denial of service (DoS) by reflecting a high-volume of network traffic to a target. This type of Network DoS takes advantage of a third-party server intermediary that hosts and will respond to a given spoofed source IP address. This third-party server is commonly termed a reflector.

## Mitigations (1)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Detection Strategy for Reflection Amplification DoS (T1498.002)

**Analytics (4):**

- **Analytic 1140** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `Windows:perfmon Sudden spike in outbound throughput without corresponding inbound traffic` → Host Status
- **Analytic 1141** (Linux) — `auditd:SYSCALL Execution of spoofing tools (e.g., hping3, nping, scapy) sending UDP packets to known amplifier ports` → Command Execution; `NSM:Flow Outbound UDP floods targeting common reflection services with spoofed IP headers` → Network Traffic Flow; `sar:network Outbound network saturation with minimal process activity` → Host Status
- **Analytic 1142** (macOS) — `macos:unifiedlog Execution of ping, nping, or crafted network packets via bash or python to reflection services` → Process Creation; `macos:unifiedlog Outbound UDP spikes to external reflector IPs` → Network Traffic Flow
- **Analytic 1143** (IaaS) — `AWS:CloudTrail Create egress rule allowing UDP to port 53, 123, 11211` → Firewall Rule Modification; `AWS:VPCFlowLogs Large outbound UDP traffic to multiple public reflector IPs` → Network Traffic Flow; `AWS:CloudWatch Sudden spike in network output without a corresponding inbound request ratio` → Host Status
