# T1499.001 — OS Exhaustion Flood

<a id="t1499001"></a>

**Tactics:** impact  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1499.001](https://attack.mitre.org/techniques/T1499/001)  
**Sub-technique of:** [T1499 — Endpoint Denial of Service](/mitre/techniques/T1499.md)  

Adversaries may launch a denial of service (DoS) attack targeting an endpoint's operating system (OS). A system's OS is responsible for managing the finite resources as well as preventing the entire system from being overwhelmed by excessive demands on its capacity.

## Mitigations (1)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Endpoint DoS via OS Exhaustion Flood Detection Strategy

**Analytics (3):**

- **Analytic 1012** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Microsoft-Windows-TCPIP Connection queue overflow or failure to allocate TCP state object` → Host Status; `NSM:Firewall High rate of inbound TCP SYN or ACK packets with missing 3-way handshake completion` → Network Traffic Content
- **Analytic 1013** (Linux) — `auditd:SYSCALL Invocation of packet generation tools (e.g., hping3, nping) or fork bombs` → Process Creation; `NSM:Flow High volumes of SYN/ACK packets with unacknowledged TCP handshakes` → Network Traffic Flow; `NSM:Flow TCP: possible SYN flood or backlog limit exceeded` → Host Status
- **Analytic 1014** (macOS) — `macos:unifiedlog network stack resource exhaustion, tcp_accept queue overflow, repeated resets` → Host Status; `macos:osquery Execution of flooding tools or compiled packet generators` → Process Creation; `NSM:Firewall Anomalous TCP SYN or ACK spikes from specific source or interface` → Network Traffic Content
