# T1499.002 — Service Exhaustion Flood

<a id="t1499002"></a>

**Tactics:** impact  
**Platforms:** Windows, IaaS, Linux, macOS  
**ATT&CK:** [T1499.002](https://attack.mitre.org/techniques/T1499/002)  
**Sub-technique of:** [T1499 — Endpoint Denial of Service](/mitre/techniques/T1499.md)  

Adversaries may target the different network services provided by systems to conduct a denial of service (DoS). Adversaries often target the availability of DNS and web services, however others have been targeted as well.

## Mitigations (1)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Detection Strategy for Endpoint DoS via Service Exhaustion Flood

**Analytics (4):**

- **Analytic 0489** (Windows) — `WinEventLog:Application Unexpected spikes in request volume, application-level errors, or thread pool exhaustion in web or API logs` → Application Log Content; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `Windows:perfmon Sustained CPU/memory exhaustion by service process (e.g., w3wp.exe)` → Host Status
- **Analytic 0490** (Linux) — `auditd:SYSCALL High frequency of accept(), read(), or SSL_read() syscalls tied to nginx/apache processes` → Process Access; `NSM:Flow Sudden spike in incoming flows to web service ports from single/multiple IPs` → Network Traffic Flow; `linux:syslog Repetitive HTTP 408, 500, or 503 errors logged within short timeframe` → Application Log Content
- **Analytic 0491** (macOS) — `macos:unifiedlog Web service process (e.g., httpd) entering crash loop or consuming excessive CPU` → Host Status; `macos:unifiedlog Rapid incoming TLS handshakes or HTTP requests in quick succession` → Network Traffic Content
- **Analytic 0492** (IaaS) — `AWS:CloudTrail AuthorizeSecurityGroupIngress` → Firewall Rule Modification; `AWS:VPCFlowLogs Unusual volume of inbound packets from single source across short time interval` → Network Traffic Flow; `AWS:CloudWatch Sustained spike in CPU usage on EC2 instance with web service role` → Host Status
