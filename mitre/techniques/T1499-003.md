# T1499.003 — Application Exhaustion Flood

<a id="t1499003"></a>

**Tactics:** impact  
**Platforms:** Windows, IaaS, Linux, macOS  
**ATT&CK:** [T1499.003](https://attack.mitre.org/techniques/T1499/003)  
**Sub-technique of:** [T1499 — Endpoint Denial of Service](/mitre/techniques/T1499.md)  

Adversaries may target resource intensive features of applications to cause a denial of service (DoS), denying availability to those applications. For example, specific features in web applications may be highly resource intensive. Repeated requests to those features may be able to exhaust system resources and deny access to the application or the server itself.

## Mitigations (1)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Application Exhaustion Flood Detection Across Platforms

**Analytics (4):**

- **Analytic 1165** (Windows) — `WinEventLog:Application High-frequency errors or hangs from resource-intensive application components (e.g., .NET, IIS, Office Suite)` → Application Log Content; `WinEventLog:Sysmon EventCode=1` → Process Creation; `Windows:perfmon Sudden spikes in CPU/Memory usage linked to specific application processes` → Host Status
- **Analytic 1166** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:syslog Error/warning logs from services indicating load spike or worker exhaustion` → Application Log Content; `NSM:Flow Sustained abnormal inbound request rate targeting application ports (e.g., 80/443/25)` → Network Traffic Content
- **Analytic 1167** (macOS) — `macos:unifiedlog Application errors or resource contention from excessive frontend or script invocation` → Application Log Content; `macos:osquery Rapid spawning of resource-heavy applications (e.g., Preview, Safari, Office)` → Process Creation
- **Analytic 1168** (IaaS) — `AWS:CloudWatch Elevated 5xx response rates in application logs or gateway layer` → Application Log Content; `AWS:CloudTrail InvokeFunction` → Cloud Service Metadata; `AWS:CloudMetrics Autoscaling, memory/cpu alarms, or instance unhealthiness` → Host Status
