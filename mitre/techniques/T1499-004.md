# T1499.004 — Application or System Exploitation

<a id="t1499004"></a>

**Tactics:** impact  
**Platforms:** Windows, IaaS, Linux, macOS  
**ATT&CK:** [T1499.004](https://attack.mitre.org/techniques/T1499/004)  
**Sub-technique of:** [T1499 — Endpoint Denial of Service](/mitre/techniques/T1499.md)  

Adversaries may exploit software vulnerabilities that can cause an application or system to crash and deny availability to users. Some systems may automatically restart critical applications and services when crashes occur, but they can likely be re-exploited to cause a persistent denial of service (DoS) condition. Adversaries may exploit known or zero-day vulnerabilities to crash applications and/or systems, which may also lead to dependent applications and/or systems to be in a DoS condition. Crashed or restarted applications or systems may also have other effects such as [Data Destruction](https://attack.mitre.org/techniques/T1485), [Firmware Corruption](https://attack.mitre.org/techniques/T1495), [Service Stop](https://attack.mitre.org/techniques/T1489) etc. which may further cause a DoS condition and deny availability to critical information, applications and/or systems.

## Mitigations (1)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Detection Strategy for Endpoint DoS via Application or System Exploitation

**Analytics (4):**

- **Analytic 0850** (Windows) — `WinEventLog:Application EventCode=1000` → Application Log Content; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:System EventCode=7031, 7034` → Service Creation
- **Analytic 0851** (Linux) — `auditd:SYSCALL Process segfault or abnormal termination after invoking vulnerable syscall sequence` → Process Termination; `journald:Application Segfault or crash log entry associated with specific application binary` → Application Log Content; `NSM:Flow Unusual request pattern leading up to service crash (e.g., malformed or oversized payload)` → Network Traffic Content
- **Analytic 0852** (macOS) — `macos:unifiedlog Crash log entries for a process receiving malformed input or known exploit patterns` → Application Log Content; `macos:unifiedlog Unusual child process tree indicating attempted recovery after crash` → Process Creation
- **Analytic 0853** (IaaS) — `AWS:CloudTrail TerminateInstances` → Instance Stop; `AWS:CloudWatch Repeated crash pattern within container or instance logs` → Application Log Content; `AWS:VPCFlowLogs Large volume of malformed or synthetic payloads to application endpoints prior to failure` → Network Traffic Content
