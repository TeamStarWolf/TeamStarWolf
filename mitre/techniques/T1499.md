# T1499 — Endpoint Denial of Service

<a id="t1499"></a>

**Tactics:** impact  
**Platforms:** Windows, Linux, macOS, Containers, IaaS  
**ATT&CK:** [T1499](https://attack.mitre.org/techniques/T1499)  

Adversaries may perform Endpoint Denial of Service (DoS) attacks to degrade or block the availability of services to users. Endpoint DoS can be performed by exhausting the system resources those services are hosted on or exploiting the system to cause a persistent crash condition.

## Mitigations (1)

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md)

## Detection

**Detection strategies:**

- Endpoint Resource Saturation and Crash Pattern Detection Across Platforms

**Analytics (5):**

- **Analytic 0584** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Application Service crash, unhandled exception, or application hang warnings for critical services (e.g., IIS, DNS, SQL Server)` → Application Log Content; `WinEventLog:System System shutdowns due to bugcheck (Event ID 1001) or watchdog timer expirations` → Host Status
- **Analytic 0585** (Linux) — `auditd:SYSCALL execve` → Process Creation; `linux:syslog Out of memory killer invoked or kernel panic entries` → Host Status; `journald:systemd Repeated service restart attempts or unit failures` → Application Log Content
- **Analytic 0586** (macOS) — `macos:unifiedlog Repeated process crashes logged by CrashReporter or system instability logs in com.apple.console` → Application Log Content; `macos:unifiedlog Spike in CPU or memory use from non-user-initiated processes` → Host Status
- **Analytic 0587** (IaaS) — `AWS:CloudWatch StatusCheckFailed or StatusCheckFailed_System for burstable instances (t2/t3)` → Host Status; `AWS:CloudTrail StartInstances` → Instance Start; `VPCFlowLogs:All High volume internal traffic with low entropy indicating looped or malicious DoS script` → Network Traffic Flow
- **Analytic 0588** (Containers) — `kubernetes:events CrashLoopBackOff, OOMKilled, container restart count exceeds threshold` → Host Status; `docker:events Container exited with non-zero code repeatedly in short period` → Application Log Content
