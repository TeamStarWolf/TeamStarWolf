# T1505.001 — SQL Stored Procedures

<a id="t1505001"></a>

**Tactics:** persistence  
**Platforms:** Windows, Linux  
**ATT&CK:** [T1505.001](https://attack.mitre.org/techniques/T1505/001)  
**Sub-technique of:** [T1505 — Server Software Component](/mitre/techniques/T1505.md)  

Adversaries may abuse SQL stored procedures to establish persistent access to systems. SQL Stored Procedures are code that can be saved and reused so that database users do not waste time rewriting frequently used SQL queries.

## Detection

**Detection strategies:**

- Detection Strategy for SQL Stored Procedures Abuse via T1505.001

**Analytics (2):**

- **Analytic 0511** (Windows) — `WinEventLog:Application Stored procedure creation, modification, or xp_cmdshell invocation via SQL logs or SQL Server auditing` → Script Execution; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Application CLR Assembly creation, loading, or modification logs via MSSQL CLR integration` → Module Load
- **Analytic 0512** (Linux) — `auditd:SYSCALL execve` → Process Creation; `ApplicationLogs:SQL Stored procedure creation or modification with shell invocation (e.g., system(), exec())` → Script Execution
