# T1505.002 — Transport Agent

<a id="t1505002"></a>

**Tactics:** persistence  
**Platforms:** Linux, Windows  
**ATT&CK:** [T1505.002](https://attack.mitre.org/techniques/T1505/002)  
**Sub-technique of:** [T1505 — Server Software Component](/mitre/techniques/T1505.md)

- **Analytic 0472** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Application Exchange Transport Service loads unusual .NET assembly or errors upon transport agent execution` → Application Log Content; `WinEventLog:Sysmon EventCode=11` → File Creation
