# T1505.006 — vSphere Installation Bundles

<a id="t1505006"></a>

**Tactics:** persistence  
**Platforms:** ESXi  
**ATT&CK:** [T1505.006](https://attack.mitre.org/techniques/T1505/006)  
**Sub-technique of:** [T1505 — Server Software Component](/mitre/techniques/T1505.md)  

Adversaries may abuse vSphere Installation Bundles (VIBs) to establish persistent access to ESXi hypervisors. VIBs are collections of files used for software distribution and virtual system management in VMware environments.

## Mitigations (3)

- [M1045 — Code Signing](/mitre/mitigations/M1045.md) — Code Signing is a security process that ensures the authenticity and integrity of software by digitally signing executables, scripts, and other code artifacts.
- [M1046 — Boot Integrity](/mitre/mitigations/M1046.md) — Boot Integrity ensures that a system starts securely by verifying the integrity of its boot process, operating system, and associated components.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Detect Abuse of vSphere Installation Bundles (VIBs) for Persistent Access

**Analytics (1):**

- **Analytic 1475** (ESXi) — `esxi:esxupdate /var/log/esxupdate.log contains VIB installed with `--force` or `--no-sig-check` and non-standard acceptance levels` → Application Log Content; `esxi:shell `esxcli software vib install` with `--force` or `--no-sig-check` from shell history or `shell.log`` → Command Execution; `linux:fim Changes to /etc/rc.local.d/local.sh or creation of unexpected startup files in persistent partitions (/etc/init.d, /store, /locker)` → File Modification
