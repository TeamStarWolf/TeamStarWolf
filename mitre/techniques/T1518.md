# T1518 — Software Discovery

<a id="t1518"></a>

**Tactics:** discovery  
**Platforms:** ESXi, IaaS, Linux, macOS, Windows  
**ATT&CK:** [T1518](https://attack.mitre.org/techniques/T1518)  

Adversaries may attempt to get a listing of software and software versions that are installed on a system or in a cloud environment. Adversaries may use the information from [Software Discovery](https://attack.mitre.org/techniques/T1518) during automated discovery to shape follow-on behaviors, including whether or not the adversary fully infects the target and/or attempts specific actions. Such software may be deployed widely across the environment for configuration management or security reasons, such as [Software Deployment Tools](https://attack.mitre.org/techniques/T1072), and may allow adversaries broad access to infect devices or move laterally. Adversaries may attempt to enumerate software for a variety of reasons, such as figuring out what security measures are present or if the compromised system has a version of software that is vulnerable to [Exploitation for Privilege Escalation](https://attack.mitre.org/techniques/T1068).

## Detection

**Detection strategies:**

- Multi-Platform Software Discovery Behavior Chain

**Analytics (5):**

- **Analytic 1100** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:PowerShell Execution of 'Get-WmiObject Win32_Product' or similar PowerShell cmdlets` → Command Execution
- **Analytic 1101** (Linux) — `auditd:SYSCALL Execution of dpkg, rpm, or other package manager with list flag` → Process Creation; `linux:shell Manual invocation of software enumeration commands via interactive shell` → Command Execution
- **Analytic 1102** (macOS) — `macos:unifiedlog Execution of system_profiler or osascript invoking enumeration` → Process Creation; `auditd:SYSCALL Command line arguments including SPApplicationsDataType` → Command Execution
- **Analytic 1103** (IaaS) — `AWS:CloudTrail ssm:ListInventoryEntries` → Cloud Service Enumeration; `AWS:CloudTrail ssm:GetCommandInvocation` → Command Execution
- **Analytic 1104** (ESXi) — `esxi:shell esxcli software vib list` → Command Execution; `esxi:hostd Host daemon command log entries related to vib enumeration` → Application Log Content
