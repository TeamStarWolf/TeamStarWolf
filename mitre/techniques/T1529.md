# T1529 — System Shutdown/Reboot

<a id="t1529"></a>

**Tactics:** impact  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1529](https://attack.mitre.org/techniques/T1529)  

Adversaries may shutdown/reboot systems to interrupt access to, or aid in the destruction of, those systems. Operating systems may contain commands to initiate a shutdown/reboot of a machine or network device.

## Detection

**Detection strategies:**

- Multi-Platform Shutdown or Reboot Detection via Execution and Host Status Events

**Analytics (5):**

- **Analytic 1538** (Windows) — `WinEventLog:Security EventCode=1074` → Host Status; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1539** (Linux) — `auditd:SYSCALL execve=/sbin/shutdown or /sbin/reboot` → Command Execution; `linux:syslog system is powering down` → Host Status
- **Analytic 1540** (macOS) — `macos:unifiedlog shutdown -h now or reboot` → Process Creation; `macos:unifiedlog System shutdown or reboot requested` → Host Status
- **Analytic 1541** (ESXi) — `esxi:hostd Powering off or restarting host` → Host Status; `esxi:shell esxcli system shutdown or reboot invoked` → Command Execution
- **Analytic 1542** (Network Devices) — `networkdevice:syslog reload command issued` → Command Execution; `networkdevice:syslog System reboot scheduled or performed` → Host Status

## Data sources & telemetry (3)

**Host Status**, **Process Creation**, **Command Execution**

## Adversary usage

**Threat groups (4):** [Lazarus Group](https://attack.mitre.org/groups/G0032), [APT37](https://attack.mitre.org/groups/G0067), [APT38](https://attack.mitre.org/groups/G0082), [Medusa Group](https://attack.mitre.org/groups/G1051)

_Notable groups seen using this technique:_

- [Lazarus Group](https://attack.mitre.org/groups/G0032) (aka Labyrinth Chollima, HIDDEN COBRA, Guardians of Peace, ZINC) — Lazarus Group is a North Korean state-sponsored cyber threat group attributed to the Reconnaissance General Bureau (RGB).
- [APT37](https://attack.mitre.org/groups/G0067) (aka InkySquid, ScarCruft, Reaper, Group123) — APT37 is a North Korean state-sponsored cyber espionage group that has been active since at least 2012. The group has targeted victims primarily in South Korea, but also in Japan, Vietnam, Russia, Nepal, China, India…
- [APT38](https://attack.mitre.org/groups/G0082) (aka NICKEL GLADSTONE, BeagleBoyz, Bluenoroff, Stardust Chollima) — APT38 is a North Korean state-sponsored threat group that specializes in financial cyber operations; it has been attributed to the Reconnaissance General Bureau.
- [Medusa Group](https://attack.mitre.org/groups/G1051) — Medusa Group has been active since at least 2021 and was initially operated as a closed ransomware group before evolving into a Ransomware-as-a-Service (RaaS) operation.
