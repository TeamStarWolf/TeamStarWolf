# T1530 — Data from Cloud Storage

<a id="t1530"></a>

**Tactics:** collection  
**Platforms:** IaaS, Office Suite, SaaS  
**ATT&CK:** [T1530](https://attack.mitre.org/techniques/T1530)  

Adversaries may access data from cloud storage. Many IaaS providers offer solutions for online data object storage such as Amazon S3, Azure Storage, and Google Cloud Storage.

## Detection

**Detection strategies:**

- Multi-Platform Cloud Storage Exfiltration Behavior Chain

**Analytics (3):**

- **Analytic 1328** (IaaS) — `AWS:CloudTrail GetObject, CopyObject` → Cloud Storage Access; `AWS:CloudTrail AssumeRole` → User Account Metadata; `AWS:VPCFlowLogs Unusual volume of data transferred from S3 storage endpoints to non-corporate IPs` → Network Traffic Content
- **Analytic 1329** (SaaS) — `m365:unified FileAccessed, FileDownloaded, ConsentGranted` → Cloud Storage Access
- **Analytic 1330** (Office Suite) — `m365:sharepoint AnonymousLinkCreated, FileDownloaded` → Cloud Storage Access; `azure:signinlogs SigninSuccess` → User Account Authentication
