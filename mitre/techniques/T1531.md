# T1531: Account Access Removal

<a id="t1531"></a>

Tactics: impact  
Platforms: Linux, macOS, Windows, SaaS, IaaS, Office Suite, ESXi  
ATT&CK: [T1531](https://attack.mitre.org/techniques/T1531)  

Adversaries may interrupt availability of system and network resources by inhibiting access to accounts utilized by legitimate users. Accounts may be deleted, locked, or manipulated (ex: changed credentials, revoked permissions for SaaS platforms such as Sharepoint) to remove access to accounts. Adversaries may also subsequently log off and/or perform a [System Shutdown/Reboot](https://attack.mitre.org/techniques/T1529) to set malicious changes into place. In Windows, [Net](https://attack.mitre.org/software/S0039) utility, <code>Set-LocalUser</code> and <code>Set-ADAccountPassword</code> [PowerShell](https://attack.mitre.org/techniques/T1059/001) cmdlets may be used by adversaries to modify user accounts. Accounts could also be disabled by Group Policy. In Linux, the <code>passwd</code> utility may be used to change passwords. On ESXi servers, accounts can be removed or modified via esxcli (`system account set`, `system account remove`). Adversaries who use ransomware or similar attacks may first perform this and other Impact behaviors, such as [Data Destruction](https://attack.mitre.org/techniques/T1485) and [Defacement](https://attack.mitre.org/techniques/T1491), in order to impede incident response/recovery before completing the [Data Encrypted for Impact](https://attack.mitre.org/techniques/T1486) objective.

## D3FEND countermeasures (7)

- [Access Modeling](/mitre/d3fend/access-modeling.md) (Model): maps. Access modeling captures and records the access permissions granted to identities (e.g., administrators, users, groups, systems) and optionally includes details on how these identities are stored, managed, and shared across systems.
- [Account Locking](/mitre/d3fend/account-locking.md) (Evict): disables. The process of temporarily disabling user accounts on a system or domain.
- [Agent Authentication](/mitre/d3fend/agent-authentication.md) (Harden): strengthens. Agent authentication is the process of verifying the identities of agents to ensure they are authorized and trustworthy participants within a system.
- [Change Default Password](/mitre/d3fend/change-default-password.md) (Harden): strengthens. Changing the default password means replacing the factory-set credentials with a strong, unique password before the device is deployed, preventing unauthorized access.
- [Restore User Account Access](/mitre/d3fend/restore-user-account-access.md) (Restore): restores. Restoring a user account's access to resources.
- [Unlock Account](/mitre/d3fend/unlock-account.md) (Restore): restores. Restoring a user account's access to resources by unlocking a locked User Account.
- [User Account Permissions](/mitre/d3fend/user-account-permissions.md) (Isolate): restricts. Restricting a user account's access to resources.

## Detection

Detection strategies:

- Account Access Removal via Multi-Platform Audit Correlation

Analytics (6):

- Analytic 0334 (Windows): `WinEventLog:Security EventCode=4723, 4724, 4740` -> User Account Modification; `WinEventLog:Sysmon EventCode=1` -> Process Creation
- Analytic 0335 (Linux): `auditd:SYSCALL SYSCALL record where exe contains passwd/userdel/chage and auid != root` -> Process Creation; `NSM:Connections Accepted password or publickey for user from remote IP` -> User Account Authentication
- Analytic 0336 (macOS): `macos:unifiedlog command includes dscl . delete or sysadminctl --deleteUser` -> Command Execution; `macos:unifiedlog successful sudo or authentication for account not normally associated with admin actions` -> User Account Authentication
- Analytic 0337 (ESXi): `esxi:hostd method=RemoveUser or esxcli system account remove invocation` -> User Account Deletion; `esxi:vpxa user login from unexpected IP or non-admin user role` -> User Account Authentication
- Analytic 0338 (Office Suite): `m365:unified Remove-Mailbox, Set-Mailbox` -> User Account Deletion; `m365:signinlogs Sign-in from anomalous location or impossible travel condition` -> User Account Authentication
- Analytic 0339 (SaaS): `saas:okta user.lifecycle.delete, user.account.lock` -> User Account Modification

## Adversary usage

Threat groups (2): [LAPSUS$](/mitre/groups/G1004.md), [Akira](/mitre/groups/G1024.md)

_Notable groups seen using this technique:_

- [LAPSUS$](/mitre/groups/G1004.md) (aka DEV-0537, Strawberry Tempest): [LAPSUS$](https://attack.mitre.org/groups/G1004) is cyber criminal threat group that has been active since at least mid-2021.
- [Akira](/mitre/groups/G1024.md) (aka GOLD SAHARA, PUNK SPIDER, Howling Scorpius): [Akira](https://attack.mitre.org/groups/G1024) is a ransomware variant and ransomware deployment entity active since at least March 2023.(Citation: Arctic Wolf Akira 2023) [Akira](https://attack.mitre.org/groups/G1024) uses compromised credentials to access single-factor external access mechanisms such as VPNs for initial access, then various publicly-available tools and techniques for lateral movement.(Citation: Arctic Wolf Akira 2023)(Citation: Secureworks GOLD SAHARA) [Akira](https://attack.mitre.org/groups/G1024) operations are associated with "double extortion" ransomware activity, where data is exfiltrated from victim environments prior to encryption, with threats to publish files if a ransom is not paid.
