# T1534 — Internal Spearphishing

<a id="t1534"></a>

**Tactics:** lateral-movement  
**Platforms:** Windows, macOS, Linux, SaaS, Office Suite  
**ATT&CK:** [T1534](https://attack.mitre.org/techniques/T1534)  

After they already have access to accounts or systems within the environment, adversaries may use internal spearphishing to gain access to additional information or compromise other users within the same organization.

## Detection

**Detection strategies:**

- Internal Spearphishing via Trusted Accounts

**Analytics (5):**

- **Analytic 0147** (Windows) — `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:Security EventCode=4625` → User Account Authentication; `WinEventLog:Security EventCode=4672` → Logon Session Metadata; `m365:unified SendOnBehalf, MessageSend, ClickThrough, MailItemsAccessed` → Application Log Content; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0148** (Linux) — `auditd:SYSCALL execve` → Process Creation; `Application:Mail smtpd$.*$: .*from=[.*@internaldomain.com](mailto:.*@internaldomain.com) to=[.*@internaldomain.com](mailto:.*@internaldomain.com)` → Application Log Content; `linux:syslog curl|wget|python .*http` → Network Traffic Content
- **Analytic 0149** (macOS) — `macos:unifiedlog com.apple.mail.* exec.*` → Process Creation; `macos:unifiedlog curl|osascript.*open location` → Network Traffic Content
- **Analytic 0150** (SaaS) — `saas:slack file_upload, message_send, message_click` → Application Log Content
- **Analytic 0151** (Office Suite) — `m365:unified SendOnBehalf, MessageSend, AttachmentPreviewed` → Application Log Content; `WinEventLog:Security EventCode=4103, 4104, 4105, 4106` → Command Execution

## Adversary usage

**Threat groups (4):** [Gamaredon Group](https://attack.mitre.org/groups/G0047), [Leviathan](https://attack.mitre.org/groups/G0065), [Kimsuky](https://attack.mitre.org/groups/G0094), [HEXANE](https://attack.mitre.org/groups/G1001)

_Notable groups seen using this technique:_

- [Gamaredon Group](https://attack.mitre.org/groups/G0047) (aka IRON TILDEN, Primitive Bear, ACTINIUM, Armageddon) — Gamaredon Group is a suspected Russian cyber espionage group that has targeted military, law enforcement, judiciary, non-profit, and non-governmental organizations in Ukraine since at least 2013.
- [Leviathan](https://attack.mitre.org/groups/G0065) (aka MUDCARP, Kryptonite Panda, Gadolinium, BRONZE MOHAWK) — Leviathan is a Chinese state-sponsored cyber espionage group that has been attributed to the Ministry of State Security's (MSS) Hainan State Security Department and an affiliated front company.
- [Kimsuky](https://attack.mitre.org/groups/G0094) (aka Black Banshee, Velvet Chollima, Emerald Sleet, THALLIUM) — Kimsuky is a North Korea-based cyber espionage group that has been active since at least 2012.
- [HEXANE](https://attack.mitre.org/groups/G1001) (aka Lyceum, Siamesekitten, Spirlin) — HEXANE is a cyber espionage threat group that has targeted oil & gas, telecommunications, aviation, and internet service provider organizations since at least 2017.
