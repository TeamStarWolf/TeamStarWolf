# T1535 — Unused/Unsupported Cloud Regions

<a id="t1535"></a>

**Tactics:** defense-evasion  
**Platforms:** IaaS  
**ATT&CK:** [T1535](https://attack.mitre.org/techniques/T1535)  

Adversaries may create cloud instances in unused geographic service regions in order to evade detection. Access is usually obtained through compromising accounts used to manage cloud infrastructure.

## Mitigations (1)

- [M1054 — Software Configuration](/mitre/mitigations/M1054.md)

## Detection

**Detection strategies:**

- Detection of Adversary Use of Unused or Unsupported Cloud Regions (IaaS)

**Analytics (1):**

- **Analytic 0690** (IaaS) — `AWS:CloudTrail RunInstances` → Instance Start; `AWS:CloudTrail CreateBucket` → Cloud Storage Creation; `CloudTrail:GetCallerIdentity GetCallerIdentity` → User Account Metadata; `AWS:VPCFlowLogs High outbound traffic from new region resource` → Network Connection Creation

## Data sources & telemetry (4)

**Instance Start**, **Cloud Storage Creation**, **User Account Metadata**, **Network Connection Creation**
