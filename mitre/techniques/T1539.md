# T1539 — Steal Web Session Cookie

<a id="t1539"></a>

**Tactics:** credential-access  
**Platforms:** Linux, Office Suite, SaaS, Windows, macOS  
**ATT&CK:** [T1539](https://attack.mitre.org/techniques/T1539)  

An adversary may steal web application or service session cookies and use them to gain access to web applications or Internet services as an authenticated user without needing credentials. Web applications and services often use session cookies as an authentication token after a user has authenticated to a website.

## Detection

**Detection strategies:**

- Detection of Web Session Cookie Theft via File, Memory, and Network Artifacts

**Analytics (5):**

- **Analytic 1402** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=2` → File Modification; `WinEventLog:Security EventCode=4688` → Process Creation
- **Analytic 1403** (Linux) — `auditd:SYSCALL open or read to browser cookie storage` → File Access; `auditd:SYSCALL ptrace syscall or access to /proc/*/mem` → Process Access
- **Analytic 1404** (macOS) — `macos:unifiedlog vm_read, task_for_pid, or file open to cookie databases` → Process Access; `fs:fsusage file open for known browser cookie paths` → File Access
- **Analytic 1405** (Office Suite) — `m365:unified RunMacro` → Application Log Content; `WinEventLog:Sysmon EventCode=2` → File Modification
- **Analytic 1406** (SaaS) — `saas:googleworkspace login with reused session token and mismatched user agent or IP` → User Account Authentication; `saas:okta session.token.reuse` → Logon Session Creation
