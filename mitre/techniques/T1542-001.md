# T1542.001 — System Firmware

<a id="t1542001"></a>

**Tactics:** persistence, defense-evasion  
**Platforms:** Windows, Network Devices  
**ATT&CK:** [T1542.001](https://attack.mitre.org/techniques/T1542/001)  
**Sub-technique of:** [T1542 — Pre-OS Boot](/mitre/techniques/T1542.md)  

Adversaries may modify system firmware to persist on systems.The BIOS (Basic Input/Output System) and The Unified Extensible Firmware Interface (UEFI) or Extensible Firmware Interface (EFI) are examples of system firmware that operate as the software interface between the operating system and hardware of a computer.

**Detection strategies:**

- Detection Strategy for T1542.001 Pre-OS Boot: System Firmware

**Analytics (2):**

- **Analytic 0275** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=9` → Drive Access; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 0276** (Network Devices) — `networkdevice:config Boot image path or firmware configuration variable modified outside of maintenance windows` → Firmware Modification; `networkdevice:runtime Firmware image uploaded via TFTP/FTP/SCP` → Drive Modification
