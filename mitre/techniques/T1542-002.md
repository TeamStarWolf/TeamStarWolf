# T1542.002 — Component Firmware

<a id="t1542002"></a>

**Tactics:** persistence, defense-evasion  
**Platforms:** Windows, Linux, macOS  
**ATT&CK:** [T1542.002](https://attack.mitre.org/techniques/T1542/002)  
**Sub-technique of:** [T1542 — Pre-OS Boot](/mitre/techniques/T1542.md)  

Adversaries may modify component firmware to persist on systems. Some adversaries may employ sophisticated means to compromise computer components and install malicious firmware that will execute adversary code outside of the operating system and main system firmware or BIOS.

**Analytics (3):**

- **Analytic 0916** (Windows) — `WinEventLog:Sysmon EventCode=6` → Driver Load; `firmware:integrity  Firmware integrity verification failures or mismatches against expected UEFI/firmware image baselines` → Firmware Modification
- **Analytic 0917** (Linux) — `auditd:SYSCALL ioctl/write: Direct firmware update or device memory manipulation syscalls` → Firmware Modification; `linux:syslog Driver load events or firmware load failures for hardware devices` → Driver Load
- **Analytic 0918** (macOS) — `macos:unifiedlog Firmware update events or kernel extension (kext) loads not signed by Apple` → Firmware Modification
