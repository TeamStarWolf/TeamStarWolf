# T1543.001 — Launch Agent

<a id="t1543001"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** macOS  
**ATT&CK:** [T1543.001](https://attack.mitre.org/techniques/T1543/001)  
**Sub-technique of:** [T1543 — Create or Modify System Process](/mitre/techniques/T1543.md)  

Adversaries may create or modify launch agents to repeatedly execute malicious payloads as part of persistence.

## Mitigations (1)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.

## Detection

**Detection strategies:**

- Detection of Launch Agent Creation or Modification on macOS

**Analytics (1):**

- **Analytic 1208** (macOS) — `macos:unifiedlog launchctl load or boot-time plist registration` → Command Execution; `fs:fsusage write or chmod to ~/Library/LaunchAgents/*.plist` → File Creation; `fs:fsusage modification of existing LaunchAgents plist` → File Modification; `macos:osquery detection of new launch agents with suspicious paths or unsigned binaries` → Service Creation
