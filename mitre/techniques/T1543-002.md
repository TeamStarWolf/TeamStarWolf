# T1543.002 — Systemd Service

<a id="t1543002"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Linux  
**ATT&CK:** [T1543.002](https://attack.mitre.org/techniques/T1543/002)  
**Sub-technique of:** [T1543 — Create or Modify System Process](/mitre/techniques/T1543.md)  

Adversaries may create or modify systemd services to repeatedly execute malicious payloads as part of persistence. Systemd is a system and service manager commonly used for managing background daemon processes (also known as services) and other system resources.

## Detection

**Detection strategies:**

- Detection of Systemd Service Creation or Modification on Linux

**Analytics (1):**

- **Analytic 0701** (Linux) — `auditd:SYSCALL write, open, or rename to /etc/systemd/system/*.service` → File Creation; `auditd:SYSCALL modification of existing .service file` → File Modification; `auditd:SYSCALL execution of systemctl or service with enable/start parameters` → Command Execution; `auditd:SYSCALL fork/exec of service via PID 1 (systemd)` → Process Creation; `linux:osquery newly registered unit file with ExecStart pointing to unknown binary` → Service Creation
