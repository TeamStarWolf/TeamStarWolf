# T1543.004 — Launch Daemon

<a id="t1543004"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** macOS  
**ATT&CK:** [T1543.004](https://attack.mitre.org/techniques/T1543/004)  
**Sub-technique of:** [T1543 — Create or Modify System Process](/mitre/techniques/T1543.md)  

Adversaries may create or modify Launch Daemons to execute malicious payloads as part of persistence. Launch Daemons are plist files used to interact with Launchd, the service management framework used by macOS.

## Detection

**Detection strategies:**

- Detection Strategy for Launch Daemon Creation or Modification (macOS)

**Analytics (1):**

- **Analytic 1126** (macOS) — `macos:unifiedlog launchd spawning processes tied to new or modified LaunchDaemon .plist entries` → Process Creation; `fs:launchdaemons file_create` → File Creation; `fs:launchdaemons file_modify` → File Modification; `macos:unifiedlog launchd loading new LaunchDaemon or changes to existing daemon configuration` → Service Creation
