# T1546.003 — Windows Management Instrumentation Event Subscription

<a id="t1546003"></a>

**Tactics:** privilege-escalation, persistence  
**Platforms:** Windows  
**ATT&CK:** [T1546.003](https://attack.mitre.org/techniques/T1546/003)  
**Sub-technique of:** [T1546 — Event Triggered Execution](/mitre/techniques/T1546.md)  

Adversaries may establish persistence and elevate privileges by executing malicious content triggered by a Windows Management Instrumentation (WMI) event subscription. WMI can be used to install event filters, providers, consumers, and bindings that execute code when a defined event occurs.

## Detection

**Detection strategies:**

- Detect WMI Event Subscription for Persistence via WmiPrvSE Process and MOF Compilation

**Analytics (1):**

- **Analytic 0236** (Windows) — `WinEventLog:WMI EventCode=5857, 5858, 5860, 5861` → WMI Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load
