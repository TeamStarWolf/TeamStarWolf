# T1546.004 — Unix Shell Configuration Modification

<a id="t1546004"></a>

**Tactics:** privilege-escalation, persistence  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1546.004](https://attack.mitre.org/techniques/T1546/004)  
**Sub-technique of:** [T1546 — Event Triggered Execution](/mitre/techniques/T1546.md)  

Adversaries may establish persistence through executing malicious commands triggered by a user’s shell. User Unix Shells execute several configuration scripts at different points throughout the session based on events.

## Mitigations (1)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.

## Detection

**Detection strategies:**

- Detect Shell Configuration Modification for Persistence via Event-Triggered Execution

**Analytics (2):**

- **Analytic 0059** (Linux) — `auditd:SYSCALL AUDIT_SYSCALL (open, write, rename, unlink)` → File Modification; `auditd:EXECVE execution of unexpected binaries during user shell startup` → Process Creation; `NSM:Flow unexpected network activity initiated shortly after shell session starts` → Network Traffic Content
- **Analytic 0060** (macOS) — `macos:unifiedlog launch of Terminal.app or shell with non-standard environment setup` → Process Creation; `macos:endpointsecurity ES_EVENT_TYPE_NOTIFY_WRITE, targeting .zshrc, .zlogin, .zprofile` → File Modification
