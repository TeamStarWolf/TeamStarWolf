# T1546.005 — Trap

<a id="t1546005"></a>

**Tactics:** privilege-escalation, persistence  
**Platforms:** macOS, Linux  
**ATT&CK:** [T1546.005](https://attack.mitre.org/techniques/T1546/005)  
**Sub-technique of:** [T1546 — Event Triggered Execution](/mitre/techniques/T1546.md)  

Adversaries may establish persistence by executing malicious content triggered by an interrupt signal. The <code>trap</code> command allows programs and shells to specify commands that will be executed upon receiving interrupt signals.

## Detection

**Detection strategies:**

- Detection Strategy for Event Triggered Execution via Trap (T1546.005)

**Analytics (2):**

- **Analytic 1038** (Linux) — `auditd:SYSCALL execve` → Process Creation; `auditd:SYSCALL Modification of user shell profile or trap registration via echo/redirection (e.g., echo "trap 'malicious_cmd' INT" >> ~/.bashrc)` → File Modification; `auditd:SYSCALL open` → File Access
- **Analytic 1039** (macOS) — `macos:unifiedlog Command line containing `trap` or `echo 'trap` written to login shell files` → Process Creation; `macos:unifiedlog File write or append to .zshrc, .bash_profile, .zprofile, etc.` → File Modification
