# T1546.008 — Accessibility Features

<a id="t1546008"></a>

**Tactics:** privilege-escalation, persistence  
**Platforms:** Windows  
**ATT&CK:** [T1546.008](https://attack.mitre.org/techniques/T1546/008)  
**Sub-technique of:** [T1546 — Event Triggered Execution](/mitre/techniques/T1546.md)  

Adversaries may establish persistence and/or elevate privileges by executing malicious content triggered by accessibility features. Windows contains accessibility features that may be launched with a key combination before a user has logged in (ex: when the user is on the Windows logon screen).

## Mitigations (3)

- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.
- [M1035 — Limit Access to Resource Over Network](/mitre/mitigations/M1035.md) — Restrict access to network resources, such as file shares, remote systems, and services, to only those users, accounts, or systems with a legitimate business requirement.
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.

## Detection

**Detection strategies:**

- Detection Strategy for Accessibility Feature Hijacking via Binary Replacement or Registry Modification

**Analytics (1):**

- **Analytic 0094** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=15` → File Metadata

## Adversary usage

**Threat groups (6):** [Axiom](https://attack.mitre.org/groups/G0001), [Deep Panda](https://attack.mitre.org/groups/G0009), [APT29](https://attack.mitre.org/groups/G0016), [APT3](https://attack.mitre.org/groups/G0022), [APT41](https://attack.mitre.org/groups/G0096), [Fox Kitten](https://attack.mitre.org/groups/G0117)

_Notable groups seen using this technique:_

- [Axiom](https://attack.mitre.org/groups/G0001) (aka Group 72) — Axiom is a suspected Chinese cyber espionage group that has targeted the aerospace, defense, government, manufacturing, and media sectors since at least 2008.
- [Deep Panda](https://attack.mitre.org/groups/G0009) (aka Shell Crew, WebMasters, KungFu Kittens, PinkPanther) — Deep Panda is a suspected Chinese threat group known to target many industries, including government, defense, financial, and telecommunications.
- [APT29](https://attack.mitre.org/groups/G0016) (aka IRON RITUAL, IRON HEMLOCK, NobleBaron, Dark Halo) — APT29 is threat group that has been attributed to Russia's Foreign Intelligence Service (SVR).
- [APT3](https://attack.mitre.org/groups/G0022) (aka Gothic Panda, Pirpi, UPS Team, Buckeye) — APT3 is a China-based threat group that researchers have attributed to China's Ministry of State Security.
- [APT41](https://attack.mitre.org/groups/G0096) (aka Wicked Panda, Brass Typhoon, BARIUM) — APT41 is a threat group that researchers have assessed as Chinese state-sponsored espionage group that also conducts financially-motivated operations.
- [Fox Kitten](https://attack.mitre.org/groups/G0117) (aka UNC757, Parisite, Pioneer Kitten, RUBIDIUM) — Fox Kitten is threat actor with a suspected nexus to the Iranian government that has been active since at least 2017 against entities in the Middle East, North Africa, Europe, Australia, and North America.
