# T1546.010 — AppInit DLLs

<a id="t1546010"></a>

**Tactics:** privilege-escalation, persistence  
**Platforms:** Windows  
**ATT&CK:** [T1546.010](https://attack.mitre.org/techniques/T1546/010)  
**Sub-technique of:** [T1546 — Event Triggered Execution](/mitre/techniques/T1546.md)  

Adversaries may establish persistence and/or elevate privileges by executing malicious content triggered by AppInit DLLs loaded into processes.

**Detection strategies:**

- Detection Strategy for Event Triggered Execution: AppInit DLLs (Windows)

- **Analytic 1536** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
