# T1546.011 — Application Shimming

<a id="t1546011"></a>

**Tactics:** privilege-escalation, persistence  
**Platforms:** Windows  
**ATT&CK:** [T1546.011](https://attack.mitre.org/techniques/T1546/011)  
**Sub-technique of:** [T1546 — Event Triggered Execution](/mitre/techniques/T1546.md)  

Adversaries may establish persistence and/or elevate privileges by executing malicious content triggered by application shims.

## Mitigations (2)

- [M1051 — Update Software](/mitre/mitigations/M1051.md) — Software updates ensure systems are protected against known vulnerabilities by applying patches and upgrades provided by vendors.
- [M1052 — User Account Control](/mitre/mitigations/M1052.md) — User Account Control (UAC) is a security feature in Microsoft Windows that prevents unauthorized changes to the operating system.

## Detection

**Detection strategies:**

- Detection Strategy for Application Shimming via sdbinst.exe and Registry Artifacts (Windows)

**Analytics (1):**

- **Analytic 0051** (Windows) — `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=11` → File Creation
