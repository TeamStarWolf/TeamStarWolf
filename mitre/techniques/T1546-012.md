# T1546.012 — Image File Execution Options Injection

<a id="t1546012"></a>

**Tactics:** privilege-escalation, persistence  
**Platforms:** Windows  
**ATT&CK:** [T1546.012](https://attack.mitre.org/techniques/T1546/012)  
**Sub-technique of:** [T1546](/mitre/techniques/T1546.md)

Adversaries may establish persistence and/or elevate privileges by executing malicious content triggered by Image File Execution Options (IFEO) debuggers. IFEOs enable a developer to attach a debugger to an application.



## D3FEND countermeasures (3)

- **Data Inventory** (Model) — inventories
- **Restore Database** (Restore) — restores
- **System Configuration Permissions** (Harden) — restricts
