# T1546.013 — PowerShell Profile

<a id="t1546013"></a>

**Tactics:** privilege-escalation, persistence  
**Platforms:** Windows  
**ATT&CK:** [T1546.013](https://attack.mitre.org/techniques/T1546/013)  
**Sub-technique of:** [T1546 — Event Triggered Execution](/mitre/techniques/T1546.md)  

Adversaries may gain persistence and elevate privileges by executing malicious content triggered by PowerShell profiles. A PowerShell profile (<code>profile.ps1</code>) is a script that runs when PowerShell starts and can be used as a logon script to customize user environments.

## Detection

**Detection strategies:**

- Detection Strategy for PowerShell Profile Persistence via profile.ps1 Modification

**Analytics (1):**

- **Analytic 1245** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=2` → File Modification; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:PowerShell Execution of PowerShell without -NoProfile flag` → Command Execution
