# T1546.017 — Udev Rules

<a id="t1546017"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Linux  
**ATT&CK:** [T1546.017](https://attack.mitre.org/techniques/T1546/017)  
**Sub-technique of:** [T1546 — Event Triggered Execution](/mitre/techniques/T1546.md)  

Adversaries may maintain persistence through executing malicious content triggered using udev rules.

## Detection

**Detection strategies:**

- Detection Strategy for T1546.017 - Udev Rules (Linux)

**Analytics (1):**

- **Analytic 1056** (Linux) — `auditd:SYSCALL chmod, write, create, open` → File Modification; `auditd:SYSCALL execve` → Process Creation; `auditd:CONFIG_CHANGE udev rule reload or trigger command executed` → Command Execution
