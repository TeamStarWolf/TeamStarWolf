# T1546.018 — Python Startup Hooks

<a id="t1546018"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1546.018](https://attack.mitre.org/techniques/T1546/018)  
**Sub-technique of:** [T1546](/mitre/techniques/T1546.md)

Adversaries may achieve persistence by leveraging Python’s startup mechanisms, including path configuration (`.pth`) files and the `sitecustomize.py` or `usercustomize.py` modules.



## Detection

- Linux Python Startup Hook Persistence via .pth and Customize Files (T1546.018)
