# T1546.018 — Python Startup Hooks

<a id="t1546018"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1546.018](https://attack.mitre.org/techniques/T1546/018)  
**Sub-technique of:** [T1546 — Event Triggered Execution](/mitre/techniques/T1546.md)  

Adversaries may achieve persistence by leveraging Python’s startup mechanisms, including path configuration (`.pth`) files and the `sitecustomize.py` or `usercustomize.py` modules.

## Detection

**Detection strategies:**

- Linux Python Startup Hook Persistence via .pth and Customize Files (T1546.018)

**Analytics (1):**

- **Analytic 0713** (Linux) — `auditd:SYSCALL execve: execve where exe=/usr/bin/python3 or similar interpreter` → Process Creation; `auditd:PATH write or create events on *.pth, sitecustomize.py, usercustomize.py in site-packages or dist-packages` → File Modification; `auditd:CONFIG_CHANGE chmod or chown of hook files indicating privilege escalation or execution permission change` → File Metadata; `NSM:Flow http::request: Outbound HTTP initiated by Python interpreter` → Network Traffic Content

## Data sources & telemetry (4)

**Process Creation**, **File Modification**, **File Metadata**, **Network Traffic Content**
