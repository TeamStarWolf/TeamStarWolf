# T1546 — Event Triggered Execution

<a id="t1546"></a>

**Tactics:** privilege-escalation, persistence  
**Platforms:** Linux, macOS, Windows, SaaS, IaaS, Office Suite  
**ATT&CK:** [T1546](https://attack.mitre.org/techniques/T1546)  

Adversaries may establish persistence and/or elevate privileges using system mechanisms that trigger execution based on specific events. Various operating systems have means to monitor and subscribe to events such as logons or other user activity such as running specific applications/binaries. Cloud environments may also support various functions and services that monitor and can be invoked in response to specific cloud events. Adversaries may abuse these mechanisms as a means of maintaining persistent access to a victim via repeatedly executing malicious code. After gaining access to a victim system, adversaries may create/modify event triggers to point to malicious content that will be executed whenever the event trigger is invoked. Since the execution can be proxied by an account with higher permissions, such as SYSTEM or service accounts, an adversary may be able to abuse these triggered execution mechanisms to escalate their privileges.

## Detection

**Detection strategies:**

- Behavioral Detection of Event Triggered Execution Across Platforms

**Analytics (6):**

- **Analytic 0024** (Windows) — `WinEventLog:Security EventCode=4698` → Scheduled Job Creation; `WinEventLog:WMI Creation or modification of __EventFilter, __FilterToConsumerBinding, or CommandLineEventConsumer` → WMI Creation; `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0025** (Linux) — `auditd:SYSCALL Inotify watch creation or auditctl changes on /etc/cron* or /lib/systemd/system/` → File Metadata; `linux:syslog Execution of non-standard script or binary by cron` → Scheduled Job Creation; `auditd:SYSCALL Execution of script interpreters by systemd timer (ExecStart)` → Command Execution
- **Analytic 0026** (macOS) — `macos:unifiedlog Modification of ~/Library/LaunchAgents or /Library/LaunchDaemons plist` → File Modification; `macos:unifiedlog Execution of launchctl with suspicious arguments` → Process Creation
- **Analytic 0027** (IaaS) — `AWS:CloudTrail CreateFunction` → Cloud Service Modification; `AWS:CloudTrail InvokeFunction` → Command Execution
- **Analytic 0028** (SaaS) — `m365:unified Creation of Power Automate flow triggered by OneDrive or Exchange event` → Cloud Service Modification; `m365:unified Automated forwarding or file sync initiated by a logic app` → Command Execution
- **Analytic 0029** (Office Suite) — `m365:office VBA auto_open, auto_close, or document_open events` → Script Execution; `m365:office External HTTP/DNS connection from Office binary shortly after macro trigger` → Network Traffic Content
