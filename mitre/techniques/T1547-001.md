# T1547.001 — Registry Run Keys / Startup Folder

<a id="t1547001"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1547.001](https://attack.mitre.org/techniques/T1547/001)  
**Sub-technique of:** [T1547 — Boot or Logon Autostart Execution](/mitre/techniques/T1547.md)  

Adversaries may achieve persistence by adding a program to a startup folder or referencing it with a Registry run key. Adding an entry to the "run keys" in the Registry or startup folder will cause the program referenced to be executed when a user logs in.

## Detection

**Detection strategies:**

- Detect Registry and Startup Folder Persistence (Windows)

**Analytics (1):**

- **Analytic 1032** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `WinEventLog:Microsoft-Windows-Shell-Core New startup folder shortcut or binary placed in Startup directory` → File Creation
