# T1547.007 — Re-opened Applications

<a id="t1547007"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** macOS  
**ATT&CK:** [T1547.007](https://attack.mitre.org/techniques/T1547/007)  
**Sub-technique of:** [T1547 — Boot or Logon Autostart Execution](/mitre/techniques/T1547.md)  

Adversaries may modify plist files to automatically run an application when a user logs in. When a user logs out or restarts via the macOS Graphical User Interface (GUI), a prompt is provided to the user with a checkbox to "Reopen windows when logging back in".

## Detection

**Detection strategies:**

- Detect persistence via reopened application plist modification (macOS)

**Analytics (1):**

- **Analytic 0349** (macOS) — `macos:unifiedlog Execution of process launched via loginwindow session restore` → Process Creation; `fs:filesystem Modification or creation of files matching 'com.apple.loginwindow.*.plist' in ~/Library/Preferences/ByHost` → File Modification; `macos:unifiedlog LoginWindow context with associated PID linked to reopened plist paths` → Logon Session Metadata; `macos:endpointsecurity es_event_file_rename_t or es_event_file_write_t` → File Metadata
