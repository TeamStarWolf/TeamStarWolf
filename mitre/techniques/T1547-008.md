# T1547.008 — LSASS Driver

<a id="t1547008"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1547.008](https://attack.mitre.org/techniques/T1547/008)  
**Sub-technique of:** [T1547 — Boot or Logon Autostart Execution](/mitre/techniques/T1547.md)  

Adversaries may modify or add LSASS drivers to obtain persistence on compromised systems. The Windows security subsystem is a set of components that manage and enforce the security policy for a computer or domain.

## Detection

**Detection strategies:**

- Detect unauthorized LSASS driver persistence via LSA plugin abuse (Windows)

**Analytics (1):**

- **Analytic 0629** (Windows) — `WinEventLog:Security EventCode=3033` → Module Load; `WinEventLog:Sysmon EventCode=6` → Driver Load; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=2` → File Modification; `WinEventLog:Sysmon EventCode=12` → Windows Registry Key Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
