# T1547.010 — Port Monitors

<a id="t1547010"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1547.010](https://attack.mitre.org/techniques/T1547/010)  
**Sub-technique of:** [T1547](/mitre/techniques/T1547.md)

Adversaries may use port monitors to run an adversary supplied DLL during system boot for persistence or privilege escalation. A port monitor can be set through the <code>AddMonitor</code> API call to set a DLL to be loaded at startup.



## D3FEND countermeasures (3)

- **Configuration Inventory** (Model) — inventories
- **Content Quarantine** (Isolate) — quarantines
- **Restore Configuration** (Restore) — restores
