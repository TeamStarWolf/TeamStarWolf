# T1547.012 — Print Processors

<a id="t1547012"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1547.012](https://attack.mitre.org/techniques/T1547/012)  
**Sub-technique of:** [T1547 — Boot or Logon Autostart Execution](/mitre/techniques/T1547.md)  

Adversaries may abuse print processors to run malicious DLLs during system boot for persistence and/or privilege escalation. Print processors are DLLs that are loaded by the print spooler service, `spoolsv.exe`, during boot.

## Mitigations (1)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
