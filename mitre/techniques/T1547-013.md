# T1547.013 — XDG Autostart Entries

<a id="t1547013"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Linux  
**ATT&CK:** [T1547.013](https://attack.mitre.org/techniques/T1547/013)  
**Sub-technique of:** [T1547 — Boot or Logon Autostart Execution](/mitre/techniques/T1547.md)  

Adversaries may add or modify XDG Autostart Entries to execute malicious programs or commands when a user’s desktop environment is loaded at login. XDG Autostart entries are available for any XDG-compliant Linux system.

## Mitigations (3)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1033 — Limit Software Installation](/mitre/mitigations/M1033.md) — Prevent users or groups from installing unauthorized or unapproved software to reduce the risk of introducing malicious or vulnerable applications.

**Analytics (1):**

- **Analytic 1096** (Linux) — `auditd:SYSCALL creat` → File Creation; `auditd:SYSCALL open` → File Access; `auditd:EXECVE Process execution via .desktop Exec path from /etc/xdg/autostart or ~/.config/autostart` → Process Creation; `linux:osquery Write or modify .desktop file in XDG autostart path` → File Metadata; `linux:auth User login event followed by unexpected process tree` → Logon Session Creation
