# T1547.014 — Active Setup

<a id="t1547014"></a>

**Tactics:** persistence, privilege-escalation  
**Platforms:** Windows  
**ATT&CK:** [T1547.014](https://attack.mitre.org/techniques/T1547/014)  
**Sub-technique of:** [T1547 — Boot or Logon Autostart Execution](/mitre/techniques/T1547.md)  

Adversaries may achieve persistence by adding a Registry key to the Active Setup of the local machine. Active Setup is a Windows mechanism that is used to execute programs when a user logs in. The value stored in the Registry key will be executed after a user logs into the computer.

## Detection

**Detection strategies:**

- Detect Active Setup Persistence via StubPath Execution

**Analytics (1):**

- **Analytic 0871** (Windows) — `WinEventLog:Security EventCode=4672` → Logon Session Metadata; `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=12` → Windows Registry Key Creation

## Data sources & telemetry (4)

**Logon Session Metadata**, **Process Creation**, **Windows Registry Key Modification**, **Windows Registry Key Creation**

## Adversary usage
