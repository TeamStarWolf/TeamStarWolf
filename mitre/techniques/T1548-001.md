# T1548.001 — Setuid and Setgid

<a id="t1548001"></a>

**Tactics:** privilege-escalation, defense-evasion  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1548.001](https://attack.mitre.org/techniques/T1548/001)  
**Sub-technique of:** [T1548 — Abuse Elevation Control Mechanism](/mitre/techniques/T1548.md)  

An adversary may abuse configurations where an application has the setuid or setgid bits set in order to get code running in a different (and possibly more privileged) user’s context.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **91 machines (17.2%)** — Linux 86 / Windows 3. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Detection

**Detection strategies:**

- Setuid/Setgid Privilege Abuse Detection (Linux/macOS)

**Analytics (2):**

- **Analytic 0307** (Linux) — `auditd:SYSCALL chmod, execve` → Command Execution; `auditd:SYSCALL execve` → Process Creation
- **Analytic 0308** (macOS) — `macos:unifiedlog chmod command with arguments including '+s', 'u+s', or numeric values 4000–6777` → Command Execution; `macos:unifiedlog exec of binary with setuid/setgid and EUID != UID` → Process Metadata
