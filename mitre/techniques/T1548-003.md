# T1548.003 — Sudo and Sudo Caching

<a id="t1548003"></a>

**Tactics:** privilege-escalation, defense-evasion  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1548.003](https://attack.mitre.org/techniques/T1548/003)  
**Sub-technique of:** [T1548 — Abuse Elevation Control Mechanism](/mitre/techniques/T1548.md)  

Adversaries may perform sudo caching and/or use the sudoers file to elevate privileges. Adversaries may do this to execute commands as other users or spawn processes with higher privileges.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **99 machines (18.7%)** — Linux 91 / Windows 1. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Detection

**Detection strategies:**

- Behavioral Detection Strategy for Abuse of Sudo and Sudo Caching

**Analytics (2):**

- **Analytic 0142** (Linux) — `auditd:SYSCALL execve call for sudo where euid != uid` → Process Metadata; `auditd:SYSCALL execve call for modification of /etc/sudoers or writing to /var/db/sudo` → File Modification
- **Analytic 0143** (macOS) — `macos:unifiedlog exec or sudo usage with NOPASSWD context or echo modifying sudoers` → Command Execution; `macos:unifiedlog Terminal process killed (killall Terminal) immediately after sudoers modification` → Process Termination
