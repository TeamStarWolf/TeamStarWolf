# T1548.005 — Temporary Elevated Cloud Access

<a id="t1548005"></a>

**Tactics:** privilege-escalation, defense-evasion  
**Platforms:** IaaS, Office Suite, Identity Provider  
**ATT&CK:** [T1548.005](https://attack.mitre.org/techniques/T1548/005)  
**Sub-technique of:** [T1548 — Abuse Elevation Control Mechanism](/mitre/techniques/T1548.md)  

Adversaries may abuse permission configurations that allow them to gain temporarily elevated access to cloud resources.

**Detection strategies:**

**Analytics (3):**

- **Analytic 1105** (IaaS) — `AWS:CloudTrail PassRole` → User Account Metadata
- **Analytic 1106** (Identity Provider) — `gcp:iam PrincipalEmail with serviceAccountTokenCreator impersonating new identity` → User Account Metadata; `gcp:workspaceaudit Token Generation via Domain Delegation` → User Account Authentication
- **Analytic 1107** (Office Suite) — `m365:unified Add-MailboxPermission or Set-ManagementRoleAssignment` → Application Log Content; `m365:signinlogs Unusual sign-in from service principal to user mailbox` → User Account Authentication
