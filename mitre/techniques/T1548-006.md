# T1548.006 — TCC Manipulation

<a id="t1548006"></a>

**Tactics:** defense-evasion, privilege-escalation  
**Platforms:** macOS  
**ATT&CK:** [T1548.006](https://attack.mitre.org/techniques/T1548/006)  
**Sub-technique of:** [T1548 — Abuse Elevation Control Mechanism](/mitre/techniques/T1548.md)  

Adversaries can manipulate or abuse the Transparency, Consent, & Control (TCC) service or database to grant malicious executables elevated permissions.

## Mitigations (3)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md)
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md)
- [M1047 — Audit](/mitre/mitigations/M1047.md)

## Detection

**Detection strategies:**

- TCC Database Manipulation via Launchctl and Unprotected SIP

**Analytics (1):**

- **Analytic 1474** (macOS) — `macos:unifiedlog Execution of binaries with TCC protected access under unexpected parent processes such as Finder.app, SystemUIServer, or nsurlsessiond` → Process Creation; `macos:unifiedlog Modification or replacement of /Library/Application Support/com.apple.TCC/TCC.db or ~/Library/Application Support/com.apple.TCC/TCC.db` → File Modification; `macos:unifiedlog Execution of launchctl with setenv or bootout targeting TCC.db or AppleScript under Finder context` → Command Execution; `macos:unifiedlog System Integrity Protection (SIP) state reported as disabled` → Host Status

## Data sources & telemetry (4)
