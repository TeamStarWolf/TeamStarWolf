# T1548 — Abuse Elevation Control Mechanism

<a id="t1548"></a>

**Tactics:** privilege-escalation, defense-evasion  
**Platforms:** Linux, macOS, Windows, IaaS, Office Suite, Identity Provider  
**ATT&CK:** [T1548](https://attack.mitre.org/techniques/T1548)  

Adversaries may circumvent mechanisms designed to control elevate privileges to gain higher-level permissions. Most modern systems contain native elevation control mechanisms that are intended to limit privileges that a user can perform on a machine.

## Detection

**Detection strategies:**

- Detection Strategy for Abuse Elevation Control Mechanism (T1548)

**Analytics (5):**

- **Analytic 0975** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Security EventCode=4672` → Logon Session Metadata; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 0976** (Linux) — `auditd:SYSCALL setuid or setgid bit changes` → File Metadata; `auditd:SYSCALL execve with UID ≠ EUID` → Process Metadata; `auditd:SYSCALL sudo or pkexec invocation` → OS API Execution
- **Analytic 0977** (macOS) — `macos:unifiedlog authorization execute privilege requests` → OS API Execution; `auditd:SYSCALL execve with escalated privileges` → Process Metadata; `fs:fsusage binary execution of security_authtrampoline` → Process Creation
- **Analytic 0978** (Identity Provider) — `azure:signinlogs unusual role assumption or elevation path` → User Account Modification
- **Analytic 0979** (IaaS) — `AWS:CloudTrail role privilege expansion detected` → User Account Modification; `AWS:CloudTrail cross-account or unexpected assume role` → Process Metadata
