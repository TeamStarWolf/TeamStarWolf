# T1550.001 — Application Access Token

<a id="t1550001"></a>

**Tactics:** defense-evasion, lateral-movement  
**Platforms:** SaaS, Containers, IaaS, Office Suite, Identity Provider  
**ATT&CK:** [T1550.001](https://attack.mitre.org/techniques/T1550/001)  
**Sub-technique of:** [T1550 — Use Alternate Authentication Material](/mitre/techniques/T1550.md)  

Adversaries may use stolen application access tokens to bypass the typical authentication process and access restricted accounts, information, or services on remote systems. These tokens are typically stolen from users or services and used in lieu of login credentials.

## Detection

**Detection strategies:**

- Behavioral Detection Strategy for Use Alternate Authentication Material: Application Access Token (T1550.001)

**Analytics (5):**

- **Analytic 0526** (IaaS) — `AWS:CloudTrail AssumeRole, GetFederationToken, GetSessionToken` → Web Credential Usage; `AWS:CloudTrail sts:GetFederationToken` → User Account Authentication
- **Analytic 0527** (Identity Provider) — `azure:signinlogs TokenIssued, RefreshTokenUsed` → Web Credential Usage; `m365:unified Delegated permission grants without user login event` → User Account Authentication
- **Analytic 0528** (SaaS) — `saas:googleworkspace OAuthTokenGranted, APIRequest` → Web Credential Usage; `saas:salesforce API login using access_token without login history` → User Account Authentication
- **Analytic 0529** (Office Suite) — `m365:unified OAuthTokenIssued, FileAccessed, MailItemsAccessed` → Web Credential Usage
- **Analytic 0530** (Containers) — `kubernetes:apiserver serviceAccount token used in API requests not tied to workload identity` → Web Credential Usage; `AWS:CloudTrail AssumeRoleWithWebIdentity` → User Account Authentication
