# T1550.002 — Pass the Hash

<a id="t1550002"></a>

**Tactics:** defense-evasion, lateral-movement  
**Platforms:** Windows  
**ATT&CK:** [T1550.002](https://attack.mitre.org/techniques/T1550/002)  
**Sub-technique of:** [T1550 — Use Alternate Authentication Material](/mitre/techniques/T1550.md)  

Adversaries may “pass the hash” using stolen password hashes to move laterally within an environment, bypassing normal system access controls. Pass the hash (PtH) is a method of authenticating as a user without having access to the user's cleartext password.

## Mitigations (4)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1051 — Update Software](/mitre/mitigations/M1051.md) — Software updates ensure systems are protected against known vulnerabilities by applying patches and upgrades provided by vendors.
- [M1052 — User Account Control](/mitre/mitigations/M1052.md) — User Account Control (UAC) is a security feature in Microsoft Windows that prevents unauthorized changes to the operating system.
