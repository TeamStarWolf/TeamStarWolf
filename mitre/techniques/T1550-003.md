# T1550.003 — Pass the Ticket

<a id="t1550003"></a>

**Tactics:** defense-evasion, lateral-movement  
**Platforms:** Windows  
**ATT&CK:** [T1550.003](https://attack.mitre.org/techniques/T1550/003)  
**Sub-technique of:** [T1550 — Use Alternate Authentication Material](/mitre/techniques/T1550.md)  

Adversaries may “pass the ticket” using stolen Kerberos tickets to move laterally within an environment, bypassing normal system access controls. Pass the ticket (PtT) is a method of authenticating to a system using Kerberos tickets without having access to an account's password.

## Mitigations (4)

- [M1015 — Active Directory Configuration](/mitre/mitigations/M1015.md) — Implement robust Active Directory (AD) configurations using group policies to secure user accounts, control access, and minimize the attack surface.
- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
