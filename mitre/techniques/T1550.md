# T1550 — Use Alternate Authentication Material

<a id="t1550"></a>

**Tactics:** defense-evasion, lateral-movement  
**Platforms:** Windows, SaaS, IaaS, Containers, Identity Provider, Office Suite, Linux  
**ATT&CK:** [T1550](https://attack.mitre.org/techniques/T1550)  

Adversaries may use alternate authentication material, such as password hashes, Kerberos tickets, and application access tokens, in order to move laterally within an environment and bypass normal system access controls.

## Mitigations (7)

- [M1013 — Application Developer Guidance](/mitre/mitigations/M1013.md) — Application Developer Guidance focuses on providing developers with the knowledge, tools, and best practices needed to write secure code, reduce vulnerabilities, and implement secure design principles.
- [M1015 — Active Directory Configuration](/mitre/mitigations/M1015.md) — Implement robust Active Directory (AD) configurations using group policies to secure user accounts, control access, and minimize the attack surface.
- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1036 — Account Use Policies](/mitre/mitigations/M1036.md) — Account Use Policies help mitigate unauthorized access by configuring and enforcing rules that govern how and when accounts can be used.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

**Analytics (7):**

- **Analytic 0954** (Windows) — `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0955** (Linux) — `auditd:SYSCALL execution of ssh, scp, or sftp using previously unseen credentials or keys` → User Account Authentication; `NSM:Connections Accepted publickey for user from unusual IP or without tty` → Logon Session Creation
- **Analytic 0956** (Identity Provider) — `azure:signinlogs TokenIssuanceStart, TokenIssuanceSuccess` → Web Credential Usage; `m365:unified login using refresh_token with no preceding authentication context` → User Account Authentication
- **Analytic 0957** (SaaS) — `saas:googleworkspace access_token issued` → Web Credential Usage; `saas:googleworkspace API access without user login` → User Account Authentication
- **Analytic 0958** (Containers) — `docker:runtime execution of cloud CLI tool (e.g., aws, az) inside container` → Application Log Content; `AWS:CloudTrail AssumeRole` → User Account Metadata
- **Analytic 0959** (Office Suite) — `m365:unified TokenIssued, FileAccessed` → Web Credential Usage
- **Analytic 0960** (IaaS) — `AWS:CloudTrail GetCallerIdentity` → Web Credential Usage; `AWS:CloudTrail AssumeRole` → User Account Metadata

## Sub-techniques (4)

- [T1550.001 — Application Access Token](/mitre/techniques/T1550-001.md) — Adversaries may use stolen application access tokens to bypass the typical authentication process and access restricted accounts, information, or services on remote systems.
- [T1550.002 — Pass the Hash](/mitre/techniques/T1550-002.md) — Adversaries may “pass the hash” using stolen password hashes to move laterally within an environment, bypassing normal system access controls.
- [T1550.003 — Pass the Ticket](/mitre/techniques/T1550-003.md) — Adversaries may “pass the ticket” using stolen Kerberos tickets to move laterally within an environment, bypassing normal system access controls.
- [T1550.004 — Web Session Cookie](/mitre/techniques/T1550-004.md) — Adversaries can use stolen session cookies to authenticate to web applications and services.
