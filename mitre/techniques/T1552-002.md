# T1552.002 — Credentials in Registry

<a id="t1552002"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1552.002](https://attack.mitre.org/techniques/T1552/002)  
**Sub-technique of:** [T1552 — Unsecured Credentials](/mitre/techniques/T1552.md)  

Adversaries may search the Registry on compromised systems for insecurely stored credentials. The Windows Registry stores configuration information that can be used by the system or other programs.

## Mitigations (3)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Detect Credential Discovery via Windows Registry Enumeration

**Analytics (1):**

- **Analytic 0694** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `EDR:hunting Behavioral rule for registry enumeration under credential-related paths` → Windows Registry Key Access
