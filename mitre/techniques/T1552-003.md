# T1552.003 — Shell History

<a id="t1552003"></a>

**Tactics:** credential-access  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1552.003](https://attack.mitre.org/techniques/T1552/003)  
**Sub-technique of:** [T1552 — Unsecured Credentials](/mitre/techniques/T1552.md)  

Adversaries may search the command history on compromised systems for insecurely stored credentials. On Linux and macOS systems, shells such as Bash and Zsh keep track of the commands users type on the command-line with the "history" utility. Once a user logs out, the history is flushed to the user's history file.

## Detection

**Detection strategies:**

- Detect Access and Parsing of .bash_history Files for Credential Harvesting

**Analytics (2):**

- **Analytic 1085** (Linux) — `auditd:SYSCALL open/read access to ~/.bash_history` → File Access; `auditd:EXECVE cat|less|grep accessing .bash_history from a non-shell process` → Process Creation; `auditd:SYSCALL write or create file after .bash_history access` → File Creation
- **Analytic 1086** (macOS) — `macos:endpointsecurity open or read syscall to ~/.bash_history` → File Access; `macos:unifiedlog non-shell process tree accessing bash history` → Process Metadata
