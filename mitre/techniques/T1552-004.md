# T1552.004 — Private Keys

<a id="t1552004"></a>

**Tactics:** credential-access  
**Platforms:** Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1552.004](https://attack.mitre.org/techniques/T1552/004)  
**Sub-technique of:** [T1552 — Unsecured Credentials](/mitre/techniques/T1552.md)  

Adversaries may search for private key certificate files on compromised systems for insecurely stored credentials. Private cryptographic keys and certificates are used for authentication, encryption/decryption, and digital signatures. Common key and certificate file extensions include:.key,.pgp,.gpg,.ppk.,.p12,.pem,.pfx,.cer,.p7b,.asc. Adversaries may also look in common key directories, such as <code>~/.ssh</code> for SSH keys on * nix-based systems or <code>C:&#92;Users&#92;(username)&#92;.ssh&#92;</code> on Windows. Adversary tools may also search compromised systems for file extensions relating to cryptographic keys and certificates. When a device is registered to Entra ID, a device key and a transport key are generated and used to verify the device’s identity. An adversary with access to the device may be able to export the keys in order to impersonate the device. On network devices, private keys may be exported via [Network Device CLI](https://attack.mitre.org/techniques/T1059/008) commands such as `crypto pki export`. Some private keys require a password or passphrase for operation, so an adversary may also use [Input Capture](https://attack.mitre.org/techniques/T1056) for keylogging or attempt to [Brute Force](https://attack.mitre.org/techniques/T1110) the passphrase off-line. These private keys can be used to authenticate to [Remote Services](https://attack.mitre.org/techniques/T1021) like SSH or for use in decrypting other collected files such as email.

## Detection

**Detection strategies:**

- Detect Suspicious Access to Private Key Files and Export Attempts Across Platforms

**Analytics (4):**

- **Analytic 1516** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Security EventCode=5145` → Network Share Access; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1517** (Linux) — `auditd:SYSCALL openat` → File Access; `auditd:EXECVE execve` → Process Creation
- **Analytic 1518** (macOS) — `macos:unifiedlog open/read access to private key files (id_rsa, *.pem, *.p12)` → File Access; `macos:unifiedlog launch of bash/zsh/python/osascript targeting key file locations` → Process Creation
- **Analytic 1519** (Network Devices) — `networkdevice:syslog Detected CLI command to export key material` → Command Execution

_Notable groups seen using this technique:_

- [Rocke](/mitre/groups/G0106.md) — Rocke is an alleged Chinese-speaking adversary whose primary objective appeared to be cryptojacking, or stealing victim system resources for the purposes of mining cryptocurrency.
- [TeamTNT](/mitre/groups/G0139.md) — TeamTNT is a threat group that has primarily targeted cloud and containerized environments.
- [Scattered Spider](/mitre/groups/G1015.md) (aka Roasted 0ktapus, Octo Tempest, Storm-0875, UNC3944) — Scattered Spider is a native English-speaking cybercriminal group active since at least 2022.
- [Volt Typhoon](/mitre/groups/G1017.md) (aka BRONZE SILHOUETTE, Vanguard Panda, DEV-0391, UNC3236) — Volt Typhoon is a People's Republic of China (PRC) state-sponsored actor that has been active since at least 2021 primarily targeting critical infrastructure organizations in the US and its territories including Guam.
- [Storm-0501](/mitre/groups/G1053.md) — Storm-0501 is a financially motivated cyber criminal group that uses commodity and open-source tools to conduct ransomware operations.
