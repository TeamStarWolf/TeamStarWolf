# T1552.005 — Cloud Instance Metadata API

<a id="t1552005"></a>

**Tactics:** credential-access  
**Platforms:** IaaS  
**ATT&CK:** [T1552.005](https://attack.mitre.org/techniques/T1552/005)  
**Sub-technique of:** [T1552 — Unsecured Credentials](/mitre/techniques/T1552.md)  

Adversaries may attempt to access the Cloud Instance Metadata API to collect credentials and other sensitive data.

## Mitigations (3)

- [M1035 — Limit Access to Resource Over Network](/mitre/mitigations/M1035.md)
- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md)
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md)

## Detection

**Detection strategies:**

- Detect Access to Cloud Instance Metadata API (IaaS)

**Analytics (1):**

- **Analytic 0001** (IaaS) — `AWS:VPCFlowLogs Outbound connection to 169.254.169.254 from EC2 workload` → Network Connection Creation; `AWS:CloudTrail GetInstanceIdentityDocument` → Cloud Service Metadata; `ebpf:syscalls Process within container accesses link-local address 169.254.169.254` → Network Traffic Content
