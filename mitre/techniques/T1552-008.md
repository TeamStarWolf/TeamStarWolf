# T1552.008 — Chat Messages

<a id="t1552008"></a>

**Tactics:** credential-access  
**Platforms:** SaaS, Office Suite  
**ATT&CK:** [T1552.008](https://attack.mitre.org/techniques/T1552/008)  
**Sub-technique of:** [T1552 — Unsecured Credentials](/mitre/techniques/T1552.md)  

Adversaries may directly collect unsecured credentials stored or passed through user communication services.

## Mitigations (2)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Detect Unsecured Credentials Shared in Chat Messages

**Analytics (2):**

- **Analytic 0309** (Office Suite) — `m365:unified MessageSend, MessageRead, or FileAttached events containing credential-like patterns` → Application Log Content
- **Analytic 0310** (SaaS) — `saas:slack chat.postMessage, files.upload, or discovery API calls involving token/credential regex` → Application Log Content; `saas:okta Unusual OAuth app requesting message-read scopes for Slack/Teams/Jira` → User Account Authentication

## Data sources & telemetry (2)

**Application Log Content**, **User Account Authentication**
