# T1553.001 — Gatekeeper Bypass

<a id="t1553001"></a>

**Tactics:** defense-evasion  
**Platforms:** macOS  
**ATT&CK:** [T1553.001](https://attack.mitre.org/techniques/T1553/001)  
**Sub-technique of:** [T1553 — Subvert Trust Controls](/mitre/techniques/T1553.md)  

Adversaries may modify file attributes and subvert Gatekeeper functionality to evade user prompts and execute untrusted programs. Gatekeeper is a set of technologies that act as layer of Apple’s security model to ensure only trusted applications are executed on a host.

## Mitigations (1)

- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.

## Detection

**Detection strategies:**

- Detect Gatekeeper Bypass via Quarantine Flag and Trust Control Manipulation

**Analytics (1):**

- **Analytic 0800** (macOS) — `macos:unifiedlog xattr -d com.apple.quarantine or similar attribute removal commands` → File Metadata; `macos:unifiedlog Trust validation failures or bypass attempts during notarization and code signing checks` → Process Creation; `macos:osquery Changes to LSFileQuarantineEnabled field in Info.plist` → File Modification
