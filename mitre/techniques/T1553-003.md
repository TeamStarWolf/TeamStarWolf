# T1553.003 — SIP and Trust Provider Hijacking

<a id="t1553003"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1553.003](https://attack.mitre.org/techniques/T1553/003)
