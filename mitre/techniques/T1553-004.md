# T1553.004 — Install Root Certificate

<a id="t1553004"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1553.004](https://attack.mitre.org/techniques/T1553/004)  
**Sub-technique of:** [T1553 — Subvert Trust Controls](/mitre/techniques/T1553.md)  

Adversaries may install a root certificate on a compromised system to avoid warnings when connecting to adversary controlled web servers. Root certificates are used in public key cryptography to identify a root certificate authority (CA).

## Mitigations (2)

- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.

**Analytics (3):**

- **Analytic 0153** (Windows) — `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=12` → Windows Registry Key Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0154** (Linux) — `auditd:SYSCALL open, write: File modifications under /etc/ssl/certs, /usr/local/share/ca-certificates, or /etc/pki/ca-trust/source/anchors` → File Modification; `auditd:EXECVE execve: Execution of update-ca-certificates or trust anchor modification commands` → Command Execution
- **Analytic 0155** (macOS) — `macos:unifiedlog Execution of /usr/bin/security add-trusted-cert or keychain modifications to System.keychain` → Command Execution; `macos:osquery query: Enumeration of root certificates showing unexpected additions` → File Modification
