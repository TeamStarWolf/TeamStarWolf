# T1553.005 — Mark-of-the-Web Bypass

<a id="t1553005"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1553.005](https://attack.mitre.org/techniques/T1553/005)  
**Sub-technique of:** [T1553 — Subvert Trust Controls](/mitre/techniques/T1553.md)  

Adversaries may abuse specific file formats to subvert Mark-of-the-Web (MOTW) controls. In Windows, when files are downloaded from the Internet, they are tagged with a hidden NTFS Alternate Data Stream (ADS) named <code>Zone.Identifier</code> with a specific value known as the MOTW.

## Detection

**Detection strategies:**

- Detect Mark-of-the-Web (MOTW) Bypass via Container and Disk Image Files

**Analytics (1):**

- **Analytic 0712** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=15` → File Metadata
