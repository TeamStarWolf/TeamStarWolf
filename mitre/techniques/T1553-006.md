# T1553.006 — Code Signing Policy Modification

<a id="t1553006"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows, macOS  
**ATT&CK:** [T1553.006](https://attack.mitre.org/techniques/T1553/006)  
**Sub-technique of:** [T1553 — Subvert Trust Controls](/mitre/techniques/T1553.md)  

Adversaries may modify code signing policies to enable execution of unsigned or self-signed code. Code signing provides a level of authenticity on a program from a developer and a guarantee that the program has not been tampered with.

## Mitigations (3)

- [M1024 — Restrict Registry Permissions](/mitre/mitigations/M1024.md) — Restricting registry permissions involves configuring access control settings for sensitive registry keys and hives to ensure that only authorized users or processes can make modifications.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1046 — Boot Integrity](/mitre/mitigations/M1046.md) — Boot Integrity ensures that a system starts securely by verifying the integrity of its boot process, operating system, and associated components.

## Detection

**Detection strategies:**

- Detect Code Signing Policy Modification (Windows & macOS)

**Analytics (2):**

- **Analytic 1446** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification
- **Analytic 1447** (macOS) — `macos:unifiedlog csrutil disable` → Command Execution; `macos:unifiedlog g_CiOptions modification or SIP state change` → Windows Registry Key Modification; `macos:unifiedlog Unsigned binary execution following SIP change` → Process Creation

## Data sources & telemetry (3)

**Process Creation**, **Windows Registry Key Modification**, **Command Execution**

## Adversary usage

**Threat groups (2):** [Turla](https://attack.mitre.org/groups/G0010), [APT39](https://attack.mitre.org/groups/G0087)

_Notable groups seen using this technique:_

- [Turla](https://attack.mitre.org/groups/G0010) (aka IRON HUNTER, Group 88, Waterbug, WhiteBear) — Turla is a cyber espionage threat group that has been attributed to Russia's Federal Security Service (FSB).
- [APT39](https://attack.mitre.org/groups/G0087) (aka ITG07, Chafer, Remix Kitten) — APT39 is one of several names for cyber espionage activity conducted by the Iranian Ministry of Intelligence and Security (MOIS) through the front company Rana Intelligence Computing since at least 2014.
