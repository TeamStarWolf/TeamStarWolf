# T1553 — Subvert Trust Controls

<a id="t1553"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows, macOS, Linux  
**ATT&CK:** [T1553](https://attack.mitre.org/techniques/T1553)  

Adversaries may undermine security controls that will either warn users of untrusted activity or prevent execution of untrusted programs. Operating systems and security products may contain mechanisms to identify programs or websites as possessing some level of trust.

## Mitigations (5)

- [M1024 — Restrict Registry Permissions](/mitre/mitigations/M1024.md) — Restricting registry permissions involves configuring access control settings for sensitive registry keys and hives to ensure that only authorized users or processes can make modifications.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.
- [M1054 — Software Configuration](/mitre/mitigations/M1054.md) — Software configuration refers to making security-focused adjustments to the settings of applications, middleware, databases, or other software to mitigate potential threats.

## Detection

**Detection strategies:**

- Detect Subversion of Trust Controls via Certificate, Registry, and Attribute Manipulation

**Analytics (3):**

- **Analytic 1246** (Windows) — `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1247** (Linux) — `auditd:SYSCALL chmod, chown, setxattr, or file writes to /etc/ssl/* or /usr/local/share/ca-certificates/*` → File Metadata; `auditd:EXECVE Process execution of update-ca-certificates or openssl with suspicious arguments` → Command Execution
- **Analytic 1248** (macOS) — `macos:unifiedlog New certificate trust settings added by unexpected process` → File Metadata; `macos:unifiedlog xattr -d com.apple.quarantine or similar removal commands` → Command Execution; `macos:osquery Unsigned or ad-hoc signed process executions in user contexts` → Process Creation

## Sub-techniques (6)

- [T1553.001 — Gatekeeper Bypass](/mitre/techniques/T1553-001.md) — Adversaries may modify file attributes and subvert Gatekeeper functionality to evade user prompts and execute untrusted programs.
- [T1553.002 — Code Signing](/mitre/techniques/T1553-002.md) — Adversaries may create, acquire, or steal code signing materials to sign their malware or tools.
- [T1553.003 — SIP and Trust Provider Hijacking](/mitre/techniques/T1553-003.md) — Adversaries may tamper with SIP and trust provider components to mislead the operating system and application control tools when conducting signature validation checks.
- [T1553.004 — Install Root Certificate](/mitre/techniques/T1553-004.md) — Adversaries may install a root certificate on a compromised system to avoid warnings when connecting to adversary controlled web servers.
- [T1553.005 — Mark-of-the-Web Bypass](/mitre/techniques/T1553-005.md) — Adversaries may abuse specific file formats to subvert Mark-of-the-Web (MOTW) controls.
- [T1553.006 — Code Signing Policy Modification](/mitre/techniques/T1553-006.md) — Adversaries may modify code signing policies to enable execution of unsigned or self-signed code.
