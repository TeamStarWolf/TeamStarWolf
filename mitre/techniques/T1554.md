# T1554 — Compromise Host Software Binary

<a id="t1554"></a>

**Tactics:** persistence  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1554](https://attack.mitre.org/techniques/T1554)  

Adversaries may modify host software binaries to establish persistent access to systems. Software binaries/executables provide a wide range of system commands or services, programs, and libraries.

## Detection

**Detection strategies:**

- Detect Compromise of Host Software Binaries

**Analytics (4):**

- **Analytic 0949** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=2` → File Modification; `WinEventLog:Security EventCode=4688` → Process Creation
- **Analytic 0950** (Linux) — `auditd:SYSCALL open, write` → File Modification; `auditd:EXECVE execve` → Process Creation
- **Analytic 0951** (macOS) — `macos:unifiedlog binary modified or replaced` → File Modification; `macos:unifiedlog execution of modified binary without valid signature` → Process Creation
- **Analytic 0952** (ESXi) — `esxi:hostd binary or module replacement event` → File Modification; `esxi:vmkernel unexpected module load` → Module Load
