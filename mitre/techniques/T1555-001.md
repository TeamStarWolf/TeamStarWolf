# T1555.001 — Keychain

<a id="t1555001"></a>

**Tactics:** credential-access  
**Platforms:** macOS  
**ATT&CK:** [T1555.001](https://attack.mitre.org/techniques/T1555/001)  
**Sub-technique of:** [T1555 — Credentials from Password Stores](/mitre/techniques/T1555.md)  

Adversaries may acquire credentials from Keychain. Keychain (or Keychain Services) is the macOS credential management system that stores account names, passwords, private keys, certificates, sensitive application data, payment data, and secure notes.

## Mitigations (1)

- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.

## Detection

**Detection strategies:**

- Detect Access to macOS Keychain for Credential Theft

**Analytics (1):**

- **Analytic 1112** (macOS) — `macos:unifiedlog execution of security or osascript` → Process Creation; `macos:unifiedlog access or unlock attempt to keychain database` → OS API Execution; `macos:unifiedlog read access to ~/Library/Keychains/login.keychain-db` → File Access
