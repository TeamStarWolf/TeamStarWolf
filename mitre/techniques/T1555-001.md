# T1555.001 — Keychain

<a id="t1555001"></a>

**Tactics:** credential-access  
**Platforms:** macOS  
**ATT&CK:** [T1555.001](https://attack.mitre.org/techniques/T1555/001)  
**Sub-technique of:** [T1555](/mitre/techniques/T1555.md)

Adversaries may acquire credentials from Keychain. Keychain (or Keychain Services) is the macOS credential management system that stores account names, passwords, private keys, certificates, sensitive application data, payment data, and secure notes.



## Mitigations (1)

- [M1027 — Password Policies](/mitre/mitigations/M1027.md)


## D3FEND countermeasures (2)

- **Restore Database** (Restore) — restores
