# T1555.002 — Securityd Memory

<a id="t1555002"></a>

**Tactics:** credential-access  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1555.002](https://attack.mitre.org/techniques/T1555/002)  
**Sub-technique of:** [T1555 — Credentials from Password Stores](/mitre/techniques/T1555.md)  

An adversary with root access may gather credentials by reading `securityd`’s memory. `securityd` is a service/daemon responsible for implementing security protocols such as encryption and authorization.

## Detection

**Detection strategies:**

- Detect Suspicious Access to securityd Memory for Credential Extraction

**Analytics (2):**

- **Analytic 0156** (macOS) — `macos:unifiedlog ptrace or task_for_pid` → Process Access; `macos:unifiedlog execution of memory inspection tools (lldb, gdb, osqueryi)` → Process Creation
- **Analytic 0157** (Linux) — `auditd:SYSCALL ptrace attach` → Process Access; `auditd:FILE /proc/*/mem read attempt` → File Access; `auditd:EXECVE gcore, gdb, strings, hexdump execution` → Command Execution
