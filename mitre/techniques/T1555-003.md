# T1555.003 — Credentials from Web Browsers

<a id="t1555003"></a>

**Tactics:** credential-access  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1555.003](https://attack.mitre.org/techniques/T1555/003)  
**Sub-technique of:** [T1555 — Credentials from Password Stores](/mitre/techniques/T1555.md)  

Adversaries may acquire credentials from web browsers by reading files specific to the target browser. Web browsers commonly save credentials such as website usernames and passwords so that they do not need to be entered manually in the future.

## Mitigations (5)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1021 — Restrict Web-Based Content](/mitre/mitigations/M1021.md) — Restricting web-based content involves enforcing policies and technologies that limit access to potentially malicious websites, unsafe downloads, and unauthorized browser behaviors.
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1051 — Update Software](/mitre/mitigations/M1051.md) — Software updates ensure systems are protected against known vulnerabilities by applying patches and upgrades provided by vendors.

## Detection

**Detection strategies:**

- Detect Suspicious Access to Browser Credential Stores

**Analytics (3):**

- **Analytic 0105** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0106** (Linux) — `auditd:FILE /home/*/.mozilla/firefox/*/logins.json OR /home/*/.config/google-chrome/*/Login Data` → File Access; `auditd:SYSCALL ptrace attach` → Process Access
- **Analytic 0107** (macOS) — `macos:unifiedlog execution of security, sqlite3, or unauthorized binaries` → Process Creation; `macos:unifiedlog ~/Library/Application Support/Google/Chrome/*/Login Data OR ~/Library/Application Support/Firefox/*/logins.json` → File Access
