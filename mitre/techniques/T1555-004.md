# T1555.004 — Windows Credential Manager

<a id="t1555004"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1555.004](https://attack.mitre.org/techniques/T1555/004)  
**Sub-technique of:** [T1555 — Credentials from Password Stores](/mitre/techniques/T1555.md)  

Adversaries may acquire credentials from the Windows Credential Manager. The Credential Manager stores credentials for signing into websites, applications, and/or devices that request authentication through NTLM or Kerberos in Credential Lockers (previously known as Windows Vaults).

## Mitigations (1)

- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.

## Detection

**Detection strategies:**

- Detect Suspicious Access to Windows Credential Manager

- **Analytic 0378** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=15` → File Metadata

## Adversary usage

**Threat groups (4):** [Turla](https://attack.mitre.org/groups/G0010), [Stealth Falcon](https://attack.mitre.org/groups/G0038), [OilRig](https://attack.mitre.org/groups/G0049), [Wizard Spider](https://attack.mitre.org/groups/G0102)

_Notable groups seen using this technique:_

- [Turla](https://attack.mitre.org/groups/G0010) (aka IRON HUNTER, Group 88, Waterbug, WhiteBear) — Turla is a cyber espionage threat group that has been attributed to Russia's Federal Security Service (FSB).
- [Stealth Falcon](https://attack.mitre.org/groups/G0038) — Stealth Falcon is a threat group that has conducted targeted spyware attacks against Emirati journalists, activists, and dissidents since at least 2012.
- [OilRig](https://attack.mitre.org/groups/G0049) (aka COBALT GYPSY, IRN2, APT34, Helix Kitten) — OilRig is a suspected Iranian threat group that has targeted Middle Eastern and international victims since at least 2014.
- [Wizard Spider](https://attack.mitre.org/groups/G0102) (aka UNC1878, TEMP.MixMaster, Grim Spider, FIN12) — Wizard Spider is a Russia-based financially motivated threat group originally known for the creation and deployment of TrickBot since at least 2016.
