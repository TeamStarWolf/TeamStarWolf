# T1555.005 — Password Managers

<a id="t1555005"></a>

**Tactics:** credential-access  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1555.005](https://attack.mitre.org/techniques/T1555/005)  
**Sub-technique of:** [T1555 — Credentials from Password Stores](/mitre/techniques/T1555.md)  

Adversaries may acquire user credentials from third-party password managers. Password managers are applications designed to store user credentials, normally in an encrypted database. Credentials are typically accessible after a user provides a master password that unlocks the database.

## Detection

**Detection strategies:**

- Detect Unauthorized Access to Password Managers

**Analytics (3):**

- **Analytic 1641** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=15` → File Metadata
- **Analytic 1642** (Linux) — `auditd:SYSCALL open/read on ~/.local/share/keepassxc/* OR ~/.password-store/*` → File Access; `auditd:SYSCALL ptrace` → Process Access
- **Analytic 1643** (macOS) — `macos:unifiedlog security OR injection attempts into 1Password OR LastPass` → Process Creation; `macos:unifiedlog *.opvault OR *.ldb OR *.kdbx` → File Access; `macos:osquery unexpected memory inspection` → Process Access
