# T1556.001 — Domain Controller Authentication

<a id="t1556001"></a>

**Tactics:** credential-access, defense-evasion, persistence  
**Platforms:** Windows  
**ATT&CK:** [T1556.001](https://attack.mitre.org/techniques/T1556/001)  
**Sub-technique of:** [T1556 — Modify Authentication Process](/mitre/techniques/T1556.md)  

Adversaries may patch the authentication process on a domain controller to bypass the typical authentication mechanisms and enable access to accounts.

## Mitigations (4)

## Detection

**Detection strategies:**

- Detect Domain Controller Authentication Process Modification (Skeleton Key)

**Analytics (1):**

- **Analytic 0757** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:System Unexpected modification to lsass.exe or cryptdll.dll` → File Modification
