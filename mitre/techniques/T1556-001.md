# T1556.001: Domain Controller Authentication

<a id="t1556001"></a>

Tactics: defense-impairment, persistence, credential-access  
Platforms: Windows  
ATT&CK: [T1556.001](https://attack.mitre.org/techniques/T1556/001)  
Sub-technique of: [T1556: Modify Authentication Process](/mitre/techniques/T1556.md)  

Adversaries may patch the authentication process on a domain controller to bypass the typical authentication mechanisms and enable access to accounts. Malware may be used to inject false credentials into the authentication process on a domain controller with the intent of creating a backdoor used to access any user’s account and/or credentials (ex: [Skeleton Key](https://attack.mitre.org/software/S0007)). Skeleton key works through a patch on an enterprise domain controller authentication process (LSASS) with credentials that adversaries may use to bypass the standard authentication system. Once patched, an adversary can use the injected password to successfully authenticate as any domain user account (until the the skeleton key is erased from memory by a reboot of the domain controller). Authenticated access may enable unfettered access to hosts and/or resources within single-factor authentication environments.

## Mitigations (4)

- [M1017: User Training](/mitre/mitigations/M1017.md): User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1025: Privileged Process Integrity](/mitre/mitigations/M1025.md): Privileged Process Integrity focuses on defending highly privileged processes (e.g., system services, antivirus, or authentication processes) from tampering, injection, or compromise by adversaries.
- [M1026: Privileged Account Management](/mitre/mitigations/M1026.md): Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1032: Multi-factor Authentication](/mitre/mitigations/M1032.md): Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.

## Detection

Detection strategies:

- Detect Domain Controller Authentication Process Modification (Skeleton Key)

Analytics (1):

- Analytic 0757 (Windows): `WinEventLog:Sysmon EventCode=10` -> Process Access; `WinEventLog:Sysmon EventCode=7` -> Module Load; `WinEventLog:Security EventCode=4624, 4648` -> Logon Session Creation; `WinEventLog:System Unexpected modification to lsass.exe or cryptdll.dll` -> File Modification
