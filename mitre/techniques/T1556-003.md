# T1556.003 — Pluggable Authentication Modules

<a id="t1556003"></a>

**Tactics:** credential-access, defense-evasion, persistence  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1556.003](https://attack.mitre.org/techniques/T1556/003)  
**Sub-technique of:** [T1556 — Modify Authentication Process](/mitre/techniques/T1556.md)  

Adversaries may modify pluggable authentication modules (PAM) to access user credentials or enable otherwise unwarranted access to accounts. PAM is a modular system of configuration files, libraries, and executable files which guide authentication for many services.

## Detection

**Detection strategies:**

- Detect Malicious Modification of Pluggable Authentication Modules (PAM)

**Analytics (2):**

- **Analytic 1250** (Linux) — `auditd:SYSCALL open, write` → File Modification; `auditd:SYSCALL execve` → Process Creation; `NSM:Connections simultaneous or anomalous logon sessions across multiple systems` → Logon Session Creation
- **Analytic 1251** (macOS) — `macos:unifiedlog authentication plugin load or modification events` → Logon Session Creation; `macos:osquery write` → File Modification
