# T1556.006 — Multi-Factor Authentication

<a id="t1556006"></a>

**Tactics:** credential-access, defense-evasion, persistence  
**Platforms:** Windows, SaaS, IaaS, Linux, macOS, Office Suite, Identity Provider  
**ATT&CK:** [T1556.006](https://attack.mitre.org/techniques/T1556/006)  
**Sub-technique of:** [T1556 — Modify Authentication Process](/mitre/techniques/T1556.md)  

Adversaries may disable or modify multi-factor authentication (MFA) mechanisms to enable persistent access to compromised accounts.

## Mitigations (3)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Detect MFA Modification or Disabling Across Platforms

**Analytics (7):**

- **Analytic 0543** (Windows) — `WinEventLog:Security EventCode=4739` → Active Directory Object Modification; `WinEventLog:PowerShell Set-ADUser or Set-ADAuthenticationPolicy with MFA attributes disabled` → Script Execution
- **Analytic 0544** (Identity Provider) — `azure:signinlogs Modify Conditional Access Policy` → Application Log Content; `m365:unified User excluded from MFA or MFA method registered` → User Account Modification
- **Analytic 0545** (IaaS) — `AWS:CloudTrail UpdateIdentityPolicy or DisableMFA` → Cloud Service Modification
- **Analytic 0546** (Linux) — `auditd:SYSCALL open/write to /etc/pam.d/*` → File Modification; `NSM:Connections Successful login without expected MFA challenge` → User Account Authentication
- **Analytic 0547** (macOS) — `macos:unifiedlog Modification of /Library/Security/SecurityAgentPlugins` → File Modification; `macos:unifiedlog Login success without MFA step` → User Account Authentication
- **Analytic 0548** (SaaS) — `saas:zoom DisableMFA or RegisterNewFactor` → User Account Modification
- **Analytic 0549** (Office Suite) — `m365:unified Set-CsOnlineUser or UpdateAuthPolicy` → Application Log Content
