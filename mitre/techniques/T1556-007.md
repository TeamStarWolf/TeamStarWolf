# T1556.007 — Hybrid Identity

<a id="t1556007"></a>

**Tactics:** credential-access, defense-evasion, persistence  
**Platforms:** Windows, SaaS, IaaS, Office Suite, Identity Provider  
**ATT&CK:** [T1556.007](https://attack.mitre.org/techniques/T1556/007)  
**Sub-technique of:** [T1556 — Modify Authentication Process](/mitre/techniques/T1556.md)  

Adversaries may patch, modify, or otherwise backdoor cloud authentication processes that are tied to on-premises user identities in order to bypass typical authentication mechanisms, access credentials, and enable persistent access to accounts.

## Mitigations (3)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md)

- [M1047 — Audit](/mitre/mitigations/M1047.md)

## Detection

**Detection strategies:**

- Detect Hybrid Identity Authentication Process Modification

**Analytics (5):**

- **Analytic 0814** (Windows) — `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Security EventCode=5136` → Active Directory Object Modification; `WinEventLog:Security Anomalous logon without MFA enforcement` → Logon Session Creation
- **Analytic 0815** (Identity Provider) — `azure:signinlogs Register PTA Agent or Modify AD FS trust` → Application Log Content; `m365:unified New agent registration by non-admin user` → User Account Modification
- **Analytic 0816** (IaaS) — `AWS:CloudTrail UpdateFederationSettings or RegisterHybridConnector` → Cloud Service Modification
- **Analytic 0817** (Office Suite) — `m365:unified Modify Federation Settings or Update Authentication Policy` → Application Log Content
- **Analytic 0818** (SaaS) — `saas:okta Federation configuration update or signing certificate change` → Application Log Content
