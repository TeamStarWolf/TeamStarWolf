# T1556 — Modify Authentication Process

<a id="t1556"></a>

**Tactics:** defense-impairment, persistence, credential-access  
**Platforms:** Windows, Linux, macOS, Network Devices, IaaS, SaaS, Office Suite, Identity Provider  
**ATT&CK:** [T1556](https://attack.mitre.org/techniques/T1556)  

Adversaries may modify authentication mechanisms and processes to access user credentials or enable otherwise unwarranted access to accounts. The authentication process is handled by mechanisms, such as the Local Security Authentication Server (LSASS) process and the Security Accounts Manager (SAM) on Windows, pluggable authentication modules (PAM) on Unix-based systems, and authorization plugins on MacOS systems, responsible for gathering, storing, and validating credentials. By modifying an authentication process, an adversary may be able to authenticate to a service or system without using [Valid Accounts](https://attack.mitre.org/techniques/T1078). Adversaries may maliciously modify a part of this process to either reveal credentials or bypass authentication mechanisms. Compromised credentials or access may be used to bypass access controls placed on various resources on systems within the network and may even be used for persistent access to remote systems and externally available services, such as VPNs, Outlook Web Access and remote desktop.

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1024 — Restrict Registry Permissions](/mitre/mitigations/M1024.md) — Restricting registry permissions involves configuring access control settings for sensitive registry keys and hives to ensure that only authorized users or processes can make modifications.
- [M1025 — Privileged Process Integrity](/mitre/mitigations/M1025.md) — Privileged Process Integrity focuses on defending highly privileged processes (e.g., system services, antivirus, or authentication processes) from tampering, injection, or compromise by adversaries.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1028 — Operating System Configuration](/mitre/mitigations/M1028.md) — Operating System Configuration involves adjusting system settings and hardening the default configurations of an operating system (OS) to mitigate adversary exploitation and prevent abuse of system functionality.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Detect Modification of Authentication Processes Across Platforms

**Analytics (5):**

- **Analytic 0287** (Windows) — `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=7` → Module Load
- **Analytic 0288** (Linux) — `auditd:SYSCALL open, write` → File Modification; `auditd:SYSCALL execve` → Process Creation
- **Analytic 0289** (macOS) — `macos:unifiedlog SecurityAgentPlugins modification` → File Modification; `macos:osquery process_open` → Process Access
- **Analytic 0290** (Identity Provider) — `azure:policy UpdatePolicy` → Cloud Service Modification; `m365:unified Set-ADUser OR Set-ADAccountControl` → User Account Modification
- **Analytic 0291** (IaaS) — `AWS:CloudTrail UpdateLoginProfile` → User Account Modification; `AWS:CloudTrail UpdateAccountPasswordPolicy` → Cloud Service Modification

## Sub-techniques (9)

- [T1556.001 — Domain Controller Authentication](/mitre/techniques/T1556-001.md) — Adversaries may patch the authentication process on a domain controller to bypass the typical authentication mechanisms and enable access to accounts.
- [T1556.002 — Password Filter DLL](/mitre/techniques/T1556-002.md) — Adversaries may register malicious password filter dynamic link libraries (DLLs) into the authentication process to acquire user credentials as they are validated.
- [T1556.003 — Pluggable Authentication Modules](/mitre/techniques/T1556-003.md) — Adversaries may modify pluggable authentication modules (PAM) to access user credentials or enable otherwise unwarranted access to accounts.
- [T1556.004 — Network Device Authentication](/mitre/techniques/T1556-004.md) — Adversaries may use [Patch System Image](https://attack.mitre.org/techniques/T1601/001) to hard code a password in the operating system, thus bypassing of native authentication mechanisms for local accounts on network devices.
- [T1556.005 — Reversible Encryption](/mitre/techniques/T1556-005.md) — An adversary may abuse Active Directory authentication encryption properties to gain access to credentials on Windows systems.
- [T1556.006 — Multi-Factor Authentication](/mitre/techniques/T1556-006.md) — Adversaries may disable or modify multi-factor authentication (MFA) mechanisms to enable persistent access to compromised accounts.
- [T1556.007 — Hybrid Identity](/mitre/techniques/T1556-007.md) — Adversaries may patch, modify, or otherwise backdoor cloud authentication processes that are tied to on-premises user identities in order to bypass typical authentication mechanisms, access credentials, and enable persistent access to accounts.
- [T1556.008 — Network Provider DLL](/mitre/techniques/T1556-008.md) — Adversaries may register malicious network provider dynamic link libraries (DLLs) to capture cleartext user credentials during the authentication process.
- [T1556.009 — Conditional Access Policies](/mitre/techniques/T1556-009.md) — Adversaries may disable or modify conditional access policies to enable persistent access to compromised accounts.
