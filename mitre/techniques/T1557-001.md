# T1557.001 — LLMNR/NBT-NS Poisoning and SMB Relay

<a id="t1557001"></a>

**Tactics:** credential-access, collection  
**Platforms:** Windows  
**ATT&CK:** [T1557.001](https://attack.mitre.org/techniques/T1557/001)  
**Sub-technique of:** [T1557 — Adversary-in-the-Middle](/mitre/techniques/T1557.md)  

By responding to LLMNR/NBT-NS network traffic, adversaries may spoof an authoritative source for name resolution to force communication with an adversary controlled system. This activity may be used to collect or relay authentication materials.

## Mitigations (4)

- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.

- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Detect LLMNR/NBT-NS Poisoning and SMB Relay on Windows

**Analytics (1):**

- **Analytic 1274** (Windows) — `WinEventLog:Security EventCode=4697` → Service Creation; `WinEventLog:Security Registry key modification HKLM\Software\Policies\Microsoft\Windows NT\DNSClient\EnableMulticast` → Windows Registry Key Modification; `NSM:Flow Unusual responses to LLMNR (UDP 5355) or NBT-NS (UDP 137) queries from unauthorized hosts` → Network Traffic Content; `NSM:Flow Abnormal SMB authentication attempts correlated with poisoned LLMNR/NBT-NS sessions` → Network Traffic Flow
