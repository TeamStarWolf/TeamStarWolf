# T1557.002 — ARP Cache Poisoning

<a id="t1557002"></a>

**Tactics:** credential-access, collection  
**Platforms:** Linux, Windows, macOS  
**ATT&CK:** [T1557.002](https://attack.mitre.org/techniques/T1557/002)  
**Sub-technique of:** [T1557 — Adversary-in-the-Middle](/mitre/techniques/T1557.md)  

Adversaries may poison Address Resolution Protocol (ARP) caches to position themselves between the communication of two or more networked devices. This activity may be used to enable follow-on behaviors such as Network Sniffing or Transmitted Data Manipulation.

## Detection

**Detection strategies:**

- Detect ARP Cache Poisoning Across Linux, Windows, and macOS

**Analytics (3):**

- **Analytic 1091** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Security ARP cache modification attempts observed through event tracing or security baselines` → Network Traffic Flow
- **Analytic 1092** (Linux) — `auditd:SYSCALL setsockopt, ioctl modifying ARP entries` → Network Traffic Content; `NSM:Flow Gratuitous ARP replies with mismatched IP-MAC binding` → Network Traffic Flow
- **Analytic 1093** (macOS) — `macos:unifiedlog ARP table updates inconsistent with expected gateway or DHCP lease assignments` → Network Traffic Flow; `NSM:Flow Excessive gratuitous ARP replies on local subnet` → Network Traffic Content
