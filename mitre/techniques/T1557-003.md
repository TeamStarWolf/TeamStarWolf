# T1557.003 — DHCP Spoofing

<a id="t1557003"></a>

**Tactics:** credential-access, collection  
**Platforms:** Linux, Windows, macOS  
**ATT&CK:** [T1557.003](https://attack.mitre.org/techniques/T1557/003)  
**Sub-technique of:** [T1557 — Adversary-in-the-Middle](/mitre/techniques/T1557.md)  

Adversaries may redirect network traffic to adversary-owned systems by spoofing Dynamic Host Configuration Protocol (DHCP) traffic and acting as a malicious DHCP server on the victim network.

## Detection

**Detection strategies:**

- Detect DHCP Spoofing Across Linux, Windows, and macOS

**Analytics (3):**

- **Analytic 1290** (Windows) — `WinEventLog:System EventCode=1341, 1342, 1020, 1063` → Application Log Content; `NSM:Flow DHCP OFFER or ACK with unauthorized DNS/gateway parameters` → Network Traffic Content
- **Analytic 1291** (Linux) — `linux:syslog suspicious DHCP lease assignment with unexpected DNS or gateway` → Application Log Content; `NSM:Flow Gratuitous or duplicate DHCP OFFER packets from non-legitimate servers` → Network Traffic Flow
- **Analytic 1292** (macOS) — `macos:unifiedlog new DHCP configuration with anomalous DNS or router values` → Application Log Content; `NSM:Flow Multiple DHCP OFFER responses for a single DISCOVER` → Network Traffic Content
