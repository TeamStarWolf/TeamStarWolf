# T1558.001 — Golden Ticket

<a id="t1558001"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1558.001](https://attack.mitre.org/techniques/T1558/001)  
**Sub-technique of:** [T1558 — Steal or Forge Kerberos Tickets](/mitre/techniques/T1558.md)  

Adversaries who have the KRBTGT account password hash may forge Kerberos ticket-granting tickets (TGT), also known as a golden ticket. Golden tickets enable adversaries to generate authentication material for any account in Active Directory.

## Mitigations (2)

- [M1015 — Active Directory Configuration](/mitre/mitigations/M1015.md) — Implement robust Active Directory (AD) configurations using group policies to secure user accounts, control access, and minimize the attack surface.
- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).

## Detection

**Detection strategies:**

- Detect Forged Kerberos Golden Tickets (T1558.001)

**Analytics (1):**

- **Analytic 0405** (Windows) — `WinEventLog:Security EventCode=4672, 4634` → Logon Session Metadata; `WinEventLog:Security EventCode=4769` → Active Directory Credential Request; `WinEventLog:Sysmon EventCode=10` → Process Access
