# T1558.003 — Kerberoasting

<a id="t1558003"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1558.003](https://attack.mitre.org/techniques/T1558/003)  
**Sub-technique of:** [T1558 — Steal or Forge Kerberos Tickets](/mitre/techniques/T1558.md)  

Adversaries may abuse a valid Kerberos ticket-granting ticket (TGT) or sniff network traffic to obtain a ticket-granting service (TGS) ticket that may be vulnerable to Brute Force. Service principal names (SPNs) are used to uniquely identify each instance of a Windows service.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **16 machines (3.0%)** — Linux 0 / Windows 15. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Detection

**Detection strategies:**

- Detect Kerberoasting Attempts (T1558.003)

**Analytics (1):**

- **Analytic 0444** (Windows) — `WinEventLog:Security EventCode=4769` → Active Directory Credential Request; `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Security EventCode=4624, 4648` → Logon Session Creation; `WinEventLog:Security EventCode=4672` → Logon Session Metadata

## Adversary usage

**Threat groups (3):** [FIN7](https://attack.mitre.org/groups/G0046), [Wizard Spider](https://attack.mitre.org/groups/G0102), [Indrik Spider](https://attack.mitre.org/groups/G0119)

_Notable groups seen using this technique:_

- [FIN7](https://attack.mitre.org/groups/G0046) (aka GOLD NIAGARA, ITG14, Carbon Spider, ELBRUS) — FIN7 is a financially-motivated threat group that has been active since 2013.
- [Wizard Spider](https://attack.mitre.org/groups/G0102) (aka UNC1878, TEMP.MixMaster, Grim Spider, FIN12) — Wizard Spider is a Russia-based financially motivated threat group originally known for the creation and deployment of TrickBot since at least 2016.
- [Indrik Spider](https://attack.mitre.org/groups/G0119) (aka Evil Corp, Manatee Tempest, DEV-0243, UNC2165) — Indrik Spider is a Russia-based cybercriminal group that has been active since at least 2014.
