# T1558.004 — AS-REP Roasting

<a id="t1558004"></a>

**Tactics:** credential-access  
**Platforms:** Windows  
**ATT&CK:** [T1558.004](https://attack.mitre.org/techniques/T1558/004)  
**Sub-technique of:** [T1558 — Steal or Forge Kerberos Tickets](/mitre/techniques/T1558.md)  

Adversaries may reveal credentials of accounts that have disabled Kerberos preauthentication by Password Cracking Kerberos messages. Preauthentication offers protection against offline Password Cracking.

## Mitigations (3)

- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1041 — Encrypt Sensitive Information](/mitre/mitigations/M1041.md) — Protect sensitive information at rest, in transit, and during processing by using strong encryption algorithms.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Detect AS-REP Roasting Attempts (T1558.004)

**Analytics (1):**

- **Analytic 0316** (Windows) — `WinEventLog:Security EventCode=4768` → Active Directory Credential Request; `WinEventLog:Sysmon EventCode=1` → Process Creation
