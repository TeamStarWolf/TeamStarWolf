# T1558.005 — Ccache Files

<a id="t1558005"></a>

**Tactics:** credential-access  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1558.005](https://attack.mitre.org/techniques/T1558/005)  
**Sub-technique of:** [T1558 — Steal or Forge Kerberos Tickets](/mitre/techniques/T1558.md)  

Adversaries may attempt to steal Kerberos tickets stored in credential cache files (or ccache). These files are used for short term storage of a user's active session credentials.

## Mitigations (2)

- [M1043 — Credential Access Protection](/mitre/mitigations/M1043.md) — Credential Access Protection focuses on implementing measures to prevent adversaries from obtaining credentials, such as passwords, hashes, tokens, or keys, that could be used for unauthorized access.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Detect Kerberos Ccache File Theft or Abuse (T1558.005)

**Analytics (2):**

- **Analytic 0069** (Linux) — `auditd:SYSCALL open: File access attempt on /tmp/krb5cc_* or /tmp/krb5.ccache` → File Access; `auditd:SYSCALL execve: Execution of klist, kinit, or tools interacting with ccache outside normal user context` → Process Creation
- **Analytic 0070** (macOS) — `macos:unifiedlog Kerberos framework calls to API:{uuid} cache outside normal process lineage` → File Access; `macos:osquery Execution of non-standard binaries accessing Kerberos APIs` → Process Creation
