# T1560.002 — Archive via Library

<a id="t1560002"></a>

**Tactics:** collection  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1560.002](https://attack.mitre.org/techniques/T1560/002)  
**Sub-technique of:** [T1560 — Archive Collected Data](/mitre/techniques/T1560.md)  

An adversary may compress or encrypt data that is collected prior to exfiltration using 3rd party libraries. Many libraries exist that can archive data, including Python rarfile , libzip , and zlib . Most libraries include functionality to encrypt and/or compress data.

## Detection

**Detection strategies:**

- Detect Archiving via Library (T1560.002)

**Analytics (3):**

- **Analytic 0747** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 0748** (Linux) — `auditd:SYSCALL execve: Execution of python, perl, or custom binaries invoking compression libraries` → Command Execution; `auditd:MMAP load: Loading of libzip.so, libz.so, or libbz2.so by processes not normally associated with archiving` → Module Load; `auditd:FILE create: Creation of .zip, .gz, .bz2 files in /tmp, /var/tmp, or /home directories` → File Creation
- **Analytic 0749** (macOS) — `macos:unifiedlog Execution of Python, Swift, or other binaries invoking archiving libraries` → Process Creation; `macos:unifiedlog Loading of libz.dylib, libarchive.dylib by non-standard applications` → Module Load; `macos:unifiedlog Creation of .zip, .gz, .dmg archives in /Users, /tmp, or application directories` → File Creation
