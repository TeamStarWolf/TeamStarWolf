# T1560.003 — Archive via Custom Method

<a id="t1560003"></a>

**Tactics:** collection  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1560.003](https://attack.mitre.org/techniques/T1560/003)  
**Sub-technique of:** [T1560 — Archive Collected Data](/mitre/techniques/T1560.md)  

An adversary may compress or encrypt data that is collected prior to exfiltration using a custom method. Adversaries may choose to use custom archival methods, such as encryption with XOR or stream ciphers implemented with no external library or utility references. Custom implementations of well-known compression algorithms have also been used.

## Detection

**Detection strategies:**

- Detect Archiving via Custom Method (T1560.003)

**Analytics (3):**

- **Analytic 1213** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=10` → Process Access
- **Analytic 1214** (Linux) — `auditd:SYSCALL execve: Execution of interpreters creating archive-like outputs without calling tar/gzip` → Command Execution; `auditd:FILE create: Creation of files with anomalous headers and entropy levels in /tmp or user directories` → File Creation; `linux:osquery Detection of bitwise operations or custom encryption functions in memory traces` → Process Modification
- **Analytic 1215** (macOS) — `macos:unifiedlog Suspicious Swift/Objective-C or scripting processes writing archive-like outputs` → Process Creation; `macos:unifiedlog Creation of files with anomalous headers and entropy values` → File Creation; `macos:unifiedlog Abnormal memory operations (XOR/bitwise loops) during archive generation` → Process Modification
