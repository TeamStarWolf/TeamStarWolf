# T1560 — Archive Collected Data

<a id="t1560"></a>

**Tactics:** collection  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1560](https://attack.mitre.org/techniques/T1560)  

An adversary may compress and/or encrypt data that is collected prior to exfiltration. Compressing the data can help to obfuscate the collected data and minimize the amount of data sent over the network.

## Detection

**Detection strategies:**

- Detect Archiving and Encryption of Collected Data (T1560)

**Analytics (3):**

- **Analytic 1458** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=7` → Module Load
- **Analytic 1459** (Linux) — `auditd:SYSCALL execve: Execution of tar, gzip, bzip2, or openssl with output redirection` → Command Execution; `auditd:FILE create: Creation of files ending in .tar, .gz, .bz2, .zip in /tmp or /var/tmp` → File Creation
- **Analytic 1460** (macOS) — `macos:unifiedlog Execution of zip, ditto, hdiutil, or openssl by non-terminal parent processes` → Process Creation; `macos:unifiedlog Creation of .zip or .dmg files in user-accessible or temporary directories` → File Creation
