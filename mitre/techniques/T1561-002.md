# T1561.002 — Disk Structure Wipe

<a id="t1561002"></a>

**Tactics:** impact  
**Platforms:** Linux, macOS, Windows, Network Devices  
**ATT&CK:** [T1561.002](https://attack.mitre.org/techniques/T1561/002)  
**Sub-technique of:** [T1561 — Disk Wipe](/mitre/techniques/T1561.md)  

Adversaries may corrupt or wipe the disk data structures on a hard drive necessary to boot a system; targeting specific critical systems or in large numbers in a network to interrupt availability to system and network resources.

## Detection

**Detection strategies:**

- Detection Strategy for Disk Structure Wipe via Boot/Partition Overwrite

**Analytics (4):**

- **Analytic 0827** (Windows) — `WinEventLog:Security EventCode=4673` → User Account Metadata; `WinEventLog:Sysmon Raw write attempts targeting \\.\PhysicalDrive0 or sector 0 (MBR/partition table)` → Drive Modification; `WinEventLog:Sysmon EventCode=6` → Driver Load
- **Analytic 0828** (Linux) — `auditd:SYSCALL write syscalls to /dev/sd* targeting offset 0` → Drive Access; `auditd:EXECVE Execution of dd/sgdisk with arguments writing to sector 0 or partition table` → Process Creation
- **Analytic 0829** (macOS) — `macos:unifiedlog diskutil partitionDisk or eraseVolume with partition scheme modifications` → Command Execution; `macos:unifiedlog IOKit raw disk write to EFI/boot partition sectors` → Drive Modification
- **Analytic 0830** (Network Devices) — `networkdevice:cli format flash:, format disk, reformat commands` → Command Execution; `networkdevice:syslog Privileged login followed by destructive format command` → User Account Authentication
