# T1561: Disk Wipe

<a id="t1561"></a>

Tactics: impact  
Platforms: Linux, macOS, Windows, Network Devices  
ATT&CK: [T1561](https://attack.mitre.org/techniques/T1561)  

Adversaries may wipe or corrupt raw disk data on specific systems or in large numbers in a network to interrupt availability to system and network resources. With direct write access to a disk, adversaries may attempt to overwrite portions of disk data. Adversaries may opt to wipe arbitrary portions of disk data and/or wipe disk structures like the master boot record (MBR). A complete wipe of all disk sectors may be attempted. To maximize impact on the target organization in operations where network-wide availability interruption is the goal, malware used for wiping disks may have worm-like features to propagate across a network by leveraging additional techniques like [Valid Accounts](https://attack.mitre.org/techniques/T1078), [OS Credential Dumping](https://attack.mitre.org/techniques/T1003), and [SMB/Windows Admin Shares](https://attack.mitre.org/techniques/T1021/002). On network devices, adversaries may wipe configuration files and other data from the device using [Network Device CLI](https://attack.mitre.org/techniques/T1059/008) commands such as `erase`.

## Mitigations (1)

- [M1053: Data Backup](/mitre/mitigations/M1053.md): Data Backup involves taking and securely storing backups of data from end-user systems and critical servers.

## Detection

Detection strategies:

- Detection Strategy for Disk Wipe via Direct Disk Access and Destructive Commands

Analytics (4):

- Analytic 0384 (Windows): `WinEventLog:Security EventCode=4673` -> User Account Metadata; `WinEventLog:Sysmon Raw disk write access via \\.\PhysicalDrive* or \\.\C:` -> Drive Modification; `WinEventLog:Sysmon EventCode=6` -> Driver Load
- Analytic 0385 (Linux): `auditd:SYSCALL open/write syscalls on /dev/sd* or /dev/nvme*` -> Drive Access; `auditd:EXECVE Execution of dd, shred, wipe targeting block devices` -> Process Creation
- Analytic 0386 (macOS): `macos:unifiedlog diskutil eraseDisk / asr restore with destructive flags` -> Command Execution; `macos:unifiedlog IOKit disk write calls targeting raw devices` -> Drive Modification
- Analytic 0387 (Network Devices): `networkdevice:cli erase flash:, erase startup-config, format disk` -> Command Execution; `networkdevice:syslog User privilege escalation to level 15/root prior to destructive commands` -> User Account Authentication
