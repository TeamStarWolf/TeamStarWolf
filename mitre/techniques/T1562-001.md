# T1562.001 — Disable or Modify Tools

<a id="t1562001"></a>

**Tactics:** defense-evasion  
**Platforms:** Containers, IaaS, Linux, macOS, Network Devices, Windows

## Detection

**Detection strategies:**

- Detection of Impair Defenses through Disabled or Modified Tools across OS Platforms.

**Analytics (6):**

- **Analytic 1369** (Windows) — `WinEventLog:System EventCode=7045` → Service Creation; `WinEventLog:Sysmon EventCode=5` → Process Termination; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 1370** (Linux) — `auditd:SYSCALL execve: systemctl stop, service stop, or kill -9 on security daemons (e.g., falcon-sensor, auditd)` → Process Creation; `auditd:CONFIG_CHANGE delete: Modification of systemd unit files or config for security agents` → Service Metadata
- **Analytic 1371** (macOS) — `macos:unifiedlog Execution of launchctl unload, kill, or removal of security agent daemons` → Process Creation; `macos:unifiedlog Modification of system configuration profiles affecting security tools` → Service Metadata
- **Analytic 1372** (IaaS) — `AWS:CloudTrail Delete* / Stop*: DeleteAlarms, StopLogging, or DisableMonitoring API calls` → Cloud Service Modification
- **Analytic 1373** (Containers) — `kubernetes:audit kubectl delete or patch of security pods/admission controllers` → Service Metadata
- **Analytic 1374** (Network Devices) — `networkdevice:config write: Startup configuration changes disabling security checks` → Service Metadata
