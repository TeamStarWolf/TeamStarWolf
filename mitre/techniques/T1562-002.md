# T1562.002 — Disable Windows Event Logging

<a id="t1562002"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1562.002](https://attack.mitre.org/techniques/T1562/002)  
**Sub-technique of:** [T1562 — Impair Defenses](/mitre/techniques/T1562.md)  

Adversaries may disable Windows event logging to limit data that can be leveraged for detections and audits. Windows event logs record user and system activity such as login attempts, process creation, and much more. This data is used by security tools and analysts to generate detections.

## Detection

**Detection strategies:**

- Detect disabled Windows event logging

**Analytics (1):**

- **Analytic 0535** (Windows) — `WinEventLog:System EventCode=7035` → Service Metadata; `WinEventLog:Security EventCode=1102` → Application Log Content; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `WinEventLog:Sysmon EventCode=1` → Process Creation

## Data sources & telemetry (4)

**Service Metadata**, **Application Log Content**, **Windows Registry Key Modification**, **Process Creation**
