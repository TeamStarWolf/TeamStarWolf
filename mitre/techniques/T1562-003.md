# T1562.003 — Impair Command History Logging

<a id="t1562003"></a>

**Tactics:** defense-evasion  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1562.003](https://attack.mitre.org/techniques/T1562/003)  
**Sub-technique of:** [T1562 — Impair Defenses](/mitre/techniques/T1562.md)  

Adversaries may impair command history logging to hide commands they run on a compromised system. Various command interpreters keep track of the commands users type in their terminal so that users can retrace what they've done.

## Detection

**Detection strategies:**

- Detection Strategy for Impair Defenses via Impair Command History Logging across OS platforms.

**Analytics (5):**

- **Analytic 1555** (Linux) — `auditd:SYSCALL execve calls modifying HISTFILE or HISTCONTROL via unset/export` → Command Execution; `linux:osquery processes modifying environment variables related to history logging` → Process Creation
- **Analytic 1556** (macOS) — `macos:unifiedlog Set or unset HIST* variables in shell environment` → Command Execution
- **Analytic 1557** (Windows) — `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1558** (ESXi) — `esxi:shell unset HISTFILE or HISTFILESIZE modifications` → Command Execution
- **Analytic 1559** (Network Devices) — `networkdevice:cli Commands like 'no logging' or equivalents that disable session history` → Command Execution
