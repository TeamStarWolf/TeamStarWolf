# T1562.004 — Disable or Modify System Firewall

<a id="t1562004"></a>

**Tactics:** defense-evasion  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1562.004](https://attack.mitre.org/techniques/T1562/004)  
**Sub-technique of:** [T1562 — Impair Defenses](/mitre/techniques/T1562.md)  

Adversaries may disable or modify system firewalls in order to bypass controls limiting network usage. Changes could be disabling the entire mechanism as well as adding, deleting, or modifying particular rules.

## Mitigations (4)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1024 — Restrict Registry Permissions](/mitre/mitigations/M1024.md) — Restricting registry permissions involves configuring access control settings for sensitive registry keys and hives to ensure that only authorized users or processes can make modifications.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Detection of Disabled or Modified System Firewalls across OS Platforms.

**Analytics (5):**

- **Analytic 0406** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 0407** (Linux) — `auditd:SYSCALL execve: iptables, nft, firewall-cmd modifications` → Command Execution; `linux:osquery execution of known firewall binaries` → Process Creation
- **Analytic 0408** (macOS) — `macos:unifiedlog pfctl -d, socketfilterfw --setglobalstate off, or modifications to com.apple.alf` → Command Execution
- **Analytic 0409** (ESXi) — `esxi:hostd esxcli network firewall set commands` → Command Execution; `esxi:hostd vSphere API calls modifying firewall settings` → Firewall Rule Modification
- **Analytic 0410** (Network Devices) — `networkdevice:cli firewall disable commands or suspicious ACL modifications` → Firewall Rule Modification

## Data sources & telemetry (4)

**Process Creation**, **Windows Registry Key Modification**, **Command Execution**, **Firewall Rule Modification**
