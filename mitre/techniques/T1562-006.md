# T1562.006 — Indicator Blocking

<a id="t1562006"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows, macOS, Linux, ESXi  
**ATT&CK:** [T1562.006](https://attack.mitre.org/techniques/T1562/006)  
**Sub-technique of:** [T1562 — Impair Defenses](/mitre/techniques/T1562.md)  

An adversary may attempt to block indicators or events typically captured by sensors from being gathered and analyzed. This could include maliciously redirecting or even disabling host-based sensors, such as Event Tracing for Windows (ETW), by tampering settings that control the collection and flow of event telemetry.

## Detection

**Detection strategies:**

- Detection Strategy for Impair Defenses Indicator Blocking

**Analytics (4):**

- **Analytic 0667** (Windows) — `WinEventLog:Sysmon EventCode=16` → Host Status; `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification
- **Analytic 0668** (Linux) — `auditd:SYSCALL execve: service stop syslog, systemctl stop rsyslog, kill -9 syslog` → Command Execution; `linux:osquery unexpected termination of syslog or rsyslog processes` → Process Termination
- **Analytic 0669** (macOS) — `macos:unifiedlog defaults write com.apple.system.logging or logd manipulation` → Command Execution
- **Analytic 0670** (ESXi) — `esxi:hostd esxcli system syslog config set or reload` → Command Execution
