# T1562.010 — Downgrade Attack

<a id="t1562010"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows, Linux, macOS  
**ATT&CK:** [T1562.010](https://attack.mitre.org/techniques/T1562/010)  
**Sub-technique of:** [T1562 — Impair Defenses](/mitre/techniques/T1562.md)  

> **⚠ Revoked in ATT&CK v19.2** — superseded by [T1689 — Downgrade Attack](/mitre/techniques/T1689.md).

Adversaries may downgrade or use a version of system features that may be outdated, vulnerable, and/or does not support updated security controls. Downgrade attacks typically take advantage of a system’s backward compatibility to force it into less secure modes of operation. Adversaries may downgrade and use various less-secure versions of features of a system, such as [Command and Scripting Interpreter](https://attack.mitre.org/techniques/T1059)s or even network protocols that can be abused to enable [Adversary-in-the-Middle](https://attack.mitre.org/techniques/T1557) or [Network Sniffing](https://attack.mitre.org/techniques/T1040). For example, [PowerShell](https://attack.mitre.org/techniques/T1059/001) versions 5+ includes Script Block Logging (SBL), which can record executed script content. However, adversaries may attempt to execute a previous version of PowerShell that does not support SBL with the intent to [Impair Defenses](https://attack.mitre.org/techniques/T1562) while running malicious scripts that may have otherwise been detected. Adversaries may similarly target network traffic to downgrade from an encrypted HTTPS connection to an unsecured HTTP connection that exposes network data in clear text. On Windows systems, adversaries may downgrade the boot manager to a vulnerable version that bypasses Secure Boot, granting the ability to disable various operating system security mechanisms.

## Detection

**Detection strategies:**

- Detecting Downgrade Attacks

**Analytics (3):**

- **Analytic 0995** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification
- **Analytic 0996** (Linux) — `auditd:SYSCALL execve: Execution of downgraded interpreters such as python2 or forced fallback commands` → Command Execution; `linux:syslog Kernel or daemon warnings of downgraded TLS or cryptographic settings` → Process Metadata
- **Analytic 0997** (macOS) — `macos:unifiedlog Execution of older or non-standard interpreters` → Process Creation; `macos:unifiedlog Modifications or writes to EFI system partition for downgraded bootloaders` → Process Metadata
