# T1562.010 — Downgrade Attack

<a id="t1562010"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows, Linux, macOS  
**ATT&CK:** [T1562.010](https://attack.mitre.org/techniques/T1562/010)  
**Sub-technique of:** [T1562 — Impair Defenses](/mitre/techniques/T1562.md)  

Adversaries may downgrade or use a version of system features that may be outdated, vulnerable, and/or does not support updated security controls. Downgrade attacks typically take advantage of a system’s backward compatibility to force it into less secure modes of operation.

## Detection

**Detection strategies:**

- Detecting Downgrade Attacks

**Analytics (3):**

- **Analytic 0995** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification
- **Analytic 0996** (Linux) — `auditd:SYSCALL execve: Execution of downgraded interpreters such as python2 or forced fallback commands` → Command Execution; `linux:syslog Kernel or daemon warnings of downgraded TLS or cryptographic settings` → Process Metadata
- **Analytic 0997** (macOS) — `macos:unifiedlog Execution of older or non-standard interpreters` → Process Creation; `macos:unifiedlog Modifications or writes to EFI system partition for downgraded bootloaders` → Process Metadata
