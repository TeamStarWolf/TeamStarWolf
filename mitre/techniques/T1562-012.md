# T1562.012 — Disable or Modify Linux Audit System

<a id="t1562012"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux  
**ATT&CK:** [T1562.012](https://attack.mitre.org/techniques/T1562/012)  
**Sub-technique of:** [T1562 — Impair Defenses](/mitre/techniques/T1562.md)  

Adversaries may disable or modify the Linux audit system to hide malicious activity and avoid detection. Linux admins use the Linux Audit system to track security-relevant information on a system.

## Mitigations (2)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md)
- [M1047 — Audit](/mitre/mitigations/M1047.md)

## Detection

**Detection strategies:**

- Detection Strategy for Disable or Modify Linux Audit System

**Analytics (1):**

- **Analytic 0171** (Linux) — `auditd:EXECVE Execution of auditctl, systemctl stop auditd, or kill -9 auditd` → Command Execution; `auditd:SYSCALL kill syscalls targeting auditd process` → Process Modification; `auditd:FILE Modification or deletion of /etc/audit/audit.rules or /etc/audit/audit.conf` → File Modification; `linux:syslog auditd service stopped or disabled` → Service Metadata
