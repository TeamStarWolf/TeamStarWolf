# T1562.013 — Disable or Modify Network Device Firewall

<a id="t1562013"></a>

**Tactics:** defense-evasion  
**Platforms:** Network Devices  
**ATT&CK:** [T1562.013](https://attack.mitre.org/techniques/T1562/013)  
**Sub-technique of:** [T1562 — Impair Defenses](/mitre/techniques/T1562.md)  

Adversaries may disable network device-based firewall mechanisms entirely or add, delete, or modify particular rules in order to bypass controls limiting network usage.

## Detection

**Detection strategies:**

- Unauthorized Network Firewall Rule Modification (T1562.013)

**Analytics (1):**

- **Analytic 0855** (Network Devices) — `networkdevice:Firewall update_rule: Access control or NAT rule modified or disabled outside maintenance window` → Firewall Rule Modification; `networkdevice:Firewall Login from untrusted IP, or new admin account accessing firewall console/API` → Logon Session Creation; `networkdevice:Firewall Audit trail or CLI/API access indicating commands like no access-list, delete rule-set, clear config` → Command Execution; `NSM:Flow Outbound traffic spike through formerly blocked ports/subnets following config change` → Network Connection Creation
