# T1562 — Impair Defenses

<a id="t1562"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows, IaaS, Linux, macOS, Containers, Network Devices, Identity Provider, Office Suite, ESXi  
**ATT&CK:** [T1562](https://attack.mitre.org/techniques/T1562)  

> **⚠ Revoked in ATT&CK v19.2** — superseded by [T1685 — Disable or Modify Tools](https://attack.mitre.org/techniques/T1685).

Adversaries may maliciously modify components of a victim environment in order to hinder or disable defensive mechanisms. This not only involves impairing preventative defenses, such as firewalls and anti-virus, but also detection capabilities that defenders can use to audit activity and identify malicious behavior. This may also span both native defenses as well as supplemental capabilities installed by users and administrators. Adversaries may also impair routine operations that contribute to defensive hygiene, such as blocking users from logging out, preventing a system from shutting down, or disabling or modifying the update process. Adversaries could also target event aggregation and analysis mechanisms, or otherwise disrupt these procedures by altering other system components. These restrictions can further enable malicious operations as well as the continued propagation of incidents.

**Analytics (9):**

- **Analytic 0886** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:System EventCode=7045` → Service Creation; `WinEventLog:Sysmon EventCode=12` → Windows Registry Key Creation
- **Analytic 0887** (Linux) — `auditd:EXECVE systemctl stop auditd, kill -9 <pid>, or modifications to /etc/selinux/config` → Process Creation; `auditd:SYSCALL kill syscalls targeting logging/security processes` → Process Termination; `linux:syslog iptables or nftables rule changes` → Firewall Rule Modification
- **Analytic 0888** (macOS) — `macos:unifiedlog spctl --master-disable, csrutil disable, or defaults write to disable Gatekeeper` → Command Execution; `macos:unifiedlog Termination of syspolicyd or XProtect processes` → Process Termination
- **Analytic 0889** (Containers) — `kubernetes:audit seccomp or AppArmor profile changes` → Service Metadata; `docker:runtime Termination of monitoring sidecar or security container` → Process Termination
- **Analytic 0890** (ESXi) — `esxi:shell esxcli system syslog config set --loghost='' or stopping hostd service` → Command Execution; `esxi:vmkernel Disabling or modifying firewall rules` → Firewall Disable
- **Analytic 0891** (IaaS) — `AWS:CloudTrail StopLogging, DeleteTrail, or DisableSecurityService` → Cloud Service Disable
- **Analytic 0892** (Identity Provider) — `azure:policy DisableMfaPolicy or change to ConditionalAccess rules` → User Account Modification
- **Analytic 0893** (Network Devices) — `networkdevice:syslog no logging buffered, no aaa new-model, disable firewall` → Command Execution

## Adversary usage

**Threat groups (2):** [Magic Hound](https://attack.mitre.org/groups/G0059), [BlackByte](https://attack.mitre.org/groups/G1043)

_Notable groups seen using this technique:_

- [Magic Hound](https://attack.mitre.org/groups/G0059) (aka TA453, COBALT ILLUSION, Charming Kitten, ITG18) — Magic Hound is an Iranian-sponsored threat group that conducts long term, resource-intensive cyber espionage operations, likely on behalf of the Islamic Revolutionary Guard Corps.
- [BlackByte](https://attack.mitre.org/groups/G1043) (aka Hecamede) — BlackByte is a ransomware threat actor operating since at least 2021. BlackByte is associated with several versions of ransomware also labeled BlackByte Ransomware.

**Software/tools (3):** [Stuxnet](https://attack.mitre.org/software/S0603), [BOLDMOVE](https://attack.mitre.org/software/S1184), [JumbledPath](https://attack.mitre.org/software/S1206)
