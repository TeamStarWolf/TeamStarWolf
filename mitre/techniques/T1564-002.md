# T1564.002 — Hidden Users

<a id="t1564002"></a>

**Tactics:** defense-evasion  
**Platforms:** macOS, Windows, Linux  
**ATT&CK:** [T1564.002](https://attack.mitre.org/techniques/T1564/002)  
**Sub-technique of:** [T1564 — Hide Artifacts](/mitre/techniques/T1564.md)  

Adversaries may use hidden users to hide the presence of user accounts they create or modify. Administrators may want to hide users when there are many user accounts on a given system or if they want to hide their administrative or other management accounts from other users.

## Mitigations (1)

## Detection

**Detection strategies:**

- Detection Strategy for Hidden User Accounts

**Analytics (3):**

- **Analytic 1001** (Windows) — `WinEventLog:Security EventCode=4720` → User Account Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 1002** (Linux) — `auditd:EXECVE Execution of gsettings set org.gnome.login-screen disable-user-list true` → Command Execution; `auditd:FILE Modification of Display Manager configuration files (/etc/gdm3/*, /etc/lightdm/*)` → File Modification
- **Analytic 1003** (macOS) — `macos:unifiedlog Execution of dscl . create with IsHidden=1` → Command Execution; `macos:unifiedlog Modification of /Library/Preferences/com.apple.loginwindow plist` → File Modification; `macos:unifiedlog Creation of user account with UID <500` → User Account Metadata
