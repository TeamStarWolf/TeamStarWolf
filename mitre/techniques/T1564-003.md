# T1564.003 — Hidden Window

<a id="t1564003"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1564.003](https://attack.mitre.org/techniques/T1564/003)  
**Sub-technique of:** [T1564 — Hide Artifacts](/mitre/techniques/T1564.md)  

Adversaries may use hidden windows to conceal malicious activity from the plain sight of users. In some cases, windows that would typically be displayed when an application carries out an operation can be hidden.

## Mitigations (2)

- [M1033 — Limit Software Installation](/mitre/mitigations/M1033.md) — Prevent users or groups from installing unauthorized or unapproved software to reduce the risk of introducing malicious or vulnerable applications.
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.

## Detection

**Detection strategies:**

- Detection Strategy for Hidden Windows

**Analytics (3):**

- **Analytic 0360** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 0361** (Linux) — `auditd:EXECVE Execution of GUI-related binaries with suppressed window/display flags` → Command Execution; `auditd:SYSCALL Use of fork/exec with DISPLAY unset or redirected` → Process Metadata
- **Analytic 0362** (macOS) — `macos:unifiedlog Modification of plist with apple.awt.UIElement set to TRUE` → File Modification; `macos:unifiedlog Execution of Java apps or other processes with hidden window attributes` → Process Creation
