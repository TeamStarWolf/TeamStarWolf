# T1564.004 — NTFS File Attributes

<a id="t1564004"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1564.004](https://attack.mitre.org/techniques/T1564/004)  
**Sub-technique of:** [T1564 — Hide Artifacts](/mitre/techniques/T1564.md)  

Adversaries may use NTFS file attributes to hide their malicious data in order to evade detection. Every New Technology File System (NTFS) formatted partition contains a Master File Table (MFT) that maintains a record for every file/directory on the partition.

## Mitigations (1)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.

## Detection

**Detection strategies:**

- Detection Strategy for NTFS File Attribute Abuse (ADS/EAs)

**Analytics (1):**

- **Analytic 1206** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=15` → File Metadata; `etw:Microsoft-Windows-Kernel-File ZwSetEaFile or ZwQueryEaFile function calls` → OS API Execution
