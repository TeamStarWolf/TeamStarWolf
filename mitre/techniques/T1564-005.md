# T1564.005 — Hidden File System

<a id="t1564005"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1564.005](https://attack.mitre.org/techniques/T1564/005)  
**Sub-technique of:** [T1564 — Hide Artifacts](/mitre/techniques/T1564.md)  

Adversaries may use a hidden file system to conceal malicious activity from users and security tools. File systems provide a structure to store and access data from physical storage.

## Detection

**Detection strategies:**

- Detection Strategy for Hidden File System Abuse

**Analytics (3):**

- **Analytic 1271** (Windows) — `WinEventLog:Security EventCode=4663, 4670, 4656` → File Modification; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification; `etw:Microsoft-Windows-Kernel-Storage Raw disk I/O operations bypassing NTFS APIs` → Firmware Modification
- **Analytic 1272** (Linux) — `auditd:SYSCALL mount or losetup commands creating hidden or encrypted FS` → File Modification; `linux:syslog Sudo or root escalation followed by filesystem mount commands` → Command Execution
- **Analytic 1273** (macOS) — `macos:unifiedlog Execution of diskutil or hdiutil attaching hidden partitions` → Process Creation; `macos:unifiedlog Hidden volume attachment or modification events` → File Modification
