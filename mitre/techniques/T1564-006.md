# T1564.006 — Run Virtual Instance

<a id="t1564006"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1564.006](https://attack.mitre.org/techniques/T1564/006)  
**Sub-technique of:** [T1564 — Hide Artifacts](/mitre/techniques/T1564.md)  

Adversaries may carry out malicious operations using a virtual instance to avoid detection. A wide variety of virtualization technologies exist that allow for the emulation of a computer or computing environment.

## Detection

**Detection strategies:**

- Detection Strategy for Hidden Virtual Instance Execution

**Analytics (4):**

- **Analytic 0909** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:System EventCode=7045` → Service Creation; `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification
- **Analytic 0910** (Linux) — `auditd:SYSCALL execve calls for qemu-system*, kvm, or VBoxHeadless` → Process Creation; `auditd:SYSCALL File creations of *.qcow2, *.vdi, *.vmdk outside standard VM directories` → File Creation
- **Analytic 0911** (macOS) — `macos:unifiedlog Process execution for VBoxHeadless, prl_vm_app, vmware-vmx` → Process Creation; `macos:unifiedlog Plist modifications containing virtualization run configurations` → File Modification
- **Analytic 0912** (ESXi) — `esxi:hostd Execution of '/bin/vmx' or modifications to '/etc/rc.local.d/local.sh'` → Command Execution; `esxi:vmkernel VMX startup messages without associated vCenter inventory records` → Image Metadata
