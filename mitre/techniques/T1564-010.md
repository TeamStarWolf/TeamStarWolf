# T1564.010 — Process Argument Spoofing

<a id="t1564010"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1564.010](https://attack.mitre.org/techniques/T1564/010)  
**Sub-technique of:** [T1564 — Hide Artifacts](/mitre/techniques/T1564.md)  

Adversaries may attempt to hide process command-line arguments by overwriting process memory. Process command-line arguments are stored in the process environment block (PEB), a data structure used by Windows to store various information about/used by a process.

## Detection

**Detection strategies:**

- Detection Strategy for Process Argument Spoofing on Windows

**Analytics (1):**

- **Analytic 0126** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=10` → Process Access
