# T1564.012 — File/Path Exclusions

<a id="t1564012"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1564.012](https://attack.mitre.org/techniques/T1564/012)  
**Sub-technique of:** [T1564](/mitre/techniques/T1564.md)
