# T1564.013 — Bind Mounts

<a id="t1564013"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux  
**ATT&CK:** [T1564.013](https://attack.mitre.org/techniques/T1564/013)  
**Sub-technique of:** [T1564 — Hide Artifacts](/mitre/techniques/T1564.md)  

Adversaries may abuse bind mounts on file structures to hide their activity and artifacts from native utilities. A bind mount maps a directory or file from one location on the filesystem to another, similar to a shortcut on Windows.

## Detection

**Detection strategies:**

- Detection Strategy for Bind Mounts on Linux

**Analytics (1):**

- **Analytic 1196** (Linux) — `auditd:SYSCALL mount system call with bind or remap flags` → OS API Execution; `auditd:PATH mount target path within /proc/*` → File Creation; `linux:osquery process metadata mismatch between /proc and runtime attributes` → Process Metadata
