# T1564.014 — Extended Attributes

<a id="t1564014"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1564.014](https://attack.mitre.org/techniques/T1564/014)  
**Sub-technique of:** [T1564 — Hide Artifacts](/mitre/techniques/T1564.md)  

Adversaries may abuse extended attributes (xattrs) on macOS and Linux to hide their malicious data in order to evade detection. Extended attributes are key-value pairs of file and directory metadata used by both macOS and Linux.

## Mitigations (1)

- [M1040 — Behavior Prevention on Endpoint](/mitre/mitigations/M1040.md) — Behavior Prevention on Endpoint refers to the use of technologies and strategies to detect and block potentially malicious activities by analyzing the behavior of processes, files, API calls, and other endpoint events.

## Detection

**Detection strategies:**

- Detection Strategy for Extended Attributes Abuse

**Analytics (2):**

- **Analytic 1135** (Linux) — `auditd:SYSCALL setxattr or getxattr system call` → File Metadata; `auditd:EXECVE execution of setfattr or getfattr commands` → Command Execution
- **Analytic 1136** (macOS) — `macos:unifiedlog xattr utility execution with -w or -p flags` → Command Execution; `macos:unifiedlog extended attribute write or modification` → File Metadata
