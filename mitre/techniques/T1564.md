# T1564 — Hide Artifacts

<a id="t1564"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, Office Suite, Windows, macOS, ESXi  
**ATT&CK:** [T1564](https://attack.mitre.org/techniques/T1564)  

Adversaries may attempt to hide artifacts associated with their behaviors to evade detection.

## Detection

**Detection strategies:**

- Detection Strategy for Hidden Artifacts Across Platforms

**Analytics (5):**

- **Analytic 1384** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 1385** (Linux) — `auditd:EXECVE Execution of chattr to set +i or +a attributes` → Command Execution; `auditd:FILE Creation of hidden files (.*) in sensitive directories (/etc, /var, /usr/bin)` → File Creation
- **Analytic 1386** (macOS) — `macos:unifiedlog Execution of chflags hidden or setfile -a V` → Command Execution; `macos:unifiedlog Creation of LaunchAgents/LaunchDaemons in hidden or non-standard directories` → File Creation
- **Analytic 1387** (ESXi) — `esxi:shell mv, rename, or chmod commands moving VM files into hidden directories` → Command Execution; `esxi:syslog Datastore file hidden or renamed unexpectedly` → File Metadata
- **Analytic 1388** (Office Suite) — `m365:unified Detection of hidden macro streams or SetHiddenAttribute actions` → Application Log Content
