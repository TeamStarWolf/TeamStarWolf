# T1565.002 — Transmitted Data Manipulation

<a id="t1565002"></a>

**Tactics:** impact  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1565.002](https://attack.mitre.org/techniques/T1565/002)  
**Sub-technique of:** [T1565 — Data Manipulation](/mitre/techniques/T1565.md)  

Adversaries may alter data en route to storage or other systems in order to manipulate external outcomes or hide activity, thus threatening the integrity of the data. By manipulating transmitted data, adversaries may attempt to affect a business process, organizational understanding, and decision making.

## Detection

**Detection strategies:**

- Detection Strategy of Transmitted Data Manipulation

**Analytics (3):**

- **Analytic 0702** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=15` → File Metadata
- **Analytic 0703** (Linux) — `auditd:SYSCALL send, recv, write: Abnormal interception or alteration of transmitted data` → OS API Execution; `linux:syslog Integrity mismatch warnings or malformed packets detected` → Network Traffic Content
- **Analytic 0704** (macOS) — `macos:unifiedlog Suspicious anomalies in transmitted data integrity during application network operations` → Network Traffic Flow; `macos:osquery CALCULATE: Integrity validation of transmitted data via hash checks` → OS API Execution
