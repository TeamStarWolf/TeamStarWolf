# T1565.003 — Runtime Data Manipulation

<a id="t1565003"></a>

**Tactics:** impact  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1565.003](https://attack.mitre.org/techniques/T1565/003)  
**Sub-technique of:** [T1565 — Data Manipulation](/mitre/techniques/T1565.md)  

Adversaries may modify systems in order to manipulate the data as it is accessed and displayed to an end user, thus threatening the integrity of the data. By manipulating runtime data, adversaries may attempt to affect a business process, organizational understanding, and decision making.

## Mitigations (2)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.

## Detection

**Detection strategies:**

- Detection Strategy for Runtime Data Manipulation.

**Analytics (3):**

- **Analytic 1097** (Windows) — `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=15` → File Metadata; `WinEventLog:Security EventCode=4657` → Windows Registry Key Modification
- **Analytic 1098** (Linux) — `auditd:SYSCALL open, write: File writes to application binaries or libraries at runtime` → File Modification; `linux:syslog Execution of modified binaries or abnormal library load sequences` → OS API Execution
- **Analytic 1099** (macOS) — `macos:unifiedlog Unexpected application binary modifications or altered signing status` → File Metadata; `macos:osquery CALCULATE: Mismatch in file integrity of critical macOS applications` → File Modification
