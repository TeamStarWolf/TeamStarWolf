# T1566.001 — Spearphishing Attachment

<a id="t1566001"></a>

**Tactics:** initial-access  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1566.001](https://attack.mitre.org/techniques/T1566/001)  
**Sub-technique of:** [T1566 — Phishing](/mitre/techniques/T1566.md)  

Adversaries may send spearphishing emails with a malicious attachment in an attempt to gain access to victim systems. Spearphishing attachment is a specific variant of spearphishing. Spearphishing attachment is different from other forms of spearphishing in that it employs the use of malware attached to an email.

## Detection

**Detection strategies:**

- Detection Strategy for Spearphishing Attachment across OS Platforms

**Analytics (3):**

- **Analytic 0655** (Windows) — `m365:unified Send/Receive: Inbound emails with attachments from suspicious or spoofed senders` → Application Log Content; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0656** (Linux) — `Application:Mail Inbound email attachments logged from MTAs with suspicious metadata` → Application Log Content; `auditd:SYSCALL execve: Execution of files saved in mail or download directories` → Process Creation; `NSM:Flow Outbound traffic from suspicious new processes post-attachment execution` → Network Traffic Flow
- **Analytic 0657** (macOS) — `macos:unifiedlog Inbound messages with attachments from suspicious domains` → Application Log Content; `macos:unifiedlog Execution of Terminal, osascript, or other interpreters originating from Mail or Preview` → Process Creation; `macos:unifiedlog Attachment files written to ~/Downloads or temporary folders` → File Creation
