# T1566.002 — Spearphishing Link

<a id="t1566002"></a>

**Tactics:** initial-access  
**Platforms:** Identity Provider, Linux, macOS, Office Suite, SaaS, Windows  
**ATT&CK:** [T1566.002](https://attack.mitre.org/techniques/T1566/002)  
**Sub-technique of:** [T1566 — Phishing](/mitre/techniques/T1566.md)  

Adversaries may send spearphishing emails with a malicious link in an attempt to gain access to victim systems. Spearphishing with a link is a specific variant of spearphishing.

## Detection

**Detection strategies:**

- Detection Strategy for Spearphishing Links

**Analytics (4):**

- **Analytic 0298** (Windows) — `m365:unified Send/Receive: Inbound emails containing embedded or shortened URLs` → Application Log Content; `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0299** (Linux) — `Application:Mail Inbound emails containing hyperlinks from suspicious sources` → Application Log Content; `auditd:SYSCALL execve: Execution of scripts or binaries spawned from browser processes` → Process Creation; `NSM:Flow Outbound requests to domains not previously resolved or associated with phishing campaigns` → Network Traffic Flow
- **Analytic 0300** (macOS) — `macos:unifiedlog Received messages with embedded or shortened URLs` → Application Log Content; `macos:unifiedlog Browser processes launching unexpected interpreters (osascript, bash)` → Process Creation; `macos:unifiedlog Connections to suspicious domains with mismatched certificate or unusual patterns` → Network Traffic Content
- **Analytic 0301** (Identity Provider) — `azure:signinlogs ConsentGrant: Suspicious consent grants to non-approved or unknown applications` → Application Log Content
