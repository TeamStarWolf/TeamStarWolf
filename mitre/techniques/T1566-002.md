# T1566.002 — Spearphishing Link

<a id="t1566002"></a>

**Tactics:** initial-access  
**Platforms:** Identity Provider, Linux, macOS, Office Suite, SaaS, Windows  
**ATT&CK:** [T1566.002](https://attack.mitre.org/techniques/T1566/002)  
**Sub-technique of:** [T1566](/mitre/techniques/T1566.md)

Adversaries may send spearphishing emails with a malicious link in an attempt to gain access to victim systems. Spearphishing with a link is a specific variant of spearphishing.
