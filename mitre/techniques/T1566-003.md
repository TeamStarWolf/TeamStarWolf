# T1566.003 — Spearphishing via Service

<a id="t1566003"></a>

**Tactics:** initial-access  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1566.003](https://attack.mitre.org/techniques/T1566/003)  
**Sub-technique of:** [T1566 — Phishing](/mitre/techniques/T1566.md)  

Adversaries may send spearphishing messages via third-party services in an attempt to gain access to victim systems. Spearphishing via service is a specific variant of spearphishing.

## Detection

**Detection strategies:**

- Detection Strategy for Spearphishing via a Service across OS Platforms

**Analytics (3):**

- **Analytic 0320** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 0321** (Linux) — `auditd:SYSCALL execve: Execution of bash, python, or perl processes spawned by browser/email client` → Process Creation; `linux:syslog Inbound messages from webmail services containing attachments or URLs` → Application Log Content; `NSM:Flow Outbound traffic to domains/IPs not previously resolved, occurring shortly after attachment download or link click` → Network Traffic Flow
- **Analytic 0322** (macOS) — `macos:unifiedlog Received messages containing embedded links or attachments from non-enterprise services` → Application Log Content; `macos:unifiedlog Execution of osascript, bash, or Terminal initiated from Mail.app or Safari` → Process Creation; `macos:unifiedlog Suspicious outbound HTTPS requests to domains flagged as newly registered or untrusted after spearphishing message interaction` → Network Traffic Content
