# T1566 — Phishing

<a id="t1566"></a>

**Tactics:** initial-access  
**Platforms:** Identity Provider, Linux, macOS, Office Suite, SaaS, Windows  
**ATT&CK:** [T1566](https://attack.mitre.org/techniques/T1566)  

Adversaries may send phishing messages to gain access to victim systems. All forms of phishing are electronically delivered social engineering. Phishing can be targeted, known as spearphishing. In spearphishing, a specific individual, company, or industry will be targeted by the adversary.

## Mitigations (6)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1021 — Restrict Web-Based Content](/mitre/mitigations/M1021.md) — Restricting web-based content involves enforcing policies and technologies that limit access to potentially malicious websites, unsafe downloads, and unauthorized browser behaviors.
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.
- [M1049 — Antivirus/Antimalware](/mitre/mitigations/M1049.md) — Antivirus/Antimalware solutions utilize signatures, heuristics, and behavioral analysis to detect, block, and remediate malicious software, including viruses, trojans, ransomware, and spyware.
- [M1054 — Software Configuration](/mitre/mitigations/M1054.md) — Software configuration refers to making security-focused adjustments to the settings of applications, middleware, databases, or other software to mitigate potential threats.

## Detection

**Detection strategies:**

- Detection Strategy for Phishing across platforms.

**Analytics (6):**

- **Analytic 0188** (Windows) — `m365:unified Send/Receive: Emails with suspicious sender domains, spoofed headers, or anomalous attachment types` → Application Log Content; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0189** (Linux) — `Application:Mail Inbound messages with anomalous headers, spoofed SPF/DKIM failures` → Application Log Content; `auditd:SYSCALL execve: Execution of scripts or binaries sourced from mail directories (/var/mail, ~/Maildir)` → Process Creation
- **Analytic 0190** (macOS) — `macos:unifiedlog Inbound email activity with suspicious domains or mismatched sender information` → Application Log Content; `macos:unifiedlog Preview.app, Safari.app, or Mail.app spawning new processes outside normal patterns` → Process Creation
- **Analytic 0191** (Office Suite) — `m365:unified FileAccessed: Access of email attachments by Office applications` → Application Log Content; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0192** (Identity Provider) — `azure:signinlogs Failed MFA attempts, unusual conditional access triggers, login attempts from unexpected IP ranges` → Logon Session Creation
- **Analytic 0193** (SaaS) — `saas:collaboration MessagePosted: Suspicious links or attachment delivery via collaboration tools (Slack, Teams, Zoom)` → Application Log Content
