# T1567.004 — Exfiltration Over Webhook

<a id="t1567004"></a>

**Tactics:** exfiltration  
**Platforms:** Windows, macOS, Linux, SaaS, Office Suite, ESXi  
**ATT&CK:** [T1567.004](https://attack.mitre.org/techniques/T1567/004)  
**Sub-technique of:** [T1567 — Exfiltration Over Web Service](/mitre/techniques/T1567.md)  

Adversaries may exfiltrate data to a webhook endpoint rather than over their primary command and control channel. Webhooks are simple mechanisms for allowing a server to push data over HTTP/S to a client without the need for the client to continuously poll the server.

## Mitigations (1)

- [M1057 — Data Loss Prevention](/mitre/mitigations/M1057.md)

## Detection

**Detection strategies:**

- Detection Strategy for Exfiltration Over Webhook

**Analytics (5):**

- **Analytic 0436** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Access
- **Analytic 0437** (Linux) — `auditd:EXECVE curl -X POST, wget --post-data` → Command Execution; `auditd:SYSCALL read/open of sensitive files` → File Access; `NSM:Flow large HTTPS POST requests to webhook endpoints` → Network Traffic Content
- **Analytic 0438** (macOS) — `macos:unifiedlog execution of osascript, curl, or unexpected automation` → Process Creation; `macos:unifiedlog file read of sensitive directories` → File Access; `macos:unifiedlog HTTPS POST to known webhook URLs` → Network Traffic Flow
- **Analytic 0439** (ESXi) — `esxi:hostd datastore file access` → File Access; `esxi:vmkernel HTTPS POST connections to webhook endpoints` → Network Traffic Content
- **Analytic 0440** (SaaS) — `m365:unified Set-Mailbox, Add-InboxRule, RegisterWebhook` → Application Log Content; `saas:api Webhook registrations or repeated POST activity` → Network Traffic Flow
