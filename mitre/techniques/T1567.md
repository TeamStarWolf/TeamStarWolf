# T1567 — Exfiltration Over Web Service

<a id="t1567"></a>

**Tactics:** exfiltration  
**Platforms:** ESXi, Linux, macOS, Office Suite, SaaS, Windows  
**ATT&CK:** [T1567](https://attack.mitre.org/techniques/T1567)  

Adversaries may use an existing, legitimate external Web service to exfiltrate data rather than their primary command and control channel.

## Mitigations (2)

- [M1021 — Restrict Web-Based Content](/mitre/mitigations/M1021.md) — Restricting web-based content involves enforcing policies and technologies that limit access to potentially malicious websites, unsafe downloads, and unauthorized browser behaviors.
- [M1057 — Data Loss Prevention](/mitre/mitigations/M1057.md) — Data Loss Prevention (DLP) involves implementing strategies and technologies to identify, categorize, monitor, and control the movement of sensitive data within an organization.

## Detection

**Detection strategies:**

- Detection Strategy for Exfiltration Over Web Service

**Analytics (5):**

- **Analytic 1511** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 1512** (Linux) — `auditd:EXECVE curl or wget with POST/PUT options` → Command Execution; `auditd:SYSCALL open/read of sensitive directories (/etc, /home/*)` → File Access; `NSM:Flow sustained outbound HTTPS sessions with high data volume` → Network Traffic Flow
- **Analytic 1513** (macOS) — `macos:unifiedlog execution of Office binaries with network activity` → Process Creation; `macos:unifiedlog read/write of user documents prior to upload` → File Access; `macos:unifiedlog outbound TLS connections to cloud storage providers` → Network Traffic Content
- **Analytic 1514** (SaaS) — `m365:unified FileUploaded or FileCopied events` → Application Log Content; `saas:box API calls exceeding baseline thresholds` → Network Traffic Content
- **Analytic 1515** (ESXi) — `esxi:vmkernel network session initiation with external HTTPS services` → Network Connection Creation; `esxi:hostd file copy or datastore upload via HTTPS` → File Access

## Adversary usage

**Threat groups (4):** [APT28](https://attack.mitre.org/groups/G0007), [Magic Hound](https://attack.mitre.org/groups/G0059), [BlackByte](https://attack.mitre.org/groups/G1043), [Contagious Interview](https://attack.mitre.org/groups/G1052)

_Notable groups seen using this technique:_

- [APT28](https://attack.mitre.org/groups/G0007) (aka IRON TWILIGHT, SNAKEMACKEREL, Swallowtail, Group 74) — APT28 is a threat group that has been attributed to Russia's General Staff Main Intelligence Directorate (GRU) 85th Main Special Service Center (GTsSS) military unit 26165. This group has been active since at least 2004.
- [Magic Hound](https://attack.mitre.org/groups/G0059) (aka TA453, COBALT ILLUSION, Charming Kitten, ITG18) — Magic Hound is an Iranian-sponsored threat group that conducts long term, resource-intensive cyber espionage operations, likely on behalf of the Islamic Revolutionary Guard Corps.
- [BlackByte](https://attack.mitre.org/groups/G1043) (aka Hecamede) — BlackByte is a ransomware threat actor operating since at least 2021. BlackByte is associated with several versions of ransomware also labeled BlackByte Ransomware.
- [Contagious Interview](https://attack.mitre.org/groups/G1052) (aka DeceptiveDevelopment, Gwisin Gang, Tenacious Pungsan, DEV#POPPER) — Contagious Interview is a North Korea–aligned threat group active since 2023. The group conducts both cyberespionage and financially motivated operations, including the theft of cryptocurrency and user credentials.

**Software/tools (7):** [ngrok](https://attack.mitre.org/software/S0508), [DropBook](https://attack.mitre.org/software/S0547), [AppleSeed](https://attack.mitre.org/software/S0622), [SampleCheck5000](https://attack.mitre.org/software/S1168), [OilCheck](https://attack.mitre.org/software/S1171), [Exbyte](https://attack.mitre.org/software/S1179), [InvisibleFerret](https://attack.mitre.org/software/S1245)
