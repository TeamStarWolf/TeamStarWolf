# T1568.001 — Fast Flux DNS

<a id="t1568001"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1568.001](https://attack.mitre.org/techniques/T1568/001)  
**Sub-technique of:** [T1568 — Dynamic Resolution](/mitre/techniques/T1568.md)  

Adversaries may use Fast Flux DNS to hide a command and control channel behind an array of rapidly changing IP addresses linked to a single domain resolution.

## Detection

**Detection strategies:**

- Detection Strategy for Dynamic Resolution using Fast Flux DNS

**Analytics (4):**

- **Analytic 1331** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Security EventCode=1` → Process Creation
- **Analytic 1332** (Linux) — `auditd:SYSCALL socket/connect` → Network Traffic Flow
- **Analytic 1333** (macOS) — `macos:unifiedlog Rapid domain-to-IP resolution changes for same domain` → Network Traffic Flow; `macos:unifiedlog Unexpected apps generating frequent DNS queries` → Process Creation
- **Analytic 1334** (ESXi) — `esxi:syslog Frequent DNS resolution of same domain with rotating IPs` → Network Traffic Flow
