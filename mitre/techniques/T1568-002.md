# T1568.002 — Domain Generation Algorithms

<a id="t1568002"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1568.002](https://attack.mitre.org/techniques/T1568/002)  
**Sub-technique of:** [T1568 — Dynamic Resolution](/mitre/techniques/T1568.md)  

Adversaries may make use of Domain Generation Algorithms (DGAs) to dynamically identify a destination domain for command and control traffic rather than relying on a list of static IP addresses or domains.

## Mitigations (2)

- [M1021 — Restrict Web-Based Content](/mitre/mitigations/M1021.md) — Restricting web-based content involves enforcing policies and technologies that limit access to potentially malicious websites, unsafe downloads, and unauthorized browser behaviors.
- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.

## Detection

**Detection strategies:**

- Detection Strategy for Dynamic Resolution using Domain Generation Algorithms.

**Analytics (4):**

- **Analytic 1178** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Security EventCode=4688` → Process Creation
- **Analytic 1179** (Linux) — `auditd:SYSCALL socket/connect` → Network Traffic Flow; `linux:syslog Multiple NXDOMAIN responses and high entropy domains` → Network Traffic Content
- **Analytic 1180** (macOS) — `macos:unifiedlog High entropy domain queries with multiple NXDOMAINs` → Network Traffic Flow; `macos:unifiedlog Unexpected apps performing repeated DNS lookups` → Process Creation
- **Analytic 1181** (ESXi) — `esxi:syslog Frequent DNS queries with high entropy names or NXDOMAIN results` → Network Traffic Flow

## Adversary usage

**Threat groups (2):** [APT41](https://attack.mitre.org/groups/G0096), [TA551](https://attack.mitre.org/groups/G0127)

_Notable groups seen using this technique:_

- [APT41](https://attack.mitre.org/groups/G0096) (aka Wicked Panda, Brass Typhoon, BARIUM) — APT41 is a threat group that researchers have assessed as Chinese state-sponsored espionage group that also conducts financially-motivated operations.
- [TA551](https://attack.mitre.org/groups/G0127) (aka GOLD CABIN, Shathak) — TA551 is a financially-motivated threat group that has been active since at least 2018. The group has primarily targeted English, German, Italian, and Japanese speakers through email-based malware distribution campaigns.
