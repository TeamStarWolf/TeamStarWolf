# T1568.003 — DNS Calculation

<a id="t1568003"></a>

**Tactics:** command-and-control  
**Platforms:** Linux, macOS, Windows, ESXi  
**ATT&CK:** [T1568.003](https://attack.mitre.org/techniques/T1568/003)  
**Sub-technique of:** [T1568](/mitre/techniques/T1568.md)

Adversaries may perform calculations on addresses returned in DNS results to determine which port and IP address to use for command and control, rather than relying on a predetermined port number or the actual returned IP address.



## Detection

- Detection Strategy for Dynamic Resolution through DNS Calculation


**Observed use:** 1 threat group(s) (per MITRE ATT&CK).
