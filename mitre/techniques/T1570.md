# T1570 — Lateral Tool Transfer

<a id="t1570"></a>

**Tactics:** lateral-movement  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1570](https://attack.mitre.org/techniques/T1570)  

Adversaries may transfer tools or other files between systems in a compromised environment. Once brought into the victim environment (i.e., [Ingress Tool Transfer](https://attack.mitre.org/techniques/T1105)) files may then be copied from one system to another to stage adversary tools or other files over the course of an operation. Adversaries may copy files between internal victim systems to support lateral movement using inherent file sharing protocols such as file sharing over [SMB/Windows Admin Shares](https://attack.mitre.org/techniques/T1021/002) to connected network shares or with authenticated connections via [Remote Desktop Protocol](https://attack.mitre.org/techniques/T1021/001). Files can also be transferred using native or otherwise present tools on the victim system, such as scp, rsync, curl, sftp, and [ftp](https://attack.mitre.org/software/S0095). In some cases, adversaries may be able to leverage [Web Service](https://attack.mitre.org/techniques/T1102)s such as Dropbox or OneDrive to copy files from one machine to another via shared, automatically synced folders.

## Mitigations (2)

- [M1031 — Network Intrusion Prevention](/mitre/mitigations/M1031.md) — Use intrusion detection signatures to block traffic at network boundaries.
- [M1037 — Filter Network Traffic](/mitre/mitigations/M1037.md) — Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.

## Detection

**Detection strategies:**

- Detection Strategy for Lateral Tool Transfer across OS platforms

**Analytics (4):**

- **Analytic 0516** (Windows) — `WinEventLog:Security EventCode=5140` → Network Share Access; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0517** (Linux) — `auditd:SYSCALL execve: Invocation of scp, rsync, curl, or sftp` → Command Execution; `auditd:FILE create: New file created in system binaries or temp directories` → File Creation
- **Analytic 0518** (macOS) — `macos:unifiedlog Execution of scp, rsync, curl with remote destination` → Process Creation; `macos:unifiedlog File created in ~/Library/LaunchAgents or executable directories` → File Creation
- **Analytic 0519** (ESXi) — `esxi:vmkernel Upload of file to datastore` → File Metadata; `esxi:hostd scp/ssh used to move file across hosts` → Command Execution
