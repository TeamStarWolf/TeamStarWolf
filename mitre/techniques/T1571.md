# T1571 — Non-Standard Port

<a id="t1571"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1571](https://attack.mitre.org/techniques/T1571)  

Adversaries may communicate using a protocol and port pairing that are typically not associated. For example, HTTPS over port 8088 or port 587 as opposed to the traditional port 443. Adversaries may make changes to the standard port used by a protocol to bypass filtering or muddle analysis/parsing of network data.

**Analytics (4):**

- **Analytic 0633** (Windows) — `WinEventLog:Security EventCode=5156, 5157` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0634** (Linux) — `auditd:SYSCALL socket/connect syscalls` → Network Traffic Flow; `linux:syslog processes binding to non-standard ports or sshd configured on unexpected port` → Application Log Content; `linux:osquery process listening or connecting on non-standard ports` → Process Creation
- **Analytic 0635** (macOS) — `macos:unifiedlog outbound TCP/UDP traffic over unexpected port` → Network Traffic Flow; `macos:unifiedlog launchd services binding to non-standard ports` → Process Creation
- **Analytic 0636** (ESXi) — `esxi:vpxd ESXi service connections on unexpected ports` → Network Traffic Flow; `esxcli:network listening sockets bound to non-standard ports` → Network Traffic Content
