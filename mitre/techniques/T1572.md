# T1572 — Protocol Tunneling

<a id="t1572"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Windows  
**ATT&CK:** [T1572](https://attack.mitre.org/techniques/T1572)  

Adversaries may tunnel network communications to and from a victim system within a separate protocol to avoid detection/network filtering and/or enable access to otherwise unreachable systems. Tunneling involves explicitly encapsulating a protocol within another.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **94 machines (17.8%)** — Linux 59 / Windows 29. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Detection

**Detection strategies:**

- Detection Strategy for Protocol Tunneling accross OS platforms.

**Analytics (4):**

- **Analytic 1483** (Windows) — `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation; `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 1484** (Linux) — `auditd:SYSCALL socket/connect calls showing SSH processes forwarding arbitrary ports` → Network Connection Creation; `linux:syslog sshd sessions with unusual port forwarding parameters` → Application Log Content; `linux:osquery socat, ssh, or nc processes opening unexpected ports` → Process Creation
- **Analytic 1485** (macOS) — `macos:unifiedlog process execution of ssh with -L/-R forwarding flags` → Process Creation; `macos:unifiedlog encrypted outbound traffic carrying unexpected application data` → Network Traffic Content
- **Analytic 1486** (ESXi) — `esxi:vpxd ESXi processes relaying traffic via SSH or unexpected ports` → Network Traffic Flow; `esxcli:network listening sockets bound with non-standard encapsulated protocols` → Network Traffic Content
