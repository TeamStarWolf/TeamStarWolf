# T1573.001: Symmetric Cryptography

<a id="t1573001"></a>

Tactics: command-and-control  
Platforms: ESXi, Linux, macOS, Network Devices, Windows  
ATT&CK: [T1573.001](https://attack.mitre.org/techniques/T1573/001)  
Sub-technique of: [T1573: Encrypted Channel](/mitre/techniques/T1573.md)  

Adversaries may employ a known symmetric encryption algorithm to conceal command and control traffic rather than relying on any inherent protections provided by a communication protocol. Symmetric encryption algorithms use the same key for plaintext encryption and ciphertext decryption. Common symmetric encryption algorithms include AES, DES, 3DES, Blowfish, and RC4.

## Detection

Detection strategies:

- Detection Strategy for Encrypted Channel via Symmetric Cryptography across OS Platforms

Analytics (5):

- Analytic 0400 (Windows): `WinEventLog:Sysmon EventCode=7` -> Module Load; `WinEventLog:Sysmon EventCode=3, 22` -> Network Connection Creation
- Analytic 0401 (Linux): `auditd:SYSCALL execve or socket/connect system calls from processes using crypto libraries` -> Process Creation; `linux:syslog System daemons initiating encrypted sessions with unexpected destinations` -> Application Log Content; `linux:osquery Process linked with libcrypto.so making external connections` -> Module Load
- Analytic 0402 (macOS): `macos:unifiedlog Process using AES/RC4 routines unexpectedly` -> Process Creation; `macos:unifiedlog Encrypted connection with anomalous payload entropy` -> Network Traffic Content
- Analytic 0403 (ESXi): `esxi:vpxd Symmetric crypto routines triggered for external session` -> Application Log Content; `esxcli:network Socket sessions with randomized payloads inconsistent with TLS` -> Network Traffic Content
- Analytic 0404 (Network Devices): `NSM:Flow Flow records with entropy signatures resembling symmetric encryption` -> Network Traffic Flow; `NSM:Connections Symmetric encryption detected without TLS handshake sequence` -> Network Traffic Content
