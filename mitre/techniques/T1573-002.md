# T1573.002 — Asymmetric Cryptography

<a id="t1573002"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1573.002](https://attack.mitre.org/techniques/T1573/002)  
**Sub-technique of:** [T1573 — Encrypted Channel](/mitre/techniques/T1573.md)  

Adversaries may employ a known asymmetric encryption algorithm to conceal command and control traffic rather than relying on any inherent protections provided by a communication protocol.

## Detection

**Detection strategies:**

- Detection Strategy for Encrypted Channel via Asymmetric Cryptography across OS Platforms

**Analytics (5):**

- **Analytic 1496** (Windows) — `WinEventLog:Sysmon EventCode=7` → Module Load; `WinEventLog:Sysmon EventCode=3, 22` → Network Connection Creation
- **Analytic 1497** (Linux) — `auditd:SYSCALL execve or socket/connect system calls for processes using RSA handshake` → Process Creation; `linux:syslog Non-standard processes negotiating SSL/TLS key exchanges` → Application Log Content; `linux:osquery Processes linked with libssl/libcrypto performing network activity` → Module Load
- **Analytic 1498** (macOS) — `macos:unifiedlog Process invoking SecKeyCreateRandomKey or asymmetric crypto APIs` → Process Creation; `macos:unifiedlog TLS connections with abnormal handshake sequence or self-signed cert` → Network Traffic Content
- **Analytic 1499** (ESXi) — `esxi:vpxd ESXi process initiating asymmetric handshake with external host` → Application Log Content; `esxcli:network Socket inspection showing RSA key exchange outside baseline endpoints` → Network Traffic Content
- **Analytic 1500** (Network Devices) — `NSM:Flow Flow records with RSA key exchange on unexpected port` → Network Traffic Flow; `IDS:TLSInspection Malformed certs, incomplete asymmetric handshakes, or invalid CAs` → Network Traffic Content
