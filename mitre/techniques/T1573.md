# T1573 — Encrypted Channel

<a id="t1573"></a>

**Tactics:** command-and-control  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1573](https://attack.mitre.org/techniques/T1573)
