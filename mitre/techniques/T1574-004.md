# T1574.004 — Dylib Hijacking

<a id="t1574004"></a>

**Tactics:** persistence, privilege-escalation, defense-evasion  
**Platforms:** macOS  
**ATT&CK:** [T1574.004](https://attack.mitre.org/techniques/T1574/004)  
**Sub-technique of:** [T1574 — Hijack Execution Flow](/mitre/techniques/T1574.md)  

Adversaries may execute their own payloads by placing a malicious dynamic library (dylib) with an expected name in a path a victim application searches at runtime. The dynamic loader will try to find the dylibs based on the sequential order of the search paths.

## Mitigations (1)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md) — Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
