# T1574.006 — Dynamic Linker Hijacking

<a id="t1574006"></a>

**Tactics:** persistence, privilege-escalation, defense-evasion  
**Platforms:** Linux, macOS  
**ATT&CK:** [T1574.006](https://attack.mitre.org/techniques/T1574/006)  
**Sub-technique of:** [T1574 — Hijack Execution Flow](/mitre/techniques/T1574.md)  

Adversaries may execute their own malicious payloads by hijacking environment variables the dynamic linker uses to load shared libraries.

## Detection

**Detection strategies:**

- Detection Strategy for Hijack Execution Flow: Dynamic Linker Hijacking

**Analytics (2):**

- **Analytic 1209** (Linux) — `auditd:SYSCALL execve with LD_PRELOAD or linker-related environment variables set` → Process Creation; `auditd:PATH creation of .so files in non-standard directories (e.g., /tmp, /home/*)` → File Creation; `linux:osquery process environment variables containing LD_PRELOAD` → Process Metadata
- **Analytic 1210** (macOS) — `macos:unifiedlog execution of process with DYLD_INSERT_LIBRARIES set` → Process Creation; `macos:unifiedlog create/modify dylib in monitored directories` → File Modification; `macos:unifiedlog loading of unexpected dylibs compared to historical baselines` → Module Load

## Adversary usage

**Threat groups (3):** [APT41](https://attack.mitre.org/groups/G0096), [Rocke](https://attack.mitre.org/groups/G0106), [Aquatic Panda](https://attack.mitre.org/groups/G0143)

_Notable groups seen using this technique:_

- [APT41](https://attack.mitre.org/groups/G0096) (aka Wicked Panda, Brass Typhoon, BARIUM) — APT41 is a threat group that researchers have assessed as Chinese state-sponsored espionage group that also conducts financially-motivated operations.
- [Rocke](https://attack.mitre.org/groups/G0106) — Rocke is an alleged Chinese-speaking adversary whose primary objective appeared to be cryptojacking, or stealing victim system resources for the purposes of mining cryptocurrency.
- [Aquatic Panda](https://attack.mitre.org/groups/G0143) — Aquatic Panda is a suspected China-based threat group with a dual mission of intelligence collection and industrial espionage.

**Software/tools (6):** [Ebury](https://attack.mitre.org/software/S0377), [HiddenWasp](https://attack.mitre.org/software/S0394), [Hildegard](https://attack.mitre.org/software/S0601), [XCSSET](https://attack.mitre.org/software/S0658), [COATHANGER](https://attack.mitre.org/software/S1105), [MEDUSA](https://attack.mitre.org/software/S1220)
