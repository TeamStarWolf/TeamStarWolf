# T1574.012 — COR_PROFILER

<a id="t1574012"></a>

**Tactics:** persistence, privilege-escalation, defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1574.012](https://attack.mitre.org/techniques/T1574/012)  
**Sub-technique of:** [T1574](/mitre/techniques/T1574.md)
