# T1574.013 — KernelCallbackTable

<a id="t1574013"></a>

**Tactics:** persistence, privilege-escalation, defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1574.013](https://attack.mitre.org/techniques/T1574/013)  
**Sub-technique of:** [T1574 — Hijack Execution Flow](/mitre/techniques/T1574.md)  

Adversaries may abuse the <code>KernelCallbackTable</code> of a process to hijack its execution flow in order to run their own payloads.

## Mitigations (1)

- [M1040 — Behavior Prevention on Endpoint](/mitre/mitigations/M1040.md)

## Detection

**Detection strategies:**

- Detection Strategy for Hijack Execution Flow through the KernelCallbackTable on Windows.

**Analytics (1):**

- **Analytic 1593** (Windows) — `WinEventLog:Sysmon EventCode=10` → Process Access; `WinEventLog:Sysmon EventCode=1` → Process Creation; `etw:Microsoft-Windows-Kernel-Process WriteProcessMemory: WriteProcessMemory targeting regions containing KernelCallbackTable addresses` → OS API Execution
