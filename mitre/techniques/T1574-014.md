# T1574.014 — AppDomainManager

<a id="t1574014"></a>

**Tactics:** persistence, privilege-escalation, defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1574.014](https://attack.mitre.org/techniques/T1574/014)  
**Sub-technique of:** [T1574 — Hijack Execution Flow](/mitre/techniques/T1574.md)  

Adversaries may execute their own malicious payloads by hijacking how the .NET `AppDomainManager` loads assemblies.

## Mitigations (1)

- [M1022 — Restrict File and Directory Permissions](/mitre/mitigations/M1022.md)

## Detection

**Detection strategies:**

- Detection Strategy for Hijack Execution Flow through the AppDomainManager on Windows.

**Analytics (1):**

- **Analytic 1433** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation; `WinEventLog:Sysmon EventCode=7` → Module Load
