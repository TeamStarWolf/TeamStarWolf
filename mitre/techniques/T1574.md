# T1574 — Hijack Execution Flow

<a id="t1574"></a>

**Tactics:** persistence, privilege-escalation, defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1574](https://attack.mitre.org/techniques/T1574)

Adversaries may execute their own malicious payloads by hijacking the way operating systems run programs. Hijacking execution flow can be for the purposes of persistence, since this hijacked execution may reoccur over time.


**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **13 machines (2.5%)** — Linux 8 / Windows 4. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.
