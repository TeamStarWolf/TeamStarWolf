# T1578.004 — Revert Cloud Instance

<a id="t1578004"></a>

**Tactics:** defense-evasion  
**Platforms:** IaaS  
**ATT&CK:** [T1578.004](https://attack.mitre.org/techniques/T1578/004)  
**Sub-technique of:** [T1578 — Modify Cloud Compute Infrastructure](/mitre/techniques/T1578.md)  

An adversary may revert changes made to a cloud instance after they have performed malicious activities in attempt to evade detection and remove evidence of their presence.

## D3FEND countermeasures (7)

- [Configuration Inventory](/mitre/d3fend/configuration-inventory.md) (Model) — inventories. Configuration inventory identifies and records the configuration of software and hardware and their components throughout the organization.
- [Endpoint Health Beacon](/mitre/d3fend/endpoint-health-beacon.md) (Detect) — monitors. Monitoring the security status of an endpoint by sending periodic messages with health status, where absence of a response may indicate that the endpoint has been compromised.
- [Logical Link Mapping](/mitre/d3fend/logical-link-mapping.md) (Model) — maps. Logical link mapping creates a model of existing or previous node-to-node connections using network-layer data or metadata.
- [Network Node Inventory](/mitre/d3fend/network-node-inventory.md) (Model) — inventories. Network node inventorying identifies and records all the network nodes (hosts, routers, switches, firewalls, etc.) in the organization's architecture.
- [Physical Link Mapping](/mitre/d3fend/physical-link-mapping.md) (Model) — maps. Physical link mapping identifies and models the link connectivity of the network devices within a physical network.
- [Restore Configuration](/mitre/d3fend/restore-configuration.md) (Restore) — restores. Restoring an software configuration.
- [Restore Network Access](/mitre/d3fend/restore-network-access.md) (Restore) — restores. Restoring a entity's access to a computer network.
