# T1578.004 — Revert Cloud Instance

<a id="t1578004"></a>

**Tactics:** defense-evasion  
**Platforms:** IaaS  
**ATT&CK:** [T1578.004](https://attack.mitre.org/techniques/T1578/004)  
**Sub-technique of:** [T1578 — Modify Cloud Compute Infrastructure](/mitre/techniques/T1578.md)  

An adversary may revert changes made to a cloud instance after they have performed malicious activities in attempt to evade detection and remove evidence of their presence.
