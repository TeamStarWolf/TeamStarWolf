# T1583.004 — Server

<a id="t1583004"></a>

**Tactics:** resource-development  
**Platforms:** PRE  
**ATT&CK:** [T1583.004](https://attack.mitre.org/techniques/T1583/004)  
**Sub-technique of:** [T1583 — Acquire Infrastructure](/mitre/techniques/T1583.md)  

Adversaries may buy, lease, rent, or obtain physical servers that can be used during targeting. Use of servers allows an adversary to stage, launch, and execute an operation.
