# T1587.002 — Code Signing Certificates

<a id="t1587002"></a>

**Tactics:** resource-development  
**Platforms:** PRE  
**ATT&CK:** [T1587.002](https://attack.mitre.org/techniques/T1587/002)  
**Sub-technique of:** [T1587 — Develop Capabilities](/mitre/techniques/T1587.md)  

Adversaries may create self-signed code signing certificates that can be used during targeting. Code signing is the process of digitally signing executables and scripts to confirm the software author and guarantee that the code has not been altered or corrupted. Code signing provides a level of authenticity for a program from the developer and a guarantee that the program has not been tampered with. Users and/or security tools may trust a signed piece of code more than an unsigned piece of code even if they don't know who issued the certificate or who the author is. Prior to [Code Signing](https://attack.mitre.org/techniques/T1553/002), adversaries may develop self-signed code signing certificates for use in operations.

## Adversary usage

**Threat groups (3):** [Patchwork](https://attack.mitre.org/groups/G0040), [PROMETHIUM](https://attack.mitre.org/groups/G0056), [Daggerfly](https://attack.mitre.org/groups/G1034)

_Notable groups seen using this technique:_

- [Patchwork](https://attack.mitre.org/groups/G0040) (aka Hangover Group, Dropping Elephant, Chinastrats, MONSOON) — Patchwork is a cyber espionage group that was first observed in December 2015. While the group has not been definitively attributed, circumstantial evidence suggests the group may be a pro-Indian or Indian entity.
- [PROMETHIUM](https://attack.mitre.org/groups/G0056) (aka StrongPity) — PROMETHIUM is an activity group focused on espionage that has been active since at least 2012. The group has conducted operations globally with a heavy emphasis on Turkish targets.
- [Daggerfly](https://attack.mitre.org/groups/G1034) (aka Evasive Panda, BRONZE HIGHLAND) — Daggerfly is a People's Republic of China-linked APT entity active since at least 2012. Daggerfly has targeted individuals, government and NGO entities, and telecommunication companies in Asia and Africa.
