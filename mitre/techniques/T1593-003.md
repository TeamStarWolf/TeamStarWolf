# T1593.003 — Code Repositories

<a id="t1593003"></a>

**Tactics:** reconnaissance  
**Platforms:** PRE  
**ATT&CK:** [T1593.003](https://attack.mitre.org/techniques/T1593/003)  
**Sub-technique of:** [T1593 — Search Open Websites/Domains](/mitre/techniques/T1593.md)  

Adversaries may search public code repositories for information about victims that can be used during targeting. Victims may store code in repositories on various third-party websites such as GitHub, GitLab, SourceForge, and BitBucket.

## Mitigations (2)

- [M1013 — Application Developer Guidance](/mitre/mitigations/M1013.md) — Application Developer Guidance focuses on providing developers with the knowledge, tools, and best practices needed to write secure code, reduce vulnerabilities, and implement secure design principles.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Adversary usage

**Threat groups (3):** [HAFNIUM](https://attack.mitre.org/groups/G0125), [LAPSUS$](https://attack.mitre.org/groups/G1004), [Contagious Interview](https://attack.mitre.org/groups/G1052)

_Notable groups seen using this technique:_

- [HAFNIUM](https://attack.mitre.org/groups/G0125) (aka Operation Exchange Marauder, Silk Typhoon) — HAFNIUM is a likely state-sponsored cyber espionage group operating out of China that has been active since at least January 2021. HAFNIUM primarily targets entities in the US across a number of industry sectors…
- [LAPSUS$](https://attack.mitre.org/groups/G1004) (aka DEV-0537, Strawberry Tempest) — LAPSUS$ is cyber criminal threat group that has been active since at least mid-2021.
- [Contagious Interview](https://attack.mitre.org/groups/G1052) (aka DeceptiveDevelopment, Gwisin Gang, Tenacious Pungsan, DEV#POPPER) — Contagious Interview is a North Korea–aligned threat group active since 2023. The group conducts both cyberespionage and financially motivated operations, including the theft of cryptocurrency and user credentials.
