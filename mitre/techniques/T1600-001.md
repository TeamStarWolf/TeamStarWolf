# T1600.001 — Reduce Key Space

<a id="t1600001"></a>

**Tactics:** defense-evasion  
**Platforms:** Network Devices  
**ATT&CK:** [T1600.001](https://attack.mitre.org/techniques/T1600/001)  
**Sub-technique of:** [T1600 — Weaken Encryption](/mitre/techniques/T1600.md)  

Adversaries may reduce the level of effort required to decrypt data transmitted over the network by reducing the cipher strength of encrypted communications.

## Detection

**Detection strategies:**

- Detection Strategy for Weaken Encryption: Reduce Key Space on Network Devices

**Analytics (1):**

- **Analytic 0681** (Network Devices) — `networkdevice:config Configuration changes referencing 'crypto', 'key length', 'cipher', or downgrade of encryption settings` → File Modification; `networkdevice:cli Execution of CLI commands altering crypto parameters (e.g., 'crypto key generate rsa modulus 512')` → Command Execution; `NSM:Flow Observed downgrade in negotiated cipher suites or TLS/SSH versions across sessions` → Network Traffic Content
