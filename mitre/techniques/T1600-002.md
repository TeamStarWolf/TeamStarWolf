# T1600.002 — Disable Crypto Hardware

<a id="t1600002"></a>

**Tactics:** defense-evasion  
**Platforms:** Network Devices  
**ATT&CK:** [T1600.002](https://attack.mitre.org/techniques/T1600/002)  
**Sub-technique of:** [T1600 — Weaken Encryption](/mitre/techniques/T1600.md)  

Adversaries disable a network device’s dedicated hardware encryption, which may enable them to leverage weaknesses in software encryption in order to reduce the effort involved in collecting, manipulating, and exfiltrating transmitted data.

## Detection

**Detection strategies:**

- Detection Strategy for Weaken Encryption: Disable Crypto Hardware on Network Devices

**Analytics (1):**

- **Analytic 1360** (Network Devices) — `networkdevice:cli Execution of commands disabling crypto hardware acceleration (e.g., 'no crypto engine enable')` → Command Execution; `networkdevice:config Configuration changes referencing cryptographic hardware modules or disabling hardware acceleration` → File Modification; `NSM:Flow Degraded encryption throughput or switch to weaker cipher suites compared to historical baselines` → Network Traffic Content

## Data sources & telemetry (3)

**Command Execution**, **File Modification**, **Network Traffic Content**
