# T1601.001 — Patch System Image

<a id="t1601001"></a>

**Tactics:** defense-evasion  
**Platforms:** Network Devices  
**ATT&CK:** [T1601.001](https://attack.mitre.org/techniques/T1601/001)  
**Sub-technique of:** [T1601 — Modify System Image](/mitre/techniques/T1601.md)  

Adversaries may modify the operating system of a network device to introduce new capabilities or weaken existing defenses. Some network devices are built with a monolithic architecture, where the entire operating system and most of the functionality of the device is contained within a single file.

## Mitigations (6)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1027 — Password Policies](/mitre/mitigations/M1027.md) — Set and enforce secure password policies for accounts to reduce the likelihood of unauthorized access.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1043 — Credential Access Protection](/mitre/mitigations/M1043.md) — Credential Access Protection focuses on implementing measures to prevent adversaries from obtaining credentials, such as passwords, hashes, tokens, or keys, that could be used for unauthorized access.
- [M1045 — Code Signing](/mitre/mitigations/M1045.md) — Code Signing is a security process that ensures the authenticity and integrity of software by digitally signing executables, scripts, and other code artifacts.
- [M1046 — Boot Integrity](/mitre/mitigations/M1046.md) — Boot Integrity ensures that a system starts securely by verifying the integrity of its boot process, operating system, and associated components.

## Detection

**Detection strategies:**

- Detection Strategy for Patch System Image on Network Devices

**Analytics (1):**

- **Analytic 1293** (Network Devices) — `networkdevice:cli Execution of privileged commands such as 'copy tftp flash', 'boot system', or 'debug memory'` → Command Execution; `networkdevice:config Configuration changes to startup image paths, boot loader parameters, or debug flags` → File Modification; `firmware:runtime Debug or memory access commands indicating attempts to alter OS instructions in memory` → Firmware Modification
