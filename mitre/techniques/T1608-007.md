# T1608.007: AI Result Poisoning

<a id="t1608007"></a>

> New in ATT&CK v20.0. MITRE added this technique in the current release. The overview, defender notes, references and related ATLAS techniques on this page are the library's own, last reviewed 2026-11-03; the NIST control and corpus signal data do not cover it yet.

Search poisoning has a new target: the answer box. Adversaries publish pages, forum posts and listings written so that AI search features and chat assistants pick them up and repeat them, putting a phishing site, a fake support number or a malicious download into an answer the user already trusts.

Netcraft reported in August 2026 that threat actors were finding their way into AI summaries, and Lasso Security showed how generative engine optimization (GEO) can push harmful claims into AI-generated answers. Because the staging happens on the open web before any victim system is involved, ATT&CK files it under Resource Development.

ATT&CK's definition: Adversaries may manipulate publicly accessible web content to influence generative AI systems or AI-powered search engines into retrieving, citing, or recommending attacker-controlled information.

## Detection

Detection strategies:

- Detection of AI Result Poisoning

Analytics (1):

- Analytic 2068 (PRE): No target-side behavioral analytic. A defender cannot reliably distinguish an adversary intentionally staging public content to manipulate future AI retrieval from ordinary publishing, SEO, inaccurate information, duplicated content, or legitimate coordinated publication using target-enterprise telemetry.

Defender notes (library): MITRE's analytic states that the target cannot reliably tell this staging apart from ordinary publishing using its own telemetry. What an organization can watch: AI answers and AI search results that mention its brand, support numbers or download locations (checked on a schedule, the way brand-protection teams already watch search ads); newly registered or lookalike domains that start appearing in those answers; and, on endpoints, users who paste a command into a shell or Run dialog shortly after visiting an AI assistant or answer page.
