# T1611 — Escape to Host

<a id="t1611"></a>

**Tactics:** privilege-escalation  
**Platforms:** Windows, Linux, Containers, ESXi  
**ATT&CK:** [T1611](https://attack.mitre.org/techniques/T1611)  

Adversaries may break out of a container or virtualized environment to gain access to the underlying host. This can allow an adversary access to other containerized or virtualized resources from the host level or to the host itself.

**Team Star Wolf corpus signal (keyword-derived, n=529 HTB training machines):** observed on **7 machines (1.3%)** — Linux 7 / Windows 0. See the corpus deep-dive and detection-coverage matrix in the Lylat Labs range for tooling and detections.

## Mitigations (5)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1038 — Execution Prevention](/mitre/mitigations/M1038.md) — Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.
- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.
- [M1048 — Application Isolation and Sandboxing](/mitre/mitigations/M1048.md) — Application Isolation and Sandboxing refers to the technique of restricting the execution of code to a controlled and isolated environment (e.g., a virtual environment, container, or sandbox).
- [M1051 — Update Software](/mitre/mitigations/M1051.md) — Software updates ensure systems are protected against known vulnerabilities by applying patches and upgrades provided by vendors.

**Analytics (4):**

- **Analytic 0612** (Containers) — `docker:daemon container create/start with privileged flag or host volume mount` → Container Creation; `kubernetes:apiserver Pod spec with hostPath or privileged securityContext` → Volume Modification
- **Analytic 0613** (Linux) — `auditd:SYSCALL unshare, mount, keyctl, setns syscalls executed by containerized processes` → OS API Execution; `linux:Sysmon process creation events linked to container namespaces executing host-level binaries` → Process Creation
- **Analytic 0614** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 0615** (ESXi) — `esxi:vmkernel VM exit/entry anomalies, unexpected hypercalls, or kernel module loading` → Kernel Module Load
