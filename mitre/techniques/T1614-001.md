# T1614.001 — System Language Discovery

<a id="t1614001"></a>

**Tactics:** discovery  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1614.001](https://attack.mitre.org/techniques/T1614/001)  
**Sub-technique of:** [T1614 — System Location Discovery](/mitre/techniques/T1614.md)  

Adversaries may attempt to gather information about the system language of a victim in order to infer the geographical location of that host. This information may be used to shape follow-on behaviors, including whether the adversary infects the target and/or attempts specific actions.

## Detection

**Detection strategies:**

- Detection Strategy for System Language Discovery

**Analytics (3):**

- **Analytic 1561** (Windows) — `WinEventLog:Security EventCode=4657` → Windows Registry Key Access; `WinEventLog:Sysmon EventCode=1` → Process Creation; `ETW Calls to GetUserDefaultUILanguage, GetSystemDefaultUILanguage, GetKeyboardLayoutList` → OS API Execution
- **Analytic 1562** (Linux) — `auditd:SYSCALL execve calls to /usr/bin/locale or shell execution of $LANG` → Command Execution; `linux:Sysmon EventCode=1` → Process Creation
- **Analytic 1563** (macOS) — `macos:unifiedlog defaults read -g AppleLocale or systemsetup -gettimezone` → Command Execution; `macos:osquery execve` → Process Creation
