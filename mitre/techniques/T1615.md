# T1615 — Group Policy Discovery

<a id="t1615"></a>

**Tactics:** discovery  
**Platforms:** Windows  
**ATT&CK:** [T1615](https://attack.mitre.org/techniques/T1615)  

Adversaries may gather information on Group Policy settings to identify paths for privilege escalation, security measures applied within a domain, and to discover patterns in domain objects that can be manipulated or used to blend in the environment.

## D3FEND countermeasures (4)

- [Access Modeling](/mitre/d3fend/access-modeling.md) (Model) — maps. Access modeling captures and records the access permissions granted to identities (e.g., administrators, users, groups, systems) and optionally includes details on how these identities are stored, managed, and shared…
- [Configuration Inventory](/mitre/d3fend/configuration-inventory.md) (Model) — inventories. Configuration inventory identifies and records the configuration of software and hardware and their components throughout the organization.
- [Network Traffic Policy Mapping](/mitre/d3fend/network-traffic-policy-mapping.md) (Model) — maps. Network traffic policy mapping identifies and models the allowed pathways of data at the network, transport, and/or application levels.
- [Restore Configuration](/mitre/d3fend/restore-configuration.md) (Restore) — restores. Restoring an software configuration.

## Detection

**Detection strategies:**

- Detection strategy for Group Policy Discovery on Windows

**Analytics (1):**

- **Analytic 0152** (Windows) — `WinEventLog:Security EventCode=4661` → Active Directory Object Access; `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `NSM:Flow query: High-volume LDAP traffic with filters targeting groupPolicyContainer attributes` → Network Traffic Content
