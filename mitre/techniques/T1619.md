# T1619: Cloud Storage Object Discovery

<a id="t1619"></a>

Tactics: discovery  
Platforms: IaaS  
ATT&CK: [T1619](https://attack.mitre.org/techniques/T1619)  

Adversaries may enumerate objects in cloud storage infrastructure. Adversaries may use this information during automated discovery to shape follow-on behaviors, including requesting all or specific objects from cloud storage. Similar to [File and Directory Discovery](https://attack.mitre.org/techniques/T1083) on a local host, after identifying available storage services (i.e. [Cloud Infrastructure Discovery](https://attack.mitre.org/techniques/T1580)) adversaries may access the contents/objects stored in cloud infrastructure. Cloud service providers offer APIs allowing users to enumerate objects stored within cloud storage. Examples include ListObjectsV2 in AWS and List Blobs in Azure.

## Mitigations (1)

- [M1018: User Account Management](/mitre/mitigations/M1018.md): User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.

## D3FEND countermeasures (6)

- [Disk Encryption](/mitre/d3fend/disk-encryption.md) (Harden): encrypts. Encrypting a hard disk partition to prevent cleartext access to a file system.
- [Disk Erasure](/mitre/d3fend/disk-erasure.md) (Evict): erases. Disk Erasure is the process of securely deleting all data on a disk to ensure that it cannot be recovered by any means.
- [Disk Formatting](/mitre/d3fend/disk-formatting.md) (Evict): modifies. Disk Formatting is the process of preparing a data storage device, such as a hard drive, solid-state drive, or USB flash drive, for initial use.
- [Hardware Component Inventory](/mitre/d3fend/hardware-component-inventory.md) (Model): inventories. Hardware component inventorying identifies and records the hardware items in the organization's architecture.
- [Hardware-based Write Protection](/mitre/d3fend/hardware-based-write-protection.md) (Harden): hardens. Physical methods of preventing data from being written to computer storage.
- [Radiation Hardening](/mitre/d3fend/radiation-hardening.md) (Harden): hardens. Radiation hardening is the process of making electronic components and circuits resistant to damage or malfunction caused by high levels of ionizing radiation.
