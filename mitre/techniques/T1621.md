# T1621 — Multi-Factor Authentication Request Generation

<a id="t1621"></a>

**Tactics:** credential-access  
**Platforms:** Windows, Linux, macOS, IaaS, SaaS, Office Suite, Identity Provider  
**ATT&CK:** [T1621](https://attack.mitre.org/techniques/T1621)  

Adversaries may attempt to bypass multi-factor authentication (MFA) mechanisms and gain access to accounts by generating MFA requests sent to users.

## Detection

**Detection strategies:**

- Detection Strategy for Multi-Factor Authentication Request Generation (T1621)

**Analytics (6):**

- **Analytic 0449** (Identity Provider) — `azure:signinlogs Multiple MFA challenge requests without successful primary login` → User Account Authentication; `NSM:Connections PushNotificationSent` → Application Log Content
- **Analytic 0450** (IaaS) — `AWS:CloudTrail AssumeRole or ConsoleLogin with repeated MFA failures followed by repeated MFA requests` → User Account Authentication
- **Analytic 0451** (Windows) — `WinEventLog:Security EventCode=4625` → User Account Authentication
- **Analytic 0452** (Linux) — `auditd:AUTH pam_unix or pam_google_authenticator invoked repeatedly within short interval` → User Account Authentication
- **Analytic 0453** (SaaS) — `saas:okta MFAChallengeIssued` → Application Log Content
- **Analytic 0454** (macOS) — `macos:unifiedlog authd generating multiple MFA token requests` → Logon Session Metadata
