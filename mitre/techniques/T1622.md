# T1622 — Debugger Evasion

<a id="t1622"></a>

**Tactics:** defense-evasion, discovery  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1622](https://attack.mitre.org/techniques/T1622)  

Adversaries may employ various means to detect and avoid debuggers. Debuggers are typically used by defenders to trace and/or analyze the execution of potential malware payloads.

## Detection

**Detection strategies:**

- Detection Strategy for Debugger Evasion (T1622)

**Analytics (3):**

- **Analytic 1045** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `etw:Microsoft-Windows-Kernel-Process NtQueryInformationProcess` → OS API Execution
- **Analytic 1046** (Linux) — `auditd:SYSCALL open/read: Access to /proc/self/status with focus on TracerPID field` → File Access
- **Analytic 1047** (macOS) — `macos:unifiedlog ptrace: Processes invoking ptrace with PTRACE_TRACEME flag` → OS API Execution

## Data sources & telemetry (3)

**Process Creation**, **OS API Execution**, **File Access**
