# T1651 — Cloud Administration Command

<a id="t1651"></a>

**Tactics:** execution  
**Platforms:** IaaS  
**ATT&CK:** [T1651](https://attack.mitre.org/techniques/T1651)  

Adversaries may abuse cloud management services to execute commands within virtual machines. Resources such as AWS Systems Manager, Azure RunCommand, and Runbooks allow users to remotely run scripts in virtual machines by leveraging installed virtual machine agents.

## Mitigations (1)

- [M1026 — Privileged Account Management](/mitre/mitigations/M1026.md) — Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
