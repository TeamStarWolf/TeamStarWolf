# T1652 — Device Driver Discovery

<a id="t1652"></a>

**Tactics:** discovery  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1652](https://attack.mitre.org/techniques/T1652)  

Adversaries may attempt to enumerate local device drivers on a victim host. Information about device drivers may highlight various insights that shape follow-on behaviors, such as the function/purpose of the host, present security tools (i.e. [Security Software Discovery](https://attack.mitre.org/techniques/T1518/001)) or other defenses (e.g., [Virtualization/Sandbox Evasion](https://attack.mitre.org/techniques/T1497)), as well as potential exploitable vulnerabilities (e.g., [Exploitation for Privilege Escalation](https://attack.mitre.org/techniques/T1068)). Many OS utilities may provide information about local device drivers, such as `driverquery.exe` and the `EnumDeviceDrivers()` API function on Windows. Information about device drivers (as well as associated services, i.e., [System Service Discovery](https://attack.mitre.org/techniques/T1007)) may also be available in the Registry. On Linux/macOS, device drivers (in the form of kernel modules) may be visible within `/dev` or using utilities such as `lsmod` and `modinfo`.

## Detection

**Detection strategies:**

- Detection Strategy for Device Driver Discovery

**Analytics (3):**

- **Analytic 1595** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 1596** (Linux) — `auditd:SYSCALL execve: Execution of lsmod, modinfo, or cat /proc/modules` → Command Execution; `auditd:FS read: File access to /proc/modules or /sys/module/` → File Access
- **Analytic 1597** (macOS) — `macos:unifiedlog exec: Execution of kextstat, kextfind, or ioreg targeting driver information` → Process Creation; `macos:unifiedlog read: File access to /System/Library/Extensions/ or related kernel extension paths` → File Access

## Data sources & telemetry (4)

**Process Creation**, **Windows Registry Key Modification**, **Command Execution**, **File Access**
