# T1653 — Power Settings

<a id="t1653"></a>

**Tactics:** persistence  
**Platforms:** Windows, Linux, macOS, Network Devices  
**ATT&CK:** [T1653](https://attack.mitre.org/techniques/T1653)  

Adversaries may impair a system's ability to hibernate, reboot, or shut down in order to extend access to infected machines. When a computer enters a dormant state, some or all software and hardware may cease to operate which can disrupt malicious activity.

## Mitigations (1)

- [M1047 — Audit](/mitre/mitigations/M1047.md)

## Detection

**Detection strategies:**

- Detection Strategy for Power Settings Abuse

**Analytics (3):**

- **Analytic 1174** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation
- **Analytic 1175** (Linux) — `auditd:SYSCALL execve: Execution of systemctl, loginctl, or systemd-inhibit commands related to sleep/hibernate` → Command Execution; `auditd:PATH write: File modifications to /etc/systemd/sleep.conf or related power configuration files` → File Modification
- **Analytic 1176** (macOS) — `macos:unifiedlog Process creation events where command line = pmset with arguments affecting sleep, hibernatemode, displaysleep` → Process Creation; `macos:unifiedlog write: File modification to com.apple.PowerManagement.plist or related system preference files` → File Modification
