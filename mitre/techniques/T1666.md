# T1666 — Modify Cloud Resource Hierarchy

<a id="t1666"></a>

**Tactics:** defense-evasion  
**Platforms:** IaaS  
**ATT&CK:** [T1666](https://attack.mitre.org/techniques/T1666)  

Adversaries may attempt to modify hierarchical structures in infrastructure-as-a-service (IaaS) environments in order to evade defenses. IaaS environments often group resources into a hierarchy, enabling improved resource management and application of policies to relevant groups.

## Mitigations (3)

- [M1018 — User Account Management](/mitre/mitigations/M1018.md) — User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.
- [M1054 — Software Configuration](/mitre/mitigations/M1054.md) — Software configuration refers to making security-focused adjustments to the settings of applications, middleware, databases, or other software to mitigate potential threats.
