# T1667 — Email Bombing

<a id="t1667"></a>

**Tactics:** impact  
**Platforms:** Linux, Office Suite, Windows, macOS  
**ATT&CK:** [T1667](https://attack.mitre.org/techniques/T1667)  

Adversaries may flood targeted email addresses with an overwhelming volume of messages. This may bury legitimate emails in a flood of spam and disrupt business operations.

## Mitigations (2)

- [M1017 — User Training](/mitre/mitigations/M1017.md) — User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.

## Detection

**Detection strategies:**

- Detection Strategy for Email Bombing

**Analytics (4):**

- **Analytic 1008** (Windows) — `m365:unified Send/Receive: Unusual spikes in inbound messages to a single recipient` → Application Log Content; `WinEventLog:Sysmon EventCode=11` → File Creation
- **Analytic 1009** (Linux) — `auditd:SYSCALL File creation events in /var/mail or /var/spool/mail exceeding baseline thresholds` → File Creation; `Application:Mail High-frequency inbound mail activity to a specific recipient address` → Application Log Content
- **Analytic 1010** (Office Suite) — `m365:exchange MailDelivery: High-frequency delivery of messages or attachments to a single recipient` → Application Log Content
- **Analytic 1011** (macOS) — `macos:unifiedlog Repetitive inbound email delivery activity logged within a short time window` → Application Log Content; `fs:fsusage create: Attachment file creation in ~/Library/Mail directories` → File Creation
