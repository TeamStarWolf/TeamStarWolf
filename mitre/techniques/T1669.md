# T1669 — Wi-Fi Networks

<a id="t1669"></a>

**Tactics:** initial-access  
**Platforms:** Linux, Network Devices, Windows, macOS  
**ATT&CK:** [T1669](https://attack.mitre.org/techniques/T1669)  

Adversaries may gain initial access to target systems by connecting to wireless networks. They may accomplish this by exploiting open Wi-Fi networks used by target devices or by accessing secured Wi-Fi networks — requiring Valid Accounts — belonging to a target organization.

## Mitigations (3)

- [M1030 — Network Segmentation](/mitre/mitigations/M1030.md) — Network segmentation involves dividing a network into smaller, isolated segments to control and limit the flow of traffic between devices, systems, and applications.
- [M1032 — Multi-factor Authentication](/mitre/mitigations/M1032.md) — Multi-Factor Authentication (MFA) enhances security by requiring users to provide at least two forms of verification to prove their identity before granting access.
- [M1041 — Encrypt Sensitive Information](/mitre/mitigations/M1041.md) — Protect sensitive information at rest, in transit, and during processing by using strong encryption algorithms.

## Detection

**Detection strategies:**

- Detection Strategy for Wi-Fi Networks

**Analytics (4):**

- **Analytic 1476** (Windows) — `WinEventLog:Microsoft-Windows-WLAN-AutoConfig EventCode=8001, 8002, 8003` → Network Connection Creation; `WinEventLog:Security EventCode=4776, 4625` → User Account Authentication
- **Analytic 1477** (Linux) — `linux:syslog New Wi-Fi connection established or repeated association failures` → Network Connection Creation; `auditd:SYSCALL ioctl: Changes to wireless network interfaces (up, down, reassociate)` → Network Traffic Flow
- **Analytic 1478** (macOS) — `macos:unifiedlog Association and authentication events including failures and new SSIDs` → Network Connection Creation; `macos:osquery query: Historical list of associated SSIDs compared against baseline` → Network Traffic Flow
- **Analytic 1479** (Network Devices) — `NSM:Firewall rule_modification: New or modified firewall rules related to wireless interfaces` → Firewall Rule Modification; `WIDS:AssociationLogs Unauthorized AP or anomalous MAC address connection attempts` → Network Traffic Content
