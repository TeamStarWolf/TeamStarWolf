# T1671 — Cloud Application Integration

<a id="t1671"></a>

**Tactics:** persistence  
**Platforms:** Office Suite, SaaS  
**ATT&CK:** [T1671](https://attack.mitre.org/techniques/T1671)  

Adversaries may achieve persistence by leveraging OAuth application integrations in a software-as-a-service environment. Adversaries may create a custom application, add a legitimate application into the environment, or even co-opt an existing integration to achieve malicious ends.

## Mitigations (2)

- [M1042 — Disable or Remove Feature or Program](/mitre/mitigations/M1042.md) — Disable or remove unnecessary and potentially vulnerable software, features, or services to reduce the attack surface and prevent abuse by adversaries.
- [M1047 — Audit](/mitre/mitigations/M1047.md) — Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.

## Detection

**Detection strategies:**

- Detection Strategy for Cloud Application Integration

**Analytics (2):**

- **Analytic 1487** (Office Suite) — `m365:unified Add app role assignment grant to user: Consent to application by privileged or unexpected accounts` → Active Directory Object Modification; `azure:audit Consent to application: OAuth application consent granted to service principal` → Cloud Service Modification
- **Analytic 1488** (SaaS) — `saas:integration New or modified third-party application integrations with elevated permissions` → Cloud Service Modification; `saas:audit Application added or consent granted: Integration persisting after original user disabled` → Application Log Content
