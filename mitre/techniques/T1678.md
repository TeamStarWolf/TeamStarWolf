# T1678 — Delay Execution

<a id="t1678"></a>

**Tactics:** defense-evasion  
**Platforms:** Linux, macOS, Windows  
**ATT&CK:** [T1678](https://attack.mitre.org/techniques/T1678)  

Adversaries may employ various time-based methods to evade detection and analysis. These techniques often exploit system clocks, delays, or timing mechanisms to obscure malicious activity, blend in with benign activity, and avoid scrutiny.

## Detection

**Detection strategies:**

- Multi-Platform Detection Strategy for T1678 - Delay Execution

**Analytics (3):**

- **Analytic 1048** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation; `WinEventLog:Sysmon EventCode=7` → Module Load
- **Analytic 1049** (Linux) — `auditd:SYSCALL execve or nanosleep with no stdout/stderr I/O` → Process Creation; `auditd:PROCTITLE scripting loop invoking sleep/ping` → Script Execution
- **Analytic 1050** (macOS) — `macos:unifiedlog launchd or osascript spawns process with delay command` → Process Creation; `macos:unifiedlog delay/sleep library usage in user context` → Module Load
