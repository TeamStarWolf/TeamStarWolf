# T1679 — Selective Exclusion

<a id="t1679"></a>

**Tactics:** defense-evasion  
**Platforms:** Windows  
**ATT&CK:** [T1679](https://attack.mitre.org/techniques/T1679)  

Adversaries may intentionally exclude certain files, folders, directories, file types, or system components from encryption or tampering during a ransomware or malicious payload execution. Some file extensions that adversaries may avoid encrypting include `.dll`, `.exe`, and `.lnk`.

## Detection

**Detection strategies:**

- Detection of Selective Exclusion

**Analytics (1):**

- **Analytic 2030** (Windows) — `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` → Command Execution; `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Security EventCode=4663, 4670, 4656` → File Modification
