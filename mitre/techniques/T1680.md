# T1680 — Local Storage Discovery

<a id="t1680"></a>

**Tactics:** discovery  
**Platforms:** ESXi, IaaS, Linux, macOS, Windows  
**ATT&CK:** [T1680](https://attack.mitre.org/techniques/T1680)  

Adversaries may enumerate local drives, disks, and/or volumes and their attributes like total or free space and volume serial number. This can be done to prepare for ransomware-related encryption, to perform Lateral Movement, or as a precursor to Direct Volume Access.

## Detection

**Detection strategies:**

- Local Storage Discovery via Drive Enumeration and Filesystem Probing

**Analytics (4):**

- **Analytic 0536** (Windows) — `WinEventLog:Sysmon EventCode=1` → Process Creation
- **Analytic 0537** (Linux) — `auditd:SYSCALL execve call with argv matching known disk enumeration commands (lsblk, parted, fdisk)` → Process Creation; `auditd:EXECVE command line arguments containing lsblk, fdisk, parted` → Command Execution
- **Analytic 0538** (macOS) — `macos:unifiedlog process launch of diskutil or system_profiler with SPStorageDataType` → Process Creation; `macos:unifiedlog log messages related to disk enumeration context or Terminal session` → Command Execution
- **Analytic 0539** (ESXi) — `esxi:hostd execution of esxcli with args matching 'storage', 'filesystem', 'core device list'` → Process Creation; `esxi:auth interactive shell or SSH access preceding storage enumeration` → User Account Authentication

## Data sources & telemetry (3)

**Process Creation**, **Command Execution**, **User Account Authentication**
