# T1685.007: Impair Autonomous Defenses

<a id="t1685007"></a>

> New in ATT&CK v20.0. MITRE added this technique in the current release. The overview, defender notes, references and related ATLAS techniques on this page are the library's own, last reviewed 2026-11-03; the NIST control and corpus signal data do not cover it yet.

Security teams now hand first-pass triage of samples, alerts and logs to LLM-based assistants. Malware authors have noticed: this technique is planting text aimed at that assistant, such as fake system messages or notes claiming the file is a benign test, so that the automated analyst skips the sample, misreads it or stops early.

SentinelLabs reported in June 2026 on macOS.Gaslight, a DPRK-linked Rust backdoor that embeds 38 fabricated system messages spoofing an LLM triage harness while hiding a credential stealer and Telegram command and control. The target is the defender's automation, not the sandbox.

ATT&CK's definition: Adversaries may use methods like Indirect Prompt Injection to disrupt, disable, or otherwise impair autonomous defensive capabilities such as LLM-assisted processing of malware, artifacts, or activity. This behavior may cause a system to ignore data, fail to alert on malicious activity, abort analysis, or to be disabled completely.

## Detection

MITRE publishes no detection strategy for this technique in ATT&CK v20.0.

Defender notes (library): Scan samples, logs and tickets for natural-language text addressed to a model (role markers, "system:" blocks, instructions to ignore or classify as benign) and treat its presence as a strong malicious indicator in itself. Compare LLM triage verdicts with static, sandbox and reputation results and send disagreements to a person; alert when an automated triage run aborts, times out or returns an empty result on a sample; and protect the configuration of autonomous defensive tooling the way you protect EDR policy.
