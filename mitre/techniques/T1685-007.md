# T1685.007: Impair Autonomous Defenses

<a id="t1685007"></a>

Tactics: defense-impairment  
Platforms: Windows, SaaS  
ATT&CK: [T1685.007](https://attack.mitre.org/techniques/T1685/007)  
Sub-technique of: [T1685: Disable or Modify Tools](/mitre/techniques/T1685.md)  

Adversaries may use methods like Indirect Prompt Injection to disrupt, disable, or otherwise impair autonomous defensive capabilities such as LLM-assisted processing of malware, artifacts, or activity. This behavior may cause a system to ignore data, fail to alert on malicious activity, abort analysis, or to be disabled completely.

## Mitigations (5)

- [M1018: User Account Management](/mitre/mitigations/M1018.md): User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1022: Restrict File and Directory Permissions](/mitre/mitigations/M1022.md): Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1026: Privileged Account Management](/mitre/mitigations/M1026.md): Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1038: Execution Prevention](/mitre/mitigations/M1038.md): Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.
- [M1047: Audit](/mitre/mitigations/M1047.md): Auditing is the process of recording activity and systematically reviewing and analyzing the activity and system configurations.
