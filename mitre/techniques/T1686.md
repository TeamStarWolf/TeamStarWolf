# T1686 — Disable or Modify System Firewall

<a id="t1686"></a>

**Tactics:** defense-impairment  
**Platforms:** ESXi, Linux, macOS, Network Devices, Windows  
**ATT&CK:** [T1686](https://attack.mitre.org/techniques/T1686)  

> **New in ATT&CK v19.2** — supersedes [T1562.004 — Disable or Modify System Firewall](/mitre/techniques/T1562-004.md) (revoked; kept for reference).

Adversaries may disable or modify host-based or network firewalls to impair defensive mechanisms and enable further action. Once an adversary has gathered sufficient privileges, they can tamper with firewall services, policies, or rule sets to remove restrictions on inbound or outbound traffic. For example, this may include turning off firewall profiles, altering existing rules to permit previously blocked ports or protocols, or adding new rules that create covert communication paths (e.g., adding a new firewall rule for a well-known protocol (such as RDP) using a non-traditional and potentially less securitized port. Adversaries may disable or modify firewalls using different behaviors, depending on the platform. For example, in ESXi, firewall rules may be modified directly via the esxcli (e.g., via esxcli network firewall set) or via the vCenter user interface.

## Detection

**Detection strategies:**

- Detection of Disabled or Modified System Firewalls across OS Platforms.

**Analytics (5):**

- **Analytic 0406** (Windows) — `WinEventLog:Security EventCode=4688` → Process Creation; `WinEventLog:Sysmon EventCode=13, 14` → Windows Registry Key Modification
- **Analytic 0407** (Linux) — `auditd:SYSCALL execve: iptables, nft, firewall-cmd modifications` → Command Execution; `linux:osquery execution of known firewall binaries` → Process Creation
- **Analytic 0408** (macOS) — `macos:unifiedlog pfctl -d, socketfilterfw --setglobalstate off, or modifications to com.apple.alf` → Command Execution
- **Analytic 0409** (ESXi) — `esxi:hostd esxcli network firewall set commands` → Command Execution; `esxi:hostd vSphere API calls modifying firewall settings` → Firewall Rule Modification
- **Analytic 0410** (Network Devices) — `networkdevice:cli firewall disable commands or suspicious ACL modifications` → Firewall Rule Modification

- [Dragonfly](/mitre/groups/G0035.md) (aka TEMP.Isotope, DYMALLOY, Berserk Bear, TG-4192) — Dragonfly is a cyber espionage group that has been attributed to Russia's Federal Security Service (FSB) Center 16.
- [FIN7](/mitre/groups/G0046.md) (aka GOLD NIAGARA, ITG14, Carbon Spider, ELBRUS) — FIN7 is a financially-motivated threat group that has been active since 2013.
- [APT38](/mitre/groups/G0082.md) (aka NICKEL GLADSTONE, BeagleBoyz, Bluenoroff, Stardust Chollima) — APT38 is a North Korean state-sponsored threat group that specializes in financial cyber operations; it has been attributed to the Reconnaissance General Bureau.
- [Kimsuky](/mitre/groups/G0094.md) (aka Black Banshee, Velvet Chollima, Emerald Sleet, THALLIUM) — Kimsuky is a North Korea-based cyber espionage group that has been active since at least 2012.
- [Rocke](/mitre/groups/G0106.md) — Rocke is an alleged Chinese-speaking adversary whose primary objective appeared to be cryptojacking, or stealing victim system resources for the purposes of mining cryptocurrency.
