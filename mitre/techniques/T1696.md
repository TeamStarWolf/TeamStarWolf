# T1696: Anti-Automation Evasion

<a id="t1696"></a>

Tactics: stealth  
Platforms: SaaS  
ATT&CK: [T1696](https://attack.mitre.org/techniques/T1696)  

> New in ATT&CK v20.0. MITRE added this technique in the current release; the library's own enrichment (NIST controls, CAPEC, detections, corpus signal) may not cover it yet.

Adversaries may employ various means to evade or complete automation checks. Automation checks distinguish human users from bot traffic and prevent bots from reaching the web pages protected by automation checks.

## Mitigations (2)

- [M1031: Network Intrusion Prevention](/mitre/mitigations/M1031.md): Use intrusion detection signatures to block traffic at network boundaries.
- [M1037: Filter Network Traffic](/mitre/mitigations/M1037.md): Employ network appliances and endpoint software to filter ingress, egress, and lateral network traffic.
