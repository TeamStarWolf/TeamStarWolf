# T1698: Indirect Prompt Injection

<a id="t1698"></a>

Tactics: execution  
Platforms: Windows, SaaS  
ATT&CK: [T1698](https://attack.mitre.org/techniques/T1698)  

> New in ATT&CK v20.0. MITRE added this technique in the current release. The overview, defender notes, references and related ATLAS techniques on this page are the library's own, last reviewed 2026-11-03; the NIST control and corpus signal data do not cover it yet.

When a copilot or agent reads a web page, an email, a ticket or a pull request on someone's behalf, whoever wrote that content gets a say in what the model does next. Indirect prompt injection hides instructions in that content, often in text a person will not notice (HTML comments, white-on-white text, alt text, metadata), and waits for an AI system to retrieve it.

Unit 42 reported web-based indirect prompt injection aimed at AI agents in the wild in March 2026, and Snyk's "Clinejection" write-up describes an AI bot in a GitHub Actions workflow being steered into a supply-chain attack. The attacker never touches the model directly; the agent's own reading does the delivery.

ATT&CK's definition: Adversaries may deliver malicious prompts to an LLM indirectly by embedding the prompts in content that the adversary expects may be processed by an LLM. These prompts can be included in web pages, documents, emails, tickets, code, or other sources that an agent, copilot, or other AI system may retrieve and process.

## Detection

MITRE publishes no detection strategy for this technique in ATT&CK v20.0.

Defender notes (library): Keep a log that ties each agent action to the content it had just retrieved: the prompt, the retrieved documents or URLs, and every tool call with its arguments. Alert when a tool call (sending mail, changing code, calling an external URL) follows retrieval of outside content and was not part of the user's request; scan inbound email, tickets, issues and shared documents for instruction-like text aimed at a model, including hidden or zero-width text; and treat unexpected agent writes to repositories or CI settings as an incident until shown otherwise.
