# T1699: Direct Prompt Injection

<a id="t1699"></a>

Tactics: execution  
Platforms: Windows, SaaS  
ATT&CK: [T1699](https://attack.mitre.org/techniques/T1699)  

Adversaries may input malicious prompts directly into an LLM’s user interface. The prompts can be designed to bypass safeguards, manipulate context, override previous instructions, or coerce the LLM into unauthorized behavior.

## Mitigations (4)

- [M1017: User Training](/mitre/mitigations/M1017.md): User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1018: User Account Management](/mitre/mitigations/M1018.md): User Account Management involves implementing and enforcing policies for the lifecycle of user accounts, including creation, modification, and deactivation.
- [M1026: Privileged Account Management](/mitre/mitigations/M1026.md): Privileged Account Management focuses on implementing policies, controls, and tools to securely manage privileged accounts (e.g., SYSTEM, root, or administrative accounts).
- [M1038: Execution Prevention](/mitre/mitigations/M1038.md): Prevent the execution of unauthorized or malicious code on systems by implementing application control, script blocking, and other execution prevention mechanisms.
