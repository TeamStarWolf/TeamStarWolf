# T1700: AI-Enabled Exfiltration

<a id="t1700"></a>

Tactics: exfiltration  
Platforms: Windows, SaaS  
ATT&CK: [T1700](https://attack.mitre.org/techniques/T1700)  

> New in ATT&CK v20.0. MITRE added this technique in the current release; the library's own enrichment (NIST controls, CAPEC, detections, corpus signal) may not cover it yet.

Adversaries may utilize Direct Prompt Injection, Indirect Prompt Injection or other methods to instruct enterprise AI agents to exfiltrate data. When enterprise systems incorporate the use of AI assistants or other AI agents, adversaries may abuse these systems to weaponize sanctioned tools available to the agent.

## Mitigations (3)

- [M1017: User Training](/mitre/mitigations/M1017.md): User Training involves educating employees and contractors on recognizing, reporting, and preventing cyber threats that rely on human interaction, such as phishing, social engineering, and other manipulative techniques.
- [M1022: Restrict File and Directory Permissions](/mitre/mitigations/M1022.md): Restricting file and directory permissions involves setting access controls at the file system level to limit which users, groups, or processes can read, write, or execute files.
- [M1048: Application Isolation and Sandboxing](/mitre/mitigations/M1048.md): Application Isolation and Sandboxing refers to the technique of restricting the execution of code to a controlled and isolated environment (e.g., a virtual environment, container, or sandbox).

## Detection

Detection strategies:

- Detect AI-Enabled Exfiltration

Analytics (3):

- Analytic 2078 (SaaS): `saas:audit Actual send/share/upload/write operation` -> Application Log Content; `AWS:bedrock AgentTrace.actionGroupInvocationInput` -> Application Log Content; `AWS:bedrock AgentTrace.knowledgeBaseLookupInput` -> Application Log Content
- Analytic 2079 (Windows): `WinEventLog:Security EventCode=4663, 4670, 4656` -> File Access; `WinEventLog:PowerShell EventCode=4103, 4104, 4105, 4106` -> Script Execution; `WinEventLog:Sysmon EventCode=1` -> Process Creation
- Analytic 2080 (Linux): `auditd:SYSCALL open/read` -> File Access; `auditd:SYSCALL EXECVE` -> Process Creation; `auditd:SYSCALL connect` -> Network Connection Creation
